# BioMate: Long-Term Memory Architecture
## User & Project Context Persistence

**Document Created:** 2025-10-31
**Status:** Production Architecture
**Philosophy:** Remember everything, retrieve intelligently

---

## Overview

BioMate needs to remember:
1. **User Context**: Who you are, what you know, how you work
2. **Project Context**: What you're working on, across multiple sessions
3. **Learned Preferences**: What tools/approaches work for you
4. **Conversation History**: Compressed summaries for context continuity
5. **Research Knowledge**: Domain-specific insights per project

---

## Storage Architecture

### Hybrid Storage Strategy

```
┌─────────────────────────────────────────────────────────┐
│           FAST ACCESS (PostgreSQL)                      │
│  - User profiles (preferences, expertise)               │
│  - Active project metadata                              │
│  - Recent conversation summaries (last 30 days)         │
│  - Tool usage statistics                                │
│  - ACE playbook rules                                   │
└─────────────────────────────────────────────────────────┘
                        ↕
┌─────────────────────────────────────────────────────────┐
│       LONG-TERM STORAGE (File System + S3)              │
│  - Complete conversation transcripts (.md files)        │
│  - Project documentation (auto-generated)               │
│  - Workflow history (execution logs, results)           │
│  - Dataset metadata cache                               │
│  - User-specific knowledge bases                        │
└─────────────────────────────────────────────────────────┘
                        ↕
┌─────────────────────────────────────────────────────────┐
│            SEARCH INDEX (Elasticsearch)                 │
│  - Full-text search across conversations               │
│  - Semantic search for similar projects                │
│  - Tool and workflow pattern matching                  │
└─────────────────────────────────────────────────────────┘
```

**Why Hybrid?**
- **PostgreSQL**: Fast queries for active data, transactional
- **File System/S3**: Cost-effective for archives, human-readable (markdown)
- **Elasticsearch**: Powerful search across historical data

## Memory Retrieval Strategy

### When User Starts New Session

```typescript
async function loadUserContext(userId: string): Promise<UserContext> {
  // 1. Load user profile from PostgreSQL
  const user = await db.query(`
    SELECT * FROM users WHERE id = $1
  `, [userId]);

  // 2. Load active projects
  const projects = await db.query(`
    SELECT * FROM projects
    WHERE user_id = $1 AND status = 'active'
    ORDER BY updated_at DESC
  `, [userId]);

  // 3. Load recent preferences
  const preferences = await db.query(`
    SELECT * FROM user_preferences
    WHERE user_id = $1
    ORDER BY last_used DESC
    LIMIT 100
  `, [userId]);

  // 4. Load recent corrections
  const corrections = await db.query(`
    SELECT * FROM correction_log
    WHERE user_id = $1
    ORDER BY created_at DESC
    LIMIT 20
  `, [userId]);

  // 5. Load most recent session summary
  const lastSession = await db.query(`
    SELECT summary, key_decisions, tools_discussed
    FROM sessions
    WHERE user_id = $1 AND ended_at IS NOT NULL
    ORDER BY ended_at DESC
    LIMIT 1
  `, [userId]);

  return {
    profile: user,
    activeProjects: projects,
    preferences: preferences,
    recentCorrections: corrections,
    lastSession: lastSession
  };
}
```

### When User Selects Project

```typescript
async function loadProjectContext(projectId: string): Promise<ProjectContext> {
  // 1. Load project metadata from PostgreSQL
  const project = await db.query(`
    SELECT * FROM projects WHERE id = $1
  `, [projectId]);

  // 2. Load project knowledge base from file
  const knowledgeBasePath = `/storage/projects/${project.user_id}/${projectId}/knowledge_base.md`;
  const knowledgeBase = await fs.readFile(knowledgeBasePath, 'utf-8');

  // 3. Load recent workflows
  const workflows = await db.query(`
    SELECT * FROM workflows
    WHERE project_id = $1
    ORDER BY created_at DESC
    LIMIT 10
  `, [projectId]);

  // 4. Load project-specific knowledge
  const knowledge = await db.query(`
    SELECT * FROM project_knowledge
    WHERE project_id = $1
    ORDER BY relevance_score DESC
  `, [projectId]);

  return {
    project: project,
    knowledgeBase: knowledgeBase,
    recentWorkflows: workflows,
    technicalNotes: knowledge.filter(k => k.knowledge_type === 'technical_note'),
    keyFindings: knowledge.filter(k => k.knowledge_type === 'key_finding')
  };
}
```

```typescript
async function saveSessionMemory(sessionId: string): Promise<void> {
  const session = await getSession(sessionId);

  // 1. Generate session summary using Claude
  const summary = await claudeClient.messages.create({
    model: 'claude-3-haiku-20240307',
    max_tokens: 1000,
    messages: [{
      role: 'user',
      content: `Summarize this research session:

Conversation messages: ${JSON.stringify(session.messages)}

Focus on:
- What the user was trying to accomplish
- Key decisions made
- Tools selected and why
- Any issues encountered
- Next steps discussed

Format as markdown.`
    }]
  });

  // 2. Extract key decisions
  const decisions = extractKeyDecisions(session.messages);

  // 3. Save to PostgreSQL
  await db.query(`
    UPDATE sessions
    SET
      ended_at = NOW(),
      duration_seconds = EXTRACT(EPOCH FROM (NOW() - started_at)),
      summary = $1,
      key_decisions = $2,
      tools_discussed = $3,
      message_count = $4
    WHERE id = $5
  `, [
    summary.content[0].text,
    JSON.stringify(decisions),
    session.toolsUsed,
    session.messages.length,
    sessionId
  ]);

  // 4. Save full transcript to file
  const transcriptPath = `/storage/projects/${session.userId}/${session.projectId}/sessions/${sessionId}/transcript.md`;
  await saveTranscriptAsMarkdown(session, transcriptPath);

  // 5. Update project knowledge base
  await updateProjectKnowledge(session.projectId, decisions);
}
```

## Search and Retrieval

### Full-Text Search Across Conversations

```typescript
async function searchConversations(
  userId: string,
  query: string
): Promise<SearchResults> {
  // Search in Elasticsearch index
  const results = await elasticsearch.search({
    index: 'conversations',
    body: {
      query: {
        bool: {
          must: [
            { term: { user_id: userId } },
            { multi_match: {
                query: query,
                fields: ['content', 'summary', 'key_decisions']
              }
            }
          ]
        }
      },
      highlight: {
        fields: {
          content: {},
          summary: {}
        }
      },
      sort: [{ created_at: 'desc' }],
      size: 20
    }
  });

  return results.hits.hits.map(hit => ({
    sessionId: hit._source.session_id,
    projectId: hit._source.project_id,
    date: hit._source.created_at,
    excerpt: hit.highlight.content || hit.highlight.summary,
    relevance: hit._score
  }));
}
```

### Find Similar Past Workflows

```typescript
async function findSimilarWorkflows(
  userId: string,
  currentWorkflowContext: WorkflowContext
): Promise<Workflow[]> {
  // Find workflows with similar domain, data type, and goal
  const similar = await db.query(`
    SELECT w.*,
           (
             CASE WHEN w.domain = $2 THEN 3 ELSE 0 END +
             CASE WHEN w.data_type = $3 THEN 2 ELSE 0 END +
             similarity(w.analysis_goal, $4)
           ) AS relevance_score
    FROM workflows w
    WHERE w.user_id = $1
      AND w.success = true
    ORDER BY relevance_score DESC
    LIMIT 5
  `, [
    userId,
    currentWorkflowContext.domain,
    currentWorkflowContext.dataType,
    currentWorkflowContext.goal
  ]);

  return similar.rows;
}
```

### Data Retention Policy

```yaml
Active Data (PostgreSQL):
  - User profiles: Lifetime
  - Active projects: Lifetime
  - Recent sessions (30 days): Full detail
  - Older sessions (30-365 days): Summary only
  - Ancient sessions (>365 days): Archived to S3

File Storage:
  - Session transcripts: 2 years
  - Workflow definitions: 5 years
  - Project documentation: 5 years
  - Archived projects: 10 years (then user confirmation)

Deletion:
  - User requests deletion: 30-day grace period
  - Inactive users (>2 years): Email notification, then archive
  - GDPR compliance: Export all data on request
```

```typescript
  if (profile.activeProjects.length > 0) {
    const currentProject = profile.activeProjects[0];
    const projectContext = await loadProjectContext(currentProject.id);

    profile.currentProjectContext = {
      name: currentProject.name,
      goal: currentProject.research_goal,
      domain: currentProject.primary_domain,
      recentFindings: projectContext.keyFindings.slice(0, 5),
      technicalNotes: projectContext.technicalNotes.slice(0, 5)
    };
  }

  // Add recent conversation context
  if (profile.lastSession) {
    profile.conversationContext = {
      summary: profile.lastSession.summary,
      keyDecisions: profile.lastSession.key_decisions,
      whereWeLeftOff: extractLastTopic(profile.lastSession)
    };
  }

  return profile;
}
```
