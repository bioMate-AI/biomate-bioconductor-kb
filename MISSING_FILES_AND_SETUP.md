## New Machine Setup Instructions

### Prerequisites
- Python 3.9+
- Node.js 16+
- Git (with Git LFS if using Option 1)

### Step 1: Clone Repository
```bash
git clone https://github.com/bioMate-AI/biomate.git
cd biomate
```

### Step 2: Backend Setup

```bash
cd backend

# Create Python virtual environment
python3 -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Download database files (if using cloud storage)
./download_databases.sh

# Create config from template
cp config/galaxy.yml.template config/galaxy.yml

# Set API keys via environment or edit galaxy.yml
export ANTHROPIC_API_KEY="your-key-here"
export OPENAI_API_KEY="your-backup-key-here"

# Start Galaxy backend
./run.sh
```

### Step 3: Frontend Setup

```bash
cd ../frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

### Step 4: Verify Setup

```bash
# Check backend
curl http://localhost:8080/api/version

# Check frontend
curl http://localhost:5173

# Test workflow generation
# Navigate to http://localhost:5173 in browser
```

### 5. Create Setup Script
**File:** `setup.sh`
```bash
#!/bin/bash
set -e

echo "BioMate Setup Script"
echo "===================="

# Check prerequisites
command -v python3 >/dev/null 2>&1 || { echo "Python 3 required"; exit 1; }
command -v node >/dev/null 2>&1 || { echo "Node.js required"; exit 1; }

# Setup backend
echo "Setting up backend..."
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Check for database files
if [ ! -f "galaxy_ai_tools.db" ]; then
    echo "ERROR: galaxy_ai_tools.db not found!"
    echo "Please download it or run the database generation script"
    exit 1
fi

# Setup config
if [ ! -f "config/galaxy.yml" ]; then
    echo "Creating config from template..."
    cp config/galaxy.yml.template config/galaxy.yml
    echo "Please edit config/galaxy.yml and add your API keys"
fi

# Setup frontend
echo "Setting up frontend..."
cd ../frontend
npm install

echo "Setup complete!"
echo "1. Edit backend/config/galaxy.yml with your API keys"
echo "2. Run: cd backend && ./run.sh"
echo "3. Run: cd frontend && npm run dev"
```
