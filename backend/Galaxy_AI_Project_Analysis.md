# Galaxy AI 助手项目改动详细分析报告

## 总体概述

Galaxy 项目在最新改动中新增了完整的 AI 助手功能，将传统的生物信息学分析平台升级为智能化的研究助理。通过集成大语言模型（LLM）技术和 RAG（检索增强生成）系统，为用户提供自然语言交互的工作流生成和分析建议服务。

## 核心改动分析

### 1. AI 助手核心架构

#### 新增文件：
- **`lib/galaxy/ai/ai_assistant.py`** - 主要的 AI 助手协调器，整合所有 AI 组件
- **`lib/galaxy/ai/enhanced_workflow_generator.py`** - 增强的工作流生成器
- **`lib/galaxy/ai/galaxy_tool_rag.py`** - 基于 RAG 的工具发现系统
- **`lib/galaxy/ai/workflow_templates.py`** - 人工验证的工作流模板库

#### 架构特点：
- 采用模块化设计，各组件职责清晰分离
- 集成意图解析、任务分解、工具推荐、工作流生成等多个 AI 功能
- 支持多种生成策略：模板基础、RAG 辅助、混合模式
- 提供完整的错误处理和容错机制

### 2. 前端集成

#### 修改文件：
- **`client/src/components/AI/AIAssistantPanel.vue`** - 全新的 AI 助手面板组件

#### 功能特性：
- **悬浮式 AI 助手面板**，用户体验友好
- **自然语言对话交互**，支持实时消息处理
- **快捷操作按钮**：
  - RNA-seq 分析
  - 变异检测
  - 基因组组装
  - 质量控制
- **实时状态显示**和消息通知
- **响应式设计**，支持移动端适配

### 3. API 服务层

#### 修改文件：
- **`lib/galaxy/webapps/galaxy/api/ai_assistant.py`** - RESTful API 端点

#### API 端点：
| 端点 | 功能 | 描述 |
|------|------|------|
| `/api/ai_assistant/status` | 状态检查 | 获取 AI 助手运行状态和配置信息 |
| `/api/ai_assistant/process_request` | 请求处理 | 处理用户的自然语言分析请求 |
| `/api/ai_assistant/create_workflow` | 工作流创建 | 基于 AI 生成的模板创建 Galaxy 工作流 |
| `/api/ai_assistant/get_workflow_recommendations` | 工作流推荐 | 获取多个工作流选项和建议 |

### 4. 工作流生成系统

#### 三层生成策略：

##### 1. 模板基础（Template-based）
- 使用人工验证的高质量模板
- 包含 RNA-seq 差异表达、变异检测、基因组组装等常用分析
- **置信度最高**，适用于标准化分析
- 模板经过生物信息学专家验证，确保科学性

##### 2. RAG 辅助（RAG-assisted）
- 动态发现和组合 Galaxy 工具
- 基于工具描述和功能进行智能匹配
- 适用于定制化分析需求
- 支持复杂的工具组合和参数优化

##### 3. 混合模式（Hybrid）
- 结合模板和 RAG 的优势
- 以模板为基础，用 RAG 发现的工具进行增强
- 平衡标准化和灵活性
- 提供最佳的分析质量和适应性

#### 预置工作流模板：

##### RNA-seq 差异表达分析流程
```
FastQC (质量评估) 
    ↓
Cutadapt (序列修剪) 
    ↓
HISAT2 (参考基因组比对) 
    ↓
featureCounts (基因计数) 
    ↓
DESeq2 (差异表达分析)
```

##### 变异检测流程
```
FastQC (质量评估) 
    ↓
BWA-MEM (序列比对) 
    ↓
Picard MarkDuplicates (去重) 
    ↓
FreeBayes (变异检测) 
    ↓
VCFfilter (变异过滤)
```

##### 基因组组装流程
```
NanoPlot (长读长数据统计) 
    ↓
Filtlong (读长过滤) 
    ↓
Flye (基因组组装) 
    ↓
Medaka (组装结果抛光) 
    ↓
QUAST (组装质量评估)
```

### 5. 工具发现和推荐系统

#### RAG 系统特点：
- **实时集成**：与 Galaxy 工具库实时同步
- **智能分类**：按功能自动分类工具
  - 质量控制（quality_control）
  - 序列比对（alignment）  
  - 基因组组装（assembly）
  - 变异检测（variant_calling）
  - RNA-seq 分析（rna_seq）
  - 序列注释（annotation）
- **兼容性匹配**：自动检查数据类型兼容性
- **流水线建议**：提供完整的分析流程建议

#### 工具索引和搜索算法：
- **多维度评分**：基于名称匹配、描述相关性、分类匹配等
- **数据类型兼容性检查**：确保工具间数据流通畅
- **智能替代**：当首选工具不可用时自动寻找替代方案
