### 2. Frontend: Standardize Source Detection

**File**: `frontend/server/routes.ts`

**Create helper function** at top of file:
```typescript
/**
 * Determine workflow execution engine based on workflow definition
 */
function getWorkflowExecutionEngine(workflowDef: any): 'galaxy' | 'nextflow' {
  const tags = workflowDef?.tags || [];
  const metadata = workflowDef?.metadata || {};

  // Check for explicit Galaxy reuse markers
  const isGalaxyReuse =
    tags.includes('galaxy-reuse') ||
    tags.includes('galaxy-import') ||
    metadata.source === 'galaxy_reuse' ||
    workflowDef?.isGalaxyWorkflow === true;

  if (isGalaxyReuse) {
    return 'galaxy';
  }

  // Check for Nextflow markers
  const isNextflow =
    tags.includes('nextflow') ||
    tags.includes('native-execution') ||
    metadata.source === 'nextflow';

  if (isNextflow) {
    return 'nextflow';
  }

  // Default to Nextflow (as per integration plan)
  return 'nextflow';
}
```

**Replace existing detection logic** (line 3915-3925) with:

**Replace detection at line 3445** with:

**Replace detection at line 4131** with:

### 3. Standardized Tag Definitions

**Tag Schema**:

| Tag | Meaning | Set By | Used For |
|-----|---------|--------|----------|
| `nextflow` | Workflow runs on Nextflow engine | Backend workflow generation | Execution engine selection |
| `galaxy-reuse` | Workflow reuses existing Galaxy template | Backend template reuse | Execution engine selection |
| `ai-generated` | Workflow was generated by AI | Backend all paths | Audit/tracking |
| `native-execution` | Legacy Nextflow marker | Legacy code | Backward compatibility |

### 4. Metadata Schema

**workflow_ga.metadata** should include:
```typescript
{
  source: 'template_reuse' | 'template_adapt' | 'tool_constrained',
  execution_engine: 'galaxy' | 'nextflow',
  confidence: number,
  generated_at: string (ISO timestamp),
  generator_version: string
}
```
