## Test Suite A — Drug Discovery QC Gates (Highest Priority)

These are the newest gates and most important to verify end-to-end.

### A1. hERG Cardiotoxicity Blocking Gate

**Intent:** ADMET_pred workflow with a known hERG blocker should produce a GOLD blocking gate.

**Steps:**
1. Start a new chat
2. Ask: *"Run ADMET safety screening for terfenadine, SMILES: OC(CCCN1CCC(CC1)C(O)(c1ccccc1)c1ccccc1)(c1ccc(cc1)C(C)(C)C)CC"*
3. Execute the suggested workflow
4. Wait for QC gate modal

**Expected:**
- Modal title: **"ADMET Safety Screening"** (not "ADMET_PRED")
- Failure listed: hERG IC50 ≈ 0.20 μM (< 1 μM threshold)
- DILI risk listed as HIGH
- Ames mutagenicity listed as advisory
- "Proceed Anyway" button requires a second click to confirm
- Troubleshooting guide mentions structural modification, logP reduction, scaffold hopping

**Pass criteria:** All 4 gate items visible; Proceed Anyway is two-click; process name is human-readable.

## Test Suite B — Core QC Gate UX

### B1. Process Name Humanisation

Run any workflow that hits a QC gate (cryo-EM motion correction, RNA-seq alignment, etc.)

**Check:** Modal title should show human-readable name from this table:

| Process name (in logs) | Expected modal title |
|---|---|
| MOTION_CORRECTION | "Motion Correction" |
| CTF_ESTIMATION | "CTF Estimation" |
| STAR_ALIGN | "Read Alignment (STAR)" |
| FASTP | "Read Trimming (FASTP)" |
| CELLRANGER_COUNT | "Single-Cell Processing (Cell Ranger)" |
| KRAKEN2 | "Taxonomic Classification (Kraken2)" |
| ADMET_PRED | "ADMET Safety Screening" |
| NCA_PKNCA | "Non-Compartmental Analysis (PKNCA)" |
| NLMIXR2_POPULATION_PK | "Population PK Modelling (nlmixr2)" |
| IVIVE | "IVIVE Hepatic Clearance" |

**Fail criteria:** Any gate modal shows a raw process name like "NLMIXR2_POPULATION_PK".

---

### B2. Proceed Anyway — Two-Click Confirmation

1. Trigger any blocking gate
2. Click "Proceed Anyway" once
3. **Expected:** Button changes to "Confirm Proceed" + audit note text appears
4. Click "Confirm Proceed"
5. **Expected:** Workflow continues

**Fail criteria:** Workflow proceeds on the first "Proceed Anyway" click.

---

### B3. Retry Counter

1. Trigger a QC gate and click Retry
2. Adjust the suggested parameter
3. The same process hits the gate again

**Expected:** Modal title shows **"Quality Control Gate Triggered (Retry #1)"**

---

### B4. Before/After Diff Panel

On the second gate trigger (after one retry):

**Expected:** A diff panel shows "vs. previous attempt:" with metric values and delta (green if improved, red if worse).

### B5. SSE Reconnection Banner

1. Start a workflow
2. While it is running, restart the backend (`kill <gunicorn pid>` then restart)
3. Watch the workflow artifact panel

**Expected:**
- A yellow banner appears: "Live updates paused — reconnecting..."
- Once backend is back, the banner disappears
- If reconnection fails after ~30s: "Live updates unavailable. [Retry]" link appears

## Test Suite C — Named QC Profiles

These test that selecting a named profile at workflow launch actually relaxes or tightens gates.

### C1. rnaseq_ribodepleted — Relaxed Alignment

1. Start an RNA-seq workflow with alignment expected ~60%
2. Run **without** a profile → gate fires at 60% < 70%
3. Run the same workflow **with profile = rnaseq_ribodepleted** → gate should NOT fire (threshold 50%)

**Where to set profile:** Look for a QC profile selector in the workflow settings / launch dialog.

---

### C2. wgs_germline_lowpass — 4× Coverage Threshold

1. Run a WGS coverage workflow expecting ~10× coverage
2. Without profile → gate fires (< 30× default)
3. With profile = wgs_germline_lowpass → no gate (threshold 4×)

---

### C3. scrna_cardiac — 30% Mito Permissive

1. Run a CellRanger scRNA-seq workflow with mito_fraction_pct = 25%
2. Without profile → gate fires (> 20% default)
3. With profile = scrna_cardiac → no gate (threshold 40%)

---

### C4. metagenomics_soil — Dark Matter Expected

1. Run Kraken2 classification expecting ~40% classified
2. Without profile → advisory/warning event fires (< 60% default warning)
3. With profile = metagenomics_soil → no event (threshold 8%)
