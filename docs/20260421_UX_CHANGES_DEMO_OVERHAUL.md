## 4. CRO demo page — proper scroll layout

**File:** `frontend/client/src/pages/drug-discovery-cro-demo.tsx`

Changed from `min-h-screen` + browser body scroll to a self-contained `flex flex-col` layout:

```tsx
// Before
<div className="min-h-screen bg-background">
  <div className="sticky top-0 z-10 ...">header</div>
  <div className="max-w-5xl ...">content</div>
</div>

// After
<div className="flex flex-col bg-background" style={{ height: 'calc(100vh - 64px)' }}>
  <div className="shrink-0 border-b ...">header</div>         {/* fixed */}
  <div className="shrink-0 ...">campaign banner</div>          {/* fixed */}
  <div className="flex-1 overflow-y-auto">                     {/* scrollable */}
    <div className="max-w-5xl mx-auto px-4 py-6">
      <DrugDiscoveryAction ... />
    </div>
  </div>
</div>
```

`64px` = SiteHeader `h-16` height. The validation table, audit log, IND form, etc. all scroll within the page. Also fixed a pre-existing TypeScript error (`endpoint: null` was missing from `DrugDiscoveryAction` props).

## 7. Tutorial tip overlay system

**Files:**
- `frontend/client/src/components/tutorial-tip-overlay.tsx` (new)
- `frontend/client/src/App.tsx` (added `<TutorialTipOverlay />`)

A global `window.__biomate_tip(text: string, durationMs?: number)` function is registered on mount. Calling it shows an animated blue callout bubble at the bottom-left of every page.

```typescript
// Usage from Playwright demo scripts:
await page.evaluate(({ t, d }) => {
  (window as any).__biomate_tip?.(t, d);
}, { t: 'BioMate identified the workflow automatically', d: 4000 });

// Or via the tip() helper in demo-helpers.ts:
await tip(page, 'Submitting to AWS Batch…', 3500);
```

Bubbles animate in with `slide-in-from-bottom-2 fade-in` and auto-dismiss after the specified duration. They are `pointer-events-none` so they never block clicks.

## 8. Demo scripts — comprehensive tutorial traversal

**Files:** `frontend/e2e/demo-01-drug-discovery.demo.ts`, `demo-02-genomics-wgs.demo.ts`, `demo-04-pkpd-modeling.demo.ts`, `demo-06-cro-compliance.demo.ts`

All demo scripts now:
- Call `tip()` at every key moment to narrate what's happening on screen
- Call `exploreTutorial(page, tipFn)` after each workflow completion, which:
  1. Iterates up to 6 phase cards, opens params panel and previews first output file per step
  2. Clicks "View Results" and pauses
  3. Clicks "Analyze Results" and waits for AI findings
  4. Hovers "Download Methods Report" with explanation tip
  5. Hovers "Download All" with explanation tip
- Add longer pauses so viewers can read each screen

### New helpers in `demo-helpers.ts`

```typescript
// Show a tutorial tip bubble
tip(page, text, durationMs?)

// Walk through all result sections after a workflow completes
exploreTutorial(page, tipFn)

// waitForNoActiveRuns — updated to poll phase cards (no longer uses removed status bar)
waitForNoActiveRuns(page, timeoutMs?)
```

## 9. run-demos.sh improvements

**File:** `frontend/e2e/run-demos.sh`

- Removed `set -e` (replaced with `set -uo pipefail`) so a stale artifact `rm -rf` failure doesn't abort the whole run
- `rm -rf e2e/demo-artifacts` now uses `2>/dev/null || true` — fails silently
- Added `sleep 1` before each demo and `sleep 2` after for Playwright finalization
- Removed unreliable GStreamer VP9 compression block
- Default demos changed from `01 02 04 05` → `01 02 04 05 06`
- Supports `DEMO_OUTPUT_DIR` env var override for video output directory
