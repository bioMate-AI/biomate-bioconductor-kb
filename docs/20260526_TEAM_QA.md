## Bug-filing flow

1. **Triage severity** using the SEV tables in `connectors/test-docs/oauth_security.md` (security) or by impact (functional).
2. **File on GitHub** with one of these labels:
   - `connectors/oauth` — OAuth server or installer
   - `connectors/mcp` — MCP server, tool manifest, drift
   - `connectors/<surface>` — surface-specific (slack, chatgpt, etc.)
   - `audit/p0`, `audit/p1` — from the audit reports
   - `pre-launch-blocker` — must fix before public push
3. **Reproducer**: paste the exact command + expected vs actual. The test-docs have "When it fails" tables that often already cover the case.
