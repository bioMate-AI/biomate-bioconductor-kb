## Application path

For each accepted proposal, update `workflow_chains.steps[].workflow_name` from placeholder → proposed catalog name. This makes the curated chains actually executable end-to-end.

```python
# Pseudo-code, NOT executed by this script:
import json, sqlite3
proposals = [json.loads(l) for l in open("docs/.../GROUNDING_PROPOSAL.jsonl")]
accepted = [p for p in proposals if p['confidence'] >= 0.7 and p['proposed_workflow']]
conn = sqlite3.connect('backend/database/galaxy_ai_tools.db')
for chain_name, steps_json in conn.execute('SELECT name, steps FROM workflow_chains'):
    steps = json.loads(steps_json or '[]')
    changed = False
    for s in steps:
        for p in accepted:
            if s.get('workflow_name') == p['name']:
                s['workflow_name'] = p['proposed_workflow']
                changed = True
    if changed:
        conn.execute('UPDATE workflow_chains SET steps=? WHERE name=?',
                     (json.dumps(steps), chain_name))
conn.commit()
```
