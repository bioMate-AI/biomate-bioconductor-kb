LLM pricing basis: Claude Sonnet API at $3/M input + $15/M output tokens; blended ~$10/M for Claude Science full-orchestration sessions. BioMate LLM cost reflects routing + parameter extraction only (~15–45k tokens per use case).

Claude Science token estimates: Derived from reported $50 spend per 2-tool project by a student user; ~2.5M tokens/tool × tool count per use case. Claude Science runs locally — compute cost is $0 but requires a capable workstation with CUDA for GPU tools.

BioMate compute cost: AWS Batch (spot pricing). CPU workflows: ~$0.08/vCPU-hr. GPU workflows: ~$0.90/hr p3.2xlarge spot. BioNeMo API calls billed per call at NVIDIA NVCF pricing (~$0.50–1.50/call for structure prediction).

Wall clock: BioMate times include AWS Batch queue + execution. Claude Science times include LLM round-trips for tool installation, error handling, and output interpretation per step. No retry failures included in either estimate.

Tool installation overhead: BioMate uses pre-built ECR containers; zero install time. Claude Science installs tools under LLM orchestration — each tool requires 3–8 LLM round-trips for dependency resolution, environment setup, and config generation.
