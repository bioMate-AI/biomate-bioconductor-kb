# Mohan Cohort Papers — Data Access Tier Classification

Generated 2026-09-14. Question answered per paper: is the underlying **per-sample data** (i) PUBLIC-DEPOSITED (repository + accession, downloadable now), (ii) ON-REQUEST (available from authors on reasonable request), or (iii) CONTROLLED (consortium / dbGaP / EGA, application required)? Publication status is not the question — every paper is published.

Tier legend: **PUBLIC-DEPOSITED** = open repository, download now · **ON-REQUEST** = author gatekeeps, email required · **CONTROLLED** = dbGaP/EGA/consortium, formal data-access application · **not-located** = no statement found (with search notes).

## Notes on the multi-omic / consortium papers
- **34783463 & 32396533** (IL-16, IFN-γ): clinical/serological data are openly downloadable from **ImmPort SDY997** (registration only), but the **raw single-cell RNA-seq is in dbGaP phs001457 — CONTROLLED** (data-access application required). Split tier: proteomics/clinical = public/on-request via ImmPort; scRNA = controlled.
- **38899167 & 40672966** (PRECISESADS): consortium-owned, GDPR-protected; nominal EGA deposit (accession not quoted in text) plus author gatekeeping → effectively **CONTROLLED** (EGA application) or on-request.
- **36996699** (PRECISESADS SLE): its **primary** data is the same PRECISESADS/EGA consortium regime; **GSE88887** cited in the abstract is only an *independent validation* set — that GEO series (ILLUMINATE/tabalumab trial, Hoffman et al., public since 2016) is public but was **not generated by this study**.
