# AI 制药平台需求 · BioMate 能力映射与差距（Capability Map & Gap）

**Date:** 2026-09-09 · **内部文档**（可含技术栈；对外文档不披露）
**用途:** 对照广州医**"AI 制药——药物分子生成与优化"平台需求（¥7000 万），逐项映射 BioMate 现有能力与差距，支撑是否/如何响应的决策。

**图例:** ✅ 已具备(有真实工作流/已测) · 🟡 部分(有框架/槽位，需补强或产品化) · ❌ 差距(需新建) · 置信度: 高/中(标注需二次核实处)

---

## 头条结论

需求主体是**第③生成层 + 第④优化层**（生成 → 活性预测 → 成药性/亲和性/安全性多目标优化 → 计算闭环）——**这正是 BioMate 的强项，绝大部分已具备**（docking / QSAR / RBFE-FEP / ADMET 自动闭环 / GP-Pareto 多目标优化，~215 个真实药物研发工作流）。

**真正的差距(也是差异化机会)集中在三处:**
1. **产品化的 de novo 生成器**——生成"槽位"在，需接入训练好的生成模型（🟡）。
2. **闭环的湿实验 DBTL 回路**——19 工具 MCP + 10 个仪器连接器已建，但"设计-合成-测试-分析"闭环尚未打通（🟡/❌，**第一诚实差距**）。
3. **专利/FTO 检索**与**非小分子模态(PROTAC 等)的产品化**（🟡/❌）。

## 一句话定位

**需求的 80% 落在 BioMate 已具备的③④层**——响应这单，我们不是"从零建平台"，而是"把已验证的生成-优化-安全闭环产品化 + 补三块差距(生成器产品化、湿实验 DBTL 闭环、专利/FTO)"。**湿实验闭环恰是我们相对"只做一个生成模型"的机构的差异化主张，也是最该在方案里主打、并向客户澄清其边界的一环。**
