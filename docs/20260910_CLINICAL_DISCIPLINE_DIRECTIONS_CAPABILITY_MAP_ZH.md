## 头条结论

四个方向里，**方向（三）"医学大数据+AI"与方向（一）"神经/精神"是我们最强的两个切入点**——且二者叠加正是 BioMate 创始团队**同行评审发表记录所在的核心域**（AD 进展预后 iScience 2024、生物标志物面板 npj Mental Health 2023、可解释跨站点可复现 ML Neuropsychopharmacology 2023、多模态分型+孟德尔随机化因果 eClinicalMedicine 2023）。与 Mohan 方向（免疫）不同，这里我们**有域内发表背书**，可信度更高（对照 [[project_fundability_thesis]] 与 `20260908_REPLY_TO_DR_MOHAN.md` 的"方法有、域内经验待建"定位——在神经/精神方向我们两者都占）。

- **方向（三）** = BioMate 数据中心化平台 + 多模态预测模型本体，**几乎逐项已具备**（专病库=数据中心化+provenance；多模态风险预测=我们发表过的原方法）。
- **方向（一）** = 早期诊断(生物标志物面板/预后模型) + 新药研发(生成-优化-安全闭环)，**方法层强，且域内有发表**。
- **方向（二）免疫共病** = 跨表型多组学整合(MOFA2/SNF 已跑通) + 遗传锚定因果 + 通用 ML 分层。**注意：我们专有的免疫基础模型(immune-FM)不纳入本合作——属内部资产，对外仅提供平台/工作流/方法层**([[project_immune_llm_vcc]])。
- **方向（四）生物材料** = 仅"药物递送载体设计+疗效评估"部分可映射到分子设计/ADMET/PBPK；**力学材料、分子马达不在当前射程**（诚实差距）。

**建议：方案主打（三）+（一），（二）作为与免疫团队(范慧敏/彭虹/邵彤)的研究引擎切入，（四）仅就"递送载体"一项有限参与，其余明确不承诺。** 符合 [[feedback_overclaiming_conclusions]]：领先说诚实差距。

## 分方向映射

### 方向（一）神经与精神学科 — 发病机制 / 早期诊断 / 干预诊疗
*团队：丁旭龙、张海龙、尹秀华*

| 子方向 | 能力映射 | 状态 | 依据 / 差距 |
|---|---|---|---|
| 1. 脑外伤及 AD 发病机制解析 + 早期诊断 | 多模态分型 + 遗传锚定(孟德尔随机化)因果；AD 进展预后模型 | ✅(方法) | iScience 2024 AD 预后、eClinicalMedicine 2023 因果——**域内发表背书**；机制解析需接其组学数据 |
| | 早期诊断 = 生物标志物面板发现 | ✅(方法) | npj Mental Health 2023 生物标志物面板(co-first) |
| | 可解释、跨队列可复现签名 | ✅(方法) | Neuropsychopharmacology 2023(通讯)——跨站点迁移正是早诊落地关键 |
| 2. 精神疾病与慢性疼痛早诊 + 快速干预 | 生物标志物面板 + 风险预测模型；大生理信号模型(多导睡眠 preprint) | ✅/🟡 | 面板/预测已验证；慢性疼痛专病数据需对接；"快速干预"偏临床决策支持(可做) |
| 3. 神经退行性疾病协同干预新策略 + 新药研发 | de novo 生成 → QSAR/对接 → ADMET 自动闭环 → GP-Pareto MPO；环肽设计 | ✅优化层/🟡生成层 | 生成-优化-安全闭环为强项(~215 药研工作流)；生成器产品化为待补项(同 Guangzhou 映射) |

**切入点：** 早期诊断(面板+可复现预测模型)是最快见效、且有发表背书的切入；新药研发接我们的计算闭环。**这是四个方向里可信度最高的一个。**

## 平台如何帮助：Workflow / DB / ML 三层

按"他们会真正用到的"三条交付线拆，而非泛泛而谈。

### ① Workflow（执行引擎）
2,400+ 个可运行管线 / 34 域，跑在 AWS Batch（R+Bioconductor / Nextflow+nf-core）：RNA-seq、WGS/变异、cryo-EM、多组学整合(MOFA2/SNF)，以及药物闭环（de novo 生成 → docking/QSAR → RBFE → ADMET 自动闭环含 hERG 门控 → GP-Pareto 多目标）。可按需生成新工作流；auto-loop QC 门控(=可验证奖励雏形)反复重跑至达标。
- 服务：（一）3 新药闭环 · （二）免疫/代谢/病毒机制的 RNA-seq+跨表型多组学 · （三）3 病毒载体=蛋白/序列设计 · （四）2 递送载体分子设计+ADMET/PBPK。
- **诚实边界：** 代谢组学/蛋白组学管线**无真实端到端运行证据**([[project_workflow_validation_gaps]])——先在其数据上验证再承诺；材料力学、分子马达不在射程。

### ② DB / 数据平台
数据中心化架构：**dataset-as-centroid + 全程 provenance/审计**、跨 60+ 数据源统一检索、连接器(19 工具 MCP + 10 仪器)。本身即"专病数据库"底座，且可复现/可追溯。
- 服务：（三）1 专病库+多模态**近乎即用**；为临床/监管提供可辩护的溯源层；跨队列 held-out 验证(leave-cohort-out，同 Mohan pilot)。
- **诚实边界：** 需接入其真实队列/EHR；临床数据**摄取侧**部分为建设项。

### ③ ML（最可信的一层）
多模态分型、**遗传锚定(孟德尔随机化)因果**、生物标志物面板、可解释**跨站点可复现**预测、预后模型——**均同行评审、且就在其神经/精神域**(eClinicalMedicine 2023 / npj Mental Health 2023 / Neuropsychopharmacology 2023 / iScience 2024)；外加 null/leakage 纪律(匹配负对照、leakage probe, [[project_immune_llm_code_audit]])。
- 服务：（一）1-2 早诊(面板+预后，**域内发表**) · （三）1-2 多模态风险+骨骼肌衰老(我们的原方法) · （二）因果靶点置信+通用 ML 分层。
- **边界：** 生成器为**研发中**，不作已完成品呈现；**专有 immune-FM 不纳入本合作**(内部资产)。

> **跨三层的卖点不是某个模型，而是"严谨+可复现"**：匹配 null、leakage probe、跨队列迁移、端到端 provenance——这才是临床可信、区别于黑箱评分之处。

## 一句话定位

**姿态=互补而非替代**：东方医院已有 Med-Go LLM + 全域数据底座，我们切入点是"可验证、可复现的执行+溯源+ML 验证层"。**主打（三）数据中心化平台+多模态预测 与（一）神经/精神早诊+新药闭环——这两处我们"方法有、域内发表也有"，可信度最高**；（二）以范慧敏的单细胞/miRNA 数据做"因果置信+通用 ML 分层"研究引擎直接对接(**专有 immune-FM 不对外**)；（四）仅递送载体分子设计有限参与。对比 Mohan(免疫，仅方法有)，神经/精神方向是更稳的可信切入。

**最具体的两个即时对接点**(已确认个人)：① 范慧敏的单细胞 CD45+ / 循环 miRNA 面板 → 我们的 ML 面板+分型；② 骨骼肌衰老 → 岳锐队列(再生医学所)做多模态预测+因果。
