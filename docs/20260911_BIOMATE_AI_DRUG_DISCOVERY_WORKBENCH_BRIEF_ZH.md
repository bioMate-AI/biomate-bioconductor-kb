# BioMate AI 药物研发工作台

## 面向“药物分子生成与优化”项目的平台说明（对外工作稿）

### 一句话定位

BioMate 是一套面向药物研发团队的 **AI 科研工作台与可执行平台**。它不把分子生成、对接、ADMET、合成规划、实验数据和报告分散在不同工具中，而是将它们组织为可配置、可运行、可复现、可审计的研发闭环：从科学问题和项目数据出发，形成候选分子与证据，再将实验结果带回下一轮决策。

对本项目而言，BioMate 可建设为一套可持续使用的平台，而不仅是一次性的候选分子交付。

---

## 1. 覆盖“发现—设计—验证—学习”的药物研发闭环

```text
疾病与靶点证据 / 文献专利 / 项目数据
  → 靶点评估、结构与口袋分析、设计假设
  → 分子生成、虚拟筛选与系列扩展
  → 活性、选择性、ADMET、安全性、可合成性与新颖性评估
  → 多目标权衡、可解释排序与人工决策
  → 合成/采购与湿实验测试
  → 结果回流、模型更新、下一轮优选
```

每个环节并非孤立报告：候选分子、输入数据、参数、模型/工作流版本、质控结论、人工审批及实验结果都可在同一个项目记录中关联、追溯和复用。

## 2. 面向项目需求的核心能力

### 2.1 多模态、可扩展的分子设计能力

- 以小分子发现与先导优化为成熟主线：从已有 hit/lead、骨架或片段出发，支持系列扩展、骨架跃迁、分子修饰、药效团约束与多样性控制。
- 平台架构不锁死单一模态，可按项目配置小分子、多肽/大环肽、PROTAC、分子胶及其他分子形式对应的表示、生成逻辑和评价规则。
- 对不同模态不使用“一个模型通吃”的不实表述；具体生成器、结构表征、实验验证和验收基准应随模态共同确定。
- 支持单靶点项目，也可将多靶点活性、反靶点选择性和多重药理纳入同一设计与排序问题。

### 2.2 结构驱动与数据驱动并行

BioMate 可将两类设计范式组合使用：

- **结构驱动**：靶点结构/预测结构检索、口袋与可成药性分析、分子对接、构象与结合模式检查、分子动力学、MM-GBSA/RBFE 等分层计算；
- **配体与数据驱动**：已知活性/非活性数据、QSAR/性质模型、药效团、相似性与虚拟筛选；
- **证据融合**：不以单一分数替代科学判断，而是将不同证据、适用域和不确定性并列呈现，供团队制定下一步实验决策。

这使平台既适用于已有可靠结构和结合位点的项目，也能服务于主要依赖配体和活性数据的靶点。

### 2.3 可配置的多目标优化，而非固定“黑箱打分”

药物研发中的效力、选择性、成药性、安全性、可合成性、新颖性和项目多样性往往彼此冲突。BioMate 将它们设置为独立、可检查的目标与约束：

- 可按项目定义硬性淘汰项、优先级、区间、权重和人工覆核规则；
- 支持 Pareto 前沿、多目标贝叶斯优化、不确定性和多样性约束，用于选择下一批值得合成或测试的化合物；
- 将 hERG、肝毒性、遗传毒性、CYP/DDI、通透性、清除/暴露等安全与 DMPK 信号作为早期优选维度；
- 将合成可行性、路线规划、化学约束、结构新颖性和专利/FTO 审查流程纳入决策链条。

计算预测用于提高优选效率，并不替代合成、体外/体内实验或专业专利意见。

### 2.4 干湿结合的 DMTA 学习闭环

平台既可运行纯计算闭环，也可建设“设计—合成—测试—分析”（DMTA）闭环：

1. 输出可交付给内部化学团队或 CRO 的候选清单、结构、优先级、预测证据、风险提示和合成/测试要求；
2. 接收合成成败、纯度/表征、活性、选择性、DMPK 和安全性等实测结果；
3. 规范化记录单位、实验条件、质控状态、失败和截断结果；
4. 在预先约定的人工审批与版本治理下，重新排序、校准或更新项目模型，并提出下一轮候选。

因此，每一轮实验不只是“验证一次结果”，也成为客户持续积累的私有研发数据资产。

### 2.5 公司数据、模型和系统的可接入性

- 支持将公司自有活性、选择性、DMPK、安全性、合成和失败数据纳入项目工作区，用于模型评估、微调或项目专属排序；
- 可接入经批准的内部模型、容器化模型或服务化模型，并保留模型版本和运行证据；
- 可按需求与 ELN、LIMS、化合物库、内部数据库、CRO 或实验数据接口衔接，减少人工搬运；
- 支持私有化/本地化部署、数据驻留、权限与审计要求的方案设计。

数据接入、模型使用权、生成化合物和衍生结果的知识产权边界，应在项目启动时由双方清晰约定。

## 3. 不只是药化工具：BioMate 的科研工作台能力

药物设计需要的不仅是一个生成模型。BioMate 可为项目提供贯穿研发协作的工作台：

- **自然语言科研入口**：研究人员用任务语言提出问题，系统协助选择适合的分析路径、预填关键参数，并在真正有歧义时提出澄清问题；
- **数据与证据工作区**：组织结构、活性数据、组学数据、文献/专利证据、工作流输入输出和项目结论，而非让团队在文件夹、脚本和表格间反复迁移；
- **靶点与疾病研究支撑**：可将多组学、遗传学、单细胞、蛋白组、结构生物学等证据接入靶点发现、验证和机制研究；
- **模型与工作流工作台**：将通用算法、公司模型和经确认的外部服务纳入受控运行环境，允许按新靶点、新项目或新策略复用和扩展；
- **真实执行与质控**：任务在计算环境中运行，过程状态、异常、输入和结果可见；关键质量门和人工审批不被静默绕过；
- **结果表达与协作**：自动沉淀方法、参数、软件/模型版本、结果与局限，形成可编辑、可导出的项目报告和决策依据。

这使 BioMate 同时服务计算化学、药物化学、药理/DMPK、实验科学家和研发管理者：每个角色看到适合其决策的信息，同时使用同一份可追溯的项目事实。

## 4. 平台交付方式

建议将平台交付分为可验收的阶段，而不是只承诺最终“生成一批分子”：

1. **项目激活**：确认模态、靶点、目标产品概况、数据权利、实验体系、部署与合规边界；
2. **项目配置与基准**：配置结构/配体设计路径、公司数据模型、多目标规则、安全和合成门槛；在预先约定的历史数据上完成基准评估；
3. **首轮 DMTA 验证**：输出候选与证据包，接收实测数据，衡量预测—实验一致性和实际研发价值；
4. **平台化扩展**：将验证有效的模型、规则、数据接口和项目模板复用于新系列、新靶点或更多团队。

验收应围绕双方预先定义的平台指标、项目数据和实际决策价值进行，例如运行可用性、可追溯性、模型评估、候选优选质量、实验回流能力和迭代效率；不应用一个脱离靶点、数据和实验条件的绝对数值概括平台效果。

## 5. BioMate 的差异化价值

| 常见做法 | BioMate 工作台 |
|---|---|
| 生成、对接、ADMET、实验数据各自分散 | 将工具、数据、项目规则和实验闭环组织为同一研发系统 |
| 由专业人员在多个界面/脚本之间手工衔接 | 用受控工作流连接，并保留每一步的输入、理由和版本 |
| 单一预测分数决定排序 | 多目标、约束、不确定性、质量门和人工决策共同作用 |
| 实验结果留在表格或报告中 | 结构化回流到项目记录，支持下一轮学习 |
| 一次性交付结论 | 形成可持续运行、可扩展、可审计的公司研发能力 |

## 结语

BioMate 的价值不在于声称某一个模型可以“自动发现新药”，而在于把客户的科学问题、私有数据、计算方法、实验反馈和专家判断组织为一个可执行、可学习、可治理的研发系统。对于“药物分子生成与优化”项目，它既能完成分子设计和多维优选，也能成为公司后续不断积累数据、模型和项目知识的 AI 药物研发工作台。

> 本说明用于能力与合作范围沟通。具体靶点、模态、模型、实验体系、数据质量、系统接口、部署方式和验收标准，应以双方技术澄清和项目方案为准。
