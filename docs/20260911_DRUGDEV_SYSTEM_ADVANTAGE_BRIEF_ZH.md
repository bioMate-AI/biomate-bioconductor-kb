# BioMate 药物研发平台 · 系统优势简报

> 一句话定位：BioMate 是一个**面向药物研发全流程的智能执行平台**——把深度学习模型、分子对接、成药性（ADMET）预测、多目标优化等**多个模块作为工具协同起来**，串成"设计分子、预测性质、筛选优化、送实验、回流数据、再迭代"一个可运行、可复现、可审计的闭环，而不是一堆彼此割裂的单点工具。

---

## 一、核心优势

### 1. 全流程闭环，而非单点工具
多数方案只解决一个环节（只做生成、或只做对接、或只做 ADMET）。BioMate 把**「设计 → 预测/筛选 → 优化 → 送 CRO 实验 → 回流实测数据 → 模型再训练」**打通成一个可循环的工作流。每一轮实验结果自动回流、更新模型，让下一轮设计更准。这条"干湿结合"的数据飞轮，是平台真正的护城河——越用越准，且沉淀的是客户自己的私有数据资产。

### 2. 智能理解需求，自动匹配工作流
用户用自然语言描述任务（"筛这批化合物的心脏毒性风险""优化这个先导物的口服吸收"），平台自动理解意图并**匹配到正确的分析流程**，跨数千个已验证工作流精准路由。内部实测路由准确率已从早期的约 39% 提升到约 97%。不需要用户懂管线、懂参数，也不需要工程团队为每个需求现搭流程。

### 3. 参数智能预填 + 主动澄清
平台从需求描述中**自动抽取并校验关键参数**（化合物结构、靶点、筛选阈值等），规则优先、模型兜底，并对照流程的合法取值做守护校验。遇到真正有歧义的地方，会**主动、有针对性地反问**（而不是默认一个值蒙混过去），把选择权交回用户——未选择的项绝不静默替用户填一个值。

### 4. ADMET 不合格会自动"修了再验"，不是给个数字就完事
成药性（心脏毒性 hERG、肝毒性、代谢稳定性等）跑出来只是第一步。平台内置**自动质控门**：某项指标一旦越过安全阈值，会自动标红拦下——**并且不止于此**。系统会自动尝试一次补救：按预设策略调整设计或参数，重新算一遍，再检查是否达标；如此**"发现问题 → 自动改一版 → 重新验证"循环往复**，直到指标合格，或明确告诉用户卡在哪、为什么改不动。也就是说，问题指标不会被人忽略、也不会悄悄流到下游，而是当场被系统自己"追着修"。阈值用户可自定义，判定过程完全透明（实测值与阈值双数字并列展示）。

### 5. 多模态，不锁死小分子
平台在架构上**对模态开放**——小分子、多肽、蛋白/生物大分子共用同一套"设计 & 生成"入口，按模态切换相应的约束条件与生成逻辑。对没有诚实生成能力的模态，平台明确标注"能力建设中"、不伪造结果；对已具备能力的路径，正常运行。既不夸大、也为后续扩展留好接口。

### 6. 可执行、可复现、可审计
所有分析都在可弹性扩展的算力上**真实运行**（不是示意图、不是本地脚本），实时回传每一步状态与产出。运行结束自动生成**规范化方法学报告**（可编辑、可导出，面向注册申报口径），全过程留痕、可溯源——这对合规要求高的药企和 CRO 尤为关键。

> 其中，**深度学习模型是系统的一个核心模块**：用于分子生成设计与成药性/性质预测，且可按项目训练、并用客户私有数据做微调适配——但它与对接、优化、质控等工具**并列协同**，共同构成一个完整系统，而非孤立的单点模型。

## 二、与常见方案的区别（客观对比）

| 维度 | 常见做法 | BioMate |
|---|---|---|
| 覆盖范围 | 单点工具，环节间人工搬运 | 全流程闭环，模块自动衔接 |
| 使用门槛 | 需懂管线/编程/调参 | 自然语言驱动，自动路由与预填 |
| 成药性把关 | 事后看报告 | 过程中自动质控门 + 自动"修了再验" |
| 数据价值 | 结果用完即弃 | 实测数据回流、模型持续增强 |
| 交付形态 | 一堆散点结果 | 可运行 + 可复现 + 可申报报告 |
| 模态 | 多为小分子专用 | 小分子/多肽/蛋白同一入口 |

> 说明：我们**不**主张"业内唯一/首创"。上述每一项单点能力业界都有玩家；BioMate 的差异化在于把它们**编排成一个自动、闭环、可审计的执行系统**，以及由此沉淀的私有数据飞轮。

## 三、现状与演进（诚实边界）

- **已具备并经真实运行验证**：智能路由、参数预填与澄清、小分子设计/对接/性质预测、ADMET 自动质控闭环、真实算力执行与方法学报告——这些是当前可交付的核心。
- **正在建设/持续增强**：更强的自研生成模型、以及"设计—实验—再训练"完整多目标优化闭环的进一步收敛；多肽/蛋白模态的生成能力。这些是平台明确的演进方向，随合作共同打磨、验证——我们如实呈现进度，不把在建能力说成已完成。
