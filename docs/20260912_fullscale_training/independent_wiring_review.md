# Independent full-scale wiring review — 2026-09-12

**The staged hybrid wiring is not an implementation of all canonical training objectives.** Review scope: `/tmp/immune_fullscale_wiring/immune_hybrid_llm.py`, `test_fullscale_wiring.py`, and canonical `/Users/kky/biomate-immune-llm/docs/program_control/OBJECTIVES.md`. No staged implementation was edited. Five existing wiring tests passed. Two additional read-only reproductions expose concrete failures below.

## Blocking scientific mismatches

1. **`target` is mislabeled supervision.** `observed_joint_loss` maps target to cross-entropy on `y`; `h_target` maps gene expression to `n_celltypes`. This trains a gene-weighted cell-type classifier, not perturbation-effect prediction, target efficacy, or canonical H1–H4. Rename/retain it only as a legacy auxiliary classifier. Do not count its gradient as canonical target training. Introduce separately named H1 transcription delta, H2 translation-efficiency, H3 protein delta explicitly consuming H2, and H4 presentation-delta heads with verified measured endpoints and pairing.
2. **`strat` is contrary to the canonical scope.** It applies a linear head and BCE to individual cell embeddings, despite the module's sample-level description. It does not pool patients or constrain patient-disjoint splits and weights patients by sampled cell counts. More fundamentally, canonical OBJECTIVES explicitly excludes clinical-outcome prediction and specifies responder stratification as a derived score. Remove it from the canonical required-objective registry; do not fix pooling and then count it as an accepted canonical objective. A derived application score must be separately evaluated under its intended sample/patient unit.
3. **Observed-mask gating does not supply missing objective semantics.** Binary `presentation` from peptide features is not perturbation-conditioned H4 repertoire delta; non-detection must be censored, never a negative. Existing genes-sized durability/inflammation heads are application proxies, not H2 or H3. Required modules also include sequence MS detectability, censored abundance, unseen-peptide sign/magnitude and class-II binding register. None are established by the current required-name list. Likewise study adversarial CE is not perturbation-delta IRM across environments. Canonical head/principle coverage must be tracked explicitly rather than inferred from names or nonzero gradients.

## Blocking implementation problems

4. **Absent modalities can inject NaN despite mask zero.** Reproduction: set `protein_mask[0]=0`, set `protein[0]=NaN`, run the tested knowledge2-joint model in eval mode: `z[0]` becomes nonfinite. Omic fusion encodes/gates the value before multiplying the presence mask; zero times NaN remains NaN. Sanitize absent rows before both encoder and gate, validate finite observed entries, and check missing-row mutation invariance. Per-feature masks are also absent: zero-filled unmeasured RNA/ADT/ATAC features are currently indistinguishable from measured zeros. Preserve explicit feature-observation/schema masks and handle them before the encoder. RNA and knowledge are currently unconditionally marked present, which is unsuitable for arbitrary heterogeneous source batches.
5. **`slice_batch` regresses integer label compatibility.** The patch removes the prior `.long()` conversion for `y`. Reproduction using the existing synthetic fixture with NumPy int32 `y`: sliced dtype is torch.int32, and observed loss raises `ValueError: Class labels require int64`. Restore validated integer-label conversion to int64 (reject nonintegral floating labels rather than truncate silently). Current test only uses int64 input and misses this regression. Add int32/int64 compatibility and invalid-label tests. Keep boolean masks strict.
6. **Heterogeneous training contract remains incomplete.** The observed loss can skip labels per batch, but `slice_batch` still requires tokens, RNA, knowledge and study for every source, while global `required_objectives` demands every listed objective within each batch. Source-specific supervision contracts are needed; an epoch-level coverage ledger should verify that enabled objectives receive genuine observations. Regularizer-only batches must not be reported as observed head training. Target/control pairing, feature schema, censoring flags, perturbation and environment IDs must survive slicing and enter their intended objectives.

## Verification needed before a full-scale claim

The passing tests establish that synthetic branches receive gradients, masked labels do not alter loss, missing required labels are rejected, selected optional fields survive slicing and the old checkpoint lacks new joint keys. They do **not** establish correct biological endpoints, valid patient/sample units, input missingness safety, canonical stage wiring, real dataset joins, or held-out prediction performance.

Add focused tests for absent-row and absent-feature mutations; int32 labels; per-source supervision and epoch coverage; train-only preprocessing and held-out pairing; H3 dependence on H2; H4 perturbation conditioning; non-detection censoring; detectability and class-II register masks; and real artifact/schema compatibility. Required negative controls and linear/no-change gates remain downstream evaluation obligations. Canonical H4 claims require a trained head beating B1 on held-out perturbations, not recovery of a known perturbation mechanism or a gradient smoke test.

The proposed central-dogma module should remain explicit and distinct from these legacy auxiliary proxies. No all-objective real-data training or acceptance result is established by this review.
