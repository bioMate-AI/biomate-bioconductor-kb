# Self-Evolving Agent Harnesses — Survey & BioMate Leverage

_Deep-research survey (2023–2026), 106 agents, 24/25 claims adversarially verified._

## Executive summary

The 2023–2026 literature converges on a clear, actionable blueprint for a self-evolving BioMate. Two comprehensive 2025 surveys (arXiv 2508.07407; 2507.21046) provide unifying taxonomies — "what/when/how(/where) to evolve" across model, memory, tools/workflow, with optimizers spanning training-based (SFT/RL), test-time feedback/search/reasoning, and prompt optimization (edit/evolutionary/generative/text-gradient) — that map every method family BioMate cares about (STaR/ReST training, DSPy/TextGrad prompt compilation, Voyager-style skill libraries, Reflexion-style episodic memory) into one design space. The single most reliable and empirically validated recipe is the STaR/ReST-EM generate→filter→fine-tune→repeat loop: filter self-generated episodes by binary/scalar correctness, fine-tune only on passers, iterate "a few times" — this significantly beats fine-tuning on human data alone and substantially reduces human-data dependence, and it directly fits BioMate's structured tasks (intent classification, workflow routing, schema-grounded parameter resolution, log diagnosis/autofix). The dominant danger is training on self-generated content: model collapse (irreversible loss of distribution tails, a universal property of learned generative models per Nature 2024) and RLHF/reward-step mode collapse; the field's own remedy is exactly BioMate's plan — ground the verifier in real production logs, human interactions, and execution/schema checks rather than self-judgment, filter on more than single-answer correctness, and keep real data in the mix. For inference-time gains without weight updates, Reflexion's verbal-RL episodic memory yields large documented improvements (e.g., +22% ALFWorld, +20% HotPotQA, 91% vs 80% HumanEval pass@1), but self-correction is not reliably beneficial on its own and must be paired with external grounding.

- arXiv 2508.07407 defines four components (System Inputs, Agent System, Environment, Optimisers) abstracting the self-evolution feedback loop, and categorizes single-agent optimization into LLM behaviour (training-based SFT/RL + test-time feedback/search/reasoning), prompt (edit/evolutionary/generative/text-gradient), memory, and tool optimization — with STaR under training-based SFT and TextGrad named as the text-gradient exemplar. arXiv 2507.21046 organizes the field around what (model, memory, tools/workflow), when (intra- vs inter-test-time, mapped to SFT/RL/inference-time), and how (textual feedback vs scalar rewards; single- vs multi-agent) to evolve. ### 2. The core self-improvement recipe for BioMate's structured tasks is the STaR/ReST-EM loop: few-shot generate candidate episodes/rationales, keep only those that pass correctness filtering, fine-tune on them, and repeat a few EM-style iterations — using a few seed examples plus a large answer-labeled (but rationale-unlabeled) dataset.
- **Confidence:** high  |  **Votes:** [3] 3-0, [10] 3-0, [11] 3-0, [13] 3-0
- STaR (Zelikman et al. 2022, openreview _3ELRdg2sgI / arXiv 2203.14465): generate rationales few-shot, keep only those yielding correct answers, fine-tune, repeat; uses a few seed rationales + large answer-labeled data, avoiding human-annotated rationale corpora. Survey 2507.21046 grounds this as the foundational generate→filter→retrain loop. ReST-EM (arXiv 2312.06585, TMLR 2024) states the method verbatim as exactly three repeated steps: '(1) generate samples...filter using binary feedback, (2) fine-tune on these samples, (3) repeat this process a few times' — an EM-style self-training loop. Practical recipe for BioMate: apply to intent classification, workflow routing, schema-grounded parameter resolution, and log diagnosis/autofix where correctness is checkable.
  - https://openreview.net/pdf?id=_3ELRdg2sgI
  - https://arxiv.org/pdf/2507.21046
  - https://arxiv.org/abs/2312.06585

### 3. Self-training on filtered self-generated data significantly outperforms fine-tuning on human data alone and substantially reduces human-data dependence — validated on reasoning and coding benchmarks.
- **Confidence:** high  |  **Votes:** [8] 3-0, [9] 3-0
- ReST-EM (arXiv 2312.06585, TMLR 2024, PaLM-2 on MATH and APPS): 'ReST^EM scales favorably with model size and significantly surpasses fine-tuning only on human data' and 'self-training with feedback can substantially reduce dependence on human-generated data.' Caveat from the same paper: diminishing returns / overfitting after ~1–2 iterations (a 2nd-iteration regression on APPS due to small training set), so limit EM cycles and restart from the base checkpoint. Implication for BioMate: a modest number of high-quality filtered episodes per task can materially cut annotation cost; iterate only a few times.
  - https://arxiv.org/abs/2312.06585

### 4. BioMate should recover training signal from failures and use richer verification than single-answer correctness: STaR-style rationalization (regenerate a rationale given the correct answer), V-STaR-style DPO verifiers trained on BOTH correct and incorrect samples, and CREST-style consistency checks via follow-up questions.
- **Confidence:** high  |  **Votes:** [12] 3-0, [14] 3-0, [15] 3-0, [16] 3-0
- STaR rationalization: for failed problems, regenerate a rationale conditioned on the correct answer as a hint (reason backward), then train on it without the hint — recovers signal from otherwise-discarded failures. V-STaR (arXiv 2402.06457, COLM 2024): use both correct and incorrect self-generated solutions to train a verifier via DPO (correct=preferred, incorrect=dispreferred), rather than discarding rejected samples; yields 4–17% test accuracy improvement (6–17% math, 4–12% code) over prior self-improvement/verification approaches with LLaMA2. CREST (arXiv 2411.06387, NAACL 2025): evaluate each rationale via follow-up questions and use that to filter/preference-train, beating STaR/RFT. Together they give BioMate a menu: mine failed runs (rationalization), train an execution/schema-grounded verifier on pass+fail logs (V-STaR analog), and cross-check rationale consistency (CREST analog).
  - https://openreview.net/pdf?id=_3ELRdg2sgI
  - https://arxiv.org/html/2402.06457v2.pdf
  - https://arxiv.org/pdf/2411.06387

### 5. Filtering on a single correctness measure is a known failure mode: models can learn flawed reasoning patterns even when final answers are correct, so BioMate's verifier must check the process/steps (execution + schema grounding), not just the outcome.
- **Confidence:** high  |  **Votes:** [17] 3-0
- CREST (arXiv 2411.06387, NAACL 2025): 'a single measure risks misjudging rationale quality, leading the models to learn flawed reasoning patterns.' Corroborated by V-STaR (adds checks on reasoning steps beyond outcome) and the broader faithfulness literature. For BioMate: a workflow that produces a plausible final report from a wrong parameter path is a false positive under answer-only filtering; ground verification in execution success, schema validity, and independent auditor checks.
  - https://arxiv.org/pdf/2411.06387

### 6. Model collapse is the primary danger of a self-generated-data flywheel: indiscriminate training on model-generated content causes irreversible loss of the distribution's tails, and this is a universal property of learned generative models (LLMs, VAEs, GMMs) — so the risk applies to any BioMate component trained iteratively on its own outputs, not just the LLM.
- **Confidence:** high  |  **Votes:** [5] 3-0, [6] 3-0
- Shumailov et al., Nature 2024: 'indiscriminate use of model-generated content in training causes irreversible defects...tails of the original content distribution disappear...we refer to this effect as model collapse'; demonstrated in LLMs, VAEs, and GMMs with 'theoretical intuition...its ubiquity among all learned generative models.' Known mitigation from follow-up work (Gerstgrasser et al., arXiv 2410.12954): collapse is avoided when synthetic data ACCUMULATES alongside real data rather than replacing it — i.e., keep real production/human data in the training mix and never train indiscriminately.
  - https://www.nature.com/articles/s41586-024-07566-y

### 7. The field's own remedy validates BioMate's design: ground the flywheel in genuine human interactions / real production logs + execution/schema verification rather than pure self-generation; use an independent auditor and external grounding, not self-judgment.
- **Confidence:** high  |  **Votes:** [7] 3-0, [23] 3-0
- Nature 2024: 'the value of data collected about genuine human interactions with systems will be increasingly valuable in the presence of LLM-generated content' — production logs ARE this class of data. CMU LM Inference Fall 2025 course (Neubig) lists 'Failure modes of self-correction' as a first-class topic alongside Self-Refine/self-debug/Reflexion, corroborating that self-correction does not reliably improve outputs and must be paired with external grounding (cf. Huang et al. 'LLMs Cannot Self-Correct Reasoning Yet,' arXiv 2310.01798). This directly situates BioMate's existing generator + independent auditor loop: keep the verifier grounded in execution/schema/human signals, not the model judging itself.
  - https://www.nature.com/articles/s41586-024-07566-y
  - https://phontron.com/class/lminference-fall2025/assets/slides/2025-09-18-self-refine/index.html

### 8. Reward-based self-evolution is prone to reward hacking and mode collapse; the RL/preference step is the dominant contributor to output-diversity loss, so BioMate should prefer grounded verifiers and monitor diversity when doing any RL/DPO stage.
- **Confidence:** high  |  **Votes:** [4] 3-0, [18] 2-1, [19] 3-0
- Survey 2507.21046: 'Reward-based learning is sensitive to the quality and design of reward functions, risking reward hacking or unintended behaviors,' and characterizes stability/sample-efficiency trade-offs across imitation, reward-based, and population/evolutionary learning. Attributing Mode Collapse (OpenReview 3pDMYjpOxk, ICLR 2024 workshop): the reward-based (RL/DPO) step is the dominant contributor to OUTPUT diversity loss (more than SFT for generation diversity; note SFT dominates token-level diversity), corroborated by Kirk et al. (arXiv 2310.06452). Instruction/alignment tuning systematically reduces output diversity vs the pre-trained model. Implication: if BioMate adds a reward/preference stage, cap it, keep the reward grounded in execution/schema, and track output diversity to catch collapse and hacking.
  - https://arxiv.org/pdf/2507.21046
  - https://openreview.net/pdf?id=3pDMYjpOxk

### 9. For inference-time self-improvement without weight updates, Reflexion's verbal-RL episodic memory is a strong, low-risk pattern that fits BioMate's log-diagnosis/autofix and multi-turn workflows.
- **Confidence:** high  |  **Votes:** [20] 3-0, [21] 3-0, [22] 3-0
- Reflexion (Shinn et al., arXiv 2303.11366, NeurIPS 2023): reinforce agents 'not by updating weights, but...through linguistic feedback,' converting binary/scalar environment feedback into reflective text stored in an episodic memory buffer used as context for the next trial. Documented gains: +22% absolute on ALFWorld over 12 iterative steps, +20% HotPotQA, up to +11% HumanEval; 91% pass@1 HumanEval vs 80% GPT-4 baseline (with standard HumanEval-contamination caveat). For BioMate: on a failed run, generate a grounded verbal reflection (from execution error + schema check + auditor) and persist it as episodic memory keyed to the task/workflow, feeding the next attempt — a weight-free first layer before any fine-tuning.
  - https://arxiv.org/pdf/2303.11366
