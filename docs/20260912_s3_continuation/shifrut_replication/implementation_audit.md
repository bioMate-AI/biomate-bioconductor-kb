## Bounded downstream reproducibility design

1. Keep every available donor/condition/target/guide pseudobulk; tabulate missing groups, cell counts and library sizes. Do not select guides by observed downstream effects or on-target success. A predeclared cell-support sensitivity analysis may accompany the inclusive result but must not become a post-hoc success filter.
2. Hash-order the eight control guides with a recorded salt, then alternate into two disjoint four-guide reference pools. Aggregate raw control counts separately within each donor/condition/pool, preserving full-library normalization. Report empty or thin pools explicitly.
3. Within each of at most 80 donor/condition/target contrasts, compare the two guide effects using separate reference pools. Swap pool assignment and report both orientations. Include shared-reference and raw-expression correlations only as clearly labeled diagnostics; neither demonstrates independent perturbation signal.
4. Exclude the direct target readout, with explicit identifier mapping. Report Pearson, Spearman, MSE and nonzero/evaluable readout counts. Use all measured genes as the primary descriptive panel; any expressed-gene sensitivity must use control-only thresholds fixed before viewing guide outcomes. Save per-contrast metrics and support, not just a grand average.
5. Compare control pseudo-effects with matched support/reference construction and keep control observations out of their own references. With only eight control guides, avoid describing many overlapping splits as independent null replicates. Cross-donor effect agreement can be reported separately, retaining condition and guide identity.
6. This is an independent-experiment data-reliability check, not validation of the existing immune model. It has only two biological donor identities and differs in intervention, assay and condition from the genome-wide CD4 experiment. Do not pool donor labels or treat 80 contrasts as 80 independent donors. A model-transfer test would require a frozen mapping, compatible target/readout coverage and untouched evaluation protocol established separately.
