## 1. BioMate 是什么？

BioMate 是一个面向结构生物学与生命科学研究的对话式 AI 平台。你只需用日常语言描述想做什么，BioMate 就会：

- **理解你的科学目标** —— 读懂你要做的实验，而不只是抠关键词
- **挑选正确的工作流（workflow）** —— 从 200 多条经过验证的生物信息学流程库中选择
- **校验你的输入** —— 在动用计算资源之前先检查前置条件是否满足
- **执行分析** —— 在云端或本地 HPC 基础设施上运行
- **呈现结果** —— 交互式可视化、可下载文件、以及可供审计的报告

BioMate 的设计目标是像领域专家一样思考。它知道什么时候该用 saposin 而不是 MSP nanodisc、什么时候该做局部精修（local refinement）、什么时候在做冷冻电镜之前必须先做功能验证实验，也知道该如何根据你的许可证情况在 AlphaFold3 与 Chai-1 之间取舍。

## 2. 快速上手

### 第 1 步 —— 描述你的实验

直接说出你想做什么，BioMate 能听懂科研语言：

> “我有一段膜转运蛋白在 saposin nanodisc 中的原始冷冻电镜 movie，想解析它的结构。”

> “我要把 20 个候选药物对接到我这个激酶结构的 ATP 结合口袋里。”

> “用 Mutect2 对这些肿瘤/正常配对的 WGS 样本做变异检测。”

### 第 2 步 —— 回答澄清问题

为了做出正确选择，BioMate 可能会问你一两个问题：

> “这是单颗粒分析（single-particle analysis）数据集，还是你在处理断层扫描用的原位/胞内（in-situ / in-cell）样本？”

简短作答即可。如果你已经给过相关信息，BioMate 不会重复追问。

<!-- SCREENSHOT: BioMate clarifying question in the chat — narrowing single-particle vs tomography | 中文说明：聊天中 BioMate 提出澄清问题 —— 区分单颗粒分析与断层扫描 -->

### 第 3 步 —— 查看工作流卡片

BioMate 会给出一张工作流卡片（workflow card），上面列出：
- 流程名称和说明
- 参数（已经为你预填好数值）
- 输入文件槽位
- 预期输出
- 任何前置条件或许可证要求

如有需要，直接在卡片上调整参数即可。

### 第 4 步 —— 上传文件（如果还没传）

把文件拖拽到上传区，或者提供云存储路径（S3、Google Drive）。

### 第 5 步 —— 确认并运行

点击 **Confirm & Run**。BioMate 会先校验输入，然后启动流程。你可以实时观看进度，并在结果陆续产出时随时查看。

## 3. 如何与 BioMate 对话

BioMate 是为自然的科研语言设计的，你不需要去记工作流的名字。

### 高效的提问方式

| 不要这样说…… | 这样说…… |
|---|---|
| “run cryosparc_standard_spa” | “我有一个 GPCR-Gi 复合物在 MSP nanodisc 中的 K3 movie，帮我解析结构。” |
| “run alphafold3” | “预测这个蛋白的结构，并把它的 ATP 配体一起共折叠（co-fold）进去。” |
| “run sarek” | “对这个三口之家（先证者 + 父母）的 WGS FASTQ 文件做胚系变异检测。” |

### 一开始就把背景讲清楚，能省不少时间

你在开头交代得越充分，BioMate 需要追问的澄清问题就越少：

**信息最少（会追问）：**
> “处理一下我的冷冻电镜数据。”

**信息完整（可直接运行）：**
> “我有 2000 张原始 movie（.tif），来自 300 kV 的 Titan Krios，0.83 Å/pix，样品是 GDN 去污剂中的 CaV1.2（约 400 kDa）。跑标准 SPA，给我最终的密度图。”

### BioMate 会自动处理哪些事

- 当你的目标有多条可行流程时，替你做出选择
- 根据样品情况设定合适的默认参数
- 在采集数据之前提醒你哪些情况必须先做功能验证实验
- 识别提问中的歧义（例如“变异检测”—— 究竟是胚系还是体细胞？）

## 4. 输入

### 支持的文件类型

| 类别 | 格式 |
|---|---|
| 原始冷冻电镜 movie | `.tif`、`.mrc`、`.eer` |
| 电子密度图 | `.mrc`、`.map` |
| 蛋白结构 | `.pdb`、`.cif`、`.mmcif` |
| 序列 | `.fasta`、`.fa` |
| 短读长测序数据 | `.fastq`、`.fastq.gz`、`.bam`、`.cram` |
| 变异文件 | `.vcf`、`.vcf.gz` |
| 小分子 | `.sdf`、`.mol2`、SMILES 字符串 |
| 数据表 / 元数据 | `.csv`、`.tsv`、`.xlsx` |
| 质谱 | `.mzML`、`.mzXML` |

### 提供输入的几种方式

**拖拽上传** —— 把文件粘贴或拖到聊天窗口里。

**引用已有文件** —— 如果你之前跑过 BioMate 工作流，那次运行的输出可以直接作为后续工作流的输入。只需说“用我上次运行得到的那个结构”即可。

**云端路径** —— 在消息里直接给出 S3（`s3://bucket/key`）或其他云存储 URI。

**登录号（accession）** —— 对于公共数据，直接给登录号即可：
> “下载 SRR1518169 并做胚系变异检测。”
> “取 PDB:6DDF，把这些化合物对接到活性位点。”

### 多个输入

对于多样本工作流，你可以一次上传多个文件，或指定一个文件夹路径。BioMate 会将它们作为一个批次处理。

点击 **Edit Parameters**，或者直接在聊天里说出要改什么：

## 6. 运行工作流

### 执行模式

| 模式 | 何时使用 | 速度 |
|---|---|---|
| **Mock / 空跑（dry-run）** | 没有提供数据，或你主动要求 | 瞬间完成 —— 生成合成输出，用于测试 |
| **本地（Local）** | 小数据集、开发调试 | 几分钟到几小时 |
| **云端（AWS Batch）** | 大数据集、GPU 密集型步骤 | 自动伸缩扩容 |

BioMate 会根据数据规模和可用资源自动选择模式。你也可以覆盖它的选择：*“在本地跑这个”* 或 *“提交到云端。”*

### 点击运行之后会发生什么

1. **输入校验** —— 检查文件格式、大小和参数取值范围
2. **流程启动** —— 工作流开始逐步执行
3. **实时进度** —— 每个步骤完成时即时显示，并附带耗时
4. **中间结果** —— 每个步骤一结束，其产出文件就可以取用（不必等整条流程跑完）
5. **完成** —— 收集最终输出、生成 QC 报告、显示下载链接

### 暂停与恢复

如果运行中断，BioMate 可以从最后一个已完成的步骤续跑。只需说：
> “恢复我那个中断的冷冻电镜运行。”

BioMate 会从中断处接着跑，不会重新处理已经完成的步骤。

## 7. 结果与可视化

### 输出类型

| 类型 | BioMate 的呈现方式 |
|---|---|
| **蛋白结构**（.pdb、.cif） | 交互式 3D 查看器 —— 可旋转、缩放，按链或属性着色 |
| **电子密度图**（.mrc） | 密度图查看器 —— 2D 切片导航、等值面（contour）调节 |
| **FSC 曲线** | 交互式图表 —— 高亮标出 0.143 阈值处的分辨率 |
| **数据表**（.csv、.tsv、.json） | 可排序、可搜索的表格查看器 |
| **图像**（.png、.jpg、.svg） | 内嵌显示 |
| **序列**（.fasta） | 带注释的序列查看器 |
| **报告**（.json、.html） | 带关键指标的格式化摘要 |

### 下载输出

每一次完成的运行都会有一个 **Download** 面板，提供：
- **单个文件** —— 点击任一输出即可下载
- **整包下载** —— 把所有输出打包成一个 ZIP 下载
- **云端同步** —— 用一条命令复制到你自己的 S3 桶（命令显示在 Download Commands 面板里）

### 各类流程的输出文件

**冷冻电镜 SPA：**
- `final_map_sharpened.mrc` —— 可用于提交的密度图
- `fsc_curve.png` + `fsc_data.csv` —— 0.143 处的金标准 FSC
- `local_resolution.mrc` —— 逐体素的分辨率估计
- `half_map_A.mrc`、`half_map_B.mrc` —— 用于向 EMDB 提交
- `molprobity_report.txt` —— 结构验证
- `qc_report.json` —— 机器可读的 QC 摘要

**药物发现（对接）：**
- `docked_poses.sdf` —— 带打分的排序构象（pose）
- `binding_affinity.csv` —— 每个化合物的 ΔG 估计
- `admet_report.csv` —— ADMET 面板结果

**基因组学（变异检测）：**
- `variants.vcf.gz` —— 过滤后的变异
- `multiqc_report.html` —— 逐样本的 QC 指标
- `annotated_variants.tsv` —— 功能注释

**结构预测：**
- `predicted_structure.pdb` —— 最优模型
- `confidence_scores.json` —— 逐残基 pLDDT / PAE 矩阵

## 9. 分领域教程

### 9A. 冷冻电镜 —— 单颗粒分析

#### BioMate 能做什么

- 完整的 23 步 CryoSPARC SPA 流程，从原始 movie 一直到可提交的密度图
- 根据分子量和样品类型自动选参
- 粒子挑选：blob picker → TOPAZ 深度学习（用你自己的数据训练）
- 2D 与 3D 分类、ab-initio 重建
- 非均匀精修（non-uniform refinement）、局部 CTF 精修、局部分辨率估计
- 密度图锐化与 FSC 验证
- 结构验证（MolProbity）

#### 典型提问

> “我有 3,000 张 movie（.tif），样品是 GDN 去污剂中的 120 kDa 离子通道。300 kV，0.83 Å/pix，50 e⁻/Å²，共 50 帧。跑完整 SPA，给我一个结构。”

#### 需要指定的关键参数

| 参数 | 为什么重要 |
|---|---|
| **像素尺寸 Pixel size (Å/pix)** | 最关键 —— 采集时就已定下，事后无法修正 |
| **电压 Voltage (kV)** | 通常是 300 或 200 —— 影响 CTF 模型 |
| **总剂量 Total dose (e⁻/Å²)** | 标准取 50-60；对辐照敏感的样品取 40-45 |
| **分子量 Molecular weight (kDa)** | BioMate 据此设定 box size 和欠焦（defocus）范围 |
| **对称性 Symmetry** | 默认 C1；只有在你确定对称性时才设 C2/C4 等 |

#### 像素尺寸速查

| 样品 | 典型像素尺寸 |
|---|---|
| 蛋白 < 60 kDa | 0.649 Å/pix |
| 多数膜蛋白、60-500 kDa 复合物 | 0.83 Å/pix |
| 大型复合物 500-1500 kDa | 1.06 Å/pix |
| 病毒衣壳、核糖体 > 1500 kDa | 1.30 Å/pix |

#### 预期输出

一次典型运行（2,000-5,000 张 movie，30 万粒子）之后，你会得到：
- 分辨率 2.5-4 Å 的 3D 密度图
- 带 0.143 交点的 FSC 图
- 局部分辨率图（高亮出柔性区域）
- 锐化后的密度图，可直接用于在 Coot/PHENIX 中建模

#### 许可证要求

CryoSPARC 需要许可证。首次使用时 BioMate 会提示你填入许可证密钥；保存之后，后续会自动使用。

### 9B. 冷冻电镜 —— 专项流程

#### Saposin Nanodisc SPA（< 60 kDa 的膜蛋白）

**适用场景：** 你的目标是一个小膜蛋白（转运体、通道亚基、受体），由于分子太小、在去污剂中做不出好的 2D class，无法用去污剂体系研究。

**示例：**
> “我在研究 MFSD2B，一个 45 kDa 的脂质转运体，已经把它重构进 saposin nanodisc。跑 SPA。”

**与标准 SPA 的区别：**
- Pixel size 锁定为 0.649 Å/pix（BioMate 会强制执行）
- Dose 设为 60 e⁻/Å²（小颗粒需要更多信号）
- 增加重构质控步骤：BioMate 会在继续之前验证你的 NS-EM nanodisc 尺寸（约 10 nm）和 SEC 谱图
- 用 TOPAZ 深度学习挑选器针对你的数据集训练（单靠 blob picker 会漏掉小颗粒）

**BioMate 会作为输出提供的重构方案：**
- Saposin A 表达与纯化指引
- γ-环糊精（γ-cyclodextrin）脂质递送参数
- Bio-Beads 去污剂去除条件
- 制网格建议（UltrAuFoil，10°C 下吸附 1.5 s）

---

#### GPCR-G 蛋白复合物 SPA

**适用场景：** 研究 G 蛋白偶联受体与 G 蛋白（Gi、Gs、Gq 等）或 arrestin 形成的复合物。这类复合物约 120-150 kDa，需要特定的稳定化处理。

**示例：**
> “我有 μ-阿片受体与 Gi1 的复合物，用 scFv16 稳定，处于 MSP1D1ΔH5 nanodisc 中。解析结构。激动剂用的是 DAMGO。”

**区别之处：**
- BioMate 会验证复合物的组装：scFv16 是否存在、是否确认无核苷酸态（apyrase 处理）、SEC 化学计量比
- 双局部精修：BioMate 分别对受体的 TM 跨膜束和 G 蛋白做聚焦精修，从而让两个结构域都达到最高分辨率
- 支持偏向性激动（biased agonism）研究（并排对比 G 蛋白与 arrestin 的结构）

**BioMate 提供的组装方案：**
- 用 Sf9 杆状病毒同时表达 GPCR 与 G 蛋白
- Apyrase 处理的时机与浓度
- scFv16 的摩尔比与孵育条件
- MSP1D1ΔH5 nanodisc 重构（为什么用 ΔH5 而非完整的 MSP1D1）

---

#### 多药物图谱（药理学研究）

**适用场景：** 你想比较多个化合物的结合情况（例如 7 种药物结合同一离子通道，或 4 个 PAM 作用于同一别构位点）。

**示例：**
> “我有 CaV1.2 分别在无药和加入 7 种不同钙通道阻滞剂条件下的冷冻电镜数据集。生成一份药物图谱，标出每种药物结合在哪里。”

**BioMate 会做的事：**
- 用完全一致的 SPA 流程处理所有数据集（apo + 每种药物）
- 生成“药物减 apo”的差值图（difference map），阈值取 ±3σ
- 验证配体密度的占据度（若某药物占据度 <60% 则报告出来）
- 输出一份并排对比的图谱

**关键要求：** 所有数据集必须用完全相同的参数采集（相同的像素尺寸、欠焦范围、剂量）。若参数不一致，BioMate 会向你告警。

---

#### 冷冻电子断层扫描 Cryo-ET（原位 / 胞内结构）

**适用场景：** 你的蛋白无法纯化（镶嵌于膜、属于细胞骨架、或是某个细胞机器的一部分），或者你想在其天然的细胞环境中研究它。

**示例：**
> “我有一批倾斜序列（tilt series），来自表达我这个激酶的细胞、经 FIB 减薄的薄片（lamellae）。做子断层平均（subtomogram averaging）。”

**流程步骤：**
- 倾斜序列导入与质量评估
- 倾斜对齐（AreTomo2）
- 断层重建（加权反投影）
- 子断层平均

**输出：** 平均后的子断层密度图、角度分布图、FSC。

---

#### 构象异质性（3DVA）

**适用场景：** 你的蛋白有柔性区域、存在多个构象状态，或你怀疑存在功能中间态（例如转运体的内向开放态 vs 外向开放态）。

**示例：**
> “我处理完剪接体数据集，得到了一个 3.5 Å 的结构。现在我想在同一个粒子集里把不同的激活态解出来。”

**BioMate 会做的事：**
- 直接以你现有的、已精修的粒子集为输入（无需重新采集）
- 运行 3D 可变性分析（3DVA），对粒子取向做 PCA
- 输出 5-6 个离散的状态体积图，展示构象变化轨迹
- 之后你可以对任何一个感兴趣的状态单独精修

### 9C. 药物发现

#### 典型的信息流

```
靶蛋白结构（或先预测一个）
        ↓
结合位点检测（P2Rank/fpocket）
        ↓
化合物库（SDF / SMILES 列表）
        ↓
分子对接（DiffDock / AutoDock Vina / Glide）
        ↓
ADMET 筛查（hERG、DILI、Ames、BBB 等）
        ↓
先导优化（REINVENT4 生成式设计）
        ↓
MD 模拟（GROMACS） → 结合亲和力（MM-GBSA）
```

#### 让 BioMate 跑完整条流水线

> “我有一个激酶的 AlphaFold 模型。把这 50 个化合物拿去筛，看它们与 ATP 位点的结合，剔掉有 hERG 风险的，再给剩下的排个序。”

BioMate 会自动把各个工作流串起来：口袋检测 → 对接 → ADMET 面板 → 排序输出。

#### 对接前先做结构预测

如果你手头没有实验结构：
> “先预测这段蛋白序列（FASTA 已附）的结构，再把这些配体对接到最可能的结合口袋里。”

BioMate 会根据你的情况选择预测工具：
- **AlphaFold3** —— 当前最先进，支持配体共折叠（需要机构账号）
- **Boltz-2** —— 开放权重，对许多靶点精度相当
- **Chai-1** —— 无需账号，适合快速筛查

#### ADMET 筛查

> “对这 200 个化合物跑完整的 ADMET 面板。”

输出包括：hERG IC₅₀ 预测（心脏安全性）、DILI 肝毒性评分、Ames 致突变性、血脑屏障（BBB）通透性、口服生物利用度估计、代谢稳定性。结果以排序表呈现。

#### 生成式先导优化

> “拿我对接得分最高的那个化合物，生成 50 个类似物，在保留核心骨架的前提下优化 BBB 穿透性。”

REINVENT4 会用强化学习设计新分子，并按类药性（Lipinski）和新颖性做过滤。

#### MD 模拟与结合亲和力

> “对我排名前 3 的化合物在 ATP 结合位点做 100 ns MD 模拟，并计算结合亲和力。”

GROMACS 流程会输出：
- RMSD/RMSF 稳定性图
- MM-GBSA ΔGbind 估计（kcal/mol）
- 结合构象轨迹（在 BioMate 中可视化）

#### 需要许可证的工具

| 工具 | 许可证类型 |
|---|---|
| Schrödinger Glide | Schrödinger 许可证服务器（机构） |
| MOE 共价对接 | Chemical Computing Group 许可证 |
| AMBER pmemd.cuda | AMBER 许可协议 |

BioMate 会提示你填写许可证信息。开源替代方案（GROMACS、AutoDock Vina、DiffDock）始终可用，无需许可证。

### 9D. 结构生物学 —— 结构预测与对接

#### 预测蛋白结构

> “预测这段序列的结构。”

或

> “预测这个激酶与其 ATP 配体共折叠后的结构。”

如果不清楚，BioMate 会先问：PDB 里是否已有实验结构？如果有，它会直接取来用，而不是去预测。

#### 比较两个结构

> “比较我这个通道的 apo 态和结合药物态的结构。RMSD 是多少？最大的构象变化在哪里？”

输出：叠合图像、逐残基 RMSD、TM-score、高亮标出的偏差区域。

#### 对接

> “把 verapamil 对接到这个 CaV1.2 结构的中央腔里。”

输出：按打分排序的前 5 个构象、每个构象的 3D 交互视图、预测的结合亲和力。

#### 别构位点识别

> “找出这个 GPCR 结构上所有潜在的药物结合位点。”

P2Rank 会对所有表面口袋打分，BioMate 会按体积和保守性高亮标出最具成药性的位点。

### 9E. 基因组学 —— 变异检测与 RNA-seq

#### 胚系变异检测

> “对这个三口之家（先证者 SRR1234、父亲 SRR1235、母亲 SRR1236）的 WGS FASTQ 文件做胚系变异检测。”

流程：nf-core/sarek（GATK HaplotypeCaller） → de novo 变异检测 → 带遗传模式的 VCF。

输出：过滤后的 VCF、注释后的 TSV（基因、后果、gnomAD 频率）、MultiQC HTML 报告。

#### 体细胞变异检测（肿瘤/正常）

> “对这些配对的肿瘤/正常 WGS 样本做体细胞变异检测。”

流程：Mutect2（配对模式） → 过滤 → SBS 突变特征。自动计算 TMB。

注意：只要有配对正常样本就一定要提供。仅肿瘤（tumor-only）模式的假阳性率更高。

#### RNA-seq 差异表达

> “我有 3 个处理组和 3 个对照组的 RNA-seq 数据。找出差异表达（differential expression）基因。”

流程：nf-core/rnaseq → DESeq2 或 edgeR → 火山图、热图、GO 富集。

输出：差异表达基因表（log2FC、校正后 p 值）、通路富集、PCA 图。

有些工具需要机构或个人许可证。BioMate 通过一个凭据库（credential store）统一管理这些许可证。

当 BioMate 检测到某工具需要许可证时：
1. 工作流卡片上会出现一个**许可证门（license gate）**
2. 点击 **Add License**，填入你的凭据（许可证密钥、服务器 URL 或 Docker 认证令牌）
3. 凭据会被安全存储，供后续运行复用
4. 你可以在 **Settings → Licenses** 里管理凭据

### 需要许可证的工具

| 工具 | 你需要准备什么 |

## 11. 使用技巧与最佳实践

### 宁多讲，勿少讲

你给出的科研背景越充分，BioMate 表现得越好。请尽量包括：
- 分子量或复合物组成
- 样品制备方法（nanodisc 类型、去污剂、稳定剂）
- 数据采集参数（如果已经采集）
- 你要回答的科学问题（结构、机制、药物结合、异质性）

### 千万别跳过功能验证实验

对于膜蛋白、GPCR 和成孔蛋白：
- 在投入冷冻电镜数据采集之前，**先确认样品是有功能的**
- BioMate 会问：“你的转运/电流/裂解实验通过了吗？”
- 无功能的样品，无论数据质量多好，都做不出好的 2D class

### 先用 NS-EM 验证样品

对于 nanodisc 重构和复合物组装：
- NS-EM（负染电镜）只需 1-2 小时，却能避免白白浪费冷冻电镜机时
- BioMate 的重构质控步骤可以自动分析你的 NS-EM 图像
- 预期 nanodisc 尺寸：saposin 约 10 nm，MSP1D1ΔH5 约 9 nm

### 粒子越多，分辨率越高（无一例外）

| 目标分辨率 | 最少粒子数 |
|---|---|
| 4-5 Å（可见二级结构） | 50,000 |
| 3-4 Å（可见侧链） | 100,000 |
| < 3 Å（高分辨率） | 200,000+ |

如果粒子不够，BioMate 会建议重新采集，或改用其他挑选策略。

### 多药物研究：先采 apo

在采集任何加药数据集之前，先采好 apo（无配体）数据集。用 apo 结构来：
1. 验证你的采集参数
2. 生成模板，供加药数据集做基于模板的挑选
3. 确立参考，供差值图相减使用

所有数据集必须使用完全相同的采集参数，差值图才有效。

### 用中间输出来做决策

你不必等整条流程跑完。跑到第 9 步（2D 分类）之后：
- 如果 2D class 显示出清晰的二级结构 → 继续
- 如果 2D class 毫无特征 → 停下，调整浓度或更换吸附条件
- 如果粒子数偏少 → 用 TOPAZ 重新挑选

可以问 BioMate：*“第 9 步的 2D class 看起来很糊，我该试试什么？”*

### 用描述性命名把数据集整理好

BioMate 会保存运行历史。给你的运行起个有描述性的名字：
> “saposin_nanodisc_mfsd2b_0649_60dose_apr2026”

这样以后引用、恢复之前的运行都会很方便。

## 附录 —— 常见失败模式与解决办法

| 现象 | 可能原因 | 该怎么办 |
|---|---|---|
| 2D class 毫无特征 / 呈圆形 | 样品聚集、浓度不对，或冰层质量差 | 用 NS-EM 优化浓度；试试更低的蛋白浓度 |
| CTF 估计失败 | 冰太厚，或填错了像素尺寸 | 核对采集元数据里的像素尺寸；重新制备更薄的冰 |
| 挑出的粒子很少 | blob picker 参数与你的颗粒尺寸不匹配 | 改用 TOPAZ；调整颗粒直径估计值 |
| 分辨率停在 4-5 Å 上不去 | 粒子太少，或存在取向偏好 | 采更多数据；尝试倾斜台采集 |
| 某个结构域局部分辨率差 | 该结构域比较柔性 | 用软 mask 对该结构域做聚焦局部精修 |
| 药物差值图上没有密度 | 占据度低，或归一化方式不对 | 核对药物浓度相对 Kd 的比例；确保采集参数完全一致 |
| 流程在 GPU 步骤失败 | GPU 显存超限 | 减小 batch size，或换用更大的实例类型 |
| 结构验证不过关（MolProbity > 2.5） | 密度图分辨率不足以支撑建模，或存在原子碰撞 | 采更多数据；多跑几轮实空间精修 |
