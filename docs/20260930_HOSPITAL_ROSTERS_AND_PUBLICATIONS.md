## A3 · Summary & key contacts
**Signature.** World's leading NPC center: a run of practice-changing Phase-III trials (GP induction NEJM 2019; PD-1 combos CAPTAIN-1st/JUPITER-02/DIPPER/PLATINUM; RT de-intensification) + a deep EBV tumor-virology program in the State Key Lab that serially defined the **EBV epithelial-entry machinery — NRP1 (2015) → EphA2 (2018, solved structure PDB 7CZE) → R9AP (Nature 2025)** + EBV vaccines, layered over strong NPC single-cell/spatial multi-omics and EBV-serology/ctDNA early-detection. Author-level affiliation checking is essential (the NPC-WGS NF-κB and one 2018 EphA2 paper are NOT SYSUCC).

**Key contacts:**
- **(i) EBV-entry-receptor peptide work → 曾木圣 / Zeng Mu-Sheng** (CAS Academician, VP): owns the entire NRP1→EphA2→R9AP franchise, has a **solved EphA2–gHgL structure (PDB 7CZE/7CZF)** for structure-based design, and **already demonstrated an R9AP-derived entry-inhibiting peptide** (Nature 2025). Working-level co-PIs: **钟茜 / Zhong Qian**, **徐淼 / Xu Miao**.
- **(ii) Tumor-target / TME peptide work → 贝锦新 / Bei Jin-Xin** (genomics + single-cell/spatial TME target nomination), **康铁邦 / Kang Tiebang** (exosomes/metastasis/drug-resistance targets), **钟茜 / Zhong Qian** (TLS/immune-escape). Clinical translation: **张力 / Zhang Li** (Phase-I Unit, China's #1 first-in-class ward) and **徐瑞华 / Xu Rui-Hua** (President; CSCO President; toripalimab + ADC programs).
