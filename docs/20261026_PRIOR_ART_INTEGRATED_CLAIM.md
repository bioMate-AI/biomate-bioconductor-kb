# Prior-art check on the integrated claim (2026-10-26)

**Scope and limits.** Five parallel web searches (standard/extended), then abstract-level reads of the closest hits. Full text was NOT read for any paper below; UnibindMD's PDF fetch was rate-limited (HTTP 429). Absence of a paper in these searches is NOT proof of absence. Treat every "gap" as UNVERIFIED until a systematic search (PubMed/bioRxiv/arXiv/Google Scholar with a librarian-style query log) is done.

## The claim being tested
A generator proposes cyclic-peptide candidates → a ladder of verification tiers (rules, structure, developability, affinity) → every tier calibrated against measured data and able to abstain → learning only from verified rewards → better calibrated shortlists than a confidence-only pipeline, on held-out documents/receptors.

## Verdict
- **"Ladder + LLM + verifiable rewards" is NOT novel as a concept.** Each ingredient has a published instance, and an integrated pipeline (UnibindMD) was posted 3 days before this check. A paper whose only claim is "we integrated knowledge, rules and computation" will not clear a high-end journal.
- **Defensible white space (all UNVERIFIED until a systematic search):**
  1. *Measured reliability of each tier for cyclic peptides under held-out evaluation* — reliability diagrams, coverage–precision/abstention curves — none of the abstracts above report calibration or abstention.
  2. *Co-folding confidence is unreliable for cyclic complexes* (pilot: default 80.8 % vs random 80.3 % vs oracle 96.2 %, n=26) and a selector trained on solved complexes, tested post-cutoff across receptors (Stage B).
  3. *Metal-dependent integrin binding* (MIDAS Mn) with FEP calibrated against measured series (A1/A2 + 542 ChEMBL αvβ6 compounds) — only if the physics validates.
  4. *Document-level held-out ChEMBL αvβ6 evaluation* of affinity tiers (35 documents) — an evaluation protocol others can reuse.
- **Therefore the paper's claim must be evidential, not architectural:** "which verification signals can be trusted for cyclic-peptide design, quantified under held-out evaluation, and a ladder that uses those measured reliabilities to abstain." The ladder is the vehicle; the measured reliability is the contribution.

## To close before any novelty wording
Read full texts of UnibindMD, the cofolding-guided cyclic design preprint, PepThink-R1, MF-LAL, LLMol; run a logged systematic search; check for cyclic-peptide co-folding selectors and integrin FEP specifically.
