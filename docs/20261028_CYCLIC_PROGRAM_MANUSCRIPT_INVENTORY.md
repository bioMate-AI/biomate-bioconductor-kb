## F. Working structure (owner, 2026-10-28): the three projects are one loop-based study
Single claim to test: **the closed loop (knowledge + rules + verified feedback) improves the cyclic-peptide LLM.** Parts:
- Model: v4 → v5 (workstream 1; audit `20261028_V4_LLM_AUDIT_AND_EVAL.md`, prereg `20261028_V5_PREREG_AND_LOOP_INTERFACE.md`).
- Loop: controlled GBM loop L5 + LLM-in-the-loop replay L7 with controls (data-matched one-shot, random feedback, shuffled labels, frozen, knowledge-off) (workstream 2; `PREREG_LOOP.md` L5–L7).
- Instrument: multi-target retrospective benchmark, held out by target family (workstream 3; `20261028_AVB6_RETROSPECTIVE_RECOVERY_PREREG.md` + A1).
Manuscript outline (one paper; separate drafts merge into it): Intro/thesis · Benchmark and evaluation design (controls, contamination, audits) · Model v4→v5 · Loop and ablations · Results with controls · Limits (retrospective only assays measured compounds; generation validity needs wet lab). The governance/RSI paper (`20261028_MANUSCRIPT_cyclic_peptide_closed_loop_RSI.md`) remains the companion framing paper; topology decision (one vs two) stays the owner's.

### F.1 Evaluation design as part of the manuscript (owner, 2026-10-28)
The family-disjoint evaluation is part of the paper (Methods + stated contribution), not a side detail. Components, each already built and audited in workstream 3 (`research/guangzhou_all_atom/multitarget/integrin_chembl/retro_recovery/`, results `docs/20261029_RETRO_RECOVERY_RESULTS_V2.md`): target-family-disjoint folds (size-balanced, `folds_v1.csv`, sha256 a896c580…c5c409, amendment A6); positives/decoys frozen with hashes before any scorer ran; same-target measured inactives as the primary analysis (I) and matched cross-target decoys (M2) after the naive cross-target analysis (M) was shown to be decided by a similarity shortcut (nearest-neighbour baseline AUROC 0.914 → 0.530 under matching); contamination flags for the pretraining corpora (58 % / 45 % of positives in the atom-LM corpus) with contamination-controlled reporting; stereoisomer/flat-structure grouping; pre-registered decision rules with positive controls. Prior-art check for the design is still to be done before claiming it as novel.

## G. Which earlier loops count as retrospective closed-loop evidence (owner, 2026-10-30; classification verified from script docstrings)
Retrospective replays on REAL measured data — cite as retrospective closed-loop validation, labelled as such, with their limits:
- `c2_retro_loop.py` (+ S3 `c2_loop/out/c2_stdout.txt`): within-target active learning on measured pAff, cluster-disjoint cut, random and fixed-model baselines; log ends `learn 0.299 / random 0.118 (+0.181, p=0.002)`, 10 targets, 28,875 affinities — **to be reproduced and audited (workstream 7) before citing numbers**; analog hit-expansion caveat.
- `replay_permeability.py` / `results/permeability_replay.json`: within-publication finite-library replay against hidden PAMPA labels (2020_Townsend, 2021_Kelly, 2024_Faris; 20 initial labels, 5 rounds × 10, 3 seeds; random vs forest mean + SD; molecule-disjoint 80/20 pool/test split); small scale; designed to avoid the cross-lab confound.
- L3/L5/L7 (this study): within-source permeability loop with controls.
NOT validation (integration test only, per its own docstring): `simulate_closed_loop.py` (SIMULATED assay → platform persistence → DPO; 'not evidence of biological improvement') and the SIMULATED fixtures behind `wetlab_kd_to_pairs.py` / `campaign_assay_to_pairs.py`.
