# An ncAA-native, multi-conditioned cyclic-peptide language model inside a rule- and knowledge-constrained design system: a controlled audit and a pre-registered held-out-family evaluation

*Working manuscript — computational study, no wet-lab validation. Draft 2026-10-28. Every number is tagged **[V]** (reproduced or measured in this draft's audit, `docs/20261028_V4_LLM_AUDIT_AND_EVAL.md`), **[P]** (from an earlier project document, not re-verified here) or **[PENDING]** (pre-registered, not yet run). No result tagged [PENDING] may be cited.*

## Abstract
Cyclic peptides used as drugs rely on N-methylated, D- and other non-canonical residues that character-level sequence models over 20 amino acids cannot represent. We describe a single autoregressive model (v4) over a 393-token monomer vocabulary (363 non-canonical monomers) conditioned on a target-protein descriptor, an enrichment bucket and a permeability bucket, trained on the union of a measured-permeability set (CycPeptMPDB) and mRNA-display enrichment pools for five targets, and the system it sits in: rule constraints, a curated knowledge base, a verifier/reward chain and preference tuning. We report first what survives a controlled audit. The stored per-target binding AUCs (0.70–0.98) reproduce exactly [V], but against the non-binder rows that share the model's own high-enrichment bucket the AUC is at chance on four of five targets (0.44–0.58; PADI4 0.66) [V], a trivial abundance sort scores 0.996–1.0 [V], and swapping the target descriptor changes the score little on three targets [V]; the permeability "gain" is scored by a regressor with cross-validated R² 0.069 [V], and the non-canonical fraction of generations (65.7–67.6 %) equals that of the training data (65.1 %) [V]. We then pre-register a held-out-target-family evaluation across 17,120 peptide macrocycles and hundreds of targets in which v4, a rule-constrained variant, a knowledge-conditioned variant, a chain-verified variant and DPO-tuned variants are compared with abundance, composition, size, RGD-motif and nearest-neighbour baselines. **[PENDING: results.]** The contribution is a representation and system whose claims are bounded by positive and negative controls, not a performance record.

## 1. Introduction
Approved cyclic-peptide drugs are rich in N-methyl, D- and unnatural residues, and none originated from de novo computational design [P: `docs/20261001_CYCLIC_PEPTIDE_SOTA_LANDSCAPE.md`]. Three questions follow for an own-model program: can one model be ncAA-native and conditionable on target and property; does the model carry binding information beyond what a read-count sort or composition gives; and do rules, knowledge and verification add anything to the bare model on targets it has not seen? We answer the first by construction, the second by audit, and set up the third as a pre-registered test.

## 2. System
**Model (v4).** 5.02 M-parameter decoder (6 layers, d = 256), monomer vocabulary of 393 tokens, input `[e-bucket, p-bucket, <bos>, monomers…, <eos>]` preceded by a target-descriptor prefix (24-d composition/charge/hydrophobicity vector of the target protein); trained 4,000 steps × 128 on 1,148,290 union examples (CycPeptMPDB oversampled to balance 560 k canonical display rows) [V: checkpoint arguments]. Binding is scored as LLR = log P(seq | target, e_hi) − log P(seq | target, e_lo); permeability is controlled by the p-bucket.
**Rules and knowledge.** Hand-coded αvβ6 gates (RGDL, D-Pro + N-Me turn, aromatic flanks, single Lys handle); a greedy conjunction learner over nine RGD/αvβ6/PD-L1 predicates; a rule-conditioned *enumeration* of a fixed αvβ6 scaffold that the code itself calls a stand-in for the neural generator; a general medicinal-chemistry KB (liability alerts, metal coordination, physchem, pharmacophore-by-class, modality) with ≈15 curated target instances [V: code read].
**Chain.** propose → score(tier) → select → revise, with a deterministic symbolic `revise`, a hand-weighted reward, Batch-dispatched cofold, a read-only physics tier (αvβ6 MM-GBSA voided: metal dropped, no anchoring control), an execution grader and reward store, and DPO from the loop's preference pairs [V: code read]. Which of these run in each evaluated arm is tabulated in the audit document §3.

## 3. Audit of the base model (all [V]; `v4_eval/`)
**Reproduction.** Rebuilding the split and the vocabulary from the checkpoint reproduces the stored AUCs exactly (PADI4 0.942, hPCSK9 0.804, FIKK13 0.835, Abeta42 0.982, hIAPP 0.700).
**Pipeline controls.** Run end to end on synthetic data, the production code detects a planted motif (AUC > 0.9) and returns chance on label-shuffled data (0.40–0.60); scoring and training use the same token alignment.
**Split.** Every flagged binder is in the test set and none is in training; the high-enrichment bucket the model learns is the low-count tail (PADI4: 6,852 such training rows against 394 test binders). Test negatives are mostly random low-enrichment rows (hard negatives: 51, 161, 11, 19, 18 per target).
**What the AUC measures.** Against hard negatives: PADI4 0.66, hPCSK9 0.50, FIKK13 0.57, Abeta42 0.58, hIAPP 0.44. A sort by log2 fold-change scores 0.996–1.0 overall and 0.95–1.0 against hard negatives. A composition logistic regression (cross-validated inside the test set, favourable to the baseline) reaches 0.69–0.94; v4 exceeds it by about 0.00–0.13. Swapping the enrichment conditioning gives 1 − AUC on all targets. Replacing the target descriptor with another target's keeps 0.84, 0.92 and 0.81 on PADI4, Abeta42 and FIKK13 (correct prefix 0.94, 0.98, 0.84) but drops hPCSK9 from 0.80 to 0.52 and hIAPP from 0.70 to 0.55; the descriptor takes five distinct values in training.
**Permeability head.** The generated-versus-conditioned permeability difference (+0.47) is scored by a composition-only random forest fit on 1,269 peptides (cross-validated R² 0.069); applied to real high- and low-permeability peptides it yields +0.53 against a measured +1.47. 9.1 % of the evaluation peptides occur verbatim in the language-model training set (69 % after collapsing D/N-methyl); 34.7 % of the data are lariat, not head-to-tail, and the model has no topology token.
**Non-canonical content.** The training data are 65.1 % "non-canonical" by the metric used (21.7 % N-methyl and 16.0 % D forms of canonical residues, 27.6 % other); generations are 65.7–67.6 %, i.e. no enrichment beyond the data. "Validity 1.0" is token-level.
**Preference tuning.** The two DPO checkpoints optimise permeability only (null target); their binding LLR ranks correlate 0.9998–0.9999 with v4 and their AUC is unchanged [V]. Their permeability gain is +0.098 (6/6 seeds, shuffled-reward placebo +0.015) on a composition regressor that shares features with the reward; 68–72 % of generated peptides are verbatim training peptides before and after [V].
**Prior evidence.** Within-target selection beats composition baselines on PADI4 but not an abundance null, and leave-one-target-out transfer is null; the leakage audit finds memorisation on 3 of 5 targets [P: `20261021_CYCLIC_LLM_PAPER_DRAFT.md`; `20261027_SELECTOR_LEAKAGE_AUDIT.md`]. Structure fine-tuning did not beat the base co-folding model on any held-out target [P: capstone §3].

## 4. Pre-registered held-out-family evaluation

## 5. Limitations
Computational only; the display labels are enrichment thresholds, not affinities; five display targets; the generator itself is not evaluated on binding; the benchmark covers the minority of compounds the converter can express in the v4 vocabulary; knowledge-base entries are curated from the same literature as many benchmark positives, so knowledge arms cannot support a held-out claim on KB-covered targets; the unified-selector "rescue" result is not yet audited (DPO audited in the audit document §6: permeability-only, no effect on the binding score); the chain's GPU physics tier is not run at benchmark scale.
