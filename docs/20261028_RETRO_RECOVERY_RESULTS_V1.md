# Multi-target retrospective recovery study — V1 results (2026-10-28)
Pre-registration: `docs/20261028_AVB6_RETROSPECTIVE_RECOVERY_PREREG.md` (§9 A1, §10 A2, §11 A3, §12 A4). Code/data/results: `research/guangzhou_all_atom/multitarget/integrin_chembl/retro_recovery/`. Frozen set committed before any scorer ran (A2 commit `7d555f46e`); arms/baselines fixed in A3 (commit `2d4ebffe5`) before scoring.

## 1. Headline
**No arm was SUPPORTED in any analysis or subset.** Primary analysis I (same-target measured inactives; 46 targets, 26 families, AUROC): S1a rules 0.494, S1b-KB 0.500 (constant on all but one target), S1b-induction 0.518 [0.458, 0.581] against the strongest baseline B3_nn_neg 0.620 [0.561, 0.675]; differences −0.125 / −0.120 / −0.101 (all NOT_SUPPORTED). Analysis M is design-confounded (A4): a similarity-to-other-target-binders shortcut scores AUROC 0.914 and EF5 11.7, so no knowledge arm can be adjudicated there. The knowledge available as a **computable** SMILES gate is one rule (RGD for integrin-MIDAS targets); on αvβ6 targets it equals the trivial B1_rgd baseline (AUROC 0.826, EF5 6.6 in M) — it adds nothing beyond it. S2 (physics chain) and S3 (v4 / atom-LM) were **not run** (S2: cost estimate only; S3: awaiting score files).

## 2. Study set (frozen; `data/FROZEN_HASHES.json`)
16,195 compounds / 14,599 flat structures (strata: 13,783 ncAA-peptide, 2,101 other macrocycle (<4 α-units), 311 canonical peptide); 30,310 (compound, target) pairs → 20,562 positive (≤1 µM), 4,021 inactive (>10 µM), 5,701 gray, 26 conflicts; 793 targets in 317 Pfam-Jaccard families. M: 299 targets / 120 families / 8,033 positives / 165,516 items. I: 46 targets / 26 families / 7,600 positives / 9,432 items (positive-heavy → AUROC primary). 55 % of eligible positives lost their matched decoys (heavier tail, enriched in canonical peptides).

## 4. BioMate components: ran vs bypassed (`results/component_log.json`)
Ran: `experience_kb.all_entries` (resolved 8 KB targets, entry ids logged; 8–16 entries each; only the integrin-MIDAS pharmacophore entry is computable → RGD gate for avb6/a4b1/a4b7); `rule_induction.induce` (unchanged learner, SMILES predicates substituted; 100 few-shot resamples per family, from other-family data only; induced rules in `results/induced_rules_I.json`); `target_kb` examples (S1b-leaky diagnostic only). Audited, not run: `medchem_kb*` (no binding signal; ingested JSONs hold no structures), `acceptance_gate` / `pharmacophore_knowledge` / `knowledge_liability_flags` (HELM input; only the RGD predicate maps to SMILES), `score.py` / `scorer_config` (expensive tier needs a prepared receptor: αvβ6 only), chain `loop.py`/`loop_batch.py` → `physics_batch` → `execution_grader` (S2; cost estimate in PREREG §11.4, not executed), BioMate workflow DB (docking/QSAR/boltz/OpenFE workflows listed; need per-target receptor or per-target training data), multi-source data layer (bypassed; table already merges BindingDB + ChEMBL). KB coverage of study targets: ≈ 15 of 344 eligible (8 KB targets mapped; 1 in analysis I).

## 5. Errors found and corrected (audit trail)
1. Family rule v0 (share any non-promiscuous Pfam) chained 356/793 targets; rejected before scoring (Jaccard ≥ 0.67 adopted). 2. Stratum classifier defects found by validating against HELM truth on 7,967 CycPeptMPDB structures (peptoid N-alkyl, D-Pro, β-amino-acid backbones missed; N-methyl-only rule) → fixed + tests; final ncAA recall 98.3 %. 3. Test-helper bug (cyclised through the Asp side chain) and hand-written SMILES with wrong stereo/order → tests rebuilt from sequences. 4. UniProt REST silently returned header-only for a batch of 60 accessions (60 missing) → smaller-batch fallback; malformed accession string 'Q15116 P01857'. 5. NaN gene names crashed the build (fixed). 6. `03_run_arms.py`: compound universe omitted inactive reference compounds (KeyError in smoke); fixed. 7. **KB RGD-requirement detector matched PD-L1's FTO-genus text (true for all 8 KB targets)** → replaced by the integrin-MIDAS pharmacophore-entry criterion before the full run. 8. Analysis M shortcut (A4) verified not a bug by independent recomputation.

## 6. Verified facts vs caveats
Verified: labels/set construction logic (unit tests, HELM validation, hash-frozen lists); harness metrics (equal to scikit-learn; planted-signal and shuffled-label controls pass on real items); B3 independently recomputed. Caveats: Pfam-Jaccard families are not sequence-identity families; stereoisomer series are collapsed only at the positive/decoy level; ChEMBL/BindingDB annotation bias (shortcuts B3/B4) limits any public-data retrospective; I is small (26 families); gray-zone (1–10 µM) compounds are excluded; assay types pooled (Ki/Kd sensitivity shown); 'peptide' stratum is small.
