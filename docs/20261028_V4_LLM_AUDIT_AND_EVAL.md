## 2. Audit of the symbolic-neural / knowledge / chain components (read-only audit; run results in §4)
| component | what it is (code read) | consequence for the evaluation |
|---|---|---|
| `rule_induction.py` | greedy conjunction over **9 hard-coded RGD/αvβ6/PD-L1-specific predicates** (`has_rgdl`, `flank_aromatic_p1`, D-Pro turn…), input HELM, induced from `target_kb/<t>.json` examples (only avb6, pdl1 run) | not a general ILP learner; defined for 2 targets; examples come from the published binders (circular for "recovery of published αvβ6 binders") |
| `rule_conditioned_generator.py` | self-described **stand-in**: enumerates a fixed αvβ6 scaffold `cyclo(p1-R-G-D-L-p6-p7-[dP]-[NMeK])` over short free-position lists, then filters by gate/FTO | not a generative model; the neural generator is not in this path; cannot score arbitrary compounds |
| `acceptance_gate.py`, `pharmacophore_knowledge.py` | hand-coded αvβ6 hard gates (RGDL, D-Pro + N-Me, aromatic flanks, one Lys handle); `pharmacophore_knowledge` records that the v4-generated αvβ6 set was **mechanistically dead (0/12 contain RGD or Asp)** | direct evidence that bare v4 does not reach αvβ6 chemistry without knowledge; but the gate *is* the published-ligand motif, so recovering published αvβ6 binders with it is definitional, not predictive |
| `experience_kb.py`, `medchem_kb.py` | general KB: D1 liability (RDKit FilterCatalog, 1,585 alerts), D2 metal coordination, D3 physchem/ADMET rules, D4 pharmacophore-by-class (**partially curated**), D5 modality heuristics; instance assets `target_kb/*.json` (≈15 targets) | D1/D3/D5 are target-agnostic and usable on every compound; D4/target_kb are target-specific, curated from literature that contains the benchmark's positives |
| `design.py` | target in → v4 generation conditioned on (target, e_hi, p_hi) → rank by the v4 LLR | = the bare v4 arm; no rules, no physics |
| `loop.py`, `loop_batch.py`, `reward.py` | loop with a deterministic **symbolic stand-in** `revise` (labelled no LLM/RL); batch seam dispatches cofold per missing candidate; reward = gates ∧ FEP/MM-GBSA terms; builds DPO pairs | the verifier tier that needs GPU is not run at benchmark scale; reward is a hand-weighted sum |
| `physics_dispatch.py` | **reads** precomputed result files; αvβ6 MM-GBSA is VOIDED (metal dropped, no anchoring control → A2 fail): "no admissible αvβ6 ΔG exists" | the chain's physics tier has no admissible αvβ6 output to use; the expensive tier is bypassed unless new cofold runs are made |
| `execution_grader.py`, `graded_run_store.py` | tier ladder (crashed→…→pass) and SQLite reward store | grades runs that were produced; offline for a retrospective list |
| `v4_dpo`, `v4_dpo_rc` | DPO-tuned v4 checkpoints from graded pairs | scorable with the same adapter (zero extra cost) — arm A6/A7 |

## 4. PRE-REGISTRATION — v4 / system arms (committed before any benchmark scoring)
Inherits `20261028_AVB6_RETROSPECTIVE_RECOVERY_PREREG.md` §3–§5, §8–§9 (A1): target-family holdout, positives ≤ 1 µM, decoys per §9, baselines B0–B3 + nearest-neighbour-to-other-targets + size/charge, EF5 (primary) and AUROC with target-cluster bootstrap B = 2000, decision rule §5. Adds:
1. **Scoring rule:** all arms are zero-fit on benchmark labels. A1 score = LLR(e_hi vs e_lo | target prefix from the UniProt sequence), mean over backbone rotations for cyclic peptides. Compounds are scored only if the SMILES→monomer conversion (`smiles_to_monomers.py`) is **complete** and every token is in the v4 vocabulary; otherwise unscored. Coverage (scored / total, per target and per class) is reported beside every metric; the primary metric is computed on the scored subset **and** every baseline is recomputed on the same subset. Validation of the converter on CycPeptMPDB (held-out half, dictionary learned on the other half): 100 % exact on the 31.3 % fully mapped; 76.0 % mean unit coverage.
2. **Held-out and contamination:** v4 saw display data for PADI4, PCSK9, FIKK13, Aβ42 and IAPP and CycPeptMPDB peptides. Benchmark targets in those families are **in-family, excluded from the held-out claim** (reported separately). Any benchmark compound that is identical (canonical SMILES) or Tanimoto ≥ 0.9 to a CycPeptMPDB peptide or to a display-derived monomer string is flagged and excluded from primary metrics. The atom LM's ChEMBL pretraining corpus contains the benchmark's compounds by construction; A2 is reported only as a typicality control, never as evidence of recovery. KB arms: entries derived from ligands of the held-out family are removed for that family; the generic D1/D3/D5 rules are kept (target-agnostic).
3. **Arms and expectations (written before running):** A1 expected to equal or fall below the strongest baseline (audit §1 items 5–8: target-agnostic, abundance-like, chance on hard negatives; target prefix has 5 training values). A1c vs A1 tests target dependence: if |ΔEF5| CI includes 0, the target prefix carries no information. A3 can only demote; claim only if A3 − A1 has lower CI bound > 0. A4/A5 are evaluated on KB-covered targets only; any gain there is reported as **in-knowledge** (circular for published ligands) and does not support the held-out claim. A6/A7 test whether feedback changes ranking; claim only if (A6 or A7) − A1 lower CI bound > 0.
4. **Decision rule for the paper:** knowledge/rules/feedback "add something" only if the pre-registered contrast has a lower 95 % bound > 0 on the held-out families **without** KB entries derived from them. Otherwise the paper reports a null with the positive controls of §1 (planted signal detected; shuffled labels at chance; converter exact where mapped).
5. **Ordering:** no scoring until (a) Workstream 3's positive/decoy lists are frozen with hashes and (b) this section is committed. Scores are written to `v4_eval/results/<arm>.jsonl` with the list hash.
