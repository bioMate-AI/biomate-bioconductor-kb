# v5 pre-registration — improvements to v4 as loop components, each its own ablation (committed BEFORE any v5 run, 2026-10-28)

Owner direction (2026-10-28): improvements to v4 are **loop components**, and the paper's claim is that **the loop improves the LLM**. This document (a) registers v5 and its six component ablations on Workstream 3's benchmark, (b) fixes the model/update interface that Workstream 2's LLM-in-the-loop retrospective replay (agent ae23e8707798a7da8) consumes, (c) records the converter-widening result (done, §5). It inherits `20261028_AVB6_RETROSPECTIVE_RECOVERY_PREREG.md` (§3–§5, §8, A1) and `20261028_V4_LLM_AUDIT_AND_EVAL.md` §4. No v5 model has been trained or scored at the time of this commit.

## 1. Baseline (v4 audit facts the v5 changes respond to; all measured in `20261028_V4_LLM_AUDIT_AND_EVAL.md`)
Target prefix = 24-d composition descriptor, 5 distinct values in training; all flagged binders in test, 0 in train; AUC at chance against hard negatives on 4/5 targets; permeability effect scored by a regressor with CV R² 0.069; 9.1 % verbatim eval/train overlap; 34.7 % lariat data with no topology token; chirality-free features in the loop study; converter fully maps 2.8 % of benchmark-domain macrocycles with the v4-style named dictionary (§5).

## 2. v5 components (each a separately switchable ablation; v5-full = all on)
| id | change | what is held fixed when it is ablated | specific failure it targets |
|---|---|---|---|
| C1 | **Target representation:** frozen protein-language-model residue embeddings of the target (or pocket residues when a structure is available), attended to by peptide tokens through cross-attention, replacing the 24-d categorical prefix | everything else = v4 data/loss | 5-value prefix cannot extrapolate; wrong-target prefix kept AUC 0.81–0.92 |
| C2 | **Peptide-enriched training data:** 17,120 affinity macrocycles (851 targets) + PDB bound-cyclic complexes + display pools + CycPeptMPDB; ChEMBL-style general SMILES ≤ 20 % of tokens; **deduplicated against all evaluation sets** (canonical SMILES identical or Tanimoto ≥ 0.9 removed — the 9.1 % overlap case) and **target-family-disjoint splits** (family = UniProt/Pfam cluster from Workstream 3's `uniprot_pfam.tsv`; no family in both fit and the benchmark) | v4 architecture | narrow training distribution; verbatim leakage |
| C3 | **Affinity loss:** continuous, censoring-aware regression on log10 affinity (Tobit-style likelihood for `<`/`>` relations) + within-target pairwise ranking loss with hard negatives (same-target measured inactives and decoys matched on size/charge/RGD-motif) | v4 data/representation | enrichment-bucket binary label; chance vs hard negatives |
| C4 | **Topology and stereochemistry tokens:** head-to-tail, lariat, stapled, bicyclic/cross-linked, linear; explicit D/L and N-methyl tokens with chirality retained in the residue token; cross-links as explicit bond tokens | v4 data | no topology token (34.7 % lariat); stereo-blind features |
| C5 | **Within-source-normalised permeability targets evaluated on measured data:** permeability head trained on within-source z-scored PAMPA; evaluated by Spearman / top-decile recovery against **measured** held-out peptides (source-grouped folds), never by a composition regressor | v4 data | regressor CV R² 0.069; random (not source-grouped) split |
| C6 | **Open-vocabulary residue tokenisation:** residue token = canonical residue-fragment SMILES kept if seen ≥ 5× in training families, else `<unk_ncaa>` + side-chain descriptor; cross-links as bond tokens (replaces the named-monomer dictionary, §5) | v4 data/loss | converter coverage 2.8 % → 4.1 % even after widening |
Everything in C1–C6 is trained with the benchmark's target families removed (C2 rule); the five display-target families (PADI4, PCSK9, FIKK13, Aβ42, IAPP) are in-family for v4 and are excluded from every held-out claim for v5 as well unless C2 removes them.

## 3. Ablation protocol (on Workstream 3's frozen lists; not yet frozen at commit time)
Arms: v4; v4+Ci for i = 1…6 (one change each); v5-full; v5-full minus Ci for i = 1…6 (leave-one-out). Primary metric EF5 (and AUROC) per `…RECOVERY_PREREG` §5 with target-cluster bootstrap (B = 2000), same scored-subset rule (coverage reported; baselines recomputed on the same subset), same baselines (abundance, composition, size/charge, RGD-motif, nearest-neighbour-to-other-targets). Seeds: 3 training seeds per arm; seed variance reported; claims use the mean over seeds with the bootstrap over targets. **Decision rules (fixed now):** a component "helps" only if (arm − v4) has 95 % lower bound > 0 on held-out families and the arm exceeds the strongest baseline's point estimate; "v5 improves on v4" requires the same for v5-full. Components are tuned only on development targets (the 4 LODO αvβ6 documents are NOT used for tuning); the external literature set is scored once per frozen version (§8 of the prereg). Every arm reports hyper-parameters, training-set sizes after dedup and seed list. A null is reported with the positive controls (§4).

## 4. Controls required before any v5 null is believed
(i) planted-signal test through the v5 training+scoring path (as `v4_eval/test_v4_audit.py`: planted motif AUC > 0.9, shuffled labels at chance); (ii) wrong-target control for C1 (shuffled target embeddings must reduce held-out EF5 to the no-target level, else the representation is not used); (iii) dedup audit (0 canonical-SMILES identical and 0 Tanimoto ≥ 0.9 pairs between fit and every evaluation set, reported); (iv) censoring unit test (Tobit loss recovers a planted threshold-censored relation); (v) converter test (`v4_eval/test_converter.py`) and open-vocabulary round-trip (tokens → fragments → SMILES identical canonical form on ≥ 99 % of mapped peptides).

## 5. Converter widening (done; owner had not decided — executed as directed, coverage reported before/after)
Method: iterative dictionary learning from CycPeptMPDB (SMILES + ground-truth monomer lists; a fragment is named only when it is the single unexplained residue of a peptide, ≥ 2 concordant peptides, no conflicts), tautomer-alternate keys for Arg/His (RDKit's tautomer canonicaliser was tried and rejected: it strips stereo, collapsing L/D). Bug found and fixed on the way: 0.17 % of benchmark-domain SMILES raised RDKit exceptions on branched/isopeptide topologies → now returned as unscored with reason.
| set | dictionary | segmented | fully mapped | exact (rotation-equivalent) among fully mapped |
|---|---|---|---|---|
| CycPeptMPDB, held-out half (dictionary learned on the other half) | base 82 tokens | 98.1 % | 16.9 % | 716 / 716 |
| same | learned 121 tokens | 98.1 % | **40.6 %** | **1,720 / 1,720** |
| benchmark-domain macrocycles (affinity table, n = 3,000 sample) | base 82 | 74.8 % | 2.8 % | (no ground truth in this table) |
| same | learned from all CycPeptMPDB, 131 tokens | 74.8 % | **4.1 %** | (no ground truth) |
Why the benchmark domain stays low (measured): 1,930 of the segmented peptides contain cross-linked units (disulfide/lactam/thioether bridges) that merge residues, 830 distinct unmapped residue fragments in 3,000 peptides, 25 % of SMILES fail to segment (518 ambiguous backbone, 209 fewer than 3 units, 28 no peptide bond). **Conclusion:** a named-monomer vocabulary cannot cover the benchmark; v5's C6 (open-vocabulary fragment tokens with cross-link bond tokens) is required, and v4/atom-LM arms in the benchmark remain limited to the small fully mapped subset (coverage reported). Artefacts: `research/guangzhou_all_atom/cyclic_llm/v4_eval/{smiles_to_monomers.py,monomer_dictionary_v5.json,test_converter.py}`.

## 6. Loop interface for Workstream 2 (LLM-in-the-loop retrospective replay)
The loop's claim is that feedback changes the model. To avoid duplicating WS2 files I define only the contract and provide adapters in `v4_eval/`; WS2 owns the replay driver and controls (data-matched one-shot, random feedback, shuffled labels, frozen, knowledge-off).
```
class LoopModel:                       # v4_eval/loop_model.py (adapter over unified_cyclic_llm v4 first; v5 swaps in without API change)
    def score(self, smiles: list[str], target_seq: str) -> list[float|None]   # None = unscored (converter), never imputed
    def update(self, labelled: list[dict], mode: str, seed: int) -> "LoopModel"
        # labelled = [{smiles, target_seq, label (float, within-source/within-target standardised), relation (=,<,>), source}]
        # mode in {"finetune_ranking","dpo","frozen","one_shot_matched"}; returns a NEW model; the original is never mutated
    def fingerprint(self) -> str                                              # hash of weights + update history (provenance of every pick)
```
Update procedures: `finetune_ranking` = pairwise ranking fine-tune on within-target pairs built from the revealed labels (C3 loss), N steps fixed in advance; `dpo` = DPO against the frozen previous round as reference on preference pairs (chosen = higher label within target); `one_shot_matched` = a single update with all labels the loop would reveal over R rounds (data-matched control); `frozen` = no update. Controls WS2 requires map to: random feedback = `labelled` with permuted labels; shuffled labels = labels permuted across compounds within target; knowledge-off = no KB/rule demotion in selection. **The adapter and the claim-to-arm mapping are provided; a v4-based `LoopModel` is implemented and tested before use (positive control: after `finetune_ranking` on planted-label data the held-out ranking improves; with permuted labels it does not).**

## 8. Amendment V5-A1 (2026-10-28, before any v5 training) — C6 decision, C2 dedup result, length limit
**C6 decision (owner-approved route): atom-level SMILES tokens, not a named-monomer vocabulary.** Reuses `allatom/atom_lm.py` (regex tokenizer keeps `@`/`@@` and `/` `\` bond stereo; vocabulary from the 2026-10-27 pretraining, 258 tokens) plus topology tokens prepended after `<bos>` (`v4_eval/v5_atom_tokens.py`, tests `test_v5_tokens.py`: 5 pass). The named-monomer converter stays only for the v4/atom-LM *comparison arms*. Measured on the 16,195 frozen benchmark compounds (`v4_eval/atom_route_audit.json`): tokenizer round-trip exact 99.72 % (45 fail: metal-chelate SMILES with dative bonds `->`, to be excluded and listed); 98.8 % carry stereo marks (chirality is represented); peptides with ≥ 1 UNK token in the SMILES tokens 0.53 % (mean 0.006 per sequence); enantiomers receive different token sequences. **Coverage on the benchmark domain: 99.7 % tokenised vs 4.1 % fully mapped by the monomer route.**
**Topology tokens — what is and is not reliable (measured against CycPeptMPDB `Molecule_Shape`, n = 8,466):** macro-ring count (0 / 1 / ≥ 2 rings of ≥ 8 atoms → linear / single / multi) is graph-exact; the **head-to-tail vs lariat split is not**: lariat recall 0.983 but head-to-tail (Circle) recall only 0.642 (two alternative rules tried and rejected: backbone-ring fraction 0.942/0.010; free-N-terminus 0.978/0.000). **Pre-registered consequence:** the shape token is taken from ground truth where it exists (CycPeptMPDB `Molecule_Shape`; PDB manifest `cyclization_type`) and from the heuristic elsewhere, with a separate `<shape_inferred>` flag token so the model can be ablated on it; `<flag_ds>` (S–S) is exact by substructure; `<flag_stap>` (≥ 6 consecutive non-backbone ring carbons) is **unvalidated** (no ground truth) and is reported as an exploratory token, excluded from the primary C4 ablation. Benchmark topology distribution (heuristic): h2t 4,665 / lariat 4,382 / multi 1,253 plus S–S and staple flags (`atom_route_audit.json`).
**Length limit:** the 2026-10-27 atom LM has max_len 256; 13.5 % of benchmark compounds exceed 256 tokens (7.1 % > 384; 1.4 % > 512; max 839). v5 sets max_len 512 (extending the positional table; pretraining from scratch on the C2 mix, not fine-tuning the 256 checkpoint) and reports the fraction truncated/excluded (1.4 %).
**C2 dedup + family folds (built, not trained on; `v4_eval/build_c2.py`, report `v4_eval/c2/c2_report.json`, per-fold train files `c2_train_heldout_fold{0-4}.csv.gz`).** Frozen WS3 hashes verified; fold rule `sha256(family) % 5` (317 families; **proposal — WS3 must confirm or replace before any training**). Dedup per fold removes every training compound with the same flat structure as, or Morgan-r2 Tanimoto ≥ 0.9 to, any compound in a held-out-fold benchmark item list. Result (train compounds before → after): fold0 13,450 → 4,718; fold1 9,078 → **1,525**; fold2 13,322 → 3,682; fold3 12,181 → 2,833; fold4 11,088 → 3,554 (pairs after: 7,621 / 1,937 / 5,722 / 4,249 / 6,207). Two findings: (i) compounds are shared across targets so family-disjoint training retains only 11–35 % of compounds; the effective C2 affinity set is **1.5–4.7 k compounds per fold, not 17 k**; (ii) folds are badly unbalanced (fold1 holds 288 targets because one GPCR family has 130 targets) — recommend size-balanced family bin-packing (to WS3). CycPeptMPDB: a random 85/15 split has **68.9 % of validation peptides sharing a flat (stereo-free) structure with training** (9.1 % was the exact monomer-tuple measure; stereo-free is the relevant one for a chirality-aware model); source-grouped folds give 0.2–8.8 % residual overlap, removed from training by flat-structure dedup. CycPeptMPDB ∩ benchmark = 12 flat structures. Display target in the benchmark: PCSK9 only (family `Ff90157a3`, fold 2) — it is in-family for v4/v5 and excluded from held-out claims. Bound-cyclic PDB v2: 776 usable of 784, 222 with `X` placeholders (sequence only, no SMILES) → used as sequence-level auxiliary data only, not in the SMILES-token model, until mapped.
**Consequence for the design:** C2's expected gain must be judged against a training set 4–10× smaller than the nominal 17 k; the primary C2 contrast is therefore "v4-architecture on C2 data vs on v4 data", at equal token budget, so a null cannot be attributed to small data without the equal-budget control.

## 9. Amendment V5-A2 (2026-10-28, before any v5 training and before any chiral scorer is run on §9.2) — folds, cost reporting, stereo evaluation, primary comparison, staged compute
**9.0 Folds (WS3 amendment A6; supersedes my fold rule).** `retro_recovery/data/folds_v1.csv` (sha256 `a896c580ccaf49c709851132d60f3c485b6b7e76f0c2149eae974e67f6c5c409`, verified in `build_c2.py`): 5-fold family-held-out rotation; each fold's model is trained with **every compound labelled on that fold's targets removed**, plus flat-structure and Morgan-r2 Tanimoto ≥ 0.9 dedup. Rebuilt C2 (`v4_eval/c2/`, `c2_report.json`): affinity training compounds after dedup — fold0 2,048 (2,901 pair rows), fold1 5,067 (8,497), fold2 2,459 (3,750), fold3 2,049 (3,007), fold4 1,872 (2,743); i.e. **1.9–2.5 k compounds / 2.7–3.8 k labelled pairs for the folds that run first (4, 2, 3, 0), 5.1 k for fold 1.** The pretraining corpus must receive the same exclusion per fold (compounds labelled on held-out targets removed by flat key and Tanimoto ≥ 0.9; not yet applied to the 2.88 M-molecule ChEMBL corpus — **blocking item for any v5 run**). Training order if compute forces a subset: 4, 2, 3, 0, 1; fold 0 is the 130-target GPCR family; M2 items exist only in folds 2–4.
**9.1 Cost reporting (owner's central claim: a small model + feedback + knowledge loop is comparable to or beats a large LLM).** Both adapters (`LoopModel` v4-backend, `AtomLoopModel` atom/v5-backend; tests pass) expose `cost()`: parameter count; FLOPs = 2·N·tokens (scoring) + 6·N·tokens (training; DPO counts the frozen-reference pass); wall-clock split into scoring and update seconds; and USD = wall-clock × a **declared** hourly rate (0.35 USD/h, spot L4-class; an assumption, not a billed cost). These accumulate across loop rounds and child updates inherit the parent's totals, so the loop's total cost per arm is reportable. Workstream 2 reports the same fields for the large-LLM arms (tokens and prices at the time of the call).
**9.2 Stereo-resolved within-flat-group ranking (pre-registered; `v4_eval/stereo_eval.py`).** Data: CycPeptMPDB PAMPA (detection floor removed); group = peptides sharing a stereo-free canonical SMILES but differing in isomeric SMILES; label per isomer = mean over its rows of within-source z-scored PAMPA (sources < 20 pooled); groups with ≥ 3 labelled isomers and non-constant labels: **341 groups, 4,770 isomers measured before any scorer** (340 with label variance). Metric: mean within-group Spearman (bootstrap over groups, B = 2000) and pairwise concordance over isomer pairs with different labels and different scores. Controls already run (they are by-construction checks): any function of a flat-structure fingerprint ties within a group → Spearman exactly 0.000 (all ties, no concordant pairs scored); random scores → +0.014 (95 % CI −0.029…+0.055), concordance 0.513. Zero-fit chiral scorer registered now: atom-LM mean token log-likelihood (stereo marks are tokens). **Expected before running: ≈ 0 (typicality of the pretraining corpus has no stereo-specific permeability information); a result with CI above 0 would be reported with this expectation stated.** SAR-setting variant: a random half of each group's isomers (seeded) is revealed to the scorer's trainer; the other half is ranked; baselines = chirality-aware Morgan-count ridge/GBM trained on the revealed isomers of all groups, and a within-group-mean baseline; the update procedures of §6 (`finetune_ranking`, `dpo`, `one_shot_matched`) are evaluated in the same split; the same shuffled-label control applies. Claim rule: a scorer "resolves stereochemistry" only if its within-group Spearman CI is > 0 **and** exceeds the strongest chiral-fingerprint baseline's point estimate.
**9.3 Primary comparison for the paper.** **Small model + loop vs large LLM + loop**, each with its own cost record (§9.1), on the same frozen items and rounds; Workstream 2 owns the replay and its controls (data-matched one-shot, random feedback, shuffled labels, frozen, knowledge-off). v5/atom LM (≈ 25 M parameters) is the small arm. Secondary: loop vs data-matched one-shot for each arm; small-frozen vs small+loop. A claim of "comparable or better at lower cost" requires: (a) the small+loop arm's lower CI bound for the difference to the large+loop arm > −δ with δ fixed by WS2 before any arm ran, and (b) the small arm's reported cost below the large arm's. If either fails the paper reports it.
**9.4 Staged compute (owner-approved).** Stage 1 = bare v4 (scored, below) + v5-full + one leave-one-out control, on fold 4 then fold 2; continue the grid only if v5-full shows a gain on the primary analysis (I, all items and contamination-controlled, vs strongest baseline, family-bootstrap CI lower bound > 0). Spot GPU only. **Cost estimate (written before any launch; assumptions explicit):** measured atom-LM pretraining speed 0.073 s/step on an L4 at max_len 256, batch 128 (2,920 s for 40 k steps, 25.5 M parameters); at max_len 512 assume ≤ 2× → 0.15 s/step ⇒ ≤ 1.7 h per 40 k-step model; 2 models (v5-full, LOO) × 2 folds × 3 seeds = 12 pretraining runs ≈ 20 GPU-hours; at the assumed 0.35 USD/h spot rate ≈ **USD 7**, ×1.5 for spot retries ≈ 10.5; plus fine-tuning/ranking stages (< 10 % of pretraining), one-off ESM-2 target embeddings for 68 accessions (minutes), and per-fold corpus filtering on CPU (≈ USD 1–3). **Estimated stage-1 total USD 10–22 < the USD 40 stop threshold; the estimate rests on the assumed hourly rate and on the trainer not being slower than 2× the measured speed — both will be re-measured on the first 500 steps and the run stopped for a report if the projected total exceeds USD 40.** Nothing has been launched: the v5 trainer (C1 target cross-attention, C3 censoring-aware + pairwise loss, C4/C6 tokens, per-fold corpus filter) is not yet implemented or tested.
