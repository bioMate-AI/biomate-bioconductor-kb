# IH-LM module ladder (R0–R4): pre-registration (T-LADDER, 2026-10-28, written BEFORE any scored run)

Owner: T-LADDER fork. Code: `research/guangzhou_all_atom/cyclic_llm/ihlm_ladder/`. Results: `docs/20261030_IHLM_LADDER_RESULTS.md`.
Scope: CPU only. This tests whether the **symbolic modules** of the in-house model add anything in a retrospective replay on CycPeptMPDB permeability. It makes **no claim about generation, wet lab, or foundation models**, and the neural analog attention (M3) and the verifier head (both xfail in `ihlm/test_ihlm.py`) are NOT used (see §3).

## 0. Disclosure (what I had seen before registering)
I read: the loop runner (`run_l7a.py`, `loop_models.py`), `ihlm/model.py`, `ihlm/symbolic.py`, the interface proposal, the integration inventory, the independent code and data reviews (defects: transductive standardisation, regime leakage, interval types, multiplicity, controls that cannot fail), and the published L5/L7 GBM results. I have seen **no result of any IH-LM rung** on any regime. Timing/benchmark runs of the symbolic memory on a handful of rows were run to size the compute (cost only, no scores).

## 1. Question and claims
Q: does each module add held-out value over the rung below it, under causal label handling and equal information? A module "adds" only if the claim rule in §7 is met in the primary regimes. Null results are reported as null. No "first", no generation claim.

## 2. Arms
Ladder (cumulative; same backbone configuration and seeds for every rung; a rung differs only by which layers are on):
- **R0** `modules=()`: net only (small standard encoder, trained by the loop's updates).
- **R1** `("M1",)`: + K-prior fusion, weight w = n0/(n0+n), n0 = 100. **K = K_phys_textbook** (label-free fixed physchem directions: z_src(−TPSA), z_src(−HBD), z_src(logP) averaged; identical to the loop runner's `Kphys`). Rationale: it uses no label, so it is leak-free in every regime. The label-mined `K_phys_channel` (kb_audit rules) is NOT used in the primary ladder (mining needs labels; a clean per-regime mining protocol is out of scope today). It is registered as arm **R1c** for regime L only (rules mined from training-lab labels of that seed) and is run only if time allows; otherwise reported "not run".
- **R2** `("M1","M2")`: + lab/source offset (closed-form ridge-shrunk b_s; replicate-anchor estimator where peptides are measured in ≥2 sources, K-residual estimator otherwise); labels offset-corrected before every net update.
- **R3** `("M1","M2","M3")`: + **symbolic** analog retrieval (k = 5 nearest revealed analogs, chirality-aware Tanimoto, softmax kernel τ = 0.04). The neural cross-attention is disabled (§3).
- **R4** `("M1","M2","M3","M4")`: + edit-space layer (closed-form conjugate-shrunk N-Me add/remove and D-flip effects estimated from revealed analog pairs; edit deltas applied to retrieved analogs). **Edit priors are the neutral default (0, pseudo-count 20)** (`EDIT_PRIORS` leaked, fixed in `87f4f6718`); the literature numbers are not used; the leak-safe loader is not used today (so R4's edit effects are data-driven only).
Reference arms (same labels and candidates): **GBM_aware** (chirality-aware fingerprints, L5 learner), **kNN** (nearest-neighbour-to-revealed), **GP** (L7i, fixed hyper-parameters), **random_fb**, **rule_kphys** (zero-learning K_phys_textbook ranking). Information-privileged block (separate, never merged): **PT / PT+analog correction** (GBM pretrained on all other labs' labels): regime L only, implemented only if time allows.
Controls: **R4_shuf** (shuffled labels: each round's new labels are drawn globally from the pool's label vector, as in L7d); **R1_kshuf** (R1 with K permuted within source, sorted-list permutation, fixed seed; paired contrast R1 − R1_kshuf); **R4_frozen** (no updates; labelled a sanity check, zero gain by construction, NOT counted as a control); planted worlds (unit tests, §8).

## 3. Implementation constraints (fixed now)
IHLM backbone default config (d = 64, layers = 2, heads = 4, max_len = 192, encoder), `slow_every = 1`, `alpha = 0.2`, `eta = 1.0`, `k = 5`, net trained with 100 steps at initialisation and 30 steps per round (the L7 values), lr 2e-3, rank weight 0.3, bs 32. The subclass in `adapter.py` disables the neural analog attention and the neural edit residual (the net is built without M3/M4 and receives no analog pack): retrieval and edit effects enter only through the symbolic memory. Net trained only through `IHLM.update`. No third-party weights. These settings were chosen before any rung score was seen and are not tuned.

## 4. Labels and standardisation (the review's F4/M6 fixes)
Learner-visible labels are **causal source-standardised** (scheme `zc`, PRIMARY): for source s with n_s revealed labels (initial + anchors + picks revealed so far), μ_s = (n_s·mean_s + m·μ_G)/(n_s + m), σ_s² = (n_s·var_s + m·σ_G²)/(n_s + m), m = 5, with μ_G, σ_G from the revealed labels only; z = (y_raw − μ_s)/σ_s computed at write time over the revealed set known at that call (IHLM keeps rows as written; GBM/kNN/GP are refit each round from the current causal z). Secondary scheme `gc` (global-centred causal labels, source offsets present, to give M2 a fair test) on 5 seeds in regimes A and L. **Transductive control** `zt` (labels as in L7: all-data source z-scores) for R0 and R4 on seeds 0–4. The **hit definition** for scoring picks and E-metrics is the fixed L5 ground truth per peptide (all-data within-source z ≥ the 90th percentile); it is never visible to a learner.

## 5. Regimes, seeds, anchors
Regimes A, B (L5 definitions via `P.setup`), L (leave-labs-out via `setup_L`; held-out labs 6–18 per seed, documented), optional M = L9 sensitivity (seeds 0–4, R0/R4 only). The same per-seed init set, pool, eval slices E/E_s/E_f and per-round candidate subsets (`subset`) are used for every arm. Development seeds 0–9. **Anchors**: k = 5 labelled peptides per source with ≥ 20 peptides, drawn from peptides in none of E, E_s, E_f (pool peptides in A/B; non-evaluation peptides of the held-out labs in L), added to the initial revealed set for EVERY arm (equal information); k ∈ {0, 10} are optional sensitivity runs (seeds 0–4, R1 vs R2 only). Confirmatory seeds 10–19 are run only if the configuration is frozen and any primary contrast in §7 has a bootstrap-mean CI lower bound > 0 on the development seeds; otherwise no confirmatory run is made (nothing to confirm) and this is stated.

## 6. Metrics and intervals
Y = total hits in the 10 × 50 selections (L5 definition). E = AUROC and EF5 on the held-out slice E, computed at the initial state and after the final round (not per round: cost). Per-round hits and pick-source counts are logged. Every interval is labelled by type: (a) percentile spread of the per-seed paired differences; (b) bootstrap CI of the mean (10,000 resamples); (c) t-interval over seeds; for regime L E-metrics also (d) held-out-lab cluster bootstrap. The decision uses the **wider of (b) and (c)**.

## 7. Contrasts, multiplicity, claim rule
Primary family (Holm, family size **8**): {R1−R0, R2−R1, R3−R2, R4−R3} × Y × {B, L}. Exploratory (BH reported, not confirmatory): the same on E-AUROC and in regime A; R4−GBM_aware, R4−kNN, R4−GP, R1−R1_kshuf, R4−R4_shuf, R4−random_fb; scheme `gc` and k-sensitivity. **A module "adds"** iff its primary-family contrast has Holm-adjusted wider-interval lower bound > 0 in BOTH B and L, the corresponding planted-world test passes, R1_kshuf/R4_shuf controls show no gain beyond the equivalence margin, and the same sign holds under `zt`/`zc`. **Equivalence margins** (fixed now): shuffled-label gain over random_fb within ±10 hits (Y) and ±0.05 AUROC (E); paired K contrast "no attributable content effect" if the wider interval lies within ±10 hits. Underpowered contrasts are reported with the minimal detectable difference (sd of paired differences × 2.8/√n); a CI including 0 is called "not detected", never "no effect".

## 8. Planted-signal and no-leak tests (written before any rung run; `test_ladder.py`)
Real SMILES, planted labels, CPU-sized: (P-K) planted K-channel effect recovered by R1 and not R0; (P-offset) planted per-source additive offsets recovered with k = 5 anchors (error < 0.15 SD) by R2 and not R1; (P-retrieval) planted analog-series effect improves R3 over R2 on peptides whose series was revealed; (P-edit) planted N-methyl-add effect recovered in `edit_eff['nme_add']` by R4 and R4 > R3; no-leak (a) corrupting every held-out-lab label changes no score or offset in regime L, (b) corrupting unrevealed pool labels changes no learner-visible label (causal standardisation), (c) anchors never come from E/E_s/E_f; determinism across `PYTHONHASHSEED` values; shuffled-label equivalence check. A rung whose planted test fails is reported "adapter/module defect" and its real-data results are not interpreted.

## 9. Compute, cost, stopping
Spot CPU instances tagged `project=cyclic-selector`, per-task S3 checkpointing, self-terminating; instance-hours and the spot price paid logged to `cost_log.csv`; **HARD CAP USD 6** cumulative; cost projected before each launch; if the projection exceeds the cap the plan shrinks (fewer seeds, optional arms dropped) by a dated amendment before running. No paid LLM APIs. Everything not run is reported as not run.

## 10. Limits stated now
One data collection (CycPeptMPDB permeability), one task, small symbolic modules + a tiny untrained-at-scale net; results say nothing about larger backbones, generation, or other properties. Regime A has near-duplicate leakage by design (reported with the leakage table from the review); regime B shifts scaffold not laboratory; only regime L's held-out-lab E metrics are clean across the lab boundary.

## 12. Amendment A2 (2026-10-28 evening, before any scored run; no rung has produced a real-data score)
Written after reading my own runner/adapter end to end and writing `ihlm_ladder/test_ladder.py` (prereg section 8). Changes, all declared before scoring:
1. **File split, no behaviour change.** World construction, causal labels, the arm loop and the K-shuffle control moved from `run_ladder.py`/`adapter.py` to the torch-free `ladder_core.py`, so that the CPU pre-flight on a bare spot instance needs no torch (lesson of the L7q pre-flight failure). `adapter.causal_labels` is re-exported.
2. **Logging for the aggregator.** Each task file additionally stores the evaluation slice (indices, sources, hit flags), the initial set, and the E scores at the initial and final state of every arm (needed for the held-out-lab cluster bootstrap (d) and for audit).
3. **zt control extended.** The claim rule (section 7) requires "the same sign under zt/zc", but section 4 ran zt only for R0 and R4, which would make R1-R3 unassessable. The transductive control `zt` is therefore run for **all five rungs R0-R4 plus gbm_aware, seeds 0-4, regimes A, B, L** (k = 5); the criterion compares the sign of each rung contrast on those seeds under zt and zc.
4. **Control definitions (clarifying section 7).** Gate controls: `R4_shuf - random_fb` and `R1_kshuf - R0`, each with the wider interval inside the equivalence margin (+-10 hits; +-0.05 AUROC). `R1 - R1_kshuf` is reported as the K-content contrast ("no attributable content effect" if its wider interval lies within +-10 hits) and is not a gate. A criterion that cannot be assessed from the files is "None" and is never counted as met.
5. **Holm p-value.** For each primary contrast p = the larger of the bootstrap-mean and t-test two-sided p-values (equivalent to using the wider interval); Holm over the 8 primary tests; "positive after Holm" additionally requires the wider 95% interval lower bound > 0 and a positive mean.
6. **Property of the pre-registered label formula, stated as a limitation.** The `zc` variance is shrunk toward the global revealed variance (m = 5), and the global variance includes between-source spread; a source whose SD is much smaller than the global SD is therefore compressed (tested: true SD 0.5 vs global ~4 gives z-SD < 0.8), and very large source shifts move every source's z-scale slightly. The formula is not changed (pre-registered); the effect on the real data is a limitation of the `zc` scheme.
