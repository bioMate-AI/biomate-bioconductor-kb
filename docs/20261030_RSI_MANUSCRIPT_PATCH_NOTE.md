## 2. Additions the RSI manuscript can use (not corrections)
1. **Benchmark validity gates.** Controls with no target information must be at chance. On the cross-target benchmark M a nearest-neighbour baseline scores AUROC 0.914 (point value); on the matched-decoy benchmark M2 the atom-LM typicality control scores 0.665 (95 % family-cluster bootstrap CI 0.551 to 0.772) and a multi-proxy control 0.690; on the primary analysis I a Morgan-fingerprint control scores 0.584 (95 % family-cluster bootstrap CI 0.533 to 0.636); a stricter matched design (M3) is not achievable. This is another instance of a benchmark shortcut caught by a control and fits §5 and §6. (`.../retro_recovery/results/validity_gate_I.json`, `validity_gate_M2.json` (J); `docs/20261030_RETRO_RECOVERY_RESULTS_V3.md` (D))
2. **Laboratory effects.** Leave-laboratories-out skill is about half of within-laboratory skill (Spearman 0.67 grouped by structure versus 0.30 leave-laboratories-out for the fingerprint GBM; point estimates), and for few-label transfer a plain nearest-neighbour baseline reaches AUROC 0.753 (5 labels) to 0.869 (25 labels) against 0.539 zero-shot (95 % family-cluster bootstrap CIs 0.715 to 0.789 and 0.835 to 0.899 for the two nearest-neighbour values); the gain is analog lookup, not demonstrated target-biology learning. (`docs/20261029_CYCLIC_PEPTIDE_STRATIFICATION_ANALYSIS.md` B2 (D); `.../results/h4b_baselines.json` (J))
3. **Feedback versus data.** In the leave-laboratories-out regime sequential selection does not improve held-out ranking beyond the same labels given at once (loop − one-shot +0.003, bootstrap CI of the mean over seeds −0.034 to 0.037) and, on the seed-based E-AUROC contrast, random feedback improves it more (loop − random −0.072, bootstrap CI of the mean over seeds −0.114 to −0.013); with the held-out laboratories as the unit (11 sources, 95 % cluster bootstrap over sources) the within-source ranking contrasts include 0 (loop − random feedback −0.032, −0.089 to 0.016; loop − shuffled +0.071, −0.079 to 0.181), so the loop's measured benefit is yield from selection, not demonstrated ranking improvement on new laboratories. (`l7_aggregate.json` (J, `contrasts_cluster`, c1250c1b8))
4. **Prompted general-purpose language models.** Cheap-tier models prompted in context with the same revealed labels gained little from feedback and were far behind a gradient-boosted model (exploratory, 4 seeds, below the power rule). (`l7_aggregate.json` (J, `contrasts_cluster`, c1250c1b8))
