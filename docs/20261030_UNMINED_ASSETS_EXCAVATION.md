# Unmined-assets excavation: earlier cyclic-peptide work (Sept-Oct 2026) as input to the hybrid loop (2026-10-30)

Status: read-only excavation, no experiment run. Written to answer one question: which earlier assets and results could feed the hybrid symbolic-neural loop proposed in `docs/20261030_HYBRID_ARCHITECTURE_PROPOSAL.md` (components C1-C7), and which earlier claims should not be relied on.

Method and limits (read first):
- Docs: I opened the head or the headline section (bounded `sed`/`grep`) of about 75 documents, and the full result lines of about 20. About 25 further matching documents were listed but not opened (Section 8). "Opened" is not "audited".
- Data: sizes, schemas, row counts were measured by reading the files or by `aws s3 ls`. Two quick computations of mine are marked (CREMP-versus-CycPeptMPDB overlap; physchem_calibration provenance).
- S3: `s3://biomate-nextflow-work/cyclic_peptide/` and `s3://knowledge-datasets-1759951976/cyclic_peptide/` listed read-only. Other buckets (models, structure-db, test-data, onprem-assets, sandbox-xfer, workflow-inputs) had no cyclic/peptide/macrocycle/display/boltz top-level prefix in a name grep. I did not list inside them deeper.
- Status vocabulary: VERIFIED = I opened the supporting file/number; CLAIMED = stated in a doc/commit message, supporting file not opened or not found; SUPERSEDED / NEGATIVE as stated.
- No IP-folder documents were opened or cited.
