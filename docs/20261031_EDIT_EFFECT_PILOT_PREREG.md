# Pilot 2 pre-registration: edit-effect prediction on real matched pairs (written 2026-10-28 ~23:50 CDT, BEFORE any model number on the test half)
Owner context: the 'M4 edit head' was dropped from the main hypothesis because its only test was a toy. Real, large, within-source matched-pair data exist; this pilot tests whether a frozen peptide-LM backbone + small head predicts the effect of an edit on held-out laboratories better than simple baselines.

## 1. Data (verified by `research/guangzhou_all_atom/cyclic_llm/edit_pilot/prep_pairs.py`; output `data/verify_pairs.json`)
Post-fix PAMPA pair table `stratification/data/mmp_pairs_pampa.csv.gz` (annotations at e2d1069bf). Edit types: **N-Me added** (4,166 pairs, 15 sources) and **D flip (D minus L)** (7,467 pairs, 18 sources). Verified: no pair straddles sources (0), stored effect equals sign*(z_b - z_a) (max error 7e-16), the edited peptide always carries the feature and the parent never does, no missing SMILES; D-flip pairs always share a flat structure, N-Me pairs never do; no pair of another source shares a flat structure with any test-half source (0 leaking pairs). **Label scale caveat (found in verification):** `source_normalize` z-scores per source only for sources with >= 20 labelled peptides; smaller sources are pooled into one group, so their z differences are compressed or shifted. Primary target therefore = **effect in z units, restricted to pairs from sources with >= 20 labelled peptides** (exact within-source z); excluded pairs are counted in the report. Secondary target: raw log-Papp difference (physical units), all pairs.
Edit effect = z(edited) - z(parent). Effects are context- and source-dependent (I2 about 0.6 for D flip, much higher for N-Me in the stratification analysis); a constant effect is therefore a real competitor, not a strawman.

## 2. Folds and halves
Halves by sha256(source) mod 2 (0 = development, 1 = test). **Test half pair counts per source are heavily concentrated**: N-Me test half = Kelly 1,107, Furukawa 143, Wang 10, then <= 7 each; D flip test half = Kelly 2,220, Furukawa 429, Faris 350, Ono 12, Taechalertpaisarn 12, then <= 4 each. The development half is ~99% Townsend (N-Me 2,851 of 2,882; D flip 4,390 of 4,427). Consequences stated now: (i) hyperparameter selection is effectively within-source (Townsend) and cannot tune cross-source behaviour: selection uses GroupKFold(5) on dev-half pairs grouped by parent flat structure; (ii) a source counts toward the held-out-source minimum only if it has >= 10 pairs (after the label-scale restriction) -> **N-Me test half has 3 qualifying sources (Kelly, Furukawa, Wang) -> verdict will be UNDERPOWERED by rule, whatever the numbers**; D flip has exactly 5 (Kelly, Furukawa, Faris, Ono, Taechalertpaisarn; subject to the label-scale restriction, which may remove Ono (8 labelled peptides) -> then 4 -> UNDERPOWERED).
Evaluation (gate): for each test-half source s, train on all pairs of all other sources (dev + remaining test sources) with the dev-selected hyperparameters; drop from training any pair sharing a flat structure (parent or edited) with a pair of s (0 expected); predict s. **Secondary, EXPLORATORY (not gate):** the same leave-one-source-out over ALL sources with >= 10 pairs (hyperparameters from the dev selection).

## 3. Models (all frozen features; no backbone fine-tuning in this pilot)
(a) constant per-edit-type mean effect (training pairs, source-averaged and pair-averaged variants; the better one on dev is the baseline); (b) pair-NN: mean effect of the k most similar training pairs (cosine on [parent Morgan-r2 chiral count FP, FP(edited) - FP(parent)]); k in {5, 20, 50} chosen on dev; (c) GBM (sklearn HistGradientBoosting, depth in {3, 5}) on [FP difference, parent FP]; (d) PeptideCLM-2 small (`ihlm_backbone`, weights pinned, no remote code) mean-pooled embedding difference + parent embedding -> ridge (alpha in {1, 10, 100, 1000}) and GBM; **ours (M4 edit head)** = same frozen embeddings -> small MLP head (hidden in {32, 128}, weight decay in {1e-3, 1e-2}, dropout 0.1, fixed 40 epochs, 3 seeds averaged). Best of (a)-(d) variants by dev score = "best baseline"; ours is compared with it per edit type.

## 4. Metrics, margin, decision rule (per edit type; fixed now)
Primary: pooled Spearman between predicted and observed effect over test-half pairs; 95% **source-cluster bootstrap** (resample qualifying + non-qualifying test sources, B = 2000, seed = crc32 of the sorted source list). Also RMSE and sign accuracy, and RMSE skill vs the constant baseline. **PASS** requires all of: (1) ours minus best baseline Spearman >= +0.05 with cluster-bootstrap CI lower bound > 0; (2) ours RMSE < constant-baseline RMSE with the CI of the paired difference excluding 0 (a Spearman win that is worse than the constant in RMSE does not pass); (3) all controls in section 5 behave as specified; (4) >= 5 qualifying held-out sources. **FAIL** if (4) holds and (1) or (2) or (3) is not met. **UNDERPOWERED** if (4) is not met (numbers still reported with CIs, no pass/fail). 'Constant mean wins' is reported as FAIL with the numbers. Per-source Spearman is reported for sources with >= 30 pairs.

## 5. Controls (run on the identical folds and pipeline)
- **Planted context-dependent effect:** replace the effect by a function of the parent only, y = +1 if the parent's aromatic-residue fraction (from the annotation table) is above the training median else -1, plus N(0, 0.3^2) noise; our model must reach held-out Spearman >= 0.5 and the constant baseline must be near 0 (|rho| < 0.1). If our model fails to recover it, the pipeline is broken and the real result is void.
- **Null edit:** effect = N(0, 1) independent of everything; ours must not beat the best baseline by the margin and its Spearman CI must include 0.
- **Shuffled effects:** effects permuted within source (training and test targets); same expectation as the null.
## 6. Cost and compute
Local CPU (frozen embeddings of ~4.9 thousand unique SMILES with the small backbone; sklearn; small MLP); no cloud spend; no GPU. Nothing on the test half is looked at before this file is committed.

Because sigma_cross includes laboratory offsets, this bound is far too conservative to be informative; **the ceiling is therefore reported as NOT INFORMATIVE**, not as evidence that the effects are unpredictable. No same-source replicate measurements exist (0 groups).
**Second data check (A1.4).** Caco-2 / RRCK / MDCK edit tables have <= 2 qualifying sources: UNDERPOWERED, no models run.
**Reading, with the wording A1.1 requires.** (1) Both edit types: no gain detectable above MDE (0.191 and 0.089); the head is not better than the baselines or the constant; for D flip it is worse than the constant mean in RMSE. (2) The point estimates and the scheme C distribution do not hint at a gain either (0 of 40 splits pass). (3) The only edit type with any predictable signal is N-Me (fingerprint-difference GBM 0.12, Furukawa 0.44), and the frozen-embedding head does not capture it. (4) D-flip within-source effects look unpredictable from structure with these features (every model about 0). (5) Decision for compute: **NO-GO for fine-tuning an edit head as a main hypothesis**; this is a statement about power-limited evidence, not a proof that edit effects cannot be learned. Limits: frozen small backbone only (no fine-tune, no base model), few qualifying sources dominated by Townsend/Kelly, label-scale restriction, GBM on 512 highest-variance fingerprint columns, ceiling uninformative.
