# Pilot 3 — constrained cyclic-peptide GENERATION: LLM generators vs tuned simple generators (pre-registration, committed BEFORE any sampling)

Status: **pre-registration. No molecule has been sampled for this pilot when this file is committed.** Owner approved scoping ("y"). Role of the pilot: a go/no-go for generation compute. It is NOT paper evidence and says nothing about binding or permeability (validity, novelty and constraint satisfaction of generated molecules are not activity evidence).

## 2. Task, data and split
**Task (seeded variant generation).** Each sample starts from a seed cyclic peptide and a generator proposes a new molecule. Same seeds, same sample budget for all generators.
**Data.** CycPeptMPDB (`data/raw/CycPeptMPDB_Peptide_All.csv`, 7,000-ish rows, flat-structure dedup). **Source split: `sha256(Source) mod 2`**: part 0 = DEV (seed pool S, all tuning); part 1 = TEST-REFERENCE (the "real peptide" distribution for total-variation distances; never used for tuning or seeding). Seed pool S = up to 300 distinct flat structures from DEV drawn with a fixed rng (seed 12345).
**Reference distribution** for TV: all TEST-REFERENCE peptides (max ring size and N-methyl count histograms; bins as in `p0_intrinsic.py`: ring [0,6,8,12,16,24,40,100], N-Me [0,1,2,3,5,8,40]).
**Novelty** = canonical isomeric SMILES not in all of CycPeptMPDB (both parts), not among the seeds, and not produced earlier by the same generator in the same run (uniqueness counted first). Novelty against the LLMs' pretraining corpora (PubChem, UniChem, ChEMBL) is **not checked** (corpora not available); stated as a limitation.

## 3. Constraint set C (fixed now)
A sample satisfies C iff: RDKit-valid and sanitises; largest ring size >= 12 (macrocycle); N-methyl amide count in [2, 6] (SMARTS `[CX3](=O)[NX3;!H1]([CH3])`, same as P0 intrinsic); 600 <= MW <= 1400; TPSA <= 300; no PAINS match (RDKit `FilterCatalog` PAINS A/B/C); single connected component. Real-peptide context only: CycPeptMPDB peptides satisfy "macrocycle" by construction; the other limits are design constraints, not claims about permeability.

## 4. Generators
LLM generators: **L-P0** (prefix completion), **L-CHEMFM** (prefix completion), **L-PCLM2** (masked infilling). Simple generators (tuned fairly, same dev tuning budget as the LLMs):
* **S-EDIT**: edit-operator genetic search from the seed: apply k random edits from `ihlm/symbolic.py::propose_edit_smiles` (N-Me add, N-Me remove, D/L flip; k in {1,2,3}), with optional residue-swap not included; no learned component.
* **S-LIB**: monomer-library enumeration: sample a cyclic head-to-tail peptide from the 131-entry monomer dictionary (`v4_eval/monomer_dictionary_v5.json`; includes D and N-Me monomers) with length range, P(N-Me), P(D) tuned on DEV. Does not use the seed (it is a seedless enumeration baseline: "what a chemist's library gives for free"). Included because it satisfies macrocycle/N-Me constraints by construction and is therefore a strong constraint baseline.
* **S-BRICS**: RDKit BRICS fragmentation of two seeds and recombination (weak baseline, expected low validity).
**Controls:** (a) **C-COPY** outputs the seed unchanged: novelty 0, Y 0 (metric plumbing); (b) **C-RANDINIT**: the same architecture with random weights for L-P0 and L-PCLM2 (config only; sampling must give Y ~ 0 and low validity: if not, the metric or the procedure is broken, and nothing is reported as a result); (c) **C-SHUF** (L-PCLM2): infill with token-shuffled logits (the sampled token drawn from the marginal vocabulary distribution) to separate the model's conditional knowledge from the infilling scaffold.

## 5. Tuning (DEV only, then freeze)
Knobs, each from a fixed small grid, chosen by maximising primary metric Y (section 6) on DEV run seeds 100-102 with 300 samples each (seeds drawn from S): S-EDIT k; S-LIB length range {5-8, 6-10, 8-12} x P(N-Me) {0.1, 0.25, 0.4} x P(D) {0.0, 0.15, 0.3}; S-BRICS fragment-count; L-P0 and L-CHEMFM prefix fraction {0.3, 0.5, 0.7} x temperature {0.8, 1.0}; L-PCLM2 mask fraction {0.15, 0.30} x rounds {1, 3} x temperature {0.8, 1.0}. The frozen configuration is committed (`generation_pilot/frozen_config.json`) before any TEST-run sample is drawn. ChemFM tuning uses 3 grid cells at 300 samples (cost); this is noted if the grid is cut for cost.

## 6. Test run, metrics and decision rules
**Test run:** run seeds 0-4, 1000 samples each (5000 per generator), seeds drawn from S. Metrics per run seed, then summarised over the 5 run seeds (mean, **t-interval of the mean over seeds (typed), and percentile bootstrap over seeds (typed, B = 5000)**; with 5 clusters both are crude and anti-conservative: reported next to each other, not combined).
* **Primary Y** = number of unique, novel, valid, constraint-satisfying molecules per 1000 samples drawn.
* Secondary: validity; uniqueness of valid; novelty; macrocycle fraction; max-ring TV and N-Me TV vs TEST-REFERENCE; **Y_cluster** (Butina clusters at Tanimoto 0.7 among the satisfying unique novel molecules per 1000 samples); internal diversity (mean 1 - Tanimoto over <= 500 satisfying molecules); and, labelled **circular proxy**, the mean score of a chirality-aware GBM permeability predictor trained on DEV-half sources only (PAMPA within-source z) on the satisfying molecules (reported only, never used in any decision).
**Gates (reported PASS/FAIL per generator; fixed now):** G1 validity >= 0.90; G2 macrocycle fraction within +/-50 % relative of real (>= 0.5); G3 N-Me TV <= P0's reference value (0.817) AND <= the best simple generator's N-Me TV.
**"LLM wins" (the only success criterion):** at least one LLM generator satisfies G1 AND its Y minus the Y of the best tuned simple generator is > 0 with the lower bound of the **t-interval** > 0 AND the percentile-bootstrap lower bound > 0 (both must agree; stated because 5 seeds is thin). If the best simple generator has Y < 5 per 1000, the outcome is **NO-ONE-PRODUCES** (reported, not a win). If the CI of the difference is wider than +/-50 % of the best simple Y, the outcome is **UNDERPOWERED**, and a miss reads "no difference detectable at this width", never "no difference". Y_cluster is reported as a guard: an LLM "win" on Y with Y_cluster lower than the best simple generator's Y_cluster is flagged as a mode-collapse win.
**Plausibly-expected outcome, stated before data:** S-LIB and S-EDIT will win Y (constraints are met by construction); L-CHEMFM will produce few macrocycles; L-PCLM2 infilling will be valid but close to the seed; the LLMs may win only on Y_cluster / diversity or not at all. A simple-generator win is a legitimate and reportable result.

## 8. Limits written down now
Validity/novelty/constraint yield is not evidence of binding, permeability or synthesisability; the seeds come from one database; "real peptide" TV uses CycPeptMPDB which is dominated by few labs; the novelty check excludes only CycPeptMPDB and seeds; PeptideCLM-2 is used outside its intended (property-prediction) use; five run seeds are thin; this pilot is a compute go/no-go and is not cited as paper evidence.

## 9. Amendment A1 (2026-10-29 ~01:20 CDT) — symmetric one-step grid extension for edge winners; declared BEFORE any test-run sample and before the configs are frozen
Reason: the DEV tables (seeds 100-102, 300 samples) put the winning cell on the grid boundary for most generators (S-LIB: shortest length 5-8 and highest P(N-Me) 0.4 with P(D) = 0; S-EDIT: k = 3 = maximum; S-BRICS: nf = 4 = minimum; L-P0: prefix 0.7 = maximum; L-PCLM2: mask 0.30, rounds 3, temperature 1.0, all maxima). Freezing boundary winners would under-tune generators and break the "tuned fairly" requirement for BOTH sides.
Rule (applies identically to every generator, simple and LLM, DEV only): for each parameter whose best value is a boundary value, add ONE outward step (the next value in the same direction) with the other parameters at their best values (one-at-a-time cells), plus nothing else; run the new cells on the same DEV seeds (100-102) and size (300); the frozen configuration is the best cell over the UNION of the original and the added cells. Extension values: S-LIB length (4,6) and P(N-Me) 0.55 (P(D) stays 0.0, its best, a boundary at 0 that cannot go lower); S-EDIT k = 4 and k = 5 (one-at-a-time, stops at 5); S-BRICS nf = 2 and 3; L-P0 prefix 0.85; L-PCLM2 mask 0.45, rounds 5, temperature 1.2; L-CHEMFM prefix 0.85 if its best is 0.7 (applied when its DEV table lands). Only one extension round is run; if the best is still on the new edge it is reported as edge-bound and the frozen config is that cell.
Consequences stated now: (a) S-LIB wins constraint satisfaction by construction and its P(D) = 0 means it generates no D residues; D-residue content is not part of C or of the gates, so this is a limit of the metrics, not a result; (b) extension can only raise the simple generators' DEV Y as well as the LLMs'; the "LLM wins" bar is therefore at least as hard as pre-registered; (c) no test-half statistic was computed before this amendment.

**Descriptive observations (not tested; no inference drawn):** (a) On Y_cluster (Butina clusters at Tanimoto 0.7 among satisfying molecules) S-EDIT scores 117, lower than the LLMs (151-166): S-EDIT's many satisfying molecules fall in few clusters (heavily edited copies of 300 seeds), while the LLMs' are somewhat more spread; S-LIB is both high-Y and diverse (Y_cluster 700, internal diversity 0.72). (b) L-CHEMFM at the frozen prefix 0.85 completes only the last ~15% of each seed's tokens, so its outputs stay close to the seeds; the grid was edge-bound after the single A1 extension round and could be under-tuned (disclosed deviation). (c) PeptideCLM-2 was used outside its intended use (masked infilling); the P0 model is a 25 M ChEMBL-dominated reference. (d) The task rewards what S-LIB gets by construction: the constraint set (macrocycle, 2-6 N-Me, MW/TPSA, no PAINS) is satisfied almost always by library enumeration built from monomers with N-Me and a macrocyclic ring; that is a property of the metric, and it does NOT mean S-LIB's molecules are good (no binding, permeability or synthesisability evidence, as stated at the top).
**What this does and does not establish.** For the generation job as pre-registered (validity/novelty/constraint yield from seed variants), a monomer-library enumeration beats the three LLM generators by about 400-470 satisfying novel molecules per 1000 samples. It does not show LLMs are useless for generation (property-conditioned or structure-conditioned generation was not tested, and none of the LLMs was trained or fine-tuned for this constraint set). It is a go/no-go for generation compute: **NO-GO for spending on LLM generation under this task definition.**
