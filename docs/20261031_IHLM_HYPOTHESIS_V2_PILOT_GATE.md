## Hypothesis H-v2
On held-out laboratories, with 5 to 25 revealed labels, a pretrained peptide-LM backbone (PeptideCLM-2) combined with stereo-aware analog retrieval ranks new peptides better than (a) the same backbone fine-tuned on the revealed labels and (b) fingerprint nearest-neighbour / the PT-GBM + analog-correction baseline.

## Pilot gate (run BEFORE any large compute; CPU/small-GPU, a few USD at most)
Frozen backbone embeddings (no fine-tuning) + the existing retrieval correction vs the strongest existing baseline, same few-label leave-labs-out protocol and folds as the H4b baselines. Hyperparameters chosen on development labs only (source split by sha256(source) mod 2, development half only); gate read on the test half.
- PASS: Spearman on the test half exceeds the best existing baseline (PT-GBM + analog correction, 0.454/0.429/0.419 at the three label budgets) by >= +0.03 at >= 2 of 3 budgets, and the lab-cluster bootstrap 95% CI of the paired difference has lower bound > 0 at those budgets.
- FAIL: otherwise. On FAIL the claim is dropped, reported as a null with its CI, and no fine-tuning compute is spent.
- Margin and rule fixed now, before the backbone has produced any number.
- **Amendment A1 (2026-10-28 ~23:40 CDT, still before any backbone number; owner objection: the data are analog-rich, so nearest-neighbour looks strong):** the PASS criterion above is evaluated on the HARD STRATUM as primary: held-out compounds whose maximum Tanimoto (Morgan r2, 2048 bit, stereo-aware) to ANY revealed compound of that lab/target is in the bottom tercile of the test half (tercile cut computed on the test half's own similarity distribution, per budget). The overall-test-half result is reported as secondary and cannot by itself pass the gate. Baselines in the hard stratum include fingerprint nearest-neighbour (expected near chance there; that is the point) and PT-GBM + analog correction. A win only counts if it beats the best baseline in the hard stratum by >= +0.03 with cluster-CI lower bound > 0 at >= 2 of 3 budgets. If the hard stratum has fewer than 5 held-out labs the gate is reported UNDERPOWERED, not passed.
## After a PASS
Fine-tuned arms (same backbone +/- retrieval, plain larger backbones) in the loop, >= 10 seeds, regimes A/B/L, causal standardisation, controls as in the L7 protocol; cost estimate shown before launch.

## Addendum A2 — executable design (written 2026-10-28 late evening, BEFORE any embedding-based score was computed; code: `research/guangzhou_all_atom/cyclic_llm/ihlm_backbone/pilot1/pilot1.py`)
**Testbed (reused unchanged).** Permeability, CycPeptMPDB labelled set, labs with >= 20 peptides, leave-labs-out few-label cells exactly as T1/T1b (`technique_sprint/fusion_b/perm_b.py`): k in {5, 10, 25}, seeds 0-4, reveal = `crc32("lab|k|seed")`, candidates exclude revealed items and flat-identical siblings, cell valid if >= 20 candidates and non-constant labels, a lab needs len - k >= 20. Metric: Spearman(score, y_raw). Aggregation: seeds averaged within lab, then labs; intervals: lab-cluster bootstrap (B = 2000, seed 20261031).
**Regression gate (done first).** The code must reproduce `fusion_b/results/perm_b_cells.csv` PT, A and PT+k cell-by-cell to 1e-9 (and the documented lab-first means 0.419/0.368/0.381 and 0.454/0.429/0.419). If not, the pilot stops and is reported as an audit problem.
**Dev/test split.** `sha256(str(source)) mod 2`: 0 = development half (hyperparameter and configuration selection only), 1 = test half (gate). Labs with len - k >= 20 per budget on the CORRECTED annotation (counted before any embedding score existed): k=5: 16 (dev 8 / test 8); k=10: 15 (7 / 8); k=25: 10 (4 / 6) (the earlier count 8/8/5 came from the pre-fix cell file and is superseded). A budget is UNDERPOWERED when fewer than 5 test labs have a valid hard-stratum value (>= 8 stratum items in at least one cell).
**Hard stratum (A1).** Per budget, pooled over the cells of the half being evaluated: theta = 33.3rd percentile of each candidate's maximum fingerprint Tanimoto (chirality-aware Morgan r2, 2048-bit, binary) to any revealed compound; stratum = candidates with max-sim <= theta; a cell's stratum Spearman needs >= 8 items.
**Backbone embeddings.** PeptideCLM-2 small (and base), our re-implementation (`ihlm_backbone/`), pinned commits as in `docs/20261031_IHLM_BACKBONE_PEPTIDECLM2.md`. Pooling: final-LayerNorm hidden state, mean over tokens excluding [CLS]/[SEP]; no fine-tuning; max_len 512 (0 peptides truncated, small). Per held-out lab, embeddings are centred by the mean of the training-lab peptides (label-free) and L2-normalised; cosine similarity `se = max(cos, 0)`.
**Baselines (all computed per cell; the margin applies against the BEST of them on the test half, chosen per budget on the test hard stratum — conservative).** A = T1 analog kernel (Tanimoto^4, lambda 0.05); NN1 = label of the most similar revealed compound; PT = HistGB prior trained on the other labs; PT+k = PT + analog residual correction (the 0.454/0.429/0.419 baseline); GP_fp = Tanimoto-kernel GP on chirality-aware Morgan r2 2048-bit COUNT vectors, **code reused unchanged from `loop_retro/loop_models.py::GP`** (amplitude = Var(revealed y), noise = 0.3 x amplitude, hyperparameters fixed there; added at the coordinator's request after the survey reported Tanimoto-kernel GPs beating fine-tuned LMs on near-duplicate-removed and scaffold splits, arXiv 2511.21566, extract-derived, unverified).
**Candidate configurations (selected on the DEV half only; one configuration per backbone size is frozen in `results/selection_<size>.json` and committed before the test half is run).** EPT_r{10,100} (ridge on standardised embeddings trained on training labs' within-source-z labels = the prior); EPTk_r{10,100} (that prior + the PT+k correction with fingerprint similarity); EA_g{1,2,4} (analog estimate with embedding similarity se^g); ECPTk_r{10,100}_a{0.25,0.5,0.75}_g{1,2} (that prior + correction with combined similarity a x fp + (1-a) x se^g); GP_fpemb (GP with kernel 0.5 x Tanimoto-count + 0.5 x linear cosine kernel on centred embeddings; same fixed hyperparameters). Selection rule: argmax of the dev-half hard-stratum Spearman, mean over dev labs then over budgets. 21 configurations, selection bias acknowledged; the test half is untouched by selection.
**Gate (unchanged from above/A1).** PASS iff, for the selected configuration, (selected - best baseline) >= +0.03 with lab-cluster bootstrap lower bound > 0 at >= 2 of 3 budgets on the test-half hard stratum, with no budget counted if UNDERPOWERED. GP_fpemb is also reported separately. Overall (all-candidate) test-half difference is secondary and cannot pass the gate.
**Controls (reported with the gate).** Negative: labels permuted within source (rng 20261031); all arms must have mean Spearman |x| < 0.05 and lab-cluster CI covering 0. Positive: synthetic labels = linear function of the top-5 principal components of the centred embeddings (+ N(0, 0.3^2)); the selected/embedding-similarity arms must beat the fingerprint arms (A, GP_fp) by >= +0.05 at k=25 over all labs; and a fingerprint-planted twin (top-5 PCs of log counts) on which the fingerprint arms must not lose to the embedding-only arm. A failed control invalidates the pilot regardless of the gate.
**Caveats fixed in advance.** (1) PeptideCLM-2's pretraining corpus (PubChem etc.) overlap with CycPeptMPDB peptides is not checked; no PubChem snapshot is available here, so the leakage sensitivity is UNCHECKED, not passed. (2) Dev and test halves are 9/8 labs (k=5), so every estimate has wide intervals; the margin +0.03 was fixed before data. (3) Base-size embeddings are run second and reported separately; they do not replace a failed small-size gate.

**A2 regression result (done before any embedding-based score; `ihlm_backbone/pilot1/results/regression_prefix.json`, `regression_postfix.json`).** Our re-implementation of the baseline cells reproduces `fusion_b/results/perm_b_cells.csv` cell-by-cell on the PRE-fix annotation file (`git show e2d1069bf^:.../annotations.csv.gz`): 606 cells (PT, A, PT+k), 0 mismatches, max abs difference 9.7e-17. On the CURRENT corrected annotation the same code gives 447 of 561 comparable cells different, with fewer cells (193 vs 202) and 16 vs 17 labs at k=5. **Audit finding: the committed T1/T1b permeability baselines (PT 0.419/0.368/0.381, PT+k 0.454/0.429/0.419, A 0.227/0.309/0.333; lab-first means) were computed on the pre-source-correction annotation (cells committed 10-28 14:34, correction 19:04-19:16).** Post-fix lab-first means (same code, corrected data; 16/15/9 labs): PT 0.401/0.369/0.388, A 0.2235/0.321/0.395, PT+k 0.425/0.418/0.429. The numbers quoted earlier in this document (0.454/0.429/0.419) are therefore pre-fix and are NOT the comparison target; the target is the best baseline recomputed on corrected data in the same run (see Baselines above). T1/T1b permeability numbers elsewhere (including the claims ledger and the manuscript drafts, if quoted) need a pre-fix label or a rerun; not done here.
**Embeddings (computed before any score).** Small: 6,960 x 512, 0 truncated, all finite, sha256 of the float32 array 73646dc99b5846e82c328d40cc568c5588093815cae08a682439b5d833dc20f7. ## Addendum A3 — representativeness analyses (owner concern, relayed by the coordinator; written BEFORE any test-half number was opened)
State at writing: the dev half was run and the selections were committed (`results/selection_{small,base}.json`, dev numbers seen); the test-half jobs for both sizes had been started but their result files had NOT been opened (only progress lines `test <lab> n <n> <s>` were seen). The single sha256 split of A2 remains the pre-specified primary analysis and is reported as such, labelled **single-split**. Everything below is added; none of it changes the A2 rule. **The gate is a go/no-go for compute only and must not be cited as paper evidence.**
1. **Minimum detectable difference (MDE).** For each budget: MDE80 = (1.96 + 0.84) x SD_d / sqrt(n_labs), where SD_d is the SD across labs of the paired difference (selected configuration minus best baseline, hard stratum) and n_labs the number of test labs with a valid hard-stratum value. Pre-registered SD_d source: the DEV half (so no test number is used); the same quantity from the test half and from all labs is reported afterwards as post hoc. Normal approximation; the lab-cluster bootstrap CI is slightly anti-conservative at n ~ 8, so the MDE is a lower bound. **Wording rule:** if MDE > 0.03 the budget is UNDERPOWERED for the +0.03 margin, and any miss is reported as "no gain detectable above MDE = x", never "no gain".
2. **Repeated source splits.** 50 random halves of the eligible labs (rng seed 20261031; 10 labs dev / 10 labs test per split; a split's budget needs >= 5 labs with a valid hard-stratum value on its test part); in each split the configuration is selected on its dev part by the A2 rule among the same 21 configurations, the best baseline is chosen on its test part, the paired difference gets a lab-cluster bootstrap CI (B = 1000), and the split "passes" under the A2 rule (>= 2 budgets with diff >= +0.03 and lower bound > 0, none UNDERPOWERED). Reported: per-budget distribution (median, IQR, 5th-95th percentile) of paired differences, fraction of splits passing, fraction underpowered, how often each configuration is selected. Splits share the same 20 labs and are not independent: descriptive only.
3. **Skill relative to the inter-laboratory noise ceiling.** From the 21 peptides measured by PAMPA in >= 2 laboratories (definition of `c2_audit/prep_anchor_data.py`): the cross-laboratory Spearman of raw values over laboratory pairs sharing >= 3 peptides (pooled over pairs, bootstrap over peptides, 2000 draws) = r_x; the approximate ceiling for a perfect predictor of one laboratory's labels is sqrt(r_x) (both measurements assumed equally noisy; an approximation). Reported: r_x and sqrt(r_x) with CIs, and each arm's hard-stratum and overall mean Spearman as a fraction of sqrt(r_x) with a CI propagated by bootstrap. 21 peptides give wide CIs; it is a scale, not a bound.
4. **Second public set.** Caco-2 from the same database (annotation column `caco2`; 9 labs with >= 20 peptides, 4 with >= 45): the SAME pipeline, the configuration frozen from the PAMPA dev half (no re-selection), baselines and PT recomputed on Caco-2 labels of the other labs, the same dev/test rule by sha256(source) mod 2, k in {5, 10} (k = 25 has too few labs), reported with its MDE and as UNDERPOWERED if < 5 test labs. MDCK (1 lab with >= 20) and RRCK (2) are too small and are not run. No non-cyclic permeability or activity set is present locally or checked on S3 for this pilot, and nothing is downloaded (licences unchecked): so the second set is the same database, a different assay, not an independent source — it cannot rescue a miss, only flag inconsistency.
5. **Outcome vocabulary.** GO-for-compute only if the primary (single-split) gate PASSES and the repeated-split pass fraction is >= 0.5 and the Caco-2 check is not contradictory; NO-GO-detectable only if it fails with MDE <= 0.03 at >= 2 budgets; otherwise INCONCLUSIVE (underpowered). Caveats of A2 stand (PubChem overlap unchecked; 21 selected-from configurations; wide intervals).
