# Pilot 4 — new-target few-shot learning curve on exact potencies: pre-registration (written 2026-10-29, before ANY potency-dependent number)

Status: **go/no-go for compute only; not paper evidence.** Owner clarification (2026-10-29): the real scenario is *few labels from a new TARGET*, iterating — earlier pilots (1, 2) tested lab shift on permeability, the wrong proxy. Code: `research/guangzhou_all_atom/cyclic_llm/ihlm_backbone/pilot4/`.

## 1. Data and design
- Source: `multitarget/integrin_chembl/retro_recovery/data/pair_labels.csv.gz` (24,583 pairs, 793 targets), `targets_v2.csv` (family = folds_v2 accession/gene/Pfam-Jaccard family; paralogs share a family), `compounds.csv.gz` (isomeric SMILES), frozen hashes in `FROZEN_HASHES*.json`.
- **Exact potencies only** (`relations == '='`): 21,575 rows, 724 targets, but only 1,559 inactives and no target with ≥ 10 inactives (censoring): classification is not possible, so the task is **potency ranking**, pActivity = −log10(value_nM·1e-9).
- **Eligible test targets (rule fixed now):** ≥ 30 exact values and SD(pActivity) ≥ 0.5 → **141 targets, 16,926 rows, 47 families** (verified 2026-10-29). Assay mix of eligible rows: IC50 53.4 %, Ki 23.5 %, EC50 10.6 %, mixed 8.3 %, Kd 4.2 % (cross-assay IC50/Ki noise is a stated caveat). Compounds: 10,918 unique in the eligible rows.
- **Dev/test split of eligible families (rule fixed now, computed from family ids only):** `sha256(family) mod 2` (0 = dev, 1 = test) → dev 26 families / 55 targets; **test 21 families / 86 targets**. One family (G997e29c2) holds 56 of the 141 targets and falls in the test half. **Aggregation is therefore family-equal:** per-target means over seeds → per-family mean over its targets → mean over families; the family-cluster bootstrap resamples families (B = 2000, percentile). Target-weighted pooling is reported as a secondary and is dominated by that family.
- **Family-disjoint training:** the 47 eligible families are balanced into 6 folds by number of eligible targets (greedy, largest first; the 56-target family is alone in one fold: loads 56/17/17/17/17/17). For a test target in fold f, every model that uses other targets (prior, meta-learner, embedding ridge) is trained on all targets with exact data **whose family is not in fold f** (incl. 341 small non-eligible-family targets used for training only). No test-family target (paralogs included) is ever seen in training.
- Dev targets are used only to choose hyperparameters (§3); the gate is read only on test-half families.

## 2. Task, protocol, metrics
- Per target, per seed (10 seeds), a permutation fixes the reveal order; reveal sets are nested: k ∈ {0, 1, 3, 5, 10, 25} first-k compounds; query = all remaining compounds (queries must have ≥ 10 compounds, so k = 25 uses targets with n ≥ 35). Stereoisomer siblings are not removed (kept: activity cliffs are part of the data; caveat: sibling lookup inflates nearest-neighbour methods, hence the hard stratum).
- Metrics on the query set: Spearman (predicted vs true pActivity; constant prediction scores 0), NDCG@10 (gain = pActivity − min over the target's exact values), top-decile recall (top 10 % of the query by truth recovered in the predicted top 10 %).
- **Hard stratum (primary):** the query compounds whose maximum Tanimoto (Morgan r2, 2048 bit, chirality-aware) to any revealed compound lies in the bottom tercile of that (target, seed, k) query set. The overall query set is secondary.
- **Iterative variant (reported, not part of the gate):** active-learning replay, k0 = 3 revealed, 5 rounds × 5 picks, 5 seeds, targets with n ≥ 30; outcome = fraction of the target's top-decile potent compounds (n_top = max(3, ⌈0.1 n⌉)) revealed after round 5, minus random. Acquisition: random; greedy (NN, d, f, g); UCB for the GP.

## 3. Methods (all fixed here; grids tuned on dev targets only, scored by mean Spearman at k ∈ {3, 5, 10})
Features: Morgan r2, 2048-bit, chirality-aware, Tanimoto (binary).
Baselines — (a) **NN**: ŷ_j = Σ w_ij p_i / Σ w_ij + 1e-3·max_i s_ij, w = s^q, q ∈ {1, 3, 6}; (b) **Tanimoto-kernel GP**, hyperparameters FIXED by this document (signal variance 1.5², noise variance 0.5², prior mean = revealed mean; global mean 7.5 at k = 0; UCB β = 1.0 for the iterative variant); (c) **RF** on fingerprints fit on revealed only (200 trees, defaults); (d) **global prior + correction**: a target-agnostic potency prior g(x) = HistGradientBoosting (fixed: 200 iterations, lr 0.1, 31 leaves, L2 1.0) on fingerprints trained on within-target z-scores of all training-family targets (n ≥ 10), plus the revealed-residual kernel correction ŷ_j = b·g_j + Σ w_ij r_i/(Σ w_ij + λ), r_i = (p_i − p̄_S) − b(g_i − ḡ_S), b = 1.0, w = s^q, q ∈ {1, 3, 6}, λ ∈ {0.3, 1, 3}; (e) **prior only** (k = 0 reference and floor for k > 0).
Candidates — (f) **meta-learned target-conditioned predictor**: MLP 2048→512→128 embedding e(x) and linear prior head g(x), trained episodically on training-family targets (episode = a target, support size drawn from {1, 3, 5, 10, 25}, 64 query compounds; 32 episodes/step, Adam 1e-3, dropout 0.1), prediction ŷ_j = b·(g_j − ḡ_S) + s·Σ_i a_ij r_i with a_ij = exp(−‖e_i − e_j‖²/τ)/(Σ_i exp(−‖e_i − e_j‖²/τ) + exp(−d0)), (b, s, τ, d0) learned scalars, MSE on p_j − p̄_S; checkpoints at 1,000 and 3,000 steps, chosen on dev. (g) **PeptideCLM-2 (small) embeddings**: frozen mean-pooled final-norm hidden states (as pilot 1, no fine-tuning); prior = ridge on standardised embeddings (α ∈ {10, 100, 1000}) trained on training families' z-scores; similarity s = 0.5·Tanimoto + 0.5·max(0, cosine of standardised embeddings); same correction as (d) with q, λ tuned on dev. The comparison (g) − (d) isolates what the LM embeddings add.

## 4. Gate (frozen now)
- For each candidate (f, g) and each k ∈ {3, 5, 10}: paired difference of **hard-stratum Spearman** between the candidate and the **best baseline among a–e chosen on the test half at that k** (conservative), family-equal means, family-cluster bootstrap 97.5 % CI (Bonferroni for the two candidates). A candidate **PASSES** if the difference is ≥ +0.03 with CI lower bound > 0 at ≥ 2 of the 3 budgets. Sensitivity (reported): baseline chosen on dev instead; overall-query Spearman; NDCG@10; top-decile recall; target-weighted pooling.
- **Minimum detectable difference** (80 % power) is computed from the DEV families' between-family SD of the paired difference, scaled to the 21 test families, and committed in an addendum **A1 before any test-family number is read**, together with the frozen hyperparameters. **Outcomes:** PASS; FAIL (not passing, MDE ≤ 0.05 at ≥ 2 of 3 budgets); **NOT DETECTED / UNDERPOWERED** (not passing and MDE > 0.05 at ≥ 2 of 3 budgets): a miss is then worded "no gain detectable above MDE", never "no gain".
- **Repeated splits:** 50 random halves of the 47 eligible families (giant family placed at random); per split, configuration chosen on its dev half, evaluated on its test half from the precomputed per-target results; report the distribution of paired differences and the fraction of splits that pass.

## 5. Controls (must hold, else the pilot is invalid and said so)
1. **Planted potency series (positive):** for each test target, p' = 5 + 4·mean_{c∈C} Tanimoto(x_j, c) + N(0, 0.3²) with C three random compounds of that target: NN and GP must reach mean Spearman ≥ 0.4 at k = 10 and (e) ≤ 0.15.
2. **Shuffled potencies within target (negative):** 10 permutation seeds; every method's mean Spearman's family-cluster 95 % CI must contain 0 and |mean| ≤ 0.05.
3. **Target-agnostic prior only** (e) is reported as the floor at every k.

## 6. Staging (to prevent peeking)
Stage 1: dev-half families only (55 targets): hyperparameter grids, dev baselines, between-family SD → **A1 commit** (MDE, frozen configurations, fold models). Stage 2: test-half families, then iterative variant, controls, repeated splits, aggregation, results section. Raw per-(target, k, seed, method) results are written to `pilot4/results/`.

## 7. Caveats declared in advance
Cross-assay IC50/Ki/EC50 noise; analog-rich series inflate lookup baselines (hence the hard stratum); one family holds 56 of 141 targets (family-equal weighting; 21 test families); exact-value targets are a selected, potency-spread subset (SD ≥ 0.5) of ChEMBL macrocycle data; PeptideCLM-2 pretraining data (PubChem et al.) may overlap these compounds (unchecked); the iterative variant has small pools (30–1,000 compounds); a gate verdict does not support any claim in a paper.

## 8. Compute
Local CPU (`nice -n 10`), no cloud; cost USD 0 (hard cap USD 3 stands if spot is needed; not expected: embedding of all 16,195 compounds took ≈ 2 min on 4 threads).

## 9. Amendment A0 (2026-10-29, coordinator/owner request; written BEFORE any potency-dependent number — pre-registered, not post hoc): secondary arm — censor-aware priors ("negative instances")
Rationale: the exact-only design discards the 2,433 `>` rows (pure) and 289 `<` rows (pure) of the 24,583 pairs (mixed-relation rows `=;>`, `<;=`, `<;>` — 281 rows — are excluded from the censored arm). In nM a `>` row means the compound is *less potent than* the bound (pActivity < bound: a left-censored potency, mostly inactives), a `<` row means more potent than the bound. Fitting only on exact rows is survivorship-biased towards potent compounds. **This arm is SECONDARY: it cannot pass or fail the gate; it is reported next to it.**
- **Arms (identical architecture and training budget; only the loss and the rows differ):** (h0) *exact-only MLP prior* — MLP 2048→256→1 (ReLU, dropout 0.1, Adam 1e-3, 30 epochs, batch 256) trained with MSE on within-target z-scores of exact rows of the training families; (h1) *censor-aware MLP prior* — same network trained with a **Tobit loss** on exact + pure censored rows of the training families: exact row → Gaussian NLL, `>` row (pAct < c) → −log Φ((c − μ)/σ), `<` row (pAct > c) → −log(1 − Φ((c − μ)/σ)); bounds c converted to the same per-target z scale using that training target's exact-row mean/SD (targets with < 10 exact rows are skipped in both arms); σ a learned shared scalar (softplus, init 0.8). Likewise (f0) the meta-learned predictor (f) as in §3 (exact-only episodes) vs (f1) *censor-aware (f)*: identical except that **query rows of training episodes may be censored and then enter the loss through the same Tobit term**; support rows (revealed labels) stay exact in training, exactly as at test time. Each of h0/h1 is also used as the prior in the correction of §3(d) to give (d-h0), (d-h1).
- **Test time is unchanged and exact-only:** revealed labels and query sets come only from exact rows of the held-out target; censored rows of held-out families are never used for training, revealing or ranking. No relation/censor value is ever a model input: features are fingerprints (and embeddings) computed from the compound only (see leakage check).
- **Reported:** paired differences (h1 − h0), (d-h1 − d-h0), (f1 − f0) in Spearman (hard stratum and overall), NDCG@10 and top-decile recall at k ∈ {0, 3, 5, 10, 25}, family-equal means, family-cluster bootstrap 95 % CIs, with the same MDE computation as §4 (A1). Wording rule for a miss as in §4.
- **Diagnostic S3 (reported, labelled censoring-confounded):** on held-out families, AUROC of the prior's score at separating held-out `>` rows (treated as inactive-side) from exact rows with pActivity ≥ 7; this can reflect the censoring shortcut documented elsewhere (63.6 % of inactives vs 3.1 % of positives censored) and is not evidence of biology.
- **Control C4 (planted censoring that depends on the true potency, by construction):** in a synthetic world built from the planted potency series of §5 for the *training* targets, rows whose planted potency falls in the lowest 30 % of that target are replaced by a `>` row at that target's 30th-percentile value (exact-only training therefore sees only the upper 70 %); held-out targets are fully observed. **Pass:** the censor-aware prior (h1) beats the exact-only prior (h0) in Spearman on the fully observed planted held-out query sets by ≥ 0.03 (mean over targets, paired), and the exact-only arm shows the pre-registered bias (mean predicted rank of the true bottom-decile compounds higher than under h1, i.e. survivorship bias).
- **Leakage check L1:** (i) unit test that the model input is the feature matrix only (no relation, censor, document or assay column can reach any arm; asserted on the function signatures); (ii) permuting the censoring flags among rows must leave (h0) predictions bit-identical, and under (h1) must degrade the planted-control gain (the gain must come from the correct flags).
- Planned order unchanged (§6): h0/h1/f0/f1 hyper-settings are fixed above (no tuning), so Stage 1 only checks they train; the secondary comparison is read in Stage 2 together with the primary results.
