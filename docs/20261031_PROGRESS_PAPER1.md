### 6.2 Tag legend and interval-type paragraph (the interval kinds now sit in the Conventions paragraph of Methods)
Tags: `[VERIFIED:<file>]` = number re-read from a committed result file by script; `[REPORTED:<file>]` = read in a committed analysis document, data file not re-read; `[LIT-VERIFIED]` = primary source re-opened in the verification pass (abstract and full text as stated per item in `docs/20261031_PAPER1_CITATION_VERIFICATION.md`; preprints cited as preprints); `[LIT-SUMMARY]` = page opened through a summarising tool; `[LIT-UNVERIFIED]` = not opened or not verifiable. **Interval types** (each interval is labelled). Three kinds are used for the loop and ladder results: (a) *seed-level t* = t-interval over the 10 or 20 seeds (used for the seed-level contrasts in §3.6 and §6 and as the first interval of each pair taken from `paper1_cluster.json`); (b) *percentile bootstrap of the mean over seeds* (95 %, 99 % for K_phys contrasts; used in the §3.1 table and the §3.2 seed-based contrast, post hoc for the L5 headline); (c) *lab-cluster t* = t-interval over source clusters with n − 1 degrees of freedom (the second interval of each pair from `paper1_cluster.json`, in §3.1, §3.6 and §6; conservative when a few laboratories carry the effect). The registered L5 criterion used the *spread* (central 95 % range of per-seed paired differences; not a confidence interval). The §3.2 table uses a percentile bootstrap over held-out sources (6 to 11 clusters; anti-conservative), and the binding and pilot results (§3.3 to §3.5, §3.7, Appendix B) use bootstraps over target families or source clusters as labelled in each place. Seed-based intervals describe variability over initial sets on one fixed library and say nothing about new laboratories. "Laboratory" in this paper means a literature source id (a paper), so within-laboratory and cross-laboratory results are bounds, not measurements of assay-to-assay transfer.
