Supported scdownstream outputs whose tables are unreadable fail visibly instead of serving unverified cached scores. Other workflow families retain their existing findings paths; this does not certify their generated interpretations.

PDF output previews previously used a blocked browser iframe. They now render authorized bytes with local PDF.js canvas and page controls, with locally bundled worker, CJK maps, fonts and image decoders. No iframe, external CDN, annotation links or document actions are executed; authorization and CSP are unchanged.

Settings no longer nests a Parameters disclosure around the Required/Optional groups or adds an internal480px scroll area. Source claims now open the uniquely identified file, including files beyond the gallery render cap; ambiguous names are reported rather than guessed. Incomplete runs retain their record and partial-file messaging, without a false no-report or no-files statement. Resume advice respects available recorded checkpoints. QC rows show source filenames and explanations; legacy not-evaluated metadata falsely tagged FASTP is labeled Output metadata while preserving reported_gate. Genuine fail/pass assessments and original records are not erased. The underlying Python scanner correction remains a separate previously reviewed pending change.

The visible Report now has source/value tables and up to three actual scientific image previews, without repeating the full file inventory. Downloadable reports retain the full inventory. Technical endpoint prose was removed and the execution profile is no longer mistaken for an input filename. UI strings added to English and Chinese catalogs.
