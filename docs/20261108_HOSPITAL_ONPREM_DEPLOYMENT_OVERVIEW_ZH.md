# BioMate 医院本地部署合作说明

BioMate 将由前站工程团队负责安装实施、配置联调、用户培训及现场协调。医院信息中心主要提供基础设施、访问条件和安全管理支持，无需承担 BioMate 应用系统的开发工作。

## 需要医院信息中心配合的事项

- **明确对接人员。** 确定基础设施、信息安全及科研团队的联系人，协调环境准备、审批和试点安排。
- **提供部署资源。** 明确可使用的服务器或私有云、存储及备份条件。BioMate 根据试点任务和使用规模提出配置建议；本地模型、分子建模或训练所需的 GPU 资源按实际任务确定，并非所有部署都需要配置 GPU。
- **确认网络和资源访问方式。** 明确科研用户访问平台的方式，以及工程师实施与支持的授权方式。公共数据库、文献检索等在线资源需要经医院批准的外网访问，或由医院提供内部访问接口。BioMate 配合完成对接与验证，相关安排遵循医院现有安全管理要求。
- **确认模型服务方案。** 可评估使用医院现有 AI 服务、部署本地模型，或对接医院批准的外部服务。BioMate 负责评估适配方式及所需资源。
- **确定试点用户和数据。** 选定参与科室、科研任务及获准使用的测试数据。初始安装可使用公开或模拟数据，不要求提供可识别患者身份的数据。

在条件适合的情况下，优先利用医院已有基础设施。

## BioMate 负责的工作

BioMate 负责环境评估、部署方案确认，以及应用软件和所需软件资源的交付。前站工程团队完成平台安装与配置，对接约定的存储、计算和模型服务，并验证选定科研流程。

平台安装后，我们将协助试点用户开展实际使用，提供培训、问题处理和运维交接。与医院科研系统或数据源的连接，按双方确认的接口范围和访问权限另行安排。初始部署不要求替换或改造医院现有临床业务系统。

## 实施安排

1. **需求确认。** 明确试点场景、参与用户、部署环境及数据安全要求。
2. **环境准备与安装。** 医院开放经批准的资源和访问条件，BioMate 前站工程团队完成安装与联调。
3. **联合验证。** 检查登录访问、数据上传、代表性科研分析、结果展示和下载。信息中心确认运行管理要求，科研团队确认选定结果的科学合理性和使用价值。
4. **试点启用与交接。** 完成用户培训和验收，明确后续支持、维护及扩展安排。

具体实施周期在基础设施及审批条件确认后，由双方共同约定。

## 数据安全与后续服务

医院掌握科研数据的访问权限及部署环境的管理权。外部 AI 服务、在线资源和远程支持连接，仅在双方约定及医院批准的范围内使用。对于受限网络或不联网环境，双方提前确认可通过院内接口访问的资源，以及需要在院内配置的模型、数据库及科研流程。如无获批的外网通道或可用的内部访问接口，实时外部检索将不可用，本地分析可使用已部署的资源开展。

医院信息中心负责底层基础设施及院方安全管理；BioMate 负责提供版本更新包、更新说明和技术支持，由前站工程团队协调实施。更新可通过医院批准的网络获取，也可使用离线安装包。实施前与医院沟通更新安排，完成必要备份，更新后验证平台运行；如出现问题，按备份和回退方案恢复。

远程维护采用医院批准的接入方式，例如院方 VPN、堡垒机或院方人员参与的屏幕共享，经医院授权后开展排查和维护。不具备远程条件时，由前站工程师现场处理，后方研发团队提供技术支持。具体更新与技术支持安排在交接时确认。

## 建议下一步

由医院信息中心、试点科研团队与 BioMate 前站工程团队召开一次联合对接会议，确认现有资源、网络限制、模型服务方案及首批试点场景。BioMate 据此提交具体配置建议和实施安排，供双方确认。
