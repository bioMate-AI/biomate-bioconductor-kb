dig @1.1.1.1 +short dev-public.biomate.ai A

## HTTPS reachability (bypass local DNS)

```bash
# preferred: SNI + Host stay correct, cert verifies
curl -sS -o /dev/null -w '%{http_code}\n' \
  --resolve 'dev-public.biomate.ai:443:52.42.49.175' \
  'https://dev-public.biomate.ai/'
# → 200

# alternate: IP + Host + insecure TLS
curl -k -sS -o /dev/null -w '%{http_code}\n' \
  -H 'Host: dev-public.biomate.ai' \
  'https://52.42.49.175/'
# → 200

# HTTP redirects to HTTPS
curl -sS -o /dev/null -w '%{http_code} %{redirect_url}\n' \
  --resolve 'dev-public.biomate.ai:80:52.42.49.175' \
  'http://dev-public.biomate.ai/'
# → 301 https://dev-public.biomate.ai/
```
