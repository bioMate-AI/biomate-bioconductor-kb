## Fix 1: Hi-C False-Positive Duplication Gate

**Problem:** MARKDUPLICATES gate (40% threshold) fires on Hi-C data, producing systematic false positives.
Hi-C uses proximity ligation; duplicate reads represent real chromatin contacts, not PCR artifacts.
WGS duplication metrics do not apply to Hi-C.

**Fix:** Added `"hic"`, `"hic_seq"`, `"hi_c"` to MARKDUPLICATES `_skip_domains` in `_check_qc_thresholds()`.

```python
_skip_domains = ("rna_seq", "rnaseq", "rna", "scrna_seq", "single_cell",
                 "atac_seq", "atacseq", "chip_seq", "chipseq",
                 "cut_and_run", "cutandrun",
                 "hic", "hic_seq", "hi_c")   # ← added
```

**Rationale:** Hi-C library complexity is measured by unique valid pairs / total valid pairs
(reported by cooler / Juicer), not by Picard's duplicate fraction. Applying WGS thresholds
produces systematic false-positive gates.

## Fix 2: CellRanger Sequencing Saturation Advisory Gate

**Problem:** `_parse_singlecell_metrics()` did not read the "Sequencing Saturation" column
from CellRanger `metrics_summary.csv`. Investigators had no systematic signal when a library
was under-sequenced.

**Fix in `_parse_singlecell_metrics()`:** Added parsing of `"Sequencing Saturation"` column
→ stored as `sequencing_saturation_pct`.

**New gate in `_check_qc_thresholds()` single-cell block:**

| Condition | Evidence | Action |
|-----------|----------|--------|
| `sequencing_saturation_pct < 30%` | [BRONZE] 10x Genomics CellRanger v7 docs — ≥ 50% recommended | Advisory (non-blocking) |

**Message:** "Most UMIs are under-sampled — additional sequencing depth would meaningfully
increase detected UMIs and genes per cell. 10x Genomics recommends ≥ 50% saturation."

## Fix 3: Near-Threshold Warnings for Coverage, TSS, NRF

**Problem:** `_check_qc_warnings()` had no near-threshold entries for DNA-seq coverage,
ATAC-seq TSS enrichment, or ATAC-seq NRF score. Investigators received no advance notice
before these metrics failed.

**New `elif` blocks added to `_check_qc_warnings()`:**

### Coverage (MOSDEPTH / SAMTOOLS_COVERAGE / GATK_COVERAGE / PICARD_WGS)
- Trigger: `_near_above(coverage, threshold)` — within 10% above the WGS (30X) or WES (80X) threshold
- Example: 31X with 30X threshold → "Coverage 31.0X is near the 30X threshold"

### TSS Enrichment (ATAC_QC / TSS_ENRICH / DEEPTOOLS_PLOTFINGERPRINT)
- Trigger: `_near_above(tss, 5.0)` — TSS in 5.0–5.5 range (marginal by ENCODE4 standards)
- Message: "TSS enrichment is near the ENCODE4 acceptable minimum (5); ideal is ≥ 7.0"

### NRF Library Complexity (ATAC_QC / TSS_ENRICH)
- Trigger: `_near_above(nrf, 0.9)` — NRF in 0.90–0.99 range
- Message: "Library complexity (NRF/PBC1) is near the ENCODE4 minimum (0.9)"
