## 0. Bottom line
1. The pilot gates are not calibrated to the data. Stated margins (+0.03/+0.05) are 2-18x smaller than the resolution of the data (MDE80 0.09-0.55), and the "CI lower bound > 0" clause makes the effective margin about 0.7 x MDE = 0.09-0.38 Spearman. Under any realistic true effect (0 to +0.05) each gate passes 1-15 % of the time per budget and about 1.6-3 % overall (pilots 1 and 4). The unbroken run of NO-GO/UNDERPOWERED verdicts is what the design predicts and says almost nothing about whether the hypotheses are true.
2. Several controls cannot fail (frozen arm, shuffled arm in the L7 aggregator, T2 S3 with a no-diversity frozen config) or cannot pass (the |x| < 0.05 negative control with about 7 labs; C2 equivalence on analysis I). A control that cannot fail validates nothing; one that cannot pass invalidates every pilot that registered it.
3. The data support within-library ranking comparisons on one assay. They do not support cross-laboratory generalisation, absolute skill, binding classification, or any claim about generative loops. The one result robust to every margin choice is the censoring finding (inverted AUROC 0.794 [DOC V5]).

## A. GATES

### A1. Validity gate (equivalence [0.45, 0.55] at 90 %, bias flag at 98.3 %)
Facts [DOC V5, gate-PC prereg]: margin 0.05 and the 98.3 % level chosen after intervals were seen; primary-control intervals on analysis I: C1 [0.458, 0.550], C2 [0.499, 0.619], C3 [0.533, 0.636] (I assume these are 95 % cluster intervals, as the manuscript labels them); 14-26 families.
Arithmetic [ARITH] (SE = 95 % half-width / 1.96; TOST passes iff |est - 0.5| <= 0.05 - 1.645 SE):
| control | SE | room 0.05 - 1.645 SE | P(equiv. passes), truth exactly 0.50 | true bias 0.02 / 0.03 |
|---|---|---|---|---|
| C1 (I_v1) | 0.0235 | +0.0114 | 0.37 | 0.27 / 0.18 |
| C2 (I_v1) | 0.0306 | -0.0004 | **0.00 (acceptance region empty)** | 0 / 0 |
| C3 (I_v1) | 0.0263 | +0.0068 | 0.20 | 0.15 / 0.11 |
| C1 (I_CD, 16 families) | 0.0298 | +0.0009 | 0.02 | 0.02 / 0.02 |
- **The gate cannot return VALID at the family counts we have.** Equivalence needs SE <= 0.0304 per primary control just to have a nonempty region (C2 on I is at 0.0306), and about 0.0145 for 80 % joint pass probability (each of three controls >= 0.93). Scaling the observed SE (C3: 0.0263 at 26 families) gives about 26 x (0.0263/0.0145)^2 = **~85 families** for P(VALID | clean) = 0.8 (same targets-per-family structure). Written-down prediction for the gate positive control: P(VALID | planted-valid) <= 0.08 at F = 26, about 0 at F = 14, and the smallest F on the grid {.., 50, 100} with P(VALID) >= 0.8 is 100 (not 50). If the run shows materially higher, my SE assumption is wrong; that is the test.
- **The positive-control decision rule cannot detect this.** PASS-A (P(BIASED) <= 0.10 on planted-valid) and PASS-B (detection >= 0.90 at a = 0.65) are both satisfiable by a gate that never says VALID. P(VALID | planted-valid), the quantity the owner's question is about ("can the gate return VALID"), is "separately reported, not part of PASS/FAIL". Add PASS-C: P(VALID | planted-valid, F of the benchmark under test) >= 0.5; otherwise call the gate a one-sided bias detector, not a validity certifier.
- **The false-alarm side is knife-edge.** Nominal family-wise false flag is <= 5 % (primary, Bonferroni 3) + <= 5 % (secondary, Bonferroni about 21) = up to 10 %, which equals the PASS-A line before any under-coverage. Percentile bootstrap over 23-26 clusters in the 98.3-99.8 % tails resolves tails poorly; at n = 10 a nominal 95 % percentile bootstrap covers 0.894 [DOC review_code D5]. I expect realised P(BIASED | clean) of 0.10-0.25 [ASSUME; the PC run measures it]. "Point-pass only at <= 0.10" is not a pass when the nominal ceiling is already 0.10.
- **Margin versus the effects it protects.** The margin certifies a benchmark carrying a shortcut of AUROC 0.55, while downstream gains hunted are 0.03-0.05 Spearman; the tolerated bias is as large as the effect measured. No mapping from shortcut AUROC to inflation of a model-comparison difference was derived.
- **Detection power** [ARITH]: with SE 0.0235 and the 98.3 % flag, P(flag) is 0.40 at a = 0.55, 0.97 at 0.60, 1.0 at 0.65; the 80 %-power effect is 0.076 (SE 0.03: 0.097). Shortcuts of 0.55-0.58 are therefore both undetected and inside the margin. PASS-B at a = 0.65 tests only the easy case; require 80 % power at a = 0.60 and report the curve.
- **Mixed logic.** Bias is flagged by a 98.3 % interval excluding 0.5 (statistical significance); equivalence needs a 90 % interval inside +-0.05 (practical). With more families a trivial AUROC 0.52 is flagged. Use one TOST-style rule: BIASED iff the 90 % interval lies wholly outside [0.45, 0.55]; VALID iff wholly inside; else INDETERMINATE (power-limited), which is not NOT_VALID.
- **What survives of "no benchmark is VALID":** the C4 censoring control (0.206 [0.134, 0.280]; inverted 0.794) is margin-independent: its interval is 0.2-0.37 from 0.5. That is a finding. "No benchmark certifies as VALID" is a statement about the gate's power, not about the benchmarks.
- The repo's gate self-calibration test accepts as few as 5/8 VALID and up to 3/8 BIASED on pure noise with 60 families (test_gate.py:27-31 [DOC review_data_eval I-6]); a test that passes with 3/8 false alarms is not a calibration test.

### A2. Pilot margins and the "CI lower bound > 0" clause
Effective margin = max(stated margin, z x SE). With MDE80 = 2.8 SE (pilots 1, 2, 5) or 3.08 SE (pilot 4), the CI clause needs an observed difference of about 0.70-0.73 x MDE: 0.09-0.38, not 0.03-0.05. [ARITH]
Gate pass probabilities for a true gain delta (P1 and P4: per-budget, then >= 2 of 3 budgets assuming independence; correlation would fatten the tail slightly):
| pilot (SE source) | delta = 0.05 | 0.10 | 0.15 | 0.25 |
|---|---|---|---|---|
| P1 small, dev-SD MDEs 0.277/0.312/0.235 (per-budget at 0.05: .07/.07/.09) | **0.016** | 0.083 | 0.27 | 0.82 |
| P1, post hoc test-half MDEs 0.208/0.235/0.466 | 0.017 | 0.092 | 0.30 | 0.85 |
| P4 candidates, MDEs 0.131/0.185/0.169 (97.5 % CI; per-budget at 0.05: .14/.08/.09) | **0.030** | 0.33 | 0.83 | - |
| P2 N-Me (one gate, MDE 0.191, margin 0.05) | 0.11 | 0.31 | 0.59 | - |
| P2 D flip (MDE 0.089) | 0.35 | 0.88 | 0.997 | - |
- A true +0.05 Spearman is already generous (the survey says frozen embeddings rarely beat ECFP/Tanimoto-GP [UNVERIFIED, extract-derived]). Gates passing 1.6 % (P1) and 3 % (P4) of the time under it were **structurally unable to pass** for the effects they were meant to find.
- **Data requirement** [ARITH]: P1's SD of the paired lab-level difference is about 0.277 x sqrt(8)/2.8 = 0.28; delta = 0.05 at 80 % power needs (2.8 x 0.28/0.05)^2 = about 250 labs (41 sources exist, 16 usable). P4 (SD about 0.24): about 220 families at delta 0.05, about 600 at 0.03; the whole dataset has 47 eligible families, giving MDE80 about 3.08 x 0.24/sqrt(47) = 0.108 even if every family were test. **A margin of 0.03-0.05 on hard-stratum Spearman is below the resolution of any dataset we hold, by a factor 2-4 at best.** These gates should have been refused at registration (MDE first), not run and labelled UNDERPOWERED afterwards.
- **"UNDERPOWERED means no statement" conflates design power with result information.** MDE says what a true effect would need in order to be seen; the interval says what the data exclude. P2 D flip: ours minus baseline +0.001 [-0.079, +0.026]; the upper bound 0.026 < 0.05 excludes a gain of the margin (subject to the 7-cluster caveat below), yet the verdict is "UNDERPOWERED". P1 small k=10 [-0.310, -0.025] excludes +0.03. Conversely P4 f upper bounds (+0.088/+0.077/+0.087) do not exclude 0.03. Report the interval against the margin; keep MDE as a design number.
- **Clusters below about 8 make the intervals unreliable.** P2 N-Me bootstraps 5 clusters, P1 4-8 per budget; a percentile bootstrap over 5 clusters has C(9,5) = 126 distinct resamples (7 clusters: 1,716) and under-covers badly (realised coverage of a nominal 95 % is plausibly 70-85 % [ASSUME]). The text calls them "slightly anti-conservative". Use t-intervals with n-1 df or exact sign-flip, and state df.
- **Best-of-K baseline chosen on the test half** (P1: 5 baselines; P4: 5; P5: 5) inflates the comparator (winner's curse). Conservative for "beats every baseline", but it handicaps the screen; make the dev-chosen baseline primary and report both (P4 does; P1 only post hoc).
- **Pilot 5 (H5).** The MDE is to be computed from the SD of (best baseline minus second-best baseline). Two baselines' errors are strongly correlated, so this understates the candidate-vs-baseline SD (H5 mixes two sources); the committed MDE will be flattered, perhaps 1.5-2x [ASSUME]. To avoid UNDERPOWERED (MDE <= 0.05) the SD must be <= 0.05 x sqrt(47)/2.8 = 0.122 [ARITH]. H5 was also formed after the pilot-4 curves showed the prior/lookup crossover, on the same 47 families; a blend of two crossing curves beats max(curve) near the crossover by construction. A PASS is exploratory, a FAIL is informative. Label it "exploratory re-analysis". With one family holding 56/141 targets alone in its fold, the 20 repeats re-pack the other 46 families around a fixed giant and are not 20 independent draws (the design already says "spread, not CI": good).

### A3. Negative-control threshold |x| < 0.05
- P1: "all arms |x| < 0.05 and lab-cluster CI covering 0". With about 7 labs and 10-20 hard-stratum items per cell, per-lab null SD of Spearman is about 0.25-0.3, so the null SE of the mean is **0.05-0.08** (the pilot says about 0.05). P(|x| < 0.05) per cell is 0.68 at SE 0.05 and 0.47 at 0.08; all 7 arms in one budget passing is 0.07 at best, all 21 arm-budget cells about 0 [ARITH]. The control could not pass; its "failure" and the "formally INVALID" verdict were predetermined and uninformative. Replace by a permutation band (>= 200 permutations) per arm: the observed null mean must lie in the permutation 95 % band and the real effect must exceed the permutation 97.5th percentile.
- P2 uses thousands of pairs, null SE about 0.02, so the 0.05 line is meaningful; P4's form (>= 21 families, CI covers 0 and |mean| <= 0.05) is right.
- Idea A decoy "within +-0.02 of D" over 5 labs with per-lab SE 0.03-0.07 passes with probability only about 0.3-0.5 under a true null [ARITH, ASSUME SE 0.03]; the observed 0.002 passed partly on luck.

### A4. "LLM wins" rule (pilot 3) and G1-G3
- The rule (t and bootstrap lower bounds > 0 with 3-5 seeds; t critical 2.78 at 4 df) is acceptable. The **task definition makes it unwinnable for an unconditioned LLM**: Y counts unique, novel, valid, constraint-satisfying molecules; S-LIB satisfies the constraints by construction (validity 1.000, macrocycle 1.000), while L-P0 (validity 0.775), L-PCLM2 (infilling, outside its intended use) and ChemFM-1B (edge-bound at prefix 0.85) are not trained to the constraint set. The pre-registration states the expected winner before the data. A test whose result is stated in advance and true by construction does not test the hybrid-LLM hypothesis. The verdict is valid only as scoped: "tuned monomer enumeration beats unconditioned sampling from three LLMs on constraint yield".
- **G3** ("N-Me TV <= P0's reference AND <= the best simple generator's") can only be passed by the argmin generator; it is a rank, not a threshold, and S-EDIT passes because it is its own comparison value. Replace with an absolute TV bound.
- **Tuning symmetry** ("same dev tuning budget"): S-LIB had a 27-cell grid, LLMs 12 cells at 300 samples, edge-bound winners for L-P0, PCLM2 and ChemFM after a single extension step; cuts in ChemFM seeds (5 to 3) and C-RANDINIT-P0 (3 of 5) fall on the LLM side. The Y gap (400-470 per 1000) is too large for this to change the verdict; it changes what a later "LLM catches up" claim needs (equal grids, interior optima).
- Y has no distance floor: S-EDIT's Y = 414 vs Y_cluster = 117 shows it rewards near-copies. Add a minimum distance to nearest seed/known peptide and report cluster yield as primary.
- Spend was about USD 6.8 against a USD 4 cap (disclosed); a process failure (a stage waiting on an uncommitted file).

### A5. Ladder claim rule and L7 contrasts
- The ladder rule (Holm over 8 contrasts on 10 development seeds, replication on 10 confirmatory seeds, shuffled-label control in A/L) is the best-structured in the program. Weaknesses: (i) seed is the sampling unit but regime L re-uses a near-fixed set of held-out labs (CHUGAI and Furukawa-2016 held out in 10/10 seeds [DOC review_data_eval I-1]); MDD 4.0-7.0 hits [DOC] is optimistic and Holm p-values are anti-conservative; the lab-cluster analysis should be primary. (ii) The shuffled control draws labels from the pool's own label vector by design (L7d), so it cannot separate learning from "this lab is rich"; its failure in A and L may be a design property, in which case the rule can never be satisfied where the loop signal is largest [ASSUME; control code not inspected]. (iii) M3 in B: effect about 3.5 hits, SE about 1.7, power about 0.5 at Holm-adjusted alpha about 0.01 [ARITH]; "significant in both B and L on both seed sets" has power about 0.3 for a real effect.
- L7 aggregator "controls": frozen passes iff CI lower <= 0 and a frozen model gives exactly 0 with CI [0,0]; shuffled passes with a large negative gain [DOC review_code D4]. Replace with equivalence-margin controls (the ladder aggregator already does this).
- Interval type: L5 "95 %/99 % CI" is a spread of per-seed differences; percentile bootstrap at n = 10 covers 0.894; no Holm over about 11 yield + 5 AUROC contrasts x 9 learners x 4 regimes [DOC review_code D1, D5].
- Loop headline (+186) is transductive; 75-92 % of the regime-L gain is already in the frozen model [DOC manuscript].
- **Frozen A/B regime L:** the seed-level "DIFFERENT" (aware - blind -16.4 [-23.9, -8.9], Holm p 0.0002) uses seed SE 3.7; the source-cluster bootstrap gives -16.4 [-64.8, 17.4] (implied SE about 21, 5.7x larger) and was outside the decision rule; the registered planted flat control FAILED in L (controls_valid = False); one lab (2020_Townsend) contributes -21.0 of the -16.4. So "DIFFERENT" is descriptive of 40 runs on about 20 labs, not inferential. The "EQUIVALENT" in A and B uses +-10 hits = 13 % and 45 % of the level (78 and 22 hits); the margin was set after a -13 was seen in seeds 0-9, i.e. just below the observed effect. A margin should come from decision value, not from the data.

### A6. T2 criteria S1-S3
- S1 (relative gain >= 5 % of the best baseline and a conservative lower bound > 0 at 99.67 % in B, B2 or L): the any-of structure with Bonferroni 3 is acceptable; holds in B only (+16.7 [7.0, 26.3]); fails in L (-13.1). The 5 % margin is meaningless where the baseline mean is about 24 hits (1.2 hits) and the interval is +-9.
- S2 (non-inferiority at -10 % of baseline mean): passes (-11.7 vs -16.7 allowed), weak margin.
- **S3 was structurally unable to pass.** It required entropy up and top-source share down at 99 % in ALL primary regimes (A, B, B2, L), while the dev-selected frozen config had lambda = 0 and no caps, and `div` equals `greedy` [DOC T2; review_code D6]. Selection was by yield only. S3 asks a question the frozen configuration cannot answer; requiring improvement in A and L where none is expected fails with probability about 1 - power^4. "S3 fails" must not be read as "diversity does not help"; it was not tested. Rule: no criterion may be registered without a registered arm whose mechanism targets it.

## C. CRITERIA for the planned all-atom hybrid LLM paper (no wet-lab data)
A valid claim without synthesis has the form: "under verifier V, on pool P, the method enriches over controls X by more than the verifier's own error". It cannot say designed, discovered or optimised permeable/binding peptides.

**Circularity and Goodhart traps, each with a minimum control:**
1. *Verifier = optimisation signal = evaluation signal.* The circular proxy in pilot 3 (GBM trained on DEV sources) is "reported only", which is right. Minimum: score outputs with (a) the optimisation verifier and (b) a held-out verifier differing in training labs (corresponding-author regrouped), architecture and features; report A-B rank agreement on generated vs on held-out real molecules (agreement collapse OOD is the Goodhart signature); add an adversarial arm (optimise A, score B) and a shuffled-A twin (must show no B gain).
2. *Lab = paper.* "Lab-disjoint" verifiers leak siblings across paper ids; regroup before calling any verifier held-out.
3. *Retrospective recovery rewards memorisation.* Pretrained LMs may have seen CycPeptMPDB/ChEMBL/PubChem. Minimum: time-split where possible; per-checkpoint contamination table; results on the contamination-clean subset; memorisation probe on the flagship models (only non-flagship probed [DOC I-11]); random-weights and shuffled-vocabulary twins.
4. *Finite-library selection is not generation.* Yield rewards any ranker; transductive standardisation leaks the hit threshold. Minimum: causal standardisation (statistics from revealed data only), source-matched random, frozen, NN and Tanimoto-GP+UCB in the loop, >= 30 seeds with lab-cluster intervals, hits-by-source decomposition. Do not say "closed-loop design" for a replay.
5. *Constraint-yield metrics are won by enumeration* (pilot 3). Include a tuned monomer-library/edit baseline with an equal grid; judge generators on verifier-A and verifier-B gain at matched novelty and diversity, with a minimum distance to nearest known/seed and cluster-count yield.
6. *Sample-efficiency curves* are the right object if paired (same reveals for all arms), tuning budgets are equal, reported as AUC of regret with cluster CI, at k that users have (3-10), with a prior-value decomposition (LLM replaced by random weights or fingerprints).
7. *Estimand and margin in absolute units tied to noise* (e.g., a gain must exceed half the inter-lab SD 0.756 log-Papp, or the verifier's lab-held-out RMSE), registered with MDE before data.
8. *Orthogonal verification subset.* Score a designated set with an independent physical/structural estimate (MD-derived PSA, CREMP ensembles, FEP for binding) not used in training; report disagreement with the learned verifier. Note simulated features did not help in idea A (5 labs, UNDERPOWERED).
9. *One primary verifier/objective* pre-registered; others BH-secondary.
10. *Peeking at the held-out verifier* while tuning generator hyperparameters turns it into training signal; freeze its role before any generator run and log accesses.

## D. RULEBOOK (adopt before any new run)
1. **MDE first, in the pre-registration.** State the SD source (a pilot or earlier data, never the test half), compute MDE80 for the primary contrast from the real number of independent clusters, and do not run if MDE80 > 2 x the margin you care about. All 2026-10 pilots failed this at registration.
2. **Set margins from decisions, not convenience.** A margin is the smallest effect that changes a decision or exceeds measurement noise, with the derivation written down; never chosen after seeing intervals or the effect (validity 0.05, +-10 hits).
3. **Report intervals against the margin, not "UNDERPOWERED".** Outcomes: margin excluded (superiority or non-superiority shown), not excluded (inconclusive; give the interval). MDE is a design number; the interval is the evidence.
4. **Unit of inference = independent cluster.** Seeds are not the unit when held-out entities repeat (regime-L labs, families). Use cluster t/wild bootstrap with n-1 df; no percentile bootstrap below about 15 clusters; report effective n; seed intervals are labelled "seed variability".
5. **A control must be able to fail and able to pass.** For each, document P(pass | true null) >= 0.8 and P(fail | planted fault) >= 0.9. Controls fixed at 0 by construction (frozen gain) or with thresholds below the null SE (|x| < 0.05 at 7 labs) are not controls. Use permutation bands (>= 200), equivalence margins, planted-effect recovery at known size.
6. **Positive controls for every instrument, including the gate.** Put P(accept | truly good) at the real cluster count into the PASS rule; the gate is a certifier only if P(VALID | planted-valid, F) >= 0.5 at the benchmark's F.
7. **Amendment discipline.** Amend only for errors or infeasibility; state what was seen before each amendment; never change a margin or primary outcome for an estimand after any result for it was read; a re-specified hypothesis gets a new ID and its own multiplicity family; report the number of versions (K_phys: >= 8); drop hand-typed clock times and rely on commit timestamps; commit analysis code before the run that produces results.
8. **Multiplicity.** One declared family per paper with a fixed denominator (all screens run, including unreported); Holm over primary, BH over secondary; report "k of N screens" and which dev/test partitions they share; one reused partition counts as one look.
9. **Data-quality gates before any model:** cross-fold duplicate/sibling and near-duplicate rates; document/lab clustering (merge paper ids into labs); per-task no-chemistry label-source classifier (the C4 check) for censoring and assay mix; contamination table per pretrained model; replicate-based noise ceiling or an explicit "unknown" with no "% of ceiling"; eligibility floors derived from the ceiling (SD >= 0.8-1.0 for potency ranking); sequence-identity folds for target splits; causal (revealed-only) standardisation.
10. **Wording follows evidence tier.** Pilots: "screen, not evidence", with a frozen vocabulary (GO / NO-GO-detectable / INCONCLUSIVE); a compute NO-GO from an INCONCLUSIVE screen is called a judgement call. Cluster-sparse or small-n results are "descriptive". No term (valid, equivalent, closed-loop, design) beyond what its instrument can power.
