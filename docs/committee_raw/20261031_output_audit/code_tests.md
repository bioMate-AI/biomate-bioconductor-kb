## Findings, ranked
### Blockers / majors
1. MAJOR [EC2 P6] feedback.GapStopMonitor is fed different inputs than it was calibrated on. orchestrator/loop.py:254-263 passes the cumulative best-so-far top-10 each round; the monitor (feedback/stop_monitor.py:45-52) expects the round batch (q=0.10 of ~400). Probe: k0=1 and pool grows 10 duplicates per round (pool 50 after 5 rounds); sd_t/sd_s come from the spread of a top-10, not a batch. Threshold behaviour is not the pre-registered one. Also GapStopMonitor has no state_dict/load_state_dict, so after resume (round_idx>0) the `round_idx==0` init never runs: k0=0, mean of empty -> NaN, should_stop can never fire [read]. Test: run_loop with GapStopMonitor, interrupt at round 3, resume, compare stopped_at to the uninterrupted run.
2. Test: scale train/stop by 10 and check the same stop round.
3. MAJOR [EC2 P5] Checkpoint dir is not bound to (run_id, seed, config): seed 1 launched on seed 0's ckpt_dir resumed seed 0's oracle log (log prefix identical). orchestrator/loop.py:203-214. Fix: store and assert run_id/seed/budget.

BlindRule.query_kwargs() is not used anywhere in orchestrator/. 6. MAJOR [read] Constraint-set disagreement. Pre-registered C (and rules/spec.py, baselines.constraint via gen_pilot) = ring>=12, 2-6 N-Me with SMARTS `[NX3;!H1]([CH3])`, MW 600-1400, TPSA<=300, PAINS. tier0_rules.HardRules (used as the Constraint in test_orchestrator_ia and exposed to the hybrid) = MW <=1300 only, no MW floor, no TPSA, N-Me SMARTS without !H1 (counts a secondary N-methylamide). A 450 Da macrocycle passes HardRules but fails C; MW 1350 fails HardRules, passes C. Hybrid vs baselines would not face the same rule set. My probe P8 crashed on an import path error so this is not EC2-confirmed. Test: compare HardRules().check with spec.satisfies_smiles on 1000 library draws.
7. MAJOR [EC2 P1] NaN verifier output poisons the metric silently. BudgetedOracle charges the call, caches NaN; topk_curve returns [1, nan, nan, nan]; summarise()/paired_contrast drop NaN pairs (P4: n=3 of 4 seeds) with no warning. pmo_harness.py:124-128, 231-236. Fix: reject non-finite scores (treat as invalid, free) and make summarise raise on NaN.
8. MAJOR [EC2 P2] SD-AUC scale inconsistency in padding. topk_curve returns zeros for a run with no calls (pmo_harness.py:137-139). On the z scale 0 is the generation-space mean: a wall-clock-truncated run with 0 calls scores 0.0, better than a run whose top-10 mean is -1.0 (P2: -1.0 vs 0.0). A4c credits truncated runs with carried-forward values; zero-call must be NaN/-inf or the run flagged. Also run_one `final_topk` and early-stop padding are fine on the z scale.
9. MAJOR [read] The physics held-out is on a different scale than A4 states. track_e/verifiers_e.py:246-266 returns a percentile against a 60 (EVAL stage passes --n-ref 20; make_ud_e.py:46-47, prereg says 60) reference, saturating at 1.0, and imputes 0.0 for failed embeddings (A3.1 says failures are counted, not imputed; A3 found 588/1116 failures systematic by size). Applying a z-scale margin to it is invalid. F1 held-out is void by prereg, so impact is on descriptive F1 held-out numbers. polar_sasa_min also swallows MMFF errors (`except Exception: pass`, line 234) and ignores non-convergence flags.
