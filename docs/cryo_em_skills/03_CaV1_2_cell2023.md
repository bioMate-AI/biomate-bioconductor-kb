## 3. Detailed Workflow with Parameters

### Phase 0: Protein Preparation
```
CaV1.2 complex assembly:
  - α1C (Q13936): full-length, N-terminal FLAG tag
  - β2b (Q08289): auxiliary subunit, palmitoylated N-term
  - α2δ-1 (P54289): extracellular, linked to δ via disulfide
  - Expression: co-transfection PiggyBac stable Expi293

Solubilization:
  Detergent: 1% GDN (glyco-diosgenin) + 0.1% CHS
  Buffer: 50 mM HEPES pH 7.5, 150 mM NaCl, 2 mM CaCl2
  Time: 2 hr, 4°C
  Spin: 100,000×g, 45 min

Purification:
  ANTI-FLAG M2 affinity (3 mL resin)
  Wash: 20 CV (0.02% GDN)
  Elute: 0.5 mg/mL FLAG peptide
  SEC: Superose 6 10/300
  Peak: ~400 kDa complex
  Final: 3–5 mg total typical

Drug addition:
  Stock: 10 mM DMSO
  Final concentration: 20–100 μM (10–50× Kd)
  Incubation: 30–60 min on ice before grid prep
  DMSO: < 1% final
```

### Phase 1: Cryo-EM Grid Preparation
```
Grid: Quantifoil R1.2/1.3 Au 300 mesh
Plasma clean: 5 s, Solarus II
Sample: 3–4 mg/mL, 3 μL applied
Vitrobot: 4°C, 100% RH, 3 s blot, force 3
Plunge: liquid ethane −175°C
Screen: next day in Talos Arctica (120 kV screening)
```

### Phase 2: Data Collection
```
Microscope: Titan Krios (300 kV)
Detector: K3 (counting mode)
Magnification: 105,000× → 0.83 Å/pix
Energy filter: 20 eV
Defocus: −1.0 to −2.5 μm (12 values)
Dose: 50 e⁻/Å²
Frames: 50
Exposure: 2.5 s
Beam-image shift: yes (5-hole pattern)
Movies per condition: 4,000–8,000
```

### Phase 3: Pre-processing (Same as standard)
```
MotionCor2: 5×5 patches, 150 B-factor
CTFFIND4: 30–5 Å, threshold CTF-FOM > 0.1
QC: defocus −1.0 to −2.5, resolution < 4.5 Å
Expected throughput: 85–90% micrographs passing
```

### Phase 4: Particle Picking & 2D Classification
```
crYOLO:
  Box: 320 px at 0.83 Å/pix (400 kDa ≈ 110 Å diameter)
  Confidence: 0.3
  Expected: 100–200 picks/micrograph

CryoSPARC 2D:
  Classes: 200
  Max res: 6 Å
  Select: classes showing TM helices + ECDs
  Reject: edge, split, broken complex
  Yield: 500K–2M per dataset

Note for large complexes: Use template-based picking after
getting good 2D/3D classes in first dataset, then apply
template to remaining conditions for consistency.
```

### Phase 5: 3D Reconstruction Per Drug Condition
```
Per-condition workflow (×7 datasets):
  1. Ab initio: 4 classes, 100K particles subset
  2. Heterogeneous refine: 4 classes
     → Select class with α2δ-1 density (confirms complex intact)
  3. Homogeneous refine (C1):
     → Target: < 3 Å for core TM region
  4. CTF refinement: per-particle defocus + beam tilt
  5. Non-uniform refinement: final iteration
  6. Local refinement of TM core (focus mask on α1C TM):
     → Often gains 0.2–0.3 Å over global refine

Typical results:
  DHP datasets: 2.6–2.9 Å
  PAA dataset: 2.8 Å
  BTZ dataset: 3.1 Å (slightly lower — channel heterogeneity)
  Gabapentin dataset: 2.7 Å (α2δ VWA domain well-resolved)
```

### Phase 6: Drug Difference Map Pipeline
```
CRITICAL WORKFLOW for multi-drug atlas studies:

Step 1: Establish reference map
  - Use apo dataset (no drug) as reference
  - Sharpen to same B-factor as drug-bound maps
  - Confirm same pixel size and box dimensions

Step 2: Per-drug subtraction
  ChimeraX:
    volume subtract apo.mrc drug.mrc
    → outputs difference.mrc
  Threshold: ±3σ (3 standard deviations of noise)
  Positive (blue): drug-unique density
  Negative (red): conformational shift in protein

Step 3: Drug placement
  - Place drug in positive density using Coot
  - Confirm: all heavy atoms within density
  - Confirm: no steric clash > 0.4 Å with protein
  - Calculate correlation coefficient > 0.8 in drug region

Step 4: Cross-validation
  - Randomize half-map phases beyond drug resolution
  - Confirm drug density persists in non-randomized half
  - Noise injection test: add 3× drug → density scales linearly

Step 5: Site annotation
  - Identify all residues within 4 Å of any drug atom
  - Categorize: hydrophobic/polar/charged
  - Note conserved vs CaV1.2-specific residues
```

### Phase 7: Cross-Condition Structural Comparison
```
Superposition:
  PHENIX superpose_models:
    mobile = drug-bound structure
    fixed = apo structure
    Selection: TM helices I-III (least drug-affected)
  
Local RMSD calculation:
  Per-residue Cα RMSD using PyMOL `rms_cur`
  Plot as B-factor putty coloring

Allosteric network analysis:
  1. Calculate Cα displacement per residue (drug vs apo)
  2. Map displacements > 1 Å on channel structure
  3. Trace from drug site to gate: identify allosteric path
  4. Compare paths across drug classes

Publication figure generation:
  - CaV1.2 + each drug site = separate figure panel
  - Use consistent orientation (extracellular up, 6-TM standard)
  - Color code: subunit coloring (α1C = blue, β2b = orange, α2δ-1 = green)
```

## 6. Key BioMate Learnable Principles

1. **Atlas design: same protein, multiple drugs = mechanistic atlas:** Running identical cryo-EM workflow on one protein with multiple drug conditions (7 in this study) produces a pharmacology atlas. BioMate should suggest this design for users studying drug mechanisms on a single target. The value is not any single structure but the comparison between states.

2. **Large multi-subunit complexes (400 kDa) can reach < 3 Å with modern detergents:** GDN (glyco-diosgenin) is the preferred mild detergent for VGIC/LGIC complexes. It maintains lipid annulus better than DDM for large complexes. BioMate should recommend GDN for ion channel complexes > 200 kDa.

3. **Drug difference maps require apo reference at identical processing settings:** Before calculating drug-apo difference maps, both datasets must use identical box size, pixel size, and sharpening. Even small B-factor differences (> 5 Å²) create artifactual features. BioMate must enforce this as a mandatory QC step.

4. **Multi-subunit AlphaFold2: run individually, dock separately, then stitch:** For complexes with 3+ subunits, running AF2-Multimer is feasible but risky for large heterotrimers. Safer approach: predict each subunit individually, rigid-body dock each into map independently, then stitch together with minimal restraints in PHENIX.

5. **Template-based picking for multi-condition datasets:** After obtaining good 2D classes from Dataset 1, use those as templates for crYOLO or CryoSPARC template matching in all subsequent datasets. This ensures consistent particle selection across conditions and reduces inter-dataset variability.

6. **3DVA reveals functionally relevant heterogeneity in ion channels:** VGIC studies show multiple gating states co-existing in a single cryo-EM sample. 3D variability analysis (CryoSPARC) decomposes this into principal components. BioMate should run 3DVA before final refinement and select the most biologically relevant component for drug binding analysis.

7. **Fenestration drug access model:** Voltage-gated channel blockers (Class I antiarrhythmics, Ca²⁺ antagonists) enter the channel pore laterally through TM helix fenestrations, not via the extracellular mouth. This explains use-dependence: channel must open to allow drug access. BioMate should include this pharmacological principle in its VGIC drug binding explanations.

8. **CaV1.1 structure as template for CaV1.2 homology:** CaV1.1 (5GJW) shares 77% TM domain identity with CaV1.2. Using 5GJW as initial model for CaV1.2 requires remodeling only variable loops and drug-binding TM segments. This is faster and more accurate than AlphaFold2 alone for CaV family members.
