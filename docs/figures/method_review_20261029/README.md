# Method study schematics

Figures 1 and 2 describe method interfaces and prospective comparisons; they contain no experimental results or simulated performance curves. SVG files are editable vector originals; PNG files are manuscript previews.

Regenerate with Python 3 and Pillow: run `python build_schematics.py`, then `python render_schematics.py`. The preview renderer uses Arial from the macOS system font directory; change the font path for another host. This is document rendering only, with no model execution or numerical experiment. Final PNGs were visually inspected for clipping and text overlap.
