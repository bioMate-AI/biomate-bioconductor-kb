- The output_files endpoint is returning 404 / empty array silently

## Bugs surfaced (prioritised)

### Bug 1 — Output files don't register after a completed run (P0)

**Symptom:** Outputs tab says "No output files registered yet" after status=completed.
**Surface impact:** Findings stuck on "Analyzing outputs…"; Download-all/Reproducibility bundle produce nothing; users see a completed run that has no deliverable.
**Likely scope:** affects every biomate-ai-tools module (not just T02) unless the publishDir/manifest contract is per-workflow.

**Next actions to triage:**
- Check `/api/workflows/runs/<runId>` raw response on dev — is `output_files` empty in the API response, or does the UI fail to render a non-empty array?
- Check the AWS Batch container logs for the T02 run — did the workflow actually emit `cart_construct.json` / `lnp_formulation_recommendation.csv` / `safety_fratricide_report.txt` to the `publishDir`?
- If yes, where did the upload land — is the S3 bucket/key being scanned by the endpoint?

### Bug 2 — Phases B/C/D never render a "running" state (P1)

**Symptom:** Phase A correctly shows `running` then `completed`. Phases B/C/D jump from `pending` to `completed` with no observable `running` state.
**Surface impact:** The "watch each phase work" live narration value-prop fails — phases that execute quickly (or via Nextflow chaining) never visibly run.

**Next actions to triage:**
- Confirm whether the backend SSE actually emits per-phase `running` events for B/C/D, or only A.
- If yes, check `nextflow-workflow-viewer.tsx` for a render-throttle that's swallowing fast transitions.
- If no, check the workflow definition: are phases B/C/D fast enough that the polling-based `data-status` check misses the running window?

### Bug 3 — Methods tab missing despite a successful run (P2)

**Symptom:** Methods sub-tab not rendered even though the run completed; no methods report visible.
**Surface impact:** users can't download / read the methods writeup for the run — a regulated-workflow blocker.

**Next actions to triage:**
- Hit `/api/invocations/<runId>/methods-report` on dev directly; is it 404, 500, or 200-with-empty?
- The methods generator should work from the workflow definition + params alone (per design); it shouldn't require output files.
