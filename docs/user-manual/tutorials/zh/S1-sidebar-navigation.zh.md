# 教程 S1 —— 侧边栏：在 BioMate 里找到方向

> **适合谁读：** 任何想弄清左侧菜单上每一个按钮都是干什么的 BioMate 用户 —— 不需要编程或生物信息学背景。读完
> 这一篇，你就能叫出侧边栏每一个条目的名字、知道点它是会弹出一个窗口还是把你带到一个新页面，还会知道哪些条目
> 目前还没上线（这样你就不会白找）。
> **用时：** 阅读约 9 分钟。
> **它在教程中的位置：** 教程零教了那一个核心循环（输入目标 → 核对通道 → 发送 → 读结果）。这一篇是围绕这个
> 循环的地图：侧边栏就是你抵达过往工作、数据、项目和设置的方式。更深入的那几篇教程（一至六）各自藏在这些条目
> 中的某一个背后，而这一页会告诉你是哪一个。

---

## 1. 它解决什么问题

一旦你向 BioMate 问过不止一个问题，你就有了历史：过往的对话、已完成的分析、你带进来的文件、你用来归拢工作的项目。
**侧边栏** —— 每个屏幕左侧边缘那条竖直的菜单 —— 是把这一切聚到一处的地方，还带着开启新工作的那些快捷入口。只要
你熟悉侧边栏，就再也不用纳闷"我上次那次运行跑哪儿去了？"或"我怎么回到我的数据？"。

本篇教程会从上到下、用大白话走一遍每一个条目：它是什么、你点它会发生什么、以及你什么时候会用到它。

> **一句话概括：** 侧边栏是 BioMate 的目录 —— 顶部是新工作，中间是你的项目和过往对话，底部是你的账户和设置。

---

## 2. 开始前需要了解的几个概念（用大白话讲）

**两种点击。** 侧边栏里的一切，点下去只会做两件事之一，点之前先知道是哪一种会有帮助：

- **弹出一个窗口（一个对话框）。** 窗口出现在你当前对话的*上方*；关掉它，你就回到了原来所在的地方。你正在做的
  一切都不会丢失。*工作流（Workflows）、连接器（Connectors）、Recent Tools（最近使用的工具）和 设置（Settings）*
  都是这样工作的。
- **把你带到一整个页面。** 整个屏幕换成一个新视图（Data、Models、Design & Generate，或一个项目）。你用浏览器的
  后退按钮回来，或者点 **新建对话（New Chat）** 或历史里的一个对话。*（为什么这个区分重要：一个对话框是一次快速
  的查看，它让你的对话一直开着；一个页面是你前往的一处地方。）*

**这里没有任何东西会自己花钱或跑一次分析。** 打开一个窗口或一个页面，只会*给你看*东西。教程零里那条规则在任何地方
依然成立：一次真正的分析（一次云端运行）只有在你审阅一条消息并按下发送之后才会开始。侧边栏是导航，不是一个触发器。

**侧边栏的三个区段。** 从上往下读，这个菜单分成三组：
1. **工作区（Workspace）** —— 开启新工作或打开一个工具的那些按钮（新建对话、工作流、连接器、Data、Models、
   Design & Generate、Recent Tools）。
2. **项目（Projects）** —— 把相关的对话、文件和运行归到一起的文件夹。
3. **对话历史 + 账户** —— 你最近的对话，然后是最底部的设置和你的个人资料。

**一个状态圆点就是一盏红绿灯。** 在你最近的那些对话旁边，有一个小小的彩色圆点，一眼告诉你那个对话的分析进行得
怎么样 —— **蓝 = 运行中，红 = 失败，绿 = 已完成，灰 = 还什么都没跑。** 第 4 节还有更多。

## 3. 什么时候用它

- 你在 BioMate 里做过几件事，想回到一次过往的运行、文件或对话。
- 你在菜单里看到一个按钮，想在点它之前先知道它是干什么的。
- 你听说 BioMate 有"Billing（账单）"或一个"CRO Library（CRO 库）"，想知道它们是否可用（简短答案：这个版本里没有 ——
  见第 6 节）。

## 4. 一步步来 —— 从上到下的每一个侧边栏条目

### 4.0 头部 —— logo、BETA 标记，以及折叠按钮

最顶上是 **BioMate logo**。它右上角有一个小小的 **BETA** 标签 —— 一个如实的提醒：这是早期体验软件，功能可能会变。
同在那个角上的还有一个**折叠按钮**（一个左侧带竖线的面板图标）。点它可以**隐藏侧边栏**，把整个宽度让给你的对话；
再点一次（或点那条留下来的细边栏里的同一个图标）就把侧边栏请回来。*（为什么：在小屏幕上，或当你在读一个长结果时，
隐藏菜单能给你更多空间。）*

### 4.1 新建对话（New Chat）—— 开始一段全新的对话

**工作区**下的第一个按钮。点它会打开一段全新的、空白的对话 —— 也就是教程零里那个**冷启动**入口，带着意图输入框和
四张模块卡片。每当你要开始一个新的、不相干的问题，又不想把它掺进一个已经在进行的对话里时，就用它。*（什么都不会
被删除；你之前的对话还留在下面的历史里。）*

### 4.2 工作流（Workflows）—— 你的运行历史与流程库

打开**工作流（Workflows）**弹窗。这是你分析的记录，也是你的流程库，分三个标签页：

- **Runs（运行）** —— 你启动过的每一次分析，最新的在前，各自带着状态。点一次运行会重新打开它所属的对话，让你去读
  它的报告；"run again（再次运行）"用同一条流程开始一次全新的分析（你可以先改文件或设置）。这是回到*"我开的那次
  分析后来怎么样了？"*最快的方式。
- **My Imports（我的导入）** —— 你添加进自己库里的那些流程，可从任何对话启动。
- **Import Workflow（导入工作流）** —— 带入一个流程文件，让它出现在 *My Imports* 下。

如果当前有任何分析正在运行，侧边栏里"工作流"这个词旁边会出现一个小小的**数字徽标** —— 实时统计有多少个正在进行。
*（为什么你要在意：这是不用打开任何东西、一眼就能知道"还有东西在煮着吗？"的指示器。）* 运行一条工作流并读它的报告
在教程三里讲。

### 4.3 连接器（Connectors）—— 你的工作区接入的一切

打开**连接器（Connectors）**弹窗 —— 那个唯一的、展示 BioMate 能触及什么的地方：公共数据库、AI 模型，以及你的
实验室仪器。它有四个标签页：

- **Public Databases（公共数据库）** —— BioMate 能在聊天里查阅的那些科学来源（UniProt、PDB、Ensembl、ChEMBL、
  ClinVar、KEGG、Open Targets，以及几十个其他）。这个标签页是一份**只读参考** —— 它展示有哪些可用；你在这里不
  配置任何东西。
- **AI & Platforms（AI 与平台）** —— BioMate 使用的那些 AI 模型（Claude、Gemini 等），以及它能接入的外部入口。
  同样是只读参考 —— 它不是你设置接入的地方。
- **Your Connections（你的连接）** —— 这个窗口里你唯一能真正*添加*东西的地方：你自己的私有数据库和你自己的 MCP
  服务器（一种进阶方式，用来连接你自己的工具）。你输入的凭据会被加密，而且数据库访问是只读的。
- **Instruments（仪器）** —— 登记一台实验室或医院的仪器（一台测序仪、一台酶标仪、一台机器人），让它的数据流入
  BioMate。这是教程六的主题。

*（为什么这一切都在一个窗口里：每一种连接背后的问题都是同一个 —— "这个工作区接入了什么，它能不能用？"）*

*（待补图：连接器窗口 —— 顶部横排的四个标签页，以及 Public Databases 列表。）*

### 4.4 Data（数据）—— 你的数据集、它们的质量与血统

把你带到 **Data（数据）**页面（一整个页面，不是弹窗）。这里住着你带进 BioMate 的那些文件：你能看到每一个数据集、
对它的一次质量检查，以及它的**血统**（哪次运行产生了它的记录）。用它来审阅、检查，或为下一次分析取用一个文件。
带入你自己的数据在教程四里讲；读取结果在教程五。

### 4.5 Models（模型）—— 训练、适配并运行预测模型

把你带到 **Models（模型）**页面。这里的一个模型是一个*预测*某种属性的工具（例如，一个分子大概有多安全、或多可溶），
而且它能**从你自己的实验结果中学习**，随时间为你的项目变得更好。这个页面是你的模型所在的登记库 —— 每一个版本都
留着，于是你能看到一个模型是怎么变化的。那个闭环的想法（实验结果 → 更好的模型 → 更好的下一轮）正是教程二的全部。

### 4.6 Design & Generate（设计与生成）—— 提出新的候选分子

把你带到 **Design & Generate（设计与生成）**页面。这里你不是问"已知什么"，而是让 BioMate **生成瞄准你所关心的那些
属性（效力指标、安全上限、成药性）的新候选分子**。它交回的是一份把各项权衡摊开来的候选清单，而不是一张白纸。这是
教程一的主题。

### 4.7 Recent Tools（最近使用的工具）—— 跳回你最近用过的一个工具

打开 **Recent Tools（最近使用的工具）**弹窗：一个列出你最近用过的那些单个工具的列表，带一个搜索框和一个使用次数，
于是你能重新打开其中一个，而不用去翻找。如果你还一个都没用过，这个列表就只是空的 —— 这在一个新账户上是预期之中的，
不是毛病。

### 4.8 项目（Projects）—— 把相关工作归到一起的文件夹

工作区那些按钮下面是**项目（Projects）**区段。一个**项目**是一个文件夹，把相关的对话、文件和运行归在一起 ——
例如，和一个药物项目或一种疾病有关的一切。

- **项目（Projects）**这个标题旁有一个小箭头（**▸ / ▾**），用来折叠或展开整个列表。
- 每一行项目各自有一个箭头。点一个项目把它打开；它的箭头展开后，会露出三个直接进入那个项目的快捷入口：
  **Chats（对话）**、**Files（文件）** 和 **Workflows（工作流）**（每一个都在相应标签页上打开那个项目）。
- 别人分享给你的项目，那一行会带一个小小的**"shared（共享）"**标记，于是你能把自己的项目和共享来的区分开。
- **New project（新建项目）**（列表脚部的一个 **＋**）新建一个空文件夹。

*（注：侧边栏显示你的活跃项目，最多十来个；归档的项目在这里被特意隐藏了，好让列表保持简短。）*

### 4.9 对话历史（Chat history）—— 你最近的对话，带状态圆点

项目下面，占着侧边栏可滚动的中段，是你的**对话历史**：你最近的对话，最新的在前，分在两个标题下 ——
**Current（当前）**（你最新的那几个）和 **Recent（最近）**（更早一些的那些）。点任何一个对话，就能从你离开的地方
原样重新打开它。如果你还没有任何对话，你会看到 **"No chats yet（暂无对话）"** —— 在一个新账户上是预期之中的。

**Current** 组里每个对话旁边是那个**状态圆点** —— 第 2 节里的那盏红绿灯 —— 它告诉你那个对话的分析进行得怎么样：

| 圆点颜色 | 含义 |
|---|---|
| **蓝**（轻轻跳动） | 这个对话里的一次分析**此刻正在运行**。 |
| **红** | 这个对话里的一次分析**失败了**。 |
| **绿** | 这个对话里的一次分析**完成了**。 |
| **灰** | 这个对话里**还什么都没跑**（它是一段普通的对话）。 |

*（这个圆点每隔几秒会自己更新，于是你不用刷新，就能看着一次运行从蓝变绿。更早的"Recent"组里的对话不带圆点。）*

### 4.10 设置与 API 密钥（Settings & API Keys）—— 你的账户与偏好

在滚动区靠底部的地方，以及作为页脚里的一个**齿轮图标**，是**设置与 API 密钥（Settings & API Keys）**。两者都打开
同一个**设置（Settings）**弹窗，沿侧边组织成几个标签页：

- **Profile（个人资料）** —— 你的名字、邮箱和角色。
- **General（通用）** —— 语言（English、中文等）。
- **Appearance（外观）** —— 浅色 / 深色 / 跟随系统主题。
- **Chat（对话）**、**Data（数据）**、**Notifications（通知）**、**Privacy（隐私）**、**Security（安全）** —— 各个
  领域的偏好（例如，你的数据存在哪里、保留多久）。
- **API Keys（API 密钥）** —— 如果你自带 AI 模型的接入权限，这里是你存自己密钥的地方。

*（为什么有两个入口：页脚里的齿轮即便在上面的列表被滚走时也始终够得着；而带标签的"设置与 API 密钥"链接是那个
一眼就能找到的。）*

### 4.11 页脚 —— 你的个人资料与退出登录

最底部：一个小头像，带着你的**名字和邮箱**、那个**齿轮**（设置，如上），以及**退出登录（Sign out）**，它会把你
登出并带回登录页。

> **仅管理员可见的条目。** 当且仅当你的账户是管理员时，页脚上方会多出一个链接（**系统管理 / System
> Administration**），通往一个管理面板。普通账户永远看不到它，所以如果你这里没有它，并不是哪里出了问题。

## 5. 如实的限制 —— 你该有的预期

- **侧边栏只负责导航。** 这里没有任何按钮会自己启动一次分析或花掉算力。一次云端运行永远要等你审阅一条消息并按下
  发送（教程零）。打开一个窗口或一个页面永远是安全的。
- **状态圆点只活在"Current"对话上。** 更早的"Recent"组不显示圆点。一个圆点反映的是那个对话里最相关的一次运行
  （一次正在运行的优先于一次已完成的）。
- **"Public Databases"和"AI & Platforms"是参考列表，不是设置界面。** 它们展示 BioMate 能触及什么；你不在那里
  配置它们。连接器窗口里你唯一能添加自己连接的地方是 **Your Connections** 标签页。
- **有些你可能听说过的东西不在这个版本里**（见第 6 节）。如果你找不到账单、一个运行仪表盘或一个 CRO 库，那是因为
  它们在这里没有上线 —— 而不是因为你找错了地方。

## 6. 本版本中不可用（免得你白找）

为了如实说清有什么、没什么，下面这些在当前构建里是被特意**关掉**的。在这里描述它们，只是为了不让你四处去找：

- **Billing / Usage & subscription（账单 / 用量与订阅）** —— 不在侧边栏里显示，它的页面在这个构建里被禁用了。
  这里没有一个账单界面可打开。
- **Runs dashboard（运行仪表盘）** —— 没有一个单独的"Runs"页面。你的运行历史改为住在**工作流（Workflows）**
  窗口里（第 4.2 节，Runs 标签页）。
- **CRO Library（药物发现 CRO 库）** —— 在这个构建里不作为一个侧边栏目的地提供。
- **IND Report（IND 报告）** —— 报告生成器在这个构建里被从侧边栏隐藏了（尽管底层页面仍然存在），所以暂且把它
  当作从菜单里够不着。

*（如果未来某个版本把这些中的任何一个打开，它们会和其他条目一起出现在工作区区段里。）*

|---|---|
| **侧边栏（Sidebar）** | 每个屏幕左侧边缘那条竖直的菜单 —— BioMate 的目录。 |
| **对话框（弹窗）（Dialog）** | 一个在你对话上方打开的窗口（工作流、连接器、Recent Tools、设置）；关掉它，你就回到了原来所在的地方。 |
| **页面（Page）** | 一个你前往的全屏视图（Data、Models、Design & Generate，一个项目）；用后退按钮或打开一个对话来返回。 |
| **工作区区段（Workspace band）** | 顶部那组开启新工作或打开一个工具的按钮。 |
| **项目（Project）** | 把相关的对话、文件和运行归到一起的文件夹；一个"shared"标记标出别人分享给你的那个。 |
| **对话历史（Chat history）** | 你最近的对话（Current + Recent）；点一个就重新打开它。 |
| **状态圆点（Status dot）** | 一个 Current 对话上的彩色圆点：**蓝** = 运行中，**红** = 失败，**绿** = 已完成，**灰** = 还什么都没跑。 |
| **折叠按钮（Collapse button）** | 头部那个面板图标，隐藏/显示侧边栏以腾出屏幕空间。 |
| **连接器（Connectors）** | 那个列出 BioMate 接入了什么的窗口：公共数据库、AI 模型、你自己的连接，以及仪器。 |
| **正在运行计数徽标（Running-count badge）** | "工作流"旁边那个小数字，显示此刻有多少个分析正在进行。 |

---

_面向进阶用户 / 开发者的配套技术参考：侧边栏实现于
`frontend/client/src/components/app-sidebar.tsx`；它打开的那些窗口是
`workflow-history-dialog.tsx`（工作流）、`connectors-dialog.tsx`（连接器）、
`recent-tools-dialog.tsx`（Recent Tools），以及 `settings-dialog.tsx`（设置）。_
