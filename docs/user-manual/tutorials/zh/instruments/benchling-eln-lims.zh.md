# 仪器教程 —— Benchling ELN / LIMS → 药物发现 ADMET 筛选

> **适合谁读：** 任何实验室在 Benchling（一套电子实验记录本 / 样品追踪系统）里记录化合物和实验结果、并
> 希望这些结果去驱动一次 BioMate 药物发现分析的人。读这篇不需要编程。
> **用时：** 约 10 分钟。
> **它在教程中的位置：** 教程六讲的是如何*注册*一个连接。这一篇回答：*"我的化合物和实验数字都存在
> Benchling 里 —— BioMate 对它们运行什么分析？我怎么启动？又怎么读结果？"*

---

## 1. 它解决什么问题

Benchling 不是一台测量什么的仪器 —— 它是药物发现团队保存化合物（连同它们的化学结构）以及针对这些化合物
测得的实验数字（效力、毒性等等）的**权威记录系统**（system of record）。要回答的分析问题是：*面对这一份
不断增长的化合物清单及其实测结果，哪些值得接着往下做，又有没有哪些很可能不安全？*

BioMate 用它的**药物发现战役（drug-discovery campaign）**来回答这个问题 —— 这是一个持续运行的项目，它
吸纳实验结果、为每个化合物预测安全性和成药性质、给它们排序，还能把监管文书组装起来。Benchling 的职责是
去**喂养**这个战役：化合物及其实测的实验值从 Benchling 流进战役，省得你重新手动录入。

> **一句话概括：** Benchling 提供化合物和实测的实验结果；BioMate 的药物发现战役为每个化合物预测它的
> 安全性 / ADMET 性质、给它们排序、并保留记录 —— 这样团队就知道该追哪些分子。

---

## 2. 这个"仪器"产出什么

从 Benchling，BioMate 读取：

- **化合物 / 样品** —— 每个都带一个写成 **SMILES** 的化学结构（一串编码一个分子的文本），外加批号、浓度、
  板上位置等标识。
- **实验结果** —— 针对这些化合物测得的数字（例如一个以纳摩尔计的 **IC50**，衡量一个化合物有多强效 ——
  越低越强效），每个都挂在一个化合物和一种实验类型上。
- **记录本上下文** —— 一条记录本条目的自由文本，用于溯源。

这些都是**湿实验事实**：真实的分子，以及针对它们测得的数字。它们将成为第 3 节那次分析的*输入*。

---

## 3. 它驱动的 BioMate 分析（以及为什么）

Benchling 数据驱动的分析，是**药物发现战役里的 ADMET 筛选**。有两处真实的部件证实了这条路径：

1. **战役会从 Benchling 拉取实验结果。** BioMate 的药物发现模块暴露了一个端点，用来把 Benchling 的实验
   结果拉进一个战役（`…/lims/poll`）并吸纳它们（`…/ingest-assay`），随后更新化合物排序。这就是教程六里
   提到的"为药物发现战役自动拉取实验结果"—— 它属于战役流程，与那个单纯的仪器注册表是分开的。
2. **那个预测分析是一个真实的目录工作流。** 化合物的 SMILES 喂给 BioMate 的 ADMET 工作流 —— **Predict
   ADMET Properties (AI)**（`predict_admet_properties`），它使用图神经网络模型（ADMET-AI，Swanson 等人
   2023），在数百万条实验测量上训练，预测约 15 项端点，包括 **hERG 心脏毒性**、CYP 酶抑制、血脑屏障
   穿透、溶解度，以及半衰期。

合起来看，这个战役的循环是：**Benchling 提供化合物 + 实测实验 → BioMate 为每个化合物预测 ADMET / 安全性
→ 化合物被排序（实测结果 + 预测）→ 有风险的化合物被标记出来、有希望的浮上来 →（可选）结果回推到
Benchling，并把监管用的 IND 文书组装起来。**

**为什么是 ADMET：** 大多数候选药物失败，不是因为它们不够强效，而是因为它们不安全、或在体内表现不佳（吸收
差、清除快、hERG 带来的心律风险）。尽早针对实测的效力，筛查每一个化合物的 ADMET 画像，正是一个团队避免在
一个从一开始就行不通的分子上耗费几个月的办法。

> **ADMET 是什么意思：** **A**bsorption（吸收）、**D**istribution（分布）、**M**etabolism（代谢）、
> **E**xcretion（排泄）、**T**oxicity（毒性）—— 决定一个强效分子能否真正成为一款安全、可用药物的那些性质。

## 4. 开始之前 —— 连上 Benchling

先完成教程六（*连接仪器*）了解连接基础：

- Benchling 是一个**云**服务，所以它的驻留徽标是 **cloud（云）** —— 当 BioMate 从它读取时，**数据会离开
  你们组织自己的系统**。连接前请确认这对你的数据是可接受的。
- 它用一个 **API 密钥 / 令牌**（而不是 host/port）来连接 —— 你为你的租户（如 `yourorg.benchling.com`）
  提供一个 Benchling API 密钥。
- 这个密钥让 BioMate 能**检查并保存**这个连接；而把实验结果*自动拉进*一个战役，是前面说的那个独立的药物
  发现战役流程，由管理员配置，而不是从那个单纯的仪器注册表里来。
- 你会创建或打开一个**药物发现战役**（侧边栏里的 **CRO Library（CRO 库）** 是这块区域的入口），并把它指向
  存放你结果的那个 Benchling 实验架构（assay schema）。

---

## 5. 一步步操作 —— 运行筛选

1. **打开药物发现区域。** 从侧边栏进入 **CRO Library（CRO 库）**（药物发现 / 战役界面），打开或创建你的
   战役。
2. **从 Benchling 拉取化合物和实验。** 在 Benchling 连接配置好之后，战役会吸纳你那些化合物的实验结果
   （`lims/poll` → `ingest-assay` 这条路径）。每个化合物到来时都带着它的 SMILES 和它的实测实验值。
3. **运行 ADMET 预测。** 化合物的 SMILES 喂给 **Predict ADMET Properties (AI)** 工作流。你也可以在聊天里
   直接启动它：*"对这些化合物跑一次 ADMET 筛选"*，附上 SMILES 清单。确认前先审一遍设置。
4. **确认并运行。** BioMate 在云端计算机上为每个化合物预测那约 15 项 ADMET 端点。
5. **读那份排好序的结果以及安全性标记**（见第 6 节）。如果配置了一道安全闸门（例如一个 hERG 阈值），越过
   它的化合物会被标记出来，而不是被悄悄地排到高位。

> **在你确认之前，什么都不会运行**，而且预测绝不会覆盖你在 Benchling 里的实测值 —— 它们是并排放着的。

---

## 6. 读结果

- **化合物排序** —— 战役把化合物的**实测**实验值（来自 Benchling）与**预测**的 ADMET 性质结合起来排序。
  清单顶部，就是团队首先要看的地方。
- **每个化合物的 ADMET 列** —— 每一项端点的预测值。最该盯着看的是 **hERG**（心脏离子通道风险）：一个被
  预测会强烈阻断 hERG 的化合物，无论多么强效，都是一个心脏安全性隐患。其余的 —— 溶解度、CYP 抑制、血脑
  屏障 —— 则分别提示吸收、药物—药物相互作用，以及脑暴露方面的问题。
- **那份三标签页报告**（教程三），针对一次 ADMET 运行 —— Summary（摘要，从真实的输出文件生成的大白话
  发现）、Outputs（输出，逐化合物的预测），以及可复现记录（Reproducibility record）。
- **导出 / 文书** —— 战役可以导出一份 CRO 订单，再往下，还能把监管用的 IND 文件组装起来 —— 那是团队交给
  合同研究组织（CRO）或监管方的正式产出。

**怎么据此行动：** 把那些既强效（实测）、ADMET 又干净（预测）的化合物往前推进；把那些因 hERG 或吸收差而
被标记的，先搁置或重新设计。预测是一个*把下一轮真实实验聚焦起来的过滤器*，而不是最终定论。

## 7. 如实的边界 —— 该抱什么预期

- **Benchling 连接器有一个 mock 模式（mock mode）—— 要搞清楚你处在哪一个。** 当没有配置真实的 API 密钥时，
  药物发现的 Benchling 连接器会**回退到合成数据**（`mock_mode`）。在那个模式下，它返回的是*编造的*化合物和
  IC50 数字，用于开发和测试 —— **不是你实验室的数据。** 在信任一个结果之前，请确认已经配置了一个真实的
  Benchling API 密钥；否则你看到的可能是合成的占位化合物（例如形如 `BNG-0001` 的通用 ID），而不是你的分子。
- **ADMET 数字是预测，不是测量。** ADMET 工作流本身就声明了它的边界：预测只是估计，需要实验验证；训练数据
  偏向成药性的小分子；它对不寻常的化学可能泛化不好。用这些预测来排优先级，再到实验室里确认那些重要的判断。
- **安全闸门在真实运行中被触发，这一点在此尚未被充分证明。** ADMET 工作流及其自动循环（闸门失败时以调整后
  的设置重跑）是 BioMate 的一项核心能力，但有一条已知的注记指出：hERG 安全闸门尚未被确认能在所有情况下于
  一次真实运行里触发。请你自己把 hERG 值读一遍；别假定闸门把一切都拦住了。
- **Benchling 是云驻留。** 从 Benchling 读取意味着数据会离开你们组织自己的系统 —— 对受限数据要把这一点
  考虑进去。
- **预测是放在测量旁边的，绝不取代它们。** 你在 Benchling 里的实测实验值始终是基准事实（ground truth）；
  ADMET 预测是额外加上的一层。

## 9. 关键术语

| 术语 | 含义 —— 以及你为什么要在意 |
|---|---|
| **ELN / LIMS** | 电子实验记录本 / 样品追踪系统。记录化合物和实验结果的地方 —— 权威记录系统。 |
| **SMILES** | 一串编码一个分子结构的文本。ADMET 工作流为每个化合物读取的输入。 |
| **实验结果（如 IC50）** | 针对一个化合物测得的数字（IC50 = 效力；越低越强效）。排序里"实测"的那一半。 |
| **战役（Campaign）** | 一个持续运行的 BioMate 药物发现项目，吸纳实验、预测 ADMET、给化合物排序。 |
| **ADMET** | 吸收、分布、代谢、排泄、毒性 —— 决定一个强效分子能否成为一款安全药物的那些性质。 |
| **hERG** | 一个心脏离子通道；阻断它会引起危险的心律问题。最该盯着看的安全性端点。 |
| **Mock 模式（Mock mode）** | 没设真实 Benchling 密钥时返回合成（假）数据的一种回退 —— 测试时有用，被误当成真实结果时很危险。 |
| **IND 文件** | 战役可以组装的正式监管文书 —— 交给 CRO 或监管方的那一环。 |

---

> **这台仪器的诚实结论：** *可用；预测工作流是真实的，但要如实披露两条告诫。* Benchling → 战役这条路径是
> 真实的（`lims/poll`/`ingest-assay` 端点确实存在），ADMET 工作流 **Predict ADMET Properties (AI)** 在目录
> 中存在、且是一项核心能力。**告诫一：** 药物发现的 Benchling 连接器有一个 **mock 模式**，在没有真实 API
> 密钥时返回合成数据 —— 请确认你用的是真实数据。**告诫二：** ADMET 值是需要实验验证的预测，而且 hERG 安全
> 闸门尚未被确认能在所有情况下于一次真实运行里触发。请你自己把那些数字读一遍。
