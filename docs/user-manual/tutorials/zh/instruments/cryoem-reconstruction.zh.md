# 仪器教程 —— Thermo EPU / 冷冻电镜 → 三维重构

> **适合谁读：** 任何在 Thermo Fisher 显微镜（Titan Krios、Talos Arctica、Glacios）上用 EPU 采集单颗粒
> 冷冻电镜数据的人。读这篇不需要编程。
> **用时：** 约 10 分钟。
> **它在教程中的位置：** 教程六讲的是如何*注册*一台仪器。这一篇回答：*"我的显微镜跑完了一次采集 ——
> BioMate 在它上面运行什么分析？我怎么启动？又怎么读懂它产出的那张三维图？"*

---

## 1. 它解决什么问题

冷冻电子显微镜不会直接递给你一张蛋白质的图像。它记录的是**成千上万条带噪声的影片** —— 一段段短片，
拍的是随机取向、散落在一薄层冰里的冷冻颗粒。每一段影片几乎全是噪声；结构藏在**几万个颗粒视角按正确的
相对角度叠加后的*平均***里。把这一堆影片变成一张清晰的**三维密度图**（density map）—— 那个你真正能把
蛋白质模型嵌进去的东西 —— 是一项很长的、多步骤的计算工作，叫**单颗粒分析（single-particle analysis，
SPA）**。

纯手工做 SPA，意味着要按顺序运行十来个专用工具（运动校正 → CTF 估计 → 颗粒挑选 → 二维分类 → 三维精修
→ 锐化），每个都有自己的设置和质量检查，还要耗上许多 GPU 工时。BioMate 把这整条流程打包好，你只要把它
指向你的 EPU 采集文件夹，就能拿回那张图，外加每一步的记录。

> **一句话概括：** BioMate 接过你显微镜采集到的原始影片帧，替你跑完整条单颗粒重构流程，返回一张三维
> 密度图，外加一个分辨率估计和一份审计留痕。

---

## 2. 这台仪器产出什么

EPU（Thermo 显微镜上的采集软件）会往一个按日期命名的采集文件夹里写入：

- **影片帧（movie frames）** —— 许许多多 `.mrc`、`.tif` 或 `.eer` 文件，每个是一个视场内冷冻颗粒的一小段
  影片（一次采集往往有几千个文件）。这是原始数据。
- **采集元数据** —— 一些很小的 `.xml` 文件，记录**加速电压**（如 300 kV）、**像素尺寸**（一个图像像素
  对应多少埃 —— 也就是显微镜有效的"尺子"）、放大倍率，以及离焦范围。BioMate 会读这些，省得你手动输入。

一个典型的 EPU 文件夹，影片大致在
`…/<date>_<sample>/Images-Disc1/GridSquare_*/Data/*.mrc`，旁边还有一个 `Metadata/` 文件夹。

## 3. 它驱动的 BioMate 分析（以及为什么）

冷冻电镜连接器会把一次完成的 EPU 采集映射到一个工作流，这在连接器代码和 BioMate 目录里都已证实：

- **工作流：** `cryosparc_standard_spa` —— *"CryoSPARC 标准单颗粒分析"*
- **关键输入参数：** `movies_path`（影片帧所在的文件夹），外加 `voltage` 和 `pixel_size`，后两个 BioMate
  会从 EPU 元数据里替你填好。
- **它是什么：** 标准的那套约 23 步 CryoSPARC 单颗粒工作流（BioMate 把它作为一条多步流程来运行）：导入
  影片 → patch 运动校正 → CTF 估计 → 颗粒挑选 → 二维分类 → 模板挑选 → 三维精修 → 后处理 / 锐化。

**为什么是这条工作流：** 这是从原始影片到三维图的那条成熟、已发表的路线，和冷冻电镜平台用的是同一套
顺序。每一步消除一类不同的误差 —— 运动校正修掉束流致动引起的模糊，CTF 估计校正显微镜的光学畸变，分类
剔除垃圾颗粒，精修再把好的颗粒对齐成一个高分辨率的平均。

这条工作流遵循的几条科学规则（这样你才能信任它报出的数字）：
- **分辨率在 FSC = 0.143 处报告** —— 这是金标准判据（Henderson 等人，2012）。埃数越小，分辨率越高
  （细节越多）；3 Å 极好，8 Å 偏低。
- **CTF 质量差的显微照片会被丢弃**，这样坏图像就不会污染平均。

## 4. 开始之前 —— 把影片送到 BioMate

如果显微镜还没接上，请先完成教程六（*连接仪器*）：

- 在 **Connectors（连接器）→ Instruments（仪器）**下注册它，类型选 **Thermo EPU / cryo-EM**，填入显微镜
  电脑的 **host/IP** 和 **port**。
- 驻留方式是 **on-prem（本地）** —— 影片留在你们平台网络内部。
- 由于冷冻电镜数据集极其庞大，多数平台会在**挂载了 EPU 输出文件夹（经由 NFS）的那台分析服务器上跑一个
  BioMate 监视器（watcher）**。它会察觉一次采集何时结束 —— 具体是：已经出现了足够多的影片（默认至少约 50
  条），并且**接下来好几分钟没有新影片到来**（采集已经平息下来）。这是管理员 / IT 的配置，设置一次即可。
  请向你的管理员确认 EPU 采集监视器是否在运行。
- 当一次采集完成，它会出现在 **New data events（新数据事件）**下，映射到 CryoSPARC SPA 工作流 —— 你也
  可以自己把 BioMate 指向采集文件夹来启动分析。

---

## 5. 一步步操作 —— 运行重构

1. **从 New-data 事件开始**（如果监视器已配置好）：在 **New data events（新数据事件）**下找到那次已完成
   的采集，按 **Launch（启动）**。BioMate 会打开一个聊天，里面带着一份预填好的草稿，要在该次采集的
   `movies_path` 上运行 `cryosparc_standard_spa`。*或者*用大白话发问：*"在文件夹 X 里的那次冷冻电镜采集上
   跑单颗粒重构。"*
2. **核对自动填好的设置。** BioMate 会从 EPU 元数据里预填 `movies_path`、`voltage` 和 `pixel_size`。
   确认像素尺寸和电压与你的显微镜相符 —— 这两个值至关重要；错误的像素尺寸会让后续每一个尺寸和分辨率都
   跟着错。
3. **确认并运行。** 这条流程在云端 GPU 计算机上运行。单颗粒重构计算量很大，视你有多少颗粒，可能要跑上
   **数小时**。
4. **看着各阶段推进。** 每个阶段（运动校正 → CTF → 挑选 → 二维 → 精修 → 后处理）都会实时地从*等待中*→
   *运行中*→*已完成*。
5. 跑完后**读报告**（见第 6 节）。

> **在你确认之前，什么都不会运行。** Launch（启动）这个操作只是打开一份已审阅的草稿 —— 要你按下 Send（发送）。

## 6. 读结果 —— 那张图和那些数字

打开 **After run（运行后）**报告（和任何 BioMate 工作流一样的那份两标签页报告 —— 见教程三）。对单颗粒
冷冻电镜，重点看：

- **三维密度图** —— 通常是一个 `.mrc` 体数据文件。这是头号产出：你分子的重构形状。你把它下载下来，在一个
  结构查看器里打开（如 ChimeraX）去看、去解读。
- **分辨率估计** —— 在 **FSC = 0.143** 处报告，单位为埃。这是那个唯一说明这张图含有多少细节的数字。越低
  越好：大致来说，低于 3 Å 时你常能看见单个侧链；4–6 Å 能看出二级结构（螺旋呈管状）；差于约 8 Å 就只能
  看出一个大致的团块。这个数字要和 FSC 曲线一起看，别孤立地看。
- **二维类平均（2-D class averages）** —— 你的颗粒从不同角度看过去、像照片一样的图像，在运行途中产生。
  干净、细节清楚的类平均是个好兆头，说明颗粒是真的、而且对齐得好；糊成一团的则提示有垃圾或存在异质性。
- **Summary（摘要）标签页** —— 一段大白话的说明，**从真实的输出文件生成**。如果 BioMate 读不到某个输出，
  它会把那条发现按下不表，而不是编造一个数字（这正是教程三里的那种如实行为）。
- **可复现记录（Reproducibility record）** —— 每一个参数、工具版本和输出文件，可作为一个文件下载，用于
  论文的方法部分或一份存库记录。

## 7. 如实的边界 —— 该抱什么预期

- **这条工作流有真实的运行证据。** 在本系列的所有仪器里，冷冻电镜单颗粒重构是 BioMate 真正在真实显微镜
  数据上端到端跑通过的那一个（团队放在 S3 上的冷冻电镜测试数据），并有一份有据可查的端到端流程文档。
  所以这里"从影片到图"这条路径是**经过验证的**，而不只是接通而已。（话虽如此，"经过验证"的意思是这条
  流程能在真实数据上跑通并产出一张图 —— *你那张*图的科学质量，仍然取决于*你的*样品和数据。）
- **图的好坏不会超过数据的好坏。** 冰层薄、分布均匀、好颗粒足够多，才能把分辨率顶上去。工作流救不了一个
  表现糟糕的样品；一张低分辨率的图，通常意味着问题出在数据，而不是流程。
- **像素尺寸和电压必须正确。** BioMate 会从 EPU 元数据里读它们，但不同版本的 EPU 存单位的方式不一样（米
  还是埃）。运行前请对面板显示的像素尺寸做一次常识性核查。
- **断层成像（tomography）是另一回事。** 这条工作流针对的是*单颗粒* SPA。冷冻电子*断层成像*（对整个细胞
  做倾斜系列）是另一条独立的流程 —— 别把这条指向断层成像数据。
- **它计算量很大。** 要有花上数小时、产生真实 GPU 费用的心理准备。启动前请仔细确认设置，别为一次像素尺寸
  填错的运行付费。

## 9. 关键术语

| 术语 | 含义 —— 以及你为什么要在意 |
|---|---|
| **单颗粒分析（SPA）** | 把几万个带噪声的颗粒视角合成为一张三维图的那条流程。 |
| **影片帧（.mrc/.tif/.eer）** | 显微镜记录的原始文件 —— 冷冻颗粒的短片。一次采集有数千个。 |
| **像素尺寸（埃）** | 一个图像像素覆盖多少真实距离 —— 显微镜的尺子。填错会让每一个尺寸 / 分辨率都跟着错。 |
| **运动校正（Motion correction）** | 消除每段影片中束流致动引起的模糊。 |
| **CTF 估计** | 测量并校正显微镜的光学畸变，让图像能被正确地叠加起来。 |
| **二维类平均（2-D class averages）** | 颗粒从不同角度看、像照片一样的平均；干净的意味着数据好。 |
| **三维密度图（3-D density map）** | 头号产出 —— 你把蛋白质模型嵌进去的那个重构形状。 |
| **FSC = 0.143 处的分辨率** | 金标准的细节度量，单位为埃。越低细节越多（3 Å 极好，8 Å 偏低）。 |
