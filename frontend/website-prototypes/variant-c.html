Security FAQ

No. BioMate orchestrates your AWS Batch jobs but never stores your raw data, intermediate files, or results. All compute output goes directly to your S3 bucket. BioMate stores only metadata: workflow selection, parameters, run status, and audit log entries — no genomic or molecular data.
No. BioMate's AI layer receives only your plain-English workflow description and the resulting parameter set — never raw data files. PHI is never included in API prompts. For HIPAA-covered workflows, we recommend using de-identified sample identifiers in all queries.
Yes. The Enterprise private deployment option runs the full BioMate stack inside your VPC. AI model calls are made to an AWS Bedrock endpoint in your account — no traffic leaves your network perimeter. Air-gapped configurations are available for environments with strict egress controls.
The audit log is a structured JSON file with a human-readable PDF summary. It includes: workflow version and container SHA256, all parameters with their sources, every QC threshold with its citation, pass/fail status per check, and timestamps for all events. The PDF summary is formatted for direct inclusion in regulatory submissions and publication methods sections.
BioMate is SOC 2 Type II certified (audit report available under NDA). HIPAA BAA is available for clinical research customers. GDPR data processing agreements are available for EU-based institutions. ISO 27001 certification is in progress (target: Q3 2026).
