Worked examples: search answers

BioMate · Spec 09 · addendum to Spec 01Status: builtLane: Instant

Spec 01 said an answer carries its references. It did not say what happens when someone clicks an example on the cold-start card. This addendum specifies that path: a search example is a worked case, and clicking it opens a full answer surface — the retrieval, what was dropped, the claims with their sources, the boundary of the answer, and the two things that legitimately follow. No configuration screen, no run object.

9.1What changed

BeforeNow
An example seeded the composer; the user then sent it and waited for a chat answer.An example opens its answer surface directly. Search is the instant lane — it answers, it does not configure.
Each track listed three or four example phrasings, none of which was actually worked.Each track lists one example, and that example is fully worked. Breadth moved into the track sentence.
—A typed question that resolves to a case says so plainly rather than silently substituting the case's subject.
Rule

An example on a card is a promise. If clicking it cannot produce the answer it names, it is not an example — it is decoration, and it belongs in the track sentence as prose instead.

9.3Answer surface anatomy

ElementBehaviour
how this was searchedOne row per source with found and kept. During retrieval the bars animate and the counts read "searching…"; they resolve together, never one source at a time.
filter chipsThe constraints the retrieval actually used (years, species, type, evidence class). Editable: changing one re-derives the answer and records the new retrieval alongside the old.
what was droppedCollapsed by default. Expands to a sentence accounting for every dropped record by reason — off-topic, review with no primary data, retracted, no accessible full text.
leadA short editorial label on a claim block ("Direction of evidence · consistent"), so a reader can see the shape of the answer before reading it.
marks newNumbered superscript buttons after each claim. Clicking one expands its reference card inline, under that claim, rather than scrolling away to a list.
boundaryAlways present. States what the answer is not evidence for, and names the index date.
disagreementPresent when the corpus disagrees, with both positions and their references. Contradicting sources are kept in the shortlist rather than dropped — "a disagreement is a finding, not noise".
evidence tableStudy · system · finding · strength, with contradicting rows labelled as such.
referencesEvery source as a card: title, authors, venue, year, the sentence relied on, kind, and an open-source link. A footer states that every link was opened and confirmed to resolve before the answer could use it.
what to do nextExactly two exits: turn it into a run on your own data, or save it as a document. Saving reveals the file name, an "Open it in Files" button, and the note that it is now editable, versioned and downloadable.

9.4Typed questions

A typed question is matched to a case by intent (SEARCH_MATCH), falling back to the case for the routed track. Because the shown retrieval is then not the user's, the surface says so: the page title is the question they typed, and a line under it reads "Answered here as the worked example '…' — the retrieval below is that one, not yours." When the typed text matches the case's own question, the note is absent.

Rule

Never silently substitute one question for another. A demo that shows a worked example under someone else's question is indistinguishable from a system that misread them.

9.5Composer parity

The composer and the cards must reach the same surface for the same sentence. Sending text that routes to Instant · search opens the answer surface, exactly as clicking the example does; it does not open a run panel. The lane preview above the composer is keyed off the same router entry, so the chip, the sentence and the destination cannot disagree.

9.6Saved answers

Saving writes a document into the project (evidence_IL11-fibrosis.md) with the retrieval record attached, so the answer can be re-derived rather than only re-read. It is a file object like any other: quality badge, origin ("Saved from a search"), versions, download menu, hand editing and chat-based editing (Spec 12). Its quality notes state that every claim carries a reference and that contradicting evidence was kept.
