Design & generate: all modalities

BioMate · Spec 11 · addendum to Spec 05Status: builtPlatform: mixed

The module was small-molecule-shaped: its name, its examples and its parameters all assumed chemistry, which left a protein designer looking at an empty module and finding their work under Models instead. This addendum makes one design module carry every modality — small molecule, peptide, protein / biologic — and makes modality a property of the request rather than of the module, the track or the run card.

11.1What changed

BeforeNow
"Propose molecules, then optimise and rank them.""Propose candidates — molecules, peptides, proteins — then optimise and rank them."
Track "Predict activity".Track "Predict & filter" — structure and activity both filter a candidate set.
One example list per track.Three per track, switched by a Modality control on the card; 34 worked example phrasings in all.
Router knew chemistry intents only.Router has peptide and protein/biologic rules, placed before the workflow rules.
Lane sentence read "This reads like molecular design…".Lane sentence is modality-neutral, and peptide / biologic requests get their own wording keyed off the matched domain.

11.2The modality control

On the opened card, under the track sentence: a row labelled Modality with three chips — Small molecule · Peptide · Protein / biologic. It sets which example set is listed, persists across track changes, and travels with the example when clicked.

Rule

Modality is not a filter over an inventory of pipelines. It states what kind of object the user is designing, and it decides which generator and which scorers are callable — so it must reach the run card, not stop at the example list.

11.4How modality reaches the card

  • clickClicking an example passes the card's current modality explicitly. This is authoritative — the user chose it two clicks ago.
  • typed textmodalityOf(text) infers it: peptide / macrocycle / staple / helicity → peptide; antibody / nanobody / CDR / framework / enzyme / thermostability / construct / expression titre → protein; otherwise small molecule.
  • heldThe clicked modality is kept in its own state and outranks inference. It is cleared when the user edits the composer text — at that point the sentence is theirs.
  • appliedwfFor(dom, modality) substitutes the run card's Modality parameter and the "… to stay on" slot: scaffold, sequence motif or framework.
Root cause fixed

Modality had been hard-coded per domain key, so a cross-cutting domain — Candidate ranking, Activity prediction — could only ever claim one modality. Ranking a set of nanobodies and ranking a set of small molecules are the same job on different objects; the card now takes the modality from the request.

Rule

A rule may not claim a sentence another domain owns. Bare expression and developability swallowed the transcriptomics, ADMET and ranking seeds; both were qualified or removed. Every seed in the product — router seeds, tiles, domain shapes, module examples — is audited against its owning domain, and the audit is part of the change, not an afterthought.

11.6Where biologics is still thin

  • open The Models worked cases are chemistry-weighted: only "Run a model" is protein. Train, Tune and Rounds are small-molecule.
  • open Design run phases are shared across modalities; expression and manufacturability probably deserve their own phase for biologics.
  • open Whether nucleic-acid modalities (siRNA, mRNA, guide design) are a fourth chip or a separate module.
