Run cards by domain

BioMate · Spec 13 · addendum to Specs 06 & 07Status: builtSurface: run panel

The composer promised a lane and a domain, then opened one hard-coded RNA-seq panel for everything. A biologics design request was answered with "Which reference build?" and a GENCODE licence gate. This addendum makes the run card a function of the routed domain and the request's modality, so the panel can never contradict the preview that produced it.

13.1The rule this enforces

Rule

The lane preview, the routed domain and the surface that opens are one decision with one source. If the chip says Protein & biologic design, the panel is a design run; if it says Data analysis, the panel is a sandbox. A preview that cannot be honoured is a lie told confidently.

Clicking an example and typing the same sentence reach the same surface. That parity is the acceptance test for this spec.

13.4What a card overrides

  • kicker + nameDomain and run kind — "Design · Design run", "Sandbox · Ad-hoc · sandbox" — never "Workflow" for a run that is not one.
  • versionIts own pipeline version. Inheriting v1.4.2 made every card read as the transcriptomics pipeline.
  • slotsThe inputs that domain actually needs, each with what resolves it. Design: target or epitope, scaffold/motif/framework to stay on, property envelope, exclusion rules.
  • paramsFour resolved parameters with provenance and a "why". Design cards carry Modality, count, hard constraints, scoring models.
  • phasesFour phases with domain-true steps. Design: input & constraints → generation → scoring & constraints → shortlist & report. Training: input & split → fit → held-out evaluation → gate & offer.
  • clarificationsIts own questions. Design asks the hard constraint, the count and which scorers may gate; training asks how the split is made and what the model must clear; sandbox asks which file version and whether the result is kept.

Step detail (the full step view, Spec 08) remains fixtured only for the shipped transcriptomics run: a phase from another domain does not borrow its evidence.

13.5Credentials

The licence gate appears only where a slot needs one — slots.some(s => s.license) — in all three places it is expressed: the input slot, the phases banner and the panel footer. Confirm-and-run is gated on needsLicence && !licensed, so a card with no licensed input starts enabled instead of being permanently unstartable.

Rule

A blocked primary action must always have its unblocking affordance on the same screen. Hiding the affordance without ungating the button turns a run panel into a dead end with no explanation.

13.6The sandbox card

ParameterValue
EnvironmentPython 3.12 · pandas, numpy, matplotlib — pinned, so the same code gives the same numbers next month.
NetworkIsolated. The sandbox cannot reach the internet or another project's files.
CodeShown before it runs. An ad-hoc number is only as trustworthy as the code behind it, so the code is part of the answer.
ProvenanceA saved output becomes a file object with a version — not an image in a transcript.

Phases: read the data → write the code → run in the sandbox → keep or discard. The last phase has no duration, because it is a decision.
