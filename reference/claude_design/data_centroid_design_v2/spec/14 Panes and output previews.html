Panes, previews and navigation

BioMate · Spec 14 · addendum to Specs 00 & 04Status: contract split — sequencing TBDSurface: shell

Three shell-level changes that the new surfaces made necessary: either side of the chat/run split can be put away and comes back predictably; outputs and artefacts are previewed as file objects rather than as terminal images; and every new page is reachable and leaveable by breadcrumb, not only by Back.

14.1Collapsing the split

ActionResult
"Hide chat" in the chat topbarThe chat collapses to a 46px rail with a vertical Chat tab; the run panel takes the full stage.
Back on the run panelThe panel hides; the chat takes the full stage and gains a "Run panel" chip that restores it exactly as it was.
Stage narrower than 880pxThe chat collapses on its own. Widening restores it — but only if the hide was automatic.
Reveal below the thresholdRestoring the chat swaps which side is away: the run panel collapses rather than building a split the stage cannot hold.
Reveal above the thresholdPanel width is clamped so the chat column gets its 380px minimum.
Rule

An automatic hide is remembered as automatic; a hide the user chose is never undone by a resize. And a collapsed pane always carries its own reopen control — a pane with no way back is indistinguishable from a broken one.

Because a pane is both user-resizable (to 320px) and auto-collapsing, the chat topbar must survive narrowness: crumb and title ellipsize on one line, buttons do not shrink, and their labels drop to icons under ~520px of pane width.

14.2Previewing outputs and artefacts

Every artefact a run or a case produces follows one resolver, whatever produced it. The user sees a short scientific label — Table, Figure, Structure, Report or Log — rather than the resolver's implementation taxonomy.

KindPreviewAffordances
tablePreview tab with the first rows and a column profile; the header states shape.Open in Files · versions · ask-to-edit (cell diff) · download.
documentThe document itself, typeset, in a Document tab.Edit in place · ask-to-edit (prose diff) · versions · download menu (5 formats).
figureThumbnail in the output grid; opens with the step that produced it.Open the step · open in Files.
model artefactNamed with its interface and size.Open the model object · registry entry.
structure / state fileNamed with what it carries (e.g. pLDDT in the B-factor column).Open in Files.
Rule

An artefact is a file object, not a picture of one. If it can be seen it can be opened and taken; versioning and editing are retained capabilities enabled when their file contract exists. A preview that dead-ends is a screenshot.

On a case page, the artefacts block states that every artifact can be opened and downloaded with its provenance. Report artifacts additionally expose the immutable original and reproducibility bundle; "Open & edit" is enabled when the retained project-file contract is available.

Model use caseproject / Models / trackProject crumb → files. "Models" crumb → the registry. Model chip → the model object. Artefacts → Files. Back → chat.

Document (on a run)Report tab"In Files" opens the same document as a file object.
Model objectModels / Registry / modelLineage links to the dataset version and the training run; consumers link to the surfaces that call it.

Opening a file from anywhere resolves its owning project, expands that project in the sidebar, selects the file and switches to Files — so a report reached from a run is in the same place as a report reached from the tree.

14.4Consistency invariants

  • one versionFile row, object header, Versions tab and open document read the same current version, through one helper.
  • one controlEach control (version chip, download, in-Files) appears once per screen; host and component never both render it.
  • one destinationA sentence typed in the composer and the same sentence clicked on a card reach the same surface.
  • named objects onlyA page may only name a model, file or run that exists and can be opened.
  • no silent substitutionIf a worked example answers a different question than the one asked, the page says so.
