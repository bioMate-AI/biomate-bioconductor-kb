Sequencing reads — from FASTQ to an answer

Turn sequencer reads into expression, variants, or microbiomes.

Your Illumina sequencer writes millions of reads as FASTQ files and uploads them to BaseSpace. BioMate reads the run's experiment type and routes it to the matching pipeline — differential expression, germline variant calling, or microbiome profiling — on cloud compute, with no FASTQs copied by hand.

What you do with reads depends entirely on what library you sequenced — and that is exactly what decides which pipeline runs.

FASTQ reads→ Experiment type→ Matched pipeline→ Expression · variants · taxa
The problem

Raw reads are not an answer — and the library decides the analysis.

A FASTQ of millions of reads means nothing until the reads are aligned, quantified, and interpreted. And “interpreted” means something different for RNA, for whole genomes, and for a 16S amplicon — run the wrong pipeline and you get a confident wrong answer.

1 · READS, NOT RESULTS

A chain, not a tool

Trimming, alignment, quantification, and QC must be chained correctly before a single count or variant exists.

2 · THE LIBRARY DECIDES

Same reads, different biology

RNA → which genes change. WGS → which variants. 16S → which microbes. The experiment type picks the path.

3 · FILES BY HAND

Provenance leaks

Copying FASTQs between tools loses the sample sheet, the genome build, and the record of what produced each number.

The pipelines are community-standard and well established. The goal is to route to the right one and run it consistently.

The ideas you need first

Four ideas behind reads-to-biology.

From a finished sequencer run to a readable result is a short, well-trodden chain. These four ideas cover all of it.

1 · FASTQ

The reads

The A/C/G/T of each fragment with a per-base quality (Phred) score. Paired-end gives R1 + R2 — bring both.

2 · EXPERIMENT TYPE

The hinge

The library kind — RNA, WGS/WES, amplicon. This is what routes the run to a pipeline.

3 · THE PIPELINE

A tested chain

Not one tool: nf-core/rnaseq, Wgs Germline Gatk, or nf-core/ampliseq — trim → align → quantify/call → QC.

4 · CLOUD RESIDENCY

Where the data lives

BaseSpace is Illumina's cloud — data leaves your organisation. For restricted data, that is yours to account for.

The experiment type is the hinge: RNA routes to expression, DNA to variants, amplicon to taxa.

Step 2 · How a run works

Launch from the run — or just ask — then confirm.

Click Launch on a completed run, or describe the goal the way you would to a colleague — for example, “germline variant calling on this WGS run against hg38,” or “nf-core/rnaseq then differential expression, treated vs control.”

Completed run / plain request→ Experiment type routes the pipeline→ Review & confirm→ Runs on cloud compute
  • The pipeline is chosen from the run type. RNA → nf-core/rnaseq, WGS → Wgs Germline Gatk, 16S → nf-core/ampliseq — a real named pipeline, never “undefined.”
  • You review before anything runs. Inputs are shown, filled in and editable, with the FASTQs linked and the genome build or grouping set.
  • Then Confirm & Run. Expect a long cloud run — phases move pending → running → completed, and a mid-run QC gate pauses-and-reports; it never silently passes a failed check.

Step 3 · The result — matched to the library

One After-run report, shaped by what you sequenced.

The run returns a report matched to the library: expression for RNA, variants for DNA, taxa for 16S.

  • RNA-seq: differentially expressed genes by log2 fold-change + FDR; a gene-count matrix and the MultiQC report.
  • WGS: an annotated VCF (position, ref vs alt, SnpEff effect), a recalibrated BAM, and coverage / QC.
  • 16S: a taxonomy table (who’s there) and diversity metrics (how varied).
  • Downloadable tables and reports for your figures and supplement.
One report, shaped by the library
Step 4 · Reading and trusting it

Standard pipelines, QC you must read, and a record you can cite.

The pipelines are community-standard and applied the same way each run. What makes a result defensible is the QC you read and the record you keep.

  • Read the QC first. RNA-seq: MultiQC per-base quality and a sensible alignment rate. WGS: mean coverage (the pipeline warns below 20×) and alignment rate (warns below 70%) — low values mean don’t over-trust the calls.
  • A flat result can be real or underpowered. No significant genes may be a true null — or too few replicates. A single-sample variant with thin coverage is a hint, not a call.
  • Cloud residency is yours to own. BaseSpace data sits in Illumina’s cloud; confirm that is acceptable for restricted or patient data before connecting — the residency badge is shown for exactly this reason.
  • A record you can defend. The genome build, parameters, tool versions, and output checksums are kept together as a reproducibility record.
A result you can defend
The habit at a glance

Launch a completed run → confirm it routed right → set build or grouping → run → read, checking QC.

The value is simple: sequencer reads become biology with one request, through the community-standard pipeline for your library, on cloud compute, with a record you can defend in a paper or a submission.
