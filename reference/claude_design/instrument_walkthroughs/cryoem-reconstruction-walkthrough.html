The problem

A microscope hands you noise, not a picture of your protein.

EPU records thousands of short movies of frozen particles scattered at random angles in thin ice. Done by hand, turning them into a sharp 3-D density map means running a dozen specialist tools in order — each with its own settings and quality checks — over many GPU-hours.

1 · NOISE, NOT A MAP

The signal is in the average

One movie is almost pure noise. The structure only emerges from tens of thousands of particle views combined at the correct relative angles.

2 · A DOZEN TOOLS IN ORDER

A chain, not a tool

Motion correction → CTF estimation → particle picking → 2-D classification → 3-D refinement → sharpening — each stage removes a different kind of error.

3 · HOURS OF GPU

Heavy and error-prone by hand

Each step has its own settings and QC, and the record of what produced the map is easily lost between tools.

This is single-particle analysis (SPA) — the established, published route that cryo-EM facilities use. BioMate’s job is to run it for you, consistently, with every step recorded.

The ideas you need first

Four ideas behind movies-to-a-map.

From a finished EPU session to a readable 3-D map is a long but well-trodden chain. These four ideas cover what you need to trust it.

1 · MOVIE FRAMES

The raw data

Many .mrc, .tif, or .eer files — short clips of one field of frozen particles, often thousands per session.

2 · PIXEL SIZE & VOLTAGE

The microscope’s ruler

Pixel size (ångströms per pixel) and voltage (e.g. 300 kV). A wrong pixel size makes every downstream size and resolution wrong.

3 · THE SPA PIPELINE

A tested chain

Not one tool: cryosparc_standard_spa, a ~23-step CryoSPARC workflow — import → motion → CTF → pick → classify → refine → sharpen.

4 · RESOLUTION AT FSC = 0.143

The detail measure

The gold-standard criterion (Henderson et al. 2012). Lower is better: 3 Å excellent, 8 Å low.

Residency is on-prem — the enormous movie datasets stay inside your facility network; only the analysis runs on cloud GPU.

Step 1 · What you provide

A completed session folder — and two numbers it already knows.

Once the microscope is connected (see Tutorial 6), BioMate maps a finished EPU session to cryosparc_standard_spa and pre-fills its inputs from the session metadata — so you mostly confirm rather than type.

1 · THE SESSION FOLDER

The movies_path

Point BioMate at the EPU session folder (e.g. Images-Disc1/GridSquare_*/Data/*.mrc). This becomes movies_path — the key input.

2 · PIXEL SIZE & VOLTAGE

Read from the metadata

BioMate reads voltage and pixel_size from the EPU .xml files. These two are critical — confirm they match your microscope.

3 · THE WATCHER’S NOTICE

Or start it yourself

In most facilities a watcher spots the finished session (≥~50 movies, then quiet). If none is set up, point BioMate at the folder by hand.

EPU versions store units differently (metres vs ångströms) — sanity-check the pixel size the panel shows before running.

Step 2 · How a run works

Launch the New-data event — or just ask — then confirm.

When a session completes it appears under New data events mapped to the SPA workflow. Press Launch and BioMate opens a pre-filled draft — or describe the goal plainly: “Run single-particle reconstruction on my cryo-EM session in folder X.”

New-data event / plain request→ Maps to cryosparc_standard_spa→ Review & confirm→ Runs on cloud GPU
  • The pipeline is a real, named workflow. cryosparc_standard_spa — the standard CryoSPARC SPA pipeline — never “undefined.” The event card maps the session straight to it.
  • Check the auto-filled settings. movies_path, voltage, and pixel_size are pre-filled from EPU metadata and editable. Confirm pixel size and voltage — a wrong pixel size wrecks every result.
  • Then confirm & run. It runs on cloud GPU and is compute-heavy — expect hours. Phases move pending → running → completed in real time. Nothing runs until you press Send.

Step 3 · The result — a map and its numbers

One After-run report: the 3-D map, the resolution, and the evidence.

The run returns the same two-tab report as any BioMate workflow (see Tutorial 3), with the outputs grouped by phase — the headline map volume, the class averages, and the resolution report.

  • 3-D density map: an .mrc volume — the headline output. Download it and open it in a structure viewer (e.g. ChimeraX) to see and fit your molecule.
  • Resolution estimate: reported at FSC = 0.143 in ångströms. Read it with the FSC curve, not alone.
  • 2-D class averages: picture-like views of the particle from many angles. Clean, detailed ones mean good, well-aligned data.
  • Results tab & record: a plain-language account built from the real output files, plus a downloadable reproducibility record.
A map, a number, and the evidence behind both
Step 4 · Reading and trusting it

Read the FSC, judge the map against the data, keep the record.

The pipeline is published and applied the same way each run. What makes your map defensible is the QC you read and the record you keep — the workflow reports honest numbers so you can.

  • Read the resolution with the FSC. At FSC = 0.143: below 3 Å you often see side chains; 4–6 Å shows secondary structure (helices as tubes); worse than ~8 Å shows only an overall blob. Micrographs with poor CTF quality are discarded so they don’t pollute the average.
  • The map is only as good as the data. Thin, well-distributed ice and enough good particles drive resolution — a low-resolution map usually means the sample or data, not the pipeline. A workflow cannot rescue a badly behaved sample.
  • This is single-particle SPA only. Cryo-electron tomography (tilt series of whole cells) is a separate pipeline — don’t point this one at tomography data.
  • A record you can defend. Every parameter, tool version, and output file is kept together — downloadable as one file for a paper’s methods or a deposition record.
