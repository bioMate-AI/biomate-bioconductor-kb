FCS events — from a table of dots to named populations

Turn flow-cytometer events into cell populations and their percentages.

Your cytometer records every cell as an event — scatter (FSC/SSC) plus a value in each fluorescence channel — and writes one sample to one .fcs file. BioMate runs the gating you would otherwise draw by hand: remove junk, pick lineages by their markers, and report each population as a percentage of its parent.

A raw .fcs is a giant table of dots, not an answer — the gating strategy and the compensation matrix are what turn it into biology.

The problem

Raw .fcs is a table of dots — and gating defines every population.

An .fcs file holds tens of thousands to millions of events and means nothing until you draw boundaries around meaningful groups of cells. And what “a population” is depends entirely on what you stained for — the wrong gating or no compensation gives a confident wrong answer.

1 · DOTS, NOT POPULATIONS

Gating, not reading

You must gate in sequence — remove debris and doublets, then pick lineages by marker thresholds — before a single percentage exists.

2 · THE PANEL DECIDES

Same dots, different biology

A surface panel → which populations and what %. CFSE → cell division. Annexin V/PI → apoptosis. What you stained picks the assay.

3 · SPILLOVER LEAKS

Dyes bleed

Without a compensation matrix, fluorescence overlaps between channels — a CD4 signal can masquerade as CD8 and look plausible.

The gating is the analysis. The goal is to write it down once, compensate correctly, and run it the same way every time.

The ideas you need first

Four ideas behind dots-to-populations.

From a finished acquisition to a readable gating tree is a short, well-defined chain. These four ideas cover all of it.

1 · FCS & EVENTS

The cells

Each event is one cell: FSC ≈ size, SSC ≈ granularity, plus a value per marker (CD3, CD4, CD8, CD19…).

2 · GATING

The decision tree

Remove junk → pick lineages → count. Each population is defined by a combination of marker thresholds.

3 · GATING STRATEGY

Written down

The tree as text — named populations with cut-offs, e.g. ["FSC-A","between",[50000,150000]] — so it is reproducible.

4 · COMPENSATION

The spillover matrix

Required. Corrects dyes bleeding across channels. You bring it from your single-stain controls.

The gating strategy is the hinge: it is how a “population” is actually defined, and what makes the result repeatable.

Step 1 · What you provide

One .fcs file, your gating logic, and a compensation matrix.

Once the cytometer is connected (see Tutorial 6) its watcher groups .fcs files by experiment folder and surfaces each run as a New data event; or bring a single file in by hand (Tutorial 4). The workflow is Analyze Flow Cytometry Immunophenotyping (cell_biology).

1 · THE FCS FILE

fcs_file_path

The single .fcs file to analyse, from your instrument export. These workflows take one file at a time.

2 · THE GATING STRATEGY

gating_strategy

The decision tree as named populations with marker thresholds. Adapt the pre-filled example to your real channel names and cut-offs.

3 · THE COMPENSATION MATRIX

compensation_matrix (required)

The spillover matrix from your single-stain controls. BioMate does not compute it for you.

Use your channel names exactly as the instrument wrote them (e.g. FSC-A, SSC-A, FL1-A, or marker names).

Step 2 · How a run works

Launch from the event — or just ask — then confirm.

Click Launch on the cytometry data event, or describe the goal plainly — for example, “immunophenotype this FCS file; gate lymphocytes on FSC/SSC, then CD3+ T cells, then CD4 vs CD8; report population percentages.”

Data event / plain request→ Assay routes the workflow→ Review & confirm→ Runs on biomni_local
  • The panel opens the named workflow. It should show Analyze Flow Cytometry Immunophenotyping, never “undefined.” The connector's label is only a hint — if it guessed CFSE / cytokine / apoptosis wrong, say which assay it is in chat.
  • You review before anything runs. Edit gating_strategy to match your panel, supply the required compensation_matrix, and attach the .fcs file if it is not already linked.
  • Then Confirm & Run. It runs on BioMate's biomni_local runtime (~16 GB RAM); a sample is typically a couple of minutes.
Nothing runs until you confirm
Step 3 · The result — a gating tree

One After-run report: the populations and what fraction each is.

The run returns a report you read as a gating tree, with the per-population tables and gating plots filed under the step that produced them.

  • Summary: populations found and what fraction each is, read as a tree — e.g. lymphocytes 62% of singlets → CD3+ 71% → CD4+ 43% / CD8+ 29%. Percentages are the headline number.
  • Outputs: per-population counts and percentages as tables (json/txt/csv), plus any gating plots the workflow emits.
  • Reproducibility record: the exact gating strategy, compensation matrix, and software version used.
  • Downloadable tables and plots for your figures.
One report, shaped by the assay
Step 4 · Reading and trusting it

Check the gates, mind compensation, and verify your first run.

The workflow does threshold-based gating from the strategy you supply. What makes a result defensible is the QC you read, honest limits you respect, and the record you keep.

  • Check the gates first. A sensible result keeps most events in the singlet/lymphocyte gate (not 90% thrown away), and population percentages sum sanely within each parent.
  • A tiny fraction can be noise. A “0.1% CD4+” is easily a gating artefact; uncompensated spillover inflating a marker usually shows up as a smear rather than a clean cluster.
  • Compensation is on you. The workflow requires a matrix and will not derive one — feed uncompensated data and populations can be wrong in ways that look plausible.
  • A record you can defend. The gating strategy, compensation matrix, and software version are kept together — not a one-off hand-drawn set of gates no one can reproduce.

The habit at a glance

Launch the cytometry event → confirm the right assay workflow → write the gating strategy + supply compensation → run → read the percentages.

The value is simple: an .fcs table of dots becomes named cell populations with one request, through a real indexed workflow, with the gating documented in a record you can reproduce — while you verify the first run against your own manual analysis in FlowJo.
