**To fill a slot:** capture per the spec, save as `docs/user-manual/assets/<slot-id>.png` (lower-case id), and replace the placeholder line in the chapter
(`*(Figure to add: …)*`) with `![<caption>](../assets/<slot-id>.png)` + the italic caption line. For the **recommended additions** (§3) insert the image
markdown under the named section in the chapter **and** delete the entry from `manual/shotlist.js`.
Honesty rules (assets/README.md): capture the real current UI only, never mock; if the state can't be produced truthfully, leave the placeholder.
Capture harness: `frontend/e2e/manual-screenshots.spec.ts` (+ the tutorial capture specs listed in tutorials/README.md).
