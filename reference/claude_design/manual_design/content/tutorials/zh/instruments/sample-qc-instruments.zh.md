# 仪器使用手册 — 样本质控与检测类仪器（RIN / NanoDrop / 细胞计数仪 / 凝胶蛋白成像仪）

> **适用对象：** 负责样本质控与检测环节的实验人员——使用 **安捷伦生物分析仪 / TapeStation**（RNA 完整性，RIN）、
> **微量分光光度计 / NanoDrop**（A260/280 与 A260/230 纯度）、**自动细胞计数仪**（细胞数 + 活率 %）、或
> **多功能凝胶蛋白成像仪**（Western 灰度定量）的用户。本手册帮助您把这些仪器导出的小文件变成
> **一个站得住脚的合格 / 不合格判定，以及一份可追溯的质控记录**，全程无需写代码。
> **阅读时间：** 约 12 分钟；这几类质控分析都很轻量，几秒到一分钟即可完成——进去一张整洁的表，出来一张合格判定表。
> **在教程体系中的位置：** 教程 6（T6）讲的是如何*连接*仪器、让文件进入 BioMate；本手册讲的是
> **文件进入 BioMate 之后怎么用**——怎样把它转化为质控结论，以及这个结论如何作为门槛，决定样本能否进入其下游流程
> （RNA-seq、蛋白质组学等）。
> **请先读 §6 的诚实状态说明：** 四项质控分析中有三项目前已经构建、但在开发环境中尚未接入路由。本手册会明确区分
> **今天可以跑的** 与 **尚待上线的**。

## 1. 这些仪器产出什么

和测序仪或质谱仪不同，这几类仪器**不**产生大体量的原始数据文件，它们产出的是**很小的表格或图像导出**，
目的只有一个：*这个样本的质量，够不够资格进入昂贵的下游实验？* 每台仪器衡量的是一个不同的质量维度。

- **生物分析仪 / TapeStation（RNA 完整性）。** 安捷伦 2100 生物分析仪与 4200/4150 TapeStation 按片段大小分离 RNA，
  并给出其**完整性**评分——即 RNA 是完好还是已降解。核心指标是 **RIN**（RNA 完整性值，1–10；TapeStation 上称 RINe），
  同时报告 **28S/18S** rRNA 比值、浓度，以及针对固定组织的 **DV200**（长度大于 200 nt 的片段占比）。
  导出格式：每样本一行的 **CSV**（外加一张 PDF 电泳图谱）。
- **微量分光光度计 / NanoDrop（核酸纯度）。** Thermo NanoDrop（One / 2000 / 8000）等仪器对 1–2 µL 样本做全紫外波段
  吸光度测定，报告**浓度**（ng/µL）以及两个纯度比值：**A260/280**（蛋白质 / 苯酚污染）与
  **A260/230**（胍盐、EDTA、糖类残留）。导出格式：每样本一行的 **CSV**。
- **自动细胞计数仪（细胞数 + 活率）。** Countess 3 / 3 FL、LUNA、Cellometer、NucleoCounter 或 Vi-CELL 通过台盼蓝或
  荧光染料排斥法计数，报告**总数 / 活细胞 / 死细胞浓度**（cells/mL）、**活率 %** 与**平均细胞直径**。
  导出格式：每样本一行的 **CSV**。
- **凝胶蛋白成像仪（Western 灰度定量）。** 多功能凝胶 / 膜成像仪对染色凝胶或化学发光 Western 膜拍照。对于
  **Western 印迹**，其定量读数是**灰度定量**——每条目标条带的积分强度，并以**内参**（GAPDH、β-actin）归一化。
  导出格式：**条带图像**（PNG / TIFF / JPEG）。

**仪器屏幕上的一个数字，还算不上质控记录。** RIN 6.4、或 A260/230 1.1，本身没有意义——要先对照一个明确的阈值判定、
连同该阈值一并记录在案，再作为*门槛*带入样本接下来要进的流程，这个数字才有价值。BioMate 在这一环做的，正是把导出
转化成 **一张合格 / 不合格表 + 一份持久、可审计的质控记录**；更关键的是，每一道门槛都是某个真实下游流程的
**准入条件**（见 §5）。

## 2. 每台仪器驱动的 BioMate 分析（以及为什么）

每台仪器都对应 `backend/biomni_workflows/nextflow_nfcore/subworkflows/lab_automation/` 下一个小而专用的质控流程。
它们都是**容错解析器**：接受不同固件导出的多种列名写法，在导出缺少派生字段时自行补算，套用一个**可配置阈值**，
最后返回一张整洁的每样本表、一份机器可读的 JSON 和一份人读的摘要。若不提供文件，流程会生成演示数据，方便您在接入
自己的导出之前先看清输出的样子。

### 2a. RNA 完整性 → `lab_automation/rin_bioanalyzer_qc`

读取生物分析仪 / TapeStation 的每样本 CSV，按**可配置的 RIN 阈值**判定合格 / 不合格，并辅以 **DV200 片段大小校验**。

- **关键参数：** `bioanalyzer_csv`（导出文件）、`rin_threshold`（默认 **7.0**）、`dv200_min_pct`（默认 **30.0 %**）、
  `assay_type`（`RNA` | `FFPE_RNA`）。
- **要点在于判定逻辑：** 对新鲜 RNA，门槛是 **RIN ≥ 阈值**（DV200 仅作参考）；对 **FFPE / 存档 RNA**——由于这类 RNA
  本身就已片段化，RIN 不再具参考意义——门槛改用 **DV200 ≥ 下限**（遵循 Illumina TruSeq RNA Access 指南）。流程会依
  `assay_type` 自动选用正确的门槛，从而不会把"虽降解但仍可用"的固定组织 RNA 误判为不合格。
- **RIN ≥ 7 为何对下游重要：** 建库与转录本定量都假定 RNA 相对完好。RIN 偏低会使覆盖偏向 3′ 端、放大技术噪声，
  因此 **RIN < 7 是判断 RNA-seq 风险的通用警示线**——详见 §5。

### 2b. 核酸纯度 → `lab_automation/nanodrop_purity_qc`

读取 NanoDrop 的 CSV，按**区分核酸类型**的吸光度窗口判定纯度合格 / 不合格。

- **关键参数：** `nanodrop_csv`、`nucleic_acid_type`（`DNA` | `RNA`）、`min_conc_ng_ul`（默认 **10.0**）、
  `a260_230_min`（默认 **2.0**）。
- **要点在于判定逻辑：** **A260/280** 的合格窗口由样本类型决定——**DNA 取 1.7–2.0，RNA 取 1.9–2.2**
  （Thermo T042 技术公告；Wilfinger 1997）——因为二者固有比值不同。**A260/230 低于约 2.0** 提示有机物残留
  （胍盐、苯酚、EDTA），会抑制下游酶反应。若导出只给出 A260 / A280 / A230 原始吸光度，流程会**自行算出比值**，
  因此不完整的导出同样能判定。
- **纯度为何对下游重要：** A260/230 偏低是建库失败、PCR / 逆转录受抑制的主因之一——在这一步抓出来，远比测序跑完才
  发现要省钱得多。

### 2c. 细胞数 + 活率 → `lab_automation/cell_counter_viability_qc`

读取细胞计数仪的 CSV，以**活率**和**活细胞浓度下限**为门槛判定，并附一个参考性的细胞大小窗口。

- **关键参数：** `cellcount_csv`、`viability_min_pct`（默认 **80.0 %**）、`min_live_conc`（cells/mL，默认 **100 000**）、
  `diameter_min_um` / `diameter_max_um`（参考项，默认 **5–30 µm**）。
- **要点在于判定逻辑：** 仅当 **活率 ≥ 下限 且 活细胞浓度 ≥ 下限** 时样本才合格。平均直径为**参考项**——超出窗口会
  提示成团或碎片，但本身不致使样本判不合格。若导出缺少活率或活细胞数，流程会据活 / 死 / 总列**反算**
  （例如 活率 = 活 ÷ 总）。
- **活率为何对下游重要：** 单细胞与原代细胞实验在活率低于约 80–90 % 时质量急剧下降（死细胞释放游离 RNA、干扰包封），
  因此这道门槛正是 §5 中单细胞流程的准入条件。

### 2d. Western 灰度定量 → `pharmacology/analyze_western_blot`

一个**真实的图像灰度定量**流程：读取印迹图像，测量每个指定条带区域的积分强度，并报告各目标条带相对于**内参**的表达量。

- **关键参数：** `blot_image_path`（PNG / TIFF / JPEG）、`target_bands`
  （由 `{name, roi:[x, y, width, height]}` 组成的列表——每个目标条带一个以像素表示的**感兴趣区域**）、
  `loading_control_band`（GAPDH / β-actin 的单个 `{name, roi}`）、`antibody_info`（一抗 / 二抗记录，写入报告以留存溯源）。
- **要点在于判定逻辑：** 对每个 ROI，流程累加灰度强度，再计算
  **相对表达量 = 目标条带强度 ÷ 内参强度**——即标准的以内参归一化的 Western 读数。输出为一张
  `Protein, Raw Intensity, Relative Expression` 表格外加一份分析日志。
- **重要限制——条带区域需手动指定。** 流程只量化*您给定*的 ROI，它**不会**自动识别泳道或条带。您需要为每条条带提供
  像素 ROI（可在成像软件或任意看图工具中读取坐标）。自动泳道灰度分析（Fiji / ImageJ 式）是已知缺口——见 §6。
  另请注意，这是 **Western 印迹（膜）** 的灰度定量：目前**没有**对拍照所得的 **DNA / 蛋白凝胶** 做灰度定量的流程（见 §6）。

| 仪器 | 回答的质控问题 | BioMate 流程 | 主门槛 |
|---|---|---|---|
| 生物分析仪 / TapeStation | 我的 RNA 够完整吗？ | `lab_automation/rin_bioanalyzer_qc` | RIN ≥ 7（FFPE 改看 DV200） |
| NanoDrop / 微量分光光度计 | 我的核酸够纯、够浓吗？ | `lab_automation/nanodrop_purity_qc` | A260/280 在窗口内，A260/230 ≥ 2.0 |
| 自动细胞计数仪 | 我的细胞活着的够多吗？ | `lab_automation/cell_counter_viability_qc` | 活率 ≥ 80 %，活细胞浓度 ≥ 下限 |
| 凝胶蛋白成像仪 | 我的蛋白量相对内参是多少？ | `pharmacology/analyze_western_blot` | 相对 GAPDH / β-actin 的表达量 |

## 3. 开始之前——先把数据放进来（见 T6），然后运行

### 把导出放进 BioMate

这几类仪器产出的是**小文件**，所以导入很简单：从数据区**上传仪器的导出**——每样本一行的 **CSV**
（生物分析仪 / NanoDrop / 细胞计数仪）或**条带图像**（PNG / TIFF / JPEG，用于印迹）。若您的厂商软件导出的是
**PDF** 报告（生物分析仪常见），请同时另存一份每样本的 **CSV / 表格** 视图——解析器读的是表格导出，而非 PDF 电泳图谱图片。
在核心平台环境中连接与自动导入将如何实现，是**教程 6**的主题；本手册假定文件已在 BioMate 中。

**您需要准备好：**
- **RIN：** 生物分析仪 / TapeStation 的每样本 CSV；明确 RNA 是**新鲜**还是 **FFPE**（决定 `assay_type`）。
- **NanoDrop：** 每样本 CSV；明确样本是 **DNA 还是 RNA**（决定 A260/280 窗口）。
- **细胞计数仪：** 每样本 CSV；根据下游实验确定**活率阈值**（默认 80 %）与**活细胞下限**。
- **Western：** 条带图像，加上每条目标条带与内参的**像素 ROI**，以及用于记录的抗体信息。

### 运行

1. **在对话中提出需求，或直接选择流程卡片。** 说明仪器与门槛，例如：*"对这份生物分析仪 CSV 做 RIN 质控，RIN 低于 7
   的判不合格"*；*"对这份 NanoDrop CSV 做纯度质控，这些是 RNA 样本"*；*"细胞计数活率质控，活率下限 85 %"*；
   *"对这张印迹做 Western 灰度定量，以 GAPDH 为内参。"*
2. **确认面板打开的是正确的质控流程**（§2），且名称显示正确、不是"undefined"。**见 §6：** 对这三个 `lab_automation`
   质控解析器而言，该路由在开发环境中**尚待上线**，因此若卡片未出现，那是已知的注册缺口，并非您操作有误。
3. **填写关键参数。** 设定您要据以判定的阈值（`rin_threshold`、经 `nucleic_acid_type` 决定的 A260/280 窗口、
   `viability_min_pct` 等）。默认值即为上述标准阈值；仅当有协议上的特定理由时才覆盖它们。
4. **确认并运行。** 这些都是轻量任务——几秒到约一分钟即可出结果。观察阶段从 *pending → running → completed* 推进。

## 4. 读懂输出

每个质控流程都写出**相同的三文件结构**，因此看懂一个就能看懂全部：

- **每样本 CSV** —— 每行一个样本，含测得值、`qc_pass` 布尔判定，以及一个 `fail_reason`，明确指出是哪个阈值未达
  （例如 `A260/230=1.1 < 2.0`）。这张表就是您归档的**质控记录**，并随下游运行一并附上。
- **结果 JSON**（`*_qc_results.json`）—— 相同数据外加一份**批次摘要**（`n_pass` / `n_fail`、合格率 %，以及
  `batch_qc_status`：全部合格为 **PASS**，有任一不合格为 **REVIEW**）。这是下游流程读取的机器可读门槛。
- **人读摘要**（`*_summary.txt`）—— 所用阈值，以及每个样本一行的判定结论。

各自额外提供的内容：

- **RIN**（`rin_per_sample.csv`、`rin_qc_results.json`、`rin_summary.txt`）：列含 `RIN`、`28S/18S`、
  `concentration_ng_ul`、`DV200_pct`，以及实际采用的门槛 `gate`（RIN 还是 DV200），摘要中另给 `mean_rin`。
  不合格行会告诉您*原因*（RIN 低于阈值，或 FFPE 的 DV200 低于下限）。
- **NanoDrop**（`nanodrop_per_sample.csv` 等）：列含 `concentration_ng_ul`、`A260`、`A280`、`A230`、`A260/280`、
  `A260/230`。不合格会指明出问题的维度——浓度偏低、260/280 超窗口、或 260/230 残留——从而让纠正措施
  （重纯化、重洗脱、还是重测浓度）一目了然。
- **细胞计数仪**（`cellcount_per_sample.csv` 等）：列含 `total/live/dead_cells_ml`、`viability_pct`、
  `mean_diameter_um`，并在直径超窗口（成团 / 碎片）时单独给出 **`size_warning`**——与硬性不合格相区分。
- **Western**（`analyze_western_blot_results.json`、`western_blot_results.csv`、`analyze_western_blot_output.txt`）：
  即 `Protein, Raw Intensity, Relative Expression` 表格（内参固定为 1.0）以及记录抗体与步骤的分析日志。

> **什么样算好，哪些要警惕。** 一个干净的批次应是 `batch_qc_status: PASS`、每个样本的 `fail_reason` 都为空。
> 遇到 **REVIEW** 状态，应视作"停下来看看"而非自动弃用：逐条阅读 `fail_reason`——单个临界样本（阈值 7.0 而 RIN 6.8）
> 是个需要判断的边界情形，而整批都栽在 A260/230 上，则指向上游提取环节出了问题。对 Western 而言，若内参强度接近零、
> 或各泳道间高低悬殊，通常意味着 ROI 位置偏了——在采信相对表达量之前，请先复核像素区域。

## 5. BioMate 还能做什么——这些门槛如何衔接真实的下游流程

一道质控门槛的意义，在于它**背后**的流程。运行这些仪器的核心平台会把样本送入 BioMate 的主分析目录，而上面的每个质控
结论,都是其中某个流程的准入条件：

- **RIN（与 NanoDrop）→ 批量 RNA-seq 差异表达。** 通过 RIN 与纯度质控的 RNA，正是经过验证的
  **`nf-core/rnaseq` → DESeq2** 差异表达链（转录组学——即平台的测序路径；参见*BaseSpace / 测序*教程）的输入。
  **RIN < 7 是判断样本构成 RNA-seq 质量风险的通用警示线**，因此这道质控门槛实实在在就是该流程的入口。
- **NanoDrop → WGS / 变异检测与 qPCR。** 通过纯度质控的 DNA 进入 **WGS 胚系 GATK** 流程，针对性工作则进入
  **`normqpcr` ΔΔCq** 定量——二者都对 A260/230 所抓的残留敏感。
- **细胞计数活率 → 单细胞与流式流程。** 活细胞悬液进入单细胞 RNA-seq 流程（Seurat / Scanpy / STARsolo，配合
  CellBender 去除游离 RNA），以及**流式免疫表型**流程（flowCore / FlowSOM；参见*流式细胞*教程）——二者都以这道门槛
  所把守的 ≥ 80 % 活率为前提。
- **Western 灰度定量 → 蛋白质组学与药理学目录。** 相对表达量读数可与 BioMate 的质谱蛋白质组学流程
  （`nf-core/proteomicslfq`、`nf-core/diaproteomics`；参见*LC-MS 蛋白质组学 / 代谢组学*教程）以及酶标仪剂量-反应 /
  命中判定实验并用，开展功能层面的后续验证。

换言之，这四台小仪器绝非配角：它们是平台转录组学、基因组学、单细胞、蛋白质组学与各类检测流程的**质量前端**。
把质控与下游分析放在同一个系统里跑，正是让 RIN / 纯度 / 活率的结论作为一道有据可查的门槛随样本一路传递，而不至于沦为
一张便利贴。

## 6. 诚实状态——今天能跑什么，还有什么尚待上线

- **三个 `lab_automation` 质控解析器（RIN、NanoDrop、细胞计数）已构建，但尚未在路由中上线。** 工作流文件已在代码库中
  （PR #226），并以标准文献为依据（RIN 依 Schroeder 2006；NanoDrop 比值依 Thermo T042 / Wilfinger 1997；活率依台盼蓝
  染料排斥法）。**但它们尚待开发数据库注册**，这意味着在开发环境中，当您提出需求时对话路由**可能还不会把它们呈现出来**。
  请把它们看作**在代码库中已就绪、但在开发环境尚未确认可端到端路由**。若流程卡片未出现，那就是这个注册缺口——补救办法
  是在开发环境做一次数据库重建索引，而非改变您的使用方式。在路由确认上线之前,请勿把这几项的质控结果作为经过验证的
  生产运行结果来报告。
- **Western 灰度定量是真实流程，但条带区域需手动指定，且仅适用于 Western 印迹（膜）。**
  `pharmacology/analyze_western_blot` 执行的是真实的图像灰度定量，但它量化的是**您提供的像素 ROI**——
  它**没有**自动泳道 / 条带识别。提供准确的 ROI 由您负责。真正的自动泳道灰度分析（Fiji / ImageJ 式）是一项公认的升级
  缺口（平台清单中的 **B9**）。
- **对拍照所得的 DNA / 蛋白凝胶，目前没有灰度定量能力。** 目录中唯一的"凝胶"流程
  `genetics/perform_pcr_and_gel_electrophoresis` 是一个**计算机模拟**——它根据 DNA **序列**与引物预测条带位置，即它是在
  *绘制*一张预期的凝胶，而**不是分析成像仪拍出的真实凝胶图像**。若您需要对实际琼脂糖 / SDS-PAGE 凝胶照片做泳道灰度定量，
  该能力目前并不存在；膜的灰度定量请走 Western 印迹路径，而凝胶图像定量请暂视为缺口。
- **连接 / 自动导入不在本手册范围内。** 本手册假定您已上传导出。核心平台如何把仪器的输出目录接入 BioMate，
  是**教程 6**的内容，不应从上文任何部分推断。

## 8. 关键术语

| 术语 | 含义——以及您为何需要关注 |
|---|---|
| **RIN / RINe** | RNA 完整性值（1–10）。衡量 RNA 的完好程度；**< 7 提示 RNA-seq 质量风险**。RINe 为 TapeStation 上的对应值。 |
| **DV200** | 长度大于 200 nt 的 RNA 片段占比。**FFPE / 降解** RNA 的完整性门槛——此时 RIN 已无参考意义。 |
| **28S/18S 比值** | 两个核糖体 RNA 峰的比值；约 2.0 表示总 RNA 完整。 |
| **A260/280** | 纯度比值；反映蛋白质 / 苯酚污染。目标 **DNA 约 1.8、RNA 约 2.0**。 |
| **A260/230** | 纯度比值；反映有机物 / 盐类残留（胍盐、苯酚、EDTA）。目标 **约 2.0–2.2**；偏低会抑制酶反应。 |
| **活率 %** | 活细胞比例（染料排斥法）。下游单细胞 / 流式实验通常要求 **≥ 80–90 %**。 |
| **活细胞浓度** | 每毫升活细胞数；须达到一个**下限**，下游实验才有足够的投入材料。 |
| **灰度定量（densitometry）** | 从印迹 / 凝胶图像测量条带强度，以定量蛋白（或 DNA）的含量。 |
| **ROI（感兴趣区域）** | 定义一条 Western 条带的像素矩形 `[x, y, width, height]`——需手动提供。 |
| **内参（loading control）** | 用于在各泳道间归一化 Western 条带强度的管家蛋白（GAPDH、β-actin）。 |
| **batch_qc_status** | 批次判定：**PASS**（全部合格）或 **REVIEW**（至少一个不合格——阅读其 `fail_reason`）。 |
