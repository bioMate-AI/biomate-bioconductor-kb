# 入门——起始页 > 一句话说明：读完这一页，你会知道如何从一个空白对话开始在 BioMate 里做任何事，以及路由器如何把一句话变成正确类型的工作。适合所有人。 ## 它的用途 每一个新对话都从**起始页**开始——这是 BioMate 的入口。这里没有一长串工具名称菜单，取而代之的是四张**功能模块**卡片和一个**意图路由器**：描述一个目标，BioMate 会在任何东西运行之前告诉你它理解到的是哪类工作（一个 Instant 回答，还是一条 Cloud 工作流）。 ## 它在哪里 起始页显示在**新对话的空白状态**下——也就是会话里还没有任何消息的时候。开一个新对话（侧边栏 → New chat）就能再次看到它。 ![起始页：意图输入框、四张模块卡片（检索与证据 · 数据分析 · 设计与生成 · 模型），以及底部带 Instructions 和 Experts 的消息框。](../../assets/i01-1-cold-start.png)
*起始页（当前版本实况截图）——通往一切的入口。* ## 怎么使用 **两种进入方式——都只会预填消息框，都不会自动发送**（你始终需要自己检查并发送）： 1. **在意图输入框里输入你的目标。** 输入框的提示文字是：*"描述目标——例如：针对 hERG 筛选这些分子，然后按成药性排序"*。在你输入时，路由器会读取内容，并显示**通道**（Instant / Cloud）和一个**领域**标签。按回车或发送按钮 → 你的文字会被放进消息框，你可以在那里编辑后再发送。
2. **打开一张模块卡片，挑一个示例。** 每张卡片默认是收起的；点击卡片标题即可展开。展开后，该模块的各个**方向**以标签页的形式出现，每个方向下都有示例目标。点击一个示例 → 它会把这个目标填进消息框，**并附上该示例预先准备好的公开演示数据集**，所以可以直接运行——无需上传。 - 对于**设计与生成**，卡片还带有一个**模态**选项（小分子 / 多肽 / 生物大分子）；你选择的模态会一并写进预填的目标中。 四个模块（检索与证据 · 数据分析 · 设计与生成 · 模型）以及它们各自通向哪里，在[概览](../overview/00-what-is-biomate.md)和各自的章节中有介绍。 ## 意图路由器（它做什么——以及不做什么） - 它会把听到的内容**复述**为"通道 + 领域"——例如"这看起来是变异检测领域的一条 Cloud 工作流"。起始页对通道的判断与消息框自身的通道预览完全一致，两者不会互相矛盾。
- 它**从不返回数量统计或工作流名称列表**——BioMate 的能力通过模块和复述来呈现，而不是通过一份清单。 ## 你能掌控什么 - **发送前检查**——预填的目标**以及附带的演示数据集**会放进消息框；检查一下，可以修改目标或换成你自己的数据，然后发送（I.2）。
- **通道**——如果路由器给出的 Instant / Cloud 判断不是你想要的，可以在消息框里改掉它（I.2 / 通道标签）。 ## 注意事项与提示 > **提示——卡片不会运行任何东西。** 点击示例只会把目标**和预先准备好的演示数据集**填进消息框，你可以直接运行（或先调整）；你仍然需要自己按发送。不会有任何东西在你不知情的情况下启动。 > **提示——随时可以回来。** 起始页就是空白对话的状态——开一个新对话就能回到入口。 > **提示——你不需要先选模块。** 直接在意图输入框里输入你的目标；路由器会判断模块、通道和领域。 ## 暂未覆盖的内容 以下设计构想经核实**目前尚未提供**（→ 附录 E）：
- 路由器预填的是你**原样输入的文字**；没有一个单独的"开始"按钮来预填经过规范化的表述。
- 没有面向老用户的**精简/收起式启动器**（始终显示完整的四卡片网格）。
- 当某个项目处于打开状态时，起始页上没有**项目范围提示行**（例如"在*项目 X* 中 · 其文件和指令已纳入上下文"）。
