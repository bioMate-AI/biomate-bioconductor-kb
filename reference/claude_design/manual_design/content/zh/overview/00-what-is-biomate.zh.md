# BioMate 是什么 —— 能力地图 > 一句话说明：读完这一页，你会知道 BioMate 能做的所有事情以及它们是如何组织的，从而迅速找到你要做的任务。适合所有人。 ## 产品的整体形态 BioMate 是一个**连着执行引擎的对话**。你用日常语言描述一个目标；BioMate 判断它能否**即时**作答，还是应该运行一条**经过验证的云端工作流**，然后去完成，并把结果带回你正在对话的同一个地方。 一切都从**起始页**开始：四张**功能模块**卡片，加上一个**意图路由器**。卡片本身不会启动任何东西——点击一个示例，只会把这个目标**预填**进你的消息框，**并附上它预先准备好的公开演示数据集**（可直接运行，无需上传）；它不会替你发送，你仍然需要自己检查并发送。路由器会读取你输入的内容，并把它**复述**为"通道 + 领域"——它从不会抛给你一长串工作流名称。 ## 两条通道（后果模型） 每个目标都会落到以下两条通道之一： - **Instant（即时）**——一个带引用的回答或一次临时计算，**就在对话里，几秒钟内**完成。基本不产生费用。
- **Cloud（云端）**——一条运行在云端的**经过验证的流水线**，耗时**几分钟到几小时**，按用量计费。它在对话旁边的运行面板中执行（见 I.6）。 起始页的意义就在于：在你做出决定之前，你始终清楚这样做的后果。 ## 四个功能模块（BioMate 能做什么） | 模块 | 用途 | 通道 | 方向（子能力） |
|---|---|---|---|
| **检索与证据** | 基于文献、数据库和专利给出带引用的回答 | Instant | 文献 · 数据库 · 专利 · 内部记录 |
| **数据分析** | 在你自己的数据上工作——临时计算或经过验证的工作流 | Instant（临时计算）/ Cloud（工作流） | 临时计算 · 经过验证的工作流（覆盖所有领域） |
| **设计与生成** | 提出候选物——小分子、多肽、蛋白——然后优化并排序 | Cloud | 生成 · 预测与筛选 · 性质优化 · 候选排序（按模态：小分子 / 多肽 / 生物大分子） |
| **模型** | 在你的数据上训练、适配或优化模型 | Cloud | 训练 · 适配 · 优化（设计—合成—测试循环） | ![BioMate 起始页：意图输入框（"你想做什么？"）与四张功能模块卡片，底部是消息框（Instructions · Experts）。](../../assets/i01-1-cold-start.png)
*起始页——四个功能模块与意图路由器。（当前版本实况截图。）* ### 每个模块通向哪里
- **检索与证据** → 一个证据回答，附带检索过程说明和可阅读、可保存的引用（见 I.3）。Instant。
- **数据分析 → 经过验证的工作流** → BioMate 会路由到约 34–36 个领域（转录组学、基因组学、冷冻电镜、药物发现、蛋白质组学……）中已收录的某条工作流，并在运行面板中运行（见 I.6 及第 III 部分的各领域章节）。**临时计算**则直接在对话中运行一小段代码。
- **设计与生成** → 按模态（小分子、多肽、生物大分子）进行生成 + 预测/筛选 + 性质优化 + 排序（见 I.11；独立页面位于 `/design`）。
- **模型** → 在你的数据上训练/适配/优化模型，并以它来把关设计循环（见 I.10；独立页面位于 `/models`）。 ## 各功能的位置 平台的主体就是对话（`/`）。你也可以直接打开以下专用页面：`/files`（数据中心——以对象的方式管理数据集）、`/models`、`/design`、`/ind-report`、`/drug-discovery-cro`、`/capabilities`、`/billing`，以及 `/workflow/:id`（直达某条生成的工作流）。这里**没有 `/dashboard`**，也**没有独立的运行列表页**——每次运行都属于它所在的对话（见 I.6）。 ## 如何阅读本手册的其余部分
- **第 I 部分——通用模块：** 跨领域的平台功能（即本页模块地图的详细展开）。
- **第 II 部分——数据库与检索：** 检索模块所依托的知识基础。
- **第 III 部分——领域：** 以用例为主线的章节（建议从"药物发现 → IND"开始，然后是转录组学……）。
- **附录：** 术语表、文件格式、QC 关卡参考、故障排查，以及一份如实列出*尚未*支持功能的**覆盖范围与路线图**。
