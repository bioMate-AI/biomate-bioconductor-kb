# 一页看懂对象模型 > 一句话说明：读完这一页，你会理解让 BioMate 浑然一体的那个核心理念——一切都是可以打开、引用和信赖的"活对象"。适合所有人。 ## 核心理念 在 BioMate 里，你处理的东西不是聊天记录里的一串文字——它们是**对象**。一个数据集、一次运行、一个输出、一份报告、一个模型、一个计划：每一个都有稳定的身份，**在任何地方都以同样的方式打开**，并且自带溯源信息。正因如此，你可以*点一下就核查*，而不必回头重读。 ## 有哪些对象 | 对象 | 它携带的信息 | 以什么形式打开 | 章节 |
|---|---|---|---|
| **数据集** | 身份 · 导入时的质量 · 血统 · 使用方 · 版本 · 来源 | 数据集对象页（`/files`）；无论从对话里的数据标签还是文件树打开都一样 | [I.5](../modules/I05-files-and-dataset-object.md) |
| **运行** | 状态 · 参数 · 实时步骤 · 输出 · 发现 | 对话旁边的运行面板；属于它所在的对话 | [I.6](../modules/I06-running-an-analysis.md) |
| **步骤** | 输入 → 工具与版本 → 输出 · 按来源区分的参数 · 渲染视图⇄原始视图 | 完整步骤视图 | [I.7](../modules/I07-full-step-view-provenance.md) |
| **输出** | 文件内容 · 类型 · 大小 · SHA-256 · 生成它的步骤 | 按证据类型匹配的应用内查看器 | [I.8](../modules/I08-outputs-viewers-interactive.md) |
| **报告** | 运行后记录 + 可编辑、带版本的方法说明；不可变的 v0"运行原始版" | 两个标签页的运行后报告 | [I.9](../modules/I09-reports-and-reproducibility.md) |
| **模型** | 身份 · 证据 · 血统 · 版本 · 接口 | 模型对象 / 模型注册表 | [I.10](../modules/I10-models.md) |
| **计划 / 假设** | 运行可以引用的目标与假设 | 项目上的一张卡片 | [I.4](../modules/I04-projects-instructions-collaboration.md) | ## 每个对象都具备的三个属性 1. **稳定的身份。** 数据集的 ID、运行的 ID、输出的引用——同一个引用从任何地方（对话里的标签、文件树、报告里的链接）都会打开同一个对象。
2. **溯源。** 输出会链接回生成它的步骤；运行会链接到它所用的参数和输入；报告会链接到它的运行（不可变的"运行原始版"）。发现中的每个数字都链接到它所出自的输出。
3. **如实的状态。** 质量是经过分析得出的，而不是凭空声称的（Good / Watch / Blocked）；校验和基于真实的文件内容（可按需计算）；系统无法支撑的能力*不会*显示出来（见[附录 E](../appendix/E-coverage-and-roadmap.md)）。 ## 为什么重要 因为对象是活的、可引用的，一整条工作线索才能串联起来：你保存的一个**证据回答** → 引用它的一个**计划** → 产出**输出**的一次**运行** → 一份**报告**，其中的数字可以点回那些输出 → 另一次运行读取的某个**数据集**版本。没有任何东西是死的文字；每一个链接都是你可以打开并核实的东西。 > **提示。** 在 BioMate 里看到一个 ID、一个标签或一个数字时，可以默认它是可点击的——它几乎总能打开背后的对象。 ## 暂未覆盖的内容
- 整个项目的跨对象关系图视图（计划 → 运行 → 报告集中在一个屏幕上）尚未构建——见[附录 E](../appendix/E-coverage-and-roadmap.md)。目前你需要在对象之间逐个跳转。
