BioMate 教程 生成式先导设计
献给想要全新化学物质的药物化学家

你还没有一个分子。BioMate 从零开始设计候选物。

筛选是从你已经拥有的库里挑出赢家。生成式设计反其道而行：它发明对准你所陈述目标的新分子。BioMate 运行 REINVENT4——来自 MolecularAI / AstraZeneca 的一个强化学习生成器——来提出新颖、类药的候选物，再对它们做过滤与排序。你描述骨架以及什么算"好"；BioMate 就产出你可以拿去合成的结构。

一个目标 + 一个种子骨架→ REINVENT4 生成→ 一个打分函数给出奖励→ 过滤 + 排序→ 排好序的候选假设
它解决的问题

类药化学空间太过浩瀚，既无法枚举，也无法逐一筛选。

可合成、又类药的分子，其空间常被估计在 10^60 上下——比任何库、任何筛选、任何算力所能覆盖的都要多。你无法把它一一列出，而围着一个骨架做暴力枚举会组合爆炸，产出的大多是不类药、难以合成或平淡无奇的类似物。真正的需求是聪明地搜索那片空间——只提出那些新颖、可合成、且对准你目标的候选物。

规模

约 10^60 个分子

类药空间让有史以来建成的每一个实体与虚拟库都相形见绌。枚举根本行不通。

组合学

类似物爆炸

只用寥寥几个片段去装饰一个骨架，就已经生出数百万个——其中大多数不值得去做。

质量

大多是废料

随机或穷举得到的候选物通常不可合成、不类药，或会干扰实验测定。

目标

多个目标同时兼顾

一个先导化合物必须同时平衡活性、类药性与合成难易——而不是孤立地看某一项指标。

需求：靠设计去搜索化学空间，而不是靠枚举
你需要先懂的几个概念

四个大白话词，就能说清整套方法。

你不需要懂神经网络的内部机理——只要这四个，其余的自会顺理成章。

1 · 生成模型

学会"画"出分子

一个在已知化学上训练出来的策略，一块一块地写出新的 SMILES——它是一个训练出来的模型，而不是一张查找表。REINVENT4 就是那个生成器。

2 · 打分函数

定义什么算"好"

一个奖励，为每个被提出的分子打分——类药性、合成难易、一个 docking 分数。这就是把你的目标变成了数字。

3 · RL 循环

生成 → 打分 → 学习

强化学习经过多轮，把生成器一点点推向打分更高的分子，于是提案随历练而改进。

4 · 多参数优化

多个目标一起兼顾

奖励可以糅合多个目标——活性、类药性与可合成性——让候选物在它们之间取得平衡，而非一味追逐一个。

整套方法就是一个循环：生成模型提出、打分函数评判、RL 引导下一批提案——并同时优化多个目标。

背景——本讲余下部分会用到的词汇
在 BioMate 里 · 大白话目标 → 工作流 → 云端

用大白话说出目标；BioMate 把它路由到 REINVENT4 工作流。

你不用去配置一个神经网络。你陈述意图——"设计这个骨架的新颖、类药类似物"——BioMate 就路由到 REINVENT4 Generative Lead Design 工作流，填好参数，再在云端算力上运行它。这是一条四步流水线，而每一步都是系统真实的行为，而非演示。

  • 大白话进，工作流出。你只需描述设计目标，BioMate 就把它路由到 REINVENT4 Generative Lead Design，并展示真实的参数面板。
  • 种子骨架已预填。必填的 Synthesizability 参数里已填好一个种子 SMILES（CC(=O)Oc1ccccc1C(=O)O，阿司匹林）——可换成你自己的骨架。
  • 五个阶段，已为你串好。输入已映射、可选参数已折叠，整条运行按五个阶段铺好，无需手动配置。
  • 选好输出位置，一键启动。结果存入 BioMate 托管存储（或你自己的 S3），点 Confirm & Run 即在云端算力上运行。

奖励 · 你朝什么方向优化

打分函数就是目标——结果再好也不会超过它。

强化学习会优化你告诉它的一切。scoring_function 参数就是那个目标，BioMate 给出三个真实的选择。挑一个与你能多有把握地为靶点定义"好"相匹配的。

qed_sa · 默认

类药性 + 可合成性

奖励高 QED（类药性）和低 SA 分数（合成可及性代价）。快、不需要靶点结构——适合通用的类先导候选物。

docking_gnina

针对受体的构象打分

针对你提供的受体（receptor.pdb），为一个 AutoDock-GPU / GNINA docking 构象打分。靶点感知——是一个计算机模拟的估计，而非实测亲和力。

custom_toml

你自己的奖励配方

一份用户提供的 REINVENT4 TOML，糅合许多组分——通往真正多参数优化最灵活的路径。

奖励奖励什么，你就得到什么。一个孱弱或设定失当的打分函数，只会给你打分很高、却并非更好的药的分子。

把目标定义好——奖励决定了结果的上限
引擎 · 生成、打分、改进

REINVENT4 运行一个循环，把生成引导向奖励。

这个生成器是一个训练出来的自回归策略——它写出 SMILES，而不是枚举。一轮又一轮地，它提出一批分子，给每个分子打分，再更新，让下一批偏向更高的奖励。BioMate 把这个循环真实的控制旋钮都暴露出来。

  • n_steps。RL 训练轮数——默认 500（在 GPU 上约 15 分钟）；快速试跑用 200。
  • batch_size。每轮采样的分子数——默认 128；越大越多样，也越占内存。
  • sigma / learning_rate。奖励把策略引导得有多陡（120），以及更新步长（0.0001）。
  • temperature。采样的发散程度——名义值 1.0，越低越保守。
  • 一个学习出来的策略——若模型或先验缺失，运行会高声报错；它绝不会悄悄退回去做枚举。
一个由奖励引导的训练生成器——而不是对一张清单做过滤
结果 · 排好序、过滤过的候选物

一张排好序的新颖候选物表——每一个都带着它的分数，并过滤了质量。

在排序之前，BioMate 会先施加真实的药物化学过滤，所以你看到的不是模型的原始输出，而是经受住了类药性、干扰和新颖度检查的候选物。输出是你可以打开、也可以直接交付的文件——无需截图来描述它们。

FILTER_RANK

质量门

QED ≥ 0.4、SA ≤ 5.0、MW ≤ 500（Lipinski），移除 PAINS，并对比种子做一道 Tanimoto 新颖度过滤——然后按 Murcko 骨架挑出多样化的头部 N 个。

generated_molecules.csv

每一个被接受的分子

SMILES 连同它的分数、QED、SA 和 MW——完整、排好序的候选集，可直接拿去分流。

top_compounds.sdf

头部 N 个的三维结构

把最佳候选物给成三维构象（RDKit ETKDG），可直接拿去 docking、查看或进一步建模。

报告 + 轨迹

一份你读得懂的记录

一份 HTML 报告，带结构网格和分数拆解、一张分数随 epoch 变化的曲线图，以及一份运行配置的 JSON 摘要。

新颖、过滤过、排好序——并带着决定排序的那些分数
负责任地使用它

这些是假设，不是命中——排序是走向实验台的起点。

每一个生成出来的分子都是一个计算上的估计：一个模型认为会在你的目标下得高分的结构。其中没有一项是实测的。它的价值，是一份排好优先级的新颖候选短名单——一批有希望的实验，而不是一批答案。正确的下一步永远是实验室。

分流

把排名当作先导来读

把靠前的化合物当作最值得化学家留意的分子——一个待验证的假设队列，而非一纸定论。

合成

先做出来，再信它

一个预测出来的分数不是一个真实的化合物。可合成性过滤降低风险；但它们并不保证真有一条可行的路线。

测定

在实验台上验证

用实验去确认活性、选择性与安全性。计算机模拟的分数——哪怕是 docking——也是必须被实测的估计。

生成式设计把一片大到不可能的空间，收窄成可以检验的寥寥几个。判定哪些是真的，靠的是实验，而不是模型。

只有经过合成与测定，才赢得信任的估计
把范围讲清楚 · 你确切得到什么

把范围讲清楚，好让你确切知道自己得到了什么。

这份能力是真实而具体的。知道它确切能做什么，正是它能让你放心用于一个要去捍卫的项目的原因。

受制于奖励

再好也不超过分数

RL 优化的是你给它的打分函数，而不是"成为一种药"。qed_sa 是廉价的描述符；docking 是一个计算机模拟的构象，而非实测亲和力。选好目标——排序的好坏，只取决于它。

学习 vs 基线

两种模式

默认是真实训练出来的 REINVENT4 策略。此外也提供一个 brics 枚举基线，清楚地标明为一个非 RL 对照项，绝不被装扮成一条训练曲线。

对准你的目标

它提出并排序新颖、可合成、对准你目标的结构——让你的化学家优先去做对的分子。
