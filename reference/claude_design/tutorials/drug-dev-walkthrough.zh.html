概念 · 为什么新药研发是一个循环，而不是一条直线 概念

一次走完永远产不出一款成品药——方法是一个会累积收益的循环。

人们很容易把它想象成一条直线：设计一次、测试一次、就做完了。真正的项目从来不是这样。每一轮都从上一轮学到东西，再喂给下一轮——这就是"设计—构建—测试—学习"循环。回报在于：每转一圈，错误都变得更便宜，候选清单也变得更好。

任务 从一个设想走到一个候选药物· 难在哪 没有哪一次走完就能做对· 传统做法 每一轮手工循环要耗上数月· BioMate 每个阶段都是可复用的工作流，可串联、可反复

请把这个循环记在心里，贯穿本教程的余下部分。接下来的几个阶段，其实就是绕着它走一圈——而真正让这个循环值得信赖的两项功能，是质控闸门（阶段五）和可复现记录（阶段七）。

阶段一 · 概念 · 明确目标 概念

在任何分子出现之前，先写下靶点、目标和约束条件。

后面每个阶段都会继承这些选择，所以目标含糊，产出的候选清单也含糊。你只需用大白话向 BioMate 描述出来，就把它记下了。

JAK1

目标

结合 · 吸收 · 安全

与靶点结合；能被口服吸收；对心脏安全（hERG）。

约束条件

新颖 · 可合成

你在这里写下的目标，会变成阶段四里用来比较的那些列——而 hERG 安全上限，会变成阶段五里的质控闸门。本讲用三种大家都熟悉的分子——阿司匹林、咖啡因、布洛芬——演示其中的机制，而非一个完整的靶点攻关项目。

阶段二 · 概念 · 设计候选分子 概念

到底应该考虑哪些分子？

与其在约 10⁶⁰ 种可能里一个个手工画分子，BioMate 的做法是围绕你给定的一个种子，系统地枚举化学上合理的各种变体，再把已知隐患过滤掉，并把留下来的排序成一份候选清单。它今天就能端到端跑完，几分钟内返回一份排好序的起始集合。

种子 → 变体

围绕种子枚举

系统地生成一个已知起始分子在化学上合理的各种变体。

过滤

筛除隐患

剔除已知的问题子结构，以及落在你属性窗口之外的候选。

排序

排好序的候选清单

返回一份排好序的清单——每个都附一句"为什么是它"的说明，以及离它最近的已知分子。

几分钟一份排好序的候选清单——把产出当作结构良好、需在下游继续筛选和打磨的"点子"，是循环的开端而非终点。

阶段三 · 概念 · 什么是 ADMET——以及为什么 hERG 决定成败 概念

ADMET 问的是：身体究竟能不能耐受这个分子？

光能结合还不够——一个分子必须被吸收、去到该去的地方、不被过快破坏、干净地排出，并且不毒害任何组织。ADMET 就是这五个问题。其中一个终点，hERG，凌驾于其余之上：堵住这个心脏钾离子通道，你就冒着致命心律失常的风险——它曾让已上市的药物被撤市。

阶段四 · 概念 · 多目标优化与帕累托前沿 概念

哪一小撮才是综合起来最好的折中？

现在每个候选都带着好几个互相打架的数字——强效却难溶，安全却难合成。BioMate 把每个目标放在各自的列里、保留各自的单位，绝不揉进一个单一分数——那样可能把一个不安全的分子藏起来——并展示帕累托前沿：在这条权衡边界上，你想再改进一个目标，就必须牺牲另一个。

排序是怎么工作的

在"设计与生成"里，一份不揉合、可自己判读的排序。被淘汰的分子依然可见，并附着它被淘汰的理由。由你来挑折中；产品绝不会悄悄把你的多个目标塌缩成一个数字。

阶段五 · 概念 · 质控闸门——为什么它绝不能静默放行 概念

一道质控闸门，把一个阈值变成一个你在运行途中就能信赖的决定。

回到那个循环上：在一次运行内部，质控闸门拿一个数值和你的上限比较，然后拦下或标记——它绝不悄悄让一个不合格的检查溜过去。一道静默放行的闸门比没有闸门更糟，因为它看起来像是成功。当一道闸门不过关时，系统会建议下一步可尝试的参数调整——记成一条清晰的改动前后对照，一个供你自行决定要不要采纳的咨询性建议，而非一次自动的重新运行。

本次运行中——模型估算值，要就着闸门来读
低hERG 阻断风险 · 估算值，非实测 IC50
高DILI · 超过 0.5 上限——闸门将其标记

原生输出是一个阻断风险评分，一个估算值——而非实测的 IC50。模型给一个低风险化合物打出的任何 IC50，都停在估算器的天花板上（约 10 mM）——是一个模型输出，而不是安全性的证据。同一次运行里，肝损伤（DILI）终点返回高，超过上限，于是安全闸门把它标出来提示跟进。要读闸门——别去相信某一个单独的数字。

阶段六 · 概念 · PK / PBPK 建模 概念

人体会需要多大剂量？

一个结合得好、看起来又安全的分子，仍必须在一个合理的剂量下达到正确的浓度。PK 讲的是身体随时间对药物做了什么；PBPK 则是一个按器官逐个建立的机制模型，用来推算人体暴露情景——常常从动物数据外推——并给出一个推算出来的、供评估用的起始剂量情景。请把这些绝对数值当作用来推敲的推算，而不是一个被保证安全的剂量。

一条三步链

异速放大（动物 → 人）→ PBPK 器官逐个模型（含肾/肝功能不全子模型）→ 虚拟患者队列（蒙特卡洛变异性）。你读到 Cmax、AUC，以及一个供评估用的推算起始剂量情景。

供评估用的推算暴露——其绝对准确度未经独立验证。上传你自己的体内浓度数据，同一条链会直接对它进行拟合。

阶段七 · 概念 · 血缘与溯源是什么——以及为什么重要 概念

一个结果有多好，取决于你能不能证明它是怎么来的。

溯源，就是从一个输出回溯到产生它的那一组确切输入、参数和软件的链条。没有它，一个数字只是一句断言；有了它，一个数字才是证据——能经得起论文、专利或 IND 申报的推敲。血缘，就是把这条链条在界面里做成可点着走的样子。

记录本身就是产品

每一次运行都会记下运行 ID、参数、软件版本、SHA-256 校验和与引用——一键导出 JSON。而如果 BioMate 读不出某个输出，它会把该条结论保留而不显示并如实说明，绝不编造一段摘要。

阶段七 · 产品 · 输出 —— 按产生它的步骤归档 实况界面实况产品捕获

每个文件都归在产生它的那一步下面。

"输出"标签页按步骤把结果分组——ADMET 结果表、质控指标、毒性报告——于是你永远不用翻找某个文件，也不用猜它是哪一步出来的。

阶段七 · 产品 · 可复现记录 实况界面实况产品捕获

完整的审计轨迹——可作为一个 JSON 下载。

这是溯源概念的落地：运行 ID、参数、软件版本、输出和引用，全都放在一份你可以附到递交材料里的记录中。本次运行里哪里是空的，记录会把它显示出来，而不是藏起来。

血缘视图沿着链条往回走：这个输出来自这个工作流，用的是这些参数、这些输入。它就是概念页里那张溯源图的、可点着走的形态。

一眼看懂整条流水线

框定 → 设计 → 预测 → 排序 → 循环 → 定剂量 → 记录。

一个完整的计算层面早期筛选循环：一个种子变成一份排好序、经过安全筛选的候选清单；一道安全闸门在一个真实隐患上触发并提出修正；每一个数字都能回溯到产生它的那一组确切输入和参数。每一张概念页讲清一个道理，每一张产品页都展示它在真实输出上运行。真正立得住的优势不是某一个模型——而是这个闭环，加上一份达到审计级别的溯源记录，跑在托管算力上、无需采购任何软件许可。

  1. 1框定目标——靶点、目标、约束条件
  2. 2–3设计候选分子，预测它们的属性
  3. 4–5给幸存者排序，在质控闸门后面闭合循环
  4. 6–7推算剂量，保留溯源记录

这个循环交付什么

  • 从单个种子得到一份排好序、经过安全筛选的候选清单——几分钟内。
  • 一道在真实隐患上触发并提出修正的安全闸门。
  • 一个用来推敲的推算人体暴露情景。
  • 每个数字背后一份达到审计级别的记录，一键导出 JSON。

这是计算层面的早期筛选，不是一款药。价值在于一开始就聪明地出发、并尽早廉价地失败——而不是跳过实验室。
