The problem this solves

Comparing thousands of genes by hand doesn't scale — and isn't safe.

A single RNA-seq run measures tens of thousands of genes across every sample. Eyeballing a spreadsheet to find what changed is slow, and it quietly invites mistakes — the wrong comparison, forgetting that testing twenty thousand genes throws up false hits by chance.

BY HAND

Too many genes

Twenty-thousand-plus rows per sample. No spreadsheet sort tells you which differences are real.

ERROR-PRONE

Easy to get wrong

Which group is the control? Did you correct for testing every gene at once? One slip changes the answer.

HARD TO DEFEND

No trail

A reviewer asks how you got the list. A one-off script leaves nothing to point to.

The need: the right statistics, run correctly, with a record — and no code to write
The ideas you need first

Four plain ideas make the whole result readable.

You don't need the maths — just these four words, and the result tells its own story.

1 · COUNT MATRIX

How much, per gene

A table: one row per gene, one column per sample, each cell how many reads landed on that gene. The measured expression.

2 · GROUPS / DESIGN

What to compare

The labels that say which samples are treated and which are control. This is the comparison you want tested.

3 · DIFFERENTIAL EXPRESSION

Which genes differ

For every gene, how much it changed between groups — the log2 fold-change — and whether that change is real.

4 · MULTIPLE-TESTING

Guarding against luck

Test 20,000 genes and some look "significant" by chance. The adjusted p-value corrects for that, so the hits hold up.

log2 fold-change: +1 means doubled, −1 means halved. Adjusted p-value (FDR): smaller is stronger; a common cut is 0.05. A big change and a small adjusted p-value is a solid hit.

One picture: what moved, how far, and how sure.

The volcano plot puts every gene in one view — fold-change left to right, confidence bottom to top. The genes that matter are pushed to the upper corners.

Step 5 · Reading it with confidence

A strong hit is a big change and a small adjusted p-value.

Two numbers, read together. Fold-change tells you how much a gene moved; the adjusted p-value tells you how sure you can be. One without the other can mislead.

FOLD-CHANGE

How much it moved

log2 fold-change: +1 is doubled, −1 is halved. A large change is biologically interesting — but only if it's real.

ADJUSTED p-VALUE

How sure you are

Already corrected for testing every gene. Below 0.05 is the usual bar; smaller is stronger evidence.

TOGETHER

What to trust

Big change and small adjusted p-value = a solid hit. A big change with a weak p-value may just be noise.

Worth knowing: a volcano with almost nothing in the top corners can be a genuine "no change" — or a study with too few replicates to detect one. The statistics are honest; they won't invent a hit that isn't there.

Read the two numbers together — the result won't over-claim
