RealBio capability · protocol QC

Does this run pass quality control? A score, not a guess.

Given an experimental protocol and its outputs, the task is a verdict: PASS or FAIL against the right quality gates — an ADMET hERG safety threshold, a sequencing coverage floor, a model's extrapolation limit. It is hard because a correct call needs the domain threshold and judgment, not fluent text. Ask a language model to eyeball it, and it guesses. BioMate checks it against a codified gate.

A protocol + its outputs→ Measured value→ Compared to the domain threshold→ PASS / FAIL — defensible
BioMate doing it · measured vs threshold

Each gate shows two numbers, then halts, advises, or passes.

BioMate evaluates every quality gate as a comparison: the measured value against the codified threshold. A breach that matters halts the run; a soft miss raises an advisory; a clean metric passes. The logic is the same each time — so the verdict is reproducible, not a matter of opinion.

The takeaway

Codified, verifiable gates beat a model guessing PASS or FAIL.

Quality control is not a writing task — it is a comparison against a known threshold. BioMate encodes the domain gate once and applies it the same way every time, so the PASS/FAIL call is reproducible and defensible. A model asked to judge the same run has no fixed threshold to hold to — and the score shows it.
