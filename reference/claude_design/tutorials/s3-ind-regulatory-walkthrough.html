The problem this solves

Writing the nonclinical overview is slow, multi-region, and easy to get inconsistent.

The science is done; the bottleneck is the document. A nonclinical overview must summarise every study faithfully, in a rigid structure, for several regulators at once — and every number in the prose has to match the study it came from. Done by hand, it is weeks of careful transcription where a single stale value can sink a submission.

THE TASK

Evidence → document

Pharmacology, PK and toxicology findings must be re-told as a structured written summary, in the exact CTD order a reviewer expects.

THE PACE

Weeks of transcription

Hand-writing each section from study reports is slow, and it repeats for every amendment as the underlying data changes.

MANY REGIONS

One dossier, four agencies

F-D-A, E-M-A, N-M-P-A and P-M-D-A each have their own acceptance criteria and expectations — the same evidence, framed four ways.

THE RISK

Numbers drift from source

When prose is typed separately from the runs, a value can go stale. An overview whose figures no longer match the data is a finding waiting to happen.

The ideas you need first

Four ideas, and the rest of the document follows.

You don't need the full regulatory code — just these four concepts, in order.

1 · CTD MODULE 2.6

Nonclinical written summaries

The ICH M4 Common Technical Document organises a submission into modules. Module 2.6 holds the nonclinical written and tabulated summaries — the structured retelling of the studies.

2 · §2.6.1

The Nonclinical Overview

The flagship section: §2.6.1 Pharmacology. Its subsections run §2.6.1.1 brief summary, §2.6.1.2 primary pharmacodynamics, §2.6.1.3 safety pharmacology, and §2.6.1.4 through §2.6.1.6.

3 · FOUR REGIONS

Region-specific criteria

F-D-A, E-M-A, N-M-P-A, P-M-D-A. Each carries its own acceptance thresholds — e.g. the E-M-A PBPK within-2-fold expectation — plus an ethnic-bridging note for N-M-P-A and P-M-D-A.

4 · GROUNDED

Integrates the run outputs

The narrative is not free-written. It integrates the campaign's ADMET, PBPK and lead-selection run outputs — each statement traces back to a real result.

The whole method is: take the campaign's finished runs, assemble the CTD §2.6.1 structure, and write each subsection as a narrative grounded in the real run data — framed for the target region.

The audit gate · a machine consistency check

A built-in auditor grades findings — and a CRITICAL one blocks downstream actions.

Before the draft moves on, a regulatory auditor runs over it, grading findings by severity. A CRITICAL or failed-qualification finding halts downstream actions — CRO export, IND assembly — until it is resolved, so a known defect cannot slip through unnoticed.

SEVERITY LADDER

CRITICAL · MAJOR · MINOR · INFO

Findings are graded on four levels. CRITICAL and MAJOR demand action; MINOR and INFO are advisory. A CRITICAL or failed-qualification finding blocks CRO export and IND assembly until resolved.

WORKED EXAMPLE

PBPK fails within-2-fold

If a PBPK model fails the E-M-A Cmax within-2-fold criterion, the auditor inserts a §2.6.2 model-limitation statement and halts — the limitation is stated in the document, not hidden.

  • Region-specific thresholds. The E-M-A within-2-fold expectation is per CHMP/EWP/37498/2011; N-M-P-A and P-M-D-A add the ethnic-bridging note. The gate is checked against the region you chose.
  • A gate, not a rewrite. When a criterion is not met, the document states the limitation and the gate halts — it never quietly passes a failed check.
Severity-graded findings, with a hard stop on CRITICAL — the limitation stated, not buried
What you get, precisely

A draft for human regulatory review — not an approval, and never submitted unchecked.

The feature is powerful, and being exact about its scope is what makes it trustworthy. Every section it produces is a draft, and the audit is a consistency check — not a regulatory sign-off. BioMate states this plainly, and so do we.

A DRAFT, NOT A FILING

Human review required

Every generated section is a BioMate-generated draft that must not be submitted without human regulatory-affairs review and a 21 C-F-R Part 11 electronic signature. The tool assembles; a qualified person decides.

A CHECK, NOT A GUARANTEE

Machine consistency only

The automated audit is a machine consistency check — it is not a regulatory approval or guarantee. Clearing the gate means the document is internally consistent, not that an agency will accept it.

STATED, NOT HIDDEN

Limitations in the open

Where a criterion is not met — a PBPK model outside within-2-fold, a missing qualification — the document states the limitation rather than hiding it, and the downstream action halts until it is addressed.

Honest about scope — an assembly aid behind human sign-off, not a self-certifying submission
