How BioMate gets smarter — the cycle behind every round

Real lab results teach BioMate to design better molecules each round.

A model is the part that makes predictions — "how strongly will this bind?", "is this likely to be toxic?" — instead of running a slow lab experiment every time. The Models area keeps these reusable predictors and is the home of the closed loop: the cycle that feeds your real laboratory results back in, so the next round of designs is better.

Why models matter · trust, and staying current Concept

A prediction is only useful if you know how far to trust it.

Relying on predictions instead of experiments raises two problems. BioMate's Models area is built to address both — by treating every model as an inspectable object, and by feeding your real results back in.

1 · TRUST

How good, and where?

A model never tested may give wrong answers with high apparent confidence — the risk is worse the further your molecule is from what it learned from.

2 · STAYING CURRENT

Your results are the truth

A model that never updates with your new measurements slowly drifts away from reality. The loop keeps it current.

Your measurements stay private to your workspace and are never used to train shared models. Today the loop learns from laboratory (bench) measurements; using patient-derived or clinical readouts to guide it is a direction BioMate is building toward, not a current feature.

Background — predictions replace experiments only when you can trust them
The idea · a model is reusable learned expertise Concept

Learned once, reused everywhere — a prediction instead of an experiment.

A model takes an input (a molecule, a protein sequence) and returns a prediction (a score, a 3-D structure). Some are pre-trained by the research community on large public datasets; others are custom, trained on your data to score your kind of molecule.

ALPHAFOLD2 / OPENFOLD2

Protein 3-D shape

Predict a protein's structure from its sequence.

BOLTZ-2

Shapes + fit

Protein structures, and how a protein and a small molecule fit together.

EVO2

Genome sequences

A model of DNA / genome sequences.

INFERENCE

Use, don't change

Making a prediction with an already-trained model, without training anything of yours.

All four pre-trained models are open and community-built; BioMate hosts them so you can use them directly. A custom model is one you train on your own data.

BioMate's guiding idea · a model is an object, not a scoreboard Concept

Shown as documented facts — and judged against a floor, not a rank.

Instead of ranking models on a scoreboard (which tempts people to game it), BioMate shows each model like a documented object you can inspect before you trust it.

EVIDENCE

How it did — vs a floor

A measured score against a required quality floor, on a held-out test — data it was not trained on, so the score can't be inflated by memorising.

LINEAGE

What produced it

The data and the run that built this model.

USED BY

What depends on it

Which analyses rely on it — so you can see the effect of changing it.

VERSIONS

Nothing overwritten

Every version is kept, not replaced.

Clearing the bar by more earns no higher rank — there is no scoreboard to climb. And a model not yet measured reads "not evaluated", never a made-up score.

A floor, not a ranking — "not evaluated" is honest, never a hidden number
Passing the floor isn't the whole story · the applicability domain Concept

Trust for your molecule depends on what the model has seen.

A good floor score means the model is accurate on test data similar to what it learned from. Whether you can trust it for your specific molecule also depends on the applicability domain — the kind of inputs it learned from.

IN DOMAIN

Close to training data

Ask about the kind of molecule the model learned from, and its prediction is on firm ground.

OUT OF DOMAIN

Low confidence — treat as unproven

Ask a kinase-inhibitor model about a peptide and it should lower its confidence, not pretend to know. Treating an out-of-domain prediction as reliable is a common cause of wet-lab experiments that were never going to work.

Like using a drug off-label: a low-confidence prediction means your input is unlike the model's training data — outside what it was tested for.

Out-of-domain → low confidence, not false certainty

Reading a model · the object view Live UILive capture on dev

Open a model and read what you'd be trusting.

Opening a model shows it as an object: Evidence (the quality floor — measured score, required floor, verdict), Lineage, Used by, and Versions. Here Evidence reads "not evaluated" — which honestly means this layer has not measured it, not that a number is hidden. The on-screen note says it plainly: a floor, not a ranking.

Make a prediction now · Run a model (inference) Live UILive capture on dev

Pick a domain, paste an input, and run it — no training.

To make a prediction now, use Run a model: pick a domain (Structure, Genomic, or Chemical), paste an input — for Structure, a protein's one-letter sequence — and run. This is inference: the model isn't changed.

Inference — livestub placeholder possible — check the label, never trust it as a real result
The closed loop · the Rounds view, and how it works Live UILive capture on dev

Design → make → test → learn — monitored as rounds.

The Rounds view is the home of the closed loop. Here it is before any loop has run: it explains what will appear and states the loop's honesty rules — every proposal is accounted for, limit values stay as limits (">30 µM" is never silently replaced by 30), and rejected candidates stay visible with their reason. Once a design–make–test loop runs in a campaign, the rounds fill in here. Each turn is a round, and the model is retrained on the combined data, then re-checked on data it was not trained on — so you see it keeping up, not a single score to climb.

The habit at a glance

Inspect the model → trust within its domain → close the loop.

Models is where BioMate keeps its reusable predictors and learns from your real results. Open a model as an object and read its evidence before trusting it; respect the applicability domain; run a pre-trained model for a quick prediction; and let the closed loop turn each round of real lab data into a better next round. The benefit compounds — three or four rounds beat designing once.
