BioMate 教程 训练自定义模型
献给手握一张电子表格和一个问题的科学家

你有一张带标签的表。BioMate 在上面训练一个模型。

你在一张电子表格里有一堆测量值，还有一列是你想预测的——有活性还是没有、一个浓度、一个产率。通常，这意味着得去找一个会写机器学习代码的人。而在 BioMate 里，你描述目标、上传那张表；它就在你的数据上运行标准的 Python 机器学习——scikit-learn，以及任务需要时的梯度提升库或深度学习库——然后交回一个训练好的模型，附带诚实的、留出的性能。

一份带标签的 CSV→ 描述那个预测→ BioMate 运行 ML 代码→ 一个模型 + 留出指标→ 是什么在驱动它
这个功能要解决的问题

你有一份 CSV 和一个问题——却没人来写这个模型。

"我能不能从其余各列预测这一列？"是实验室里最常见的问题之一，也是没有一个专职分析师就最难动手的问题之一。缺口不在想法上，而在那些管道活上：载入表、正确地切分、挑一个模型、交叉验证、在它从没见过的数据上打分，再读出哪些特征要紧——而这每一步，都是很容易在不知不觉中写错的代码。

这张表

行与列

每一行是一个样本；大多数列是测量值，有一列是你想预测的那个答案。

这门手艺

没有 ML 工程师

训练/测试切分、交叉验证、对的指标——做起来容易，没有懂行的人也容易做错。

这个陷阱

自欺欺人

在你用来训练它的同一批数据上打分，任何模型看起来都光彩夺目。诚实的数字，需要模型从没见过的数据。

所求

一个站得住脚的答案

不只是一个数字——一个你敢信的模型，带着你能拿给审稿人看的性能与驱动因素。

所需：把一张带标签的表变成一个经过诚实评估的模型——而不用写代码
开始前要懂的几个概念

四个大白话词，就能说清整个任务。

你不需要懂那些库——只需要这四个，其余的一切都顺理成章。

1 · 特征与标签

输入与答案

特征是你测量的那些列；标签是你想预测的那一列。模型学的就是两者之间的联系。

2 · 训练 / 测试切分

先学，再查

留出一部分数据。模型在一部分上学习，再在它从没见过的那一部分上打分——那才是唯一诚实的检验。

3 · 模型族

哪一种模型

一个随机森林、梯度提升，或一个小型神经网络。答案是一个类别就做分类；是一个数值就做回归。

4 · 指标

它有多好

类别用 accuracy 或 AUC；数值用 RMSE 或 R²。一个你报得出口的清晰分数。

整个任务，就是把 特征 + 标签 → 切分 → 模型 → 指标，从一个编码项目，变成一个被描述出来的目标和一个上传的文件。

背景——本讲后续会用到的词汇
它是怎么跑的 · 描述 + 上传 → 运行

你描述那个预测；BioMate 替你运行 ML 代码。

这不是一条带着固定按钮的固定流水线。它是 BioMate 的 run_code 路径：你说出想预测什么、附上你的表，BioMate 就在一个沙箱化的后端里为它写出并执行标准的 Python 机器学习代码——然后报告它找到了什么。那条用来过滤一个文件、或跑一次统计检验的同一条路径，在这里就用来训练并评估一个模型。

"从其余各列预测 Y 列"→ 上传你的 CSV→ run_code: scikit-learn / XGBoost / PyTorch→ 模型 + 指标 + 图

后端预装了标准的科学 Python 库——pandas、NumPy、scikit-learn、statsmodels——并在相应的环境里运行更重的梯度提升库或深度学习库。

一个被描述出来的目标，作为真实的 Python 执行——不是黑箱，也不是模拟
输入 · 一张带标签的表

你要带来的：一份带特征列和一个目标列的 CSV。

你唯一需要准备的，是一张干净的表。每一行是一个样本；特征列装着那些测量值；有一列装着你想预测的那个值。你说清哪一列是目标、你想要一个类别还是一个数值——其余的 BioMate 来办。

行 = 样本

一行一个例子

化合物、病人、批次、细胞——你测的无论是什么。行越多，模型就越可信。

列 = 特征

那些测量值

数值或类别：实验读数、描述符、条件。这些是模型从中学习的输入。

一个目标

答案列

一个类别标签（有活性 / 无活性，有毒 / 安全）用于分类，或一个数值（IC50、产率）用于回归。

文件为这次运行私密地暂存；BioMate 用 pandas 读入它，并在训练之前先报告形状、各列类型，以及任何缺失值。

只要你能导出一张带标签的电子表格，你就能训练一个模型
步骤 · 切分、交叉验证、拟合

它切分数据、交叉验证，再拟合模型。

表一载入，BioMate 就自动把那些讲规矩的部分做掉。它留出一个测试集，在其余的上面训练，并在训练数据上用交叉验证来衡量稳定性，而不是指望某一次运气好的切分。一个标准模型——对大多数表格数据用随机森林或梯度提升树，在合适的地方用一个小型神经网络——只在训练那一部分上拟合。

留出切分

把测试集留在一旁

一部分行一开始就被单独留出、永不用于训练——纯粹留着给成品模型打分。

交叉验证

分折，别赌运气

训练数据被切成若干折、反复打分，于是性能反映的是数据本身，而不是某一次运气好的洗牌。

拟合

学会那个模式

选定的模型在训练那些行上拟合——学会特征如何映射到标签。

对于一张小的或不平衡的表，分层折和简单的类别平衡让切分保持代表性——恰恰是那种手工做时容易忘掉的细节。

方法学是内建的——在一部分上训练，在另一部分上评判
步骤 · 在它从没见过的数据上打分

你得到的数字，是在留出集上测得的。

这才是真正要紧的那个数字，而且它报得诚实——在模型从没训练过的那些测试行上，而不是在它背下来的那批数据上。对一个类别，你得到 accuracy 和 AUC，连同一个混淆矩阵；对一个数值，你得到 RMSE、MAE 和 R²。训练分数和留出分数之间的差距会被摆出来，而不是藏起来，因为它是过拟合最清楚的信号。

分类

Accuracy · AUC

它判对的频率，以及它把正例排在负例之上的本事——外加一个记录错误的混淆矩阵。

回归

RMSE · MAE · R²

以目标自身单位计的典型预测误差，以及模型解释了多少变异。

差距

训练对留出

并排摆出。差距大，意味着模型是背下来而非学会了——诚实的数字胜过好看的数字。

一个在训练上得分高、却在留出集上得分差的模型，会被明明白白地告诉你——这正是把那个测试集单独留在一旁的全部意义。

性能报告在要紧之处——在未见过的数据上
步骤 · 是什么在驱动这个预测

它展示模型实际倚重哪些特征。

单有一个分数，仍然是一个黑箱。BioMate 还会报告特征重要性——模型最倚重哪些测量值——于是这个结果变成一个你能从科学上讲清所以然的东西。真正的洞见往往就藏在那里：模型印证了一个已知的驱动因素，或标出一个你原本没怎么看重的。

训练好的模型→ 给特征排序→ 头部驱动因素，带一张图→ 一个你能讲清的结果

重要性是对模型用了什么的一个指引，而不是生物学因果的证据——一个靠前的排名是一个待检验的假设，而不是一个被确认的机制。把它当作方向来读，再到实验室里去验证它。

不只是它预测得多好——还有它是从什么在预测
得到一个可信的模型 · 最佳实践

三个让这个数字可信的习惯。

一个训练好的模型，用得好就真有用处。下面三个习惯能让你把它用到最好——因为一个模型始终是一个由你给它的数据所塑造的估计，懂得这一点，正是你出于正确的理由去信那个数字的方式。

先把数据备好

质量决定结果

质量与数量决定一切。表越干净、越大，模型就越能泛化——所以先在数据上下功夫。

小数据要交叉验证

分折，别赌运气

行数一少，单独一次切分就可能把你带偏。交叉验证在若干折上打分，让数字反映数据本身，而不是一次运气好的洗牌。

依赖前先验证

先确认，再信任

把留出分数当作一个估计来读，在新鲜数据上确认之后再动手——那个数字正是这样赢得你的信任的。

一个模型是从你的数据得来的一个估计——在你依赖它之前先验证它
一眼看懂它的价值
