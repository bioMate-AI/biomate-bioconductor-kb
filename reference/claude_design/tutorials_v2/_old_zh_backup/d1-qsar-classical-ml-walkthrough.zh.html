QSAR — 从分子结构预测活性与毒性

仅凭结构，就预测一个分子会做什么——在你动手合成它之前。

QSAR——定量构效关系——把一个分子的化学结构变成一个预测出来的数字：它击中靶点的强度有多大，或者它有多大可能产生毒性。这一集讲的是实现这件事的经典机器学习方法——建立在分子指纹之上的随机森林——并展示 BioMate 如何在两个真实的、托管的工作流上运行它。

内容扎根于今天就在运行的两个工作流：Qsar Rf Model（随机森林活性预测）与 herg_cardiac_safety_qsar（心脏毒性筛查）。这里提到的每一个参数、每一项输出、每一道质量门，都是从这两个工作流里读出来的，而非编造。深度学习 ADMET 是它的姊妹集 D2。

结构（SMILES）→ 描述符 / 指纹→ 随机森林→ 预测的活性 · 毒性→ 适用域检查
理念 · 这件事要解决什么——QSAR 为何存在 概念

结构相似的分子，行为也往往相似——所以结构应当能预测活性。

整个领域就建立在这一个假设之上。如果两个分子在化学上看起来相像，它们通常结合方式相近、代谢途径也相近。QSAR 把这件事量化了：从你已经测量过的分子出发，学出一个把结构 → 一个数字映射起来的函数——比如 pIC50 这样的活性，或 hERG IC50 这样的毒性——再把它用到你只是在屏幕上画出来的分子上。

输入

一个结构，什么都还没合成

一个以 SMILES 文本写出来的分子。还没有样品，没有检测，也没有花费实验时间。

输出

一个预测出来的数字

活性方面是效力（pIC50），毒性方面是 IC50 或一个风险等级——并带着一条可信度提醒。

为什么重要

在合成之前先分流

几分钟内给成千上万个候选物打分，留下有希望的，让其余的以极低成本被淘汰。

QSAR 是一道筛子，而非一纸判决。它对下一步该做什么、测什么进行排序和分流——却永远不会取代湿实验检测。它的价值，在于更早地做出正确的分子。

理念 · 把分子变成数字——特征与适用域 概念

模型读不懂一个分子——所以你得先把它变成特征。

机器学习模型需要的是数字，而不是一张化学结构图。主导的特征有两大类：人能看懂的描述符，以及子结构指纹。而无论你选哪种，模型只有在它的适用域之内才值得信赖——也就是训练集真正覆盖到的那片化学空间。

描述符

可解释的理化性质

分子量、logP、氢键供体/受体、环数、可旋转键。一个简短而有含义的向量——herg_cardiac_safety_qsar 模型正是建立在这些之上。

指纹

子结构是否存在

Morgan / ECFP 指纹：每一位都标记某个环状子结构（半径 2）是否存在。Qsar Rf Model 用的是 1024 位 Morgan 指纹——高维而稀疏。

适用域

它可被信赖的范围

对一个与训练集任何东西都不像的分子做预测，就是外推——无论那个数字看起来多有把握，都要谨慎对待。

描述符数量少、能解释为什么；指纹数量多、能刻画细微结构。两者单独都算不上"最先进"——正确的选择取决于数据和问题本身。

理念 · 深入经典机器学习——随机森林 概念

许多各不相同的浅层决策树，平均成一个稳定的预测。

单独一棵决策树用"是/否"的问题切分特征空间，直到给出一个预测——但一棵树会过拟合。随机森林生长出成百上千棵树，每棵树都在化合物的一个自助重采样、以及特征的一个随机子集上训练，再把它们的答案取平均。树与树之间的分歧相互抵消，而信号得以保留。

任务 把指纹 → 活性· 难在哪 高维、稀疏、非线性· 经典做法 随机森林开箱即用

随机森林为何契合 QSAR 指纹

  • 能处理 1024 个稀疏二值位，无需特征缩放或特征选择。
  • 能捕捉非线性的构效关系——这是线性模型会错过的。
  • 通过 bagging 抵抗过拟合——哪怕只有几十个化合物也依然稳健。
  • 几乎不用调参：真实工作流用 200 棵树和一个固定种子，就跑得很好。
理念 · 训练、验证并读懂模型 概念

一个没经过验证的模型，只是一个充满希望的猜测。

训练很容易；判断该不该相信结果，才是真正的工作。标准做法是 k 折交叉验证：把化合物分成 k 份，用 k−1 份训练、在留出的那一份上测试，轮换，再取平均。真实的 Qsar Rf Model 用 5 折，并报告 CV R² 与 CV RMSE——在模型从未训练过的数据上，预测贴合实际的程度。

如何读这些数字

  • CV R² 接近 1 = 预测贴合实际；真实的 QC 门会在低于 0.5 时阻断（Golbraikh & Tropsha 2002）。
  • CV RMSE 是以目标自身单位计的典型误差——要和 R² 并排着看。
  • 特征重要性对哪些子结构在驱动预测做排序——这是随机森林免费附赠的可解释性。
  • 小样本会虚高 CV：低于 50 个化合物时，工作流会发出一条 BRONZE 提醒。
理念 · 经典 RF 与深度学习 ADMET——各自何时取胜 概念

随机森林往往就是正确答案——只有当数据和需求都值得时，才去用图网络。

深度学习并不天然更好。在多数项目真正拥有的那种小规模、表格式、指纹形状的数据集上，随机森林更快、可解释、可复现，而且常常一样准。只有当你拥有大量标签、并希望模型自己去学习表示时，图神经网络才值回它的成本。

随机森林（本集）

在这些情形下选它……

  • 数据量属中小规模——几十到几千个测量过的化合物。
  • 特征是表格式 / 指纹，且本身已有信息量。
  • 你需要可解释性——特征重要性，一份站得住脚的记录。
  • 速度与可复现性要紧——在 CPU 上几分钟跑完，带固定种子。

图神经网络（D2 集）

在这些情形下选它……

  • 带标签的数据量很大——数千乃至更多。
  • 分子图才是合适的表示，固定指纹会丢失信号。
  • 你能端到端地学习特征，并利用预训练 / 迁移。
  • 额外算力可以接受，以换取可能的精度提升。

用大白话描述任务；BioMate 把它路由到正确的 QSAR 工作流，并托管运行。

你不用安装 RDKit 或 scikit-learn。你描述要做的分析，核对它摆出来的参数，它就在托管算力上运行。两个真实的工作流覆盖了 QSAR 的活性与毒性两面。

活性 · Qsar Rf Model

指纹上的随机森林

输入：一个带 smiles 列和目标列（默认 pIC50）的 CSV。参数：5 折 CV、200 棵树、Morgan r2 / 1024 位、固定种子。至少需要 10 个化合物。

毒性 · herg_cardiac_safety_qsar

用于心脏风险的描述符 QSAR

输入：一组 SMILES，外加可选的实测 hERG IC50、剂量（mg）与游离分数。一个建立在 MW / logP / pKa / 阳离子密度之上的理化模型（Aronov 2005；Sanguinetti 2006）。

两者都是经典 QSAR：一个从你测量的活性里学出随机森林；另一个套用一个已发表的理化模型，再加上 Nav1.5 结构警示。无需写代码，也无需购买软件授权。

在 BioMate 里 · 读懂输出——以及质量门 产品

直接从运行中读出的真实数字——配上一道绝不悄悄放过弱模型的门。

每一次运行都会写出结构化的输出，供你直接阅读。对于活性，在你信任它之前，模型经交叉验证的质量会对照一个已发表的阈值被检查；对于毒性，输出是一个风险等级和一个安全窗，而有意不给出单一的精确 IC50。

每一次运行返回什么

  • Qsar Rf Model → qsar_results.json：cv_r2_score、cv_rmse、n_compounds、featurizer，外加一份便于阅读的 qsar_model_report.txt。
  • herg_cardiac_safety_qsar → herg_risk.json：hERG IC50、安全窗、ICH E14 风险等级（HIGH/MEDIUM/LOW/MINIMAL），以及一份列出结构警示的 nav15_alerts.csv。
质量门——要读，绝不悄悄放过

理念 · 有把握地读一个 QSAR · 适用域 概念

一个 QSAR 的好坏，取决于它的数据与特征——而读好它，意味着在它的适用域之内去读。

经典 QSAR 之所以有力，正因为它简单、可解释、可检验。读好它只需记住一点：始终在它的适用域之内去读每一个预测。

1 · 适用域

适用性

对与训练集不同的化学空间做预测就是外推——无论它看起来多有把握，都不可靠。

2 · 特征

描述符的选择

换一套指纹或描述符，模型就会变。并不存在一个放之四海而皆准的最佳选择。

3 · 小样本

过拟合风险

化合物很少时，连交叉验证都可能显得乐观。一个外部测试集才是真正的检验。

4 · 模型

hERG 只是一个代理

心脏模型是一个理化 QSAR，带着约 1 个对数单位的误差——它给的是风险等级，而非实测的 IC50。

5 · 可溯源

核实特征化方式

如果缺了 RDKit，随机森林会退回到模拟特征——featurizer 字段会说明用的是哪一种，所以要核实它读出的是 morgan_fp_r2_1024。

纪律每次都一样：先验证再信任，读懂适用域，并把预测当作一道把正确的分子送去检测的筛子——而永远不要拿它替代检测本身。

QSAR 一览

结构 → 特征化 → 随机森林 → 交叉验证 → 带着它的提醒来读。

经典机器学习把一个结构变成一个站得住脚的预测：用建立在分子指纹上的随机森林做活性，用理化描述符模型做心脏毒性，两者都经过交叉验证、都设了门。它是那个可解释、数据高效的默认选择。当你的数据和问题不断成长时，D2 集会把同一件任务交给图神经网络。

  1. 1带来测量过的化合物——SMILES 配上一个目标值
  2. 2特征化——描述符或 Morgan 指纹
  3. 3随机森林，5 折交叉验证
  4. 4在适用域之内，读 R² / RMSE 和风险等级

这两个工作流交付什么

  • 一个经交叉验证的活性模型——来自 Qsar Rf Model 的 CV R² 与 RMSE。
  • 一份心脏安全性读数——hERG 风险等级、安全窗、Nav1.5 警示。
  • 一道质量门，拦下弱模型，而不是悄悄放过它。
  • 一份可解释、可复现的记录——特征重要性和一个固定种子。

一道筛子，而非一纸判决。它的价值在于更早地做出正确的分子——而不在于省掉实验室这一步。
