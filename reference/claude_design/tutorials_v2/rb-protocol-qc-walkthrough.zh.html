这次运行通得过质控吗？是一个分数，而不是一次猜测。

给定一份实验方案及其产出，任务就是给出一个结论：对照正确的质量门，判定它通过还是没通过——一条 ADMET hERG 安全上限、一个最低测序覆盖深度、一个模型被允许外推的限度。它之所以难，是因为判得对靠的是领域阈值和判断，而不是一段通顺的文字。让一个语言模型扫一眼，它只能靠猜。BioMate 则拿它去对照一条编码化的质量门来检查。

一份方案及其产出→ 实测值→ 对照领域阈值→ PASS / FAIL——站得住脚
BioMate 的做法 · 实测值对比阈值

每道门展示两个数字，然后中止、提醒或放行。

BioMate 把每一道质量门都当作一次比较来评估：实测值对比编码化的阈值。要紧的越界会中止运行；轻微的未达标给出一条提醒；指标干净则放行。每次的逻辑都一样——所以这个结论是可复现的，而不是一家之见。

要点

编码化、可验证的质量门，胜过模型去猜 PASS 还是 FAIL。

质控不是一项写作任务——它是一次对照已知阈值的比较。BioMate 把领域质量门编码一次，并在每次运行中都以同样的方式应用，于是这个 PASS/FAIL 的结论是可复现、站得住脚的。而让一个模型来判同一次运行，它没有一条固定的阈值来约束自己——分数也说明了这一点。
