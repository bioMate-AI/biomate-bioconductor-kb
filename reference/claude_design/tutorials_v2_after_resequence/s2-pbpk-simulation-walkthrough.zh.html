1 · 概念 · 任务——一条浓度-时间曲线 概念

药代动力学，就是身体随时间对药物做了什么。

一条曲线——上升、达峰、下降——承载着每一个给药决策所依赖的数字。

Cmax · Tmax
峰值
药物升到多高，以及何时达到。
AUC
总暴露量
曲线随时间下的面积。
t½
半衰期
身体清除它有多快。
2 · 概念 · 现状——PBPK 为什么难 概念

难的是输入和方程——而不是画那条曲线。

耦合的微分方程，每个器官一个——好坏全看你喂给它的输入。

风险

3 · 概念 · 基线——非房室分析（NCA） 概念

如果你已经测到了浓度，就不需要模型。

NCA 直接从观测数据上读出数字；PBPK 则预测你没有数据的地方。

NCA
归纳你已有的数据
AUC、Cmax、t½ 直接从观测曲线读出——无需模型。
PBPK
向前预测
一个新剂量、一个儿童、一个肾功能受损的病人——无需数据。
4 · 概念 · 机理式 PBPK——器官房室即 ODE 概念

把身体建模成相连的房室，每个器官一个方程。

肠道、肝脏、肺、肾脏和血浆——血流把它们连起来，一个 ODE 系统一并求解。

5 · 概念 · 特殊人群——选择机理方式的真正理由 概念

改变生理学，再跑同一组方程。

一个儿童、一次妊娠、一个受损的器官，不是新模型——只是不同的生理参数。

扎根于监管指南——给出剂量调整比值和标签草稿文本，由药理学家审阅，绝不自动提交。
