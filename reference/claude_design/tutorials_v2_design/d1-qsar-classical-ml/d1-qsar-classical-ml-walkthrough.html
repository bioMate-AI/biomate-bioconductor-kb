Idea · Classical ML in depth — the random forest Concept

Many shallow trees, each a little different, averaged into one stable prediction.

Hundreds of trees on resampled data; their disagreement cancels, the signal survives.

Idea · Classical RF vs deep-learning ADMET — when each wins Concept

A random forest is often the right answer — reach for a graph network only when it is earned.

Deep learning is not automatically better; on small, fingerprint-shaped data the forest wins.

Random forest (this episode)

Choose it when…

  • Small-to-medium data — tens to a few thousand compounds.
  • Tabular / fingerprint features, already informative.
  • You need interpretability — and minutes on CPU.

Graph neural network (deep learning)

Choose it when…

  • Labelled data is large — many thousands or more.
  • The graph is the right representation, not fixed bits.
  • Learn features end to end — extra compute acceptable.
