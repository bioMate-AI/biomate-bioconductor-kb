QSAR — 从分子结构预测活性与毒性

仅凭结构，就预测一个分子会做什么——在你动手合成它之前。

把化学结构变成一个预测出来的数字——它结合得有多强，有多大可能有毒。

结构（SMILES）→ 指纹→ 随机森林→ 活性 · 毒性→ 适用域检查
理念 · 这件事要解决什么——QSAR 为何存在 概念

结构相似的分子，行为也往往相似——所以结构能预测一个数字。

从测量过的分子里学出一个函数，把结构直接映射成一个预测。

理念 · 经典 RF 与深度学习 ADMET——各自何时取胜 概念

随机森林往往就是正确答案——只有当确实值得时，才动用图网络。

深度学习并不天然更好；在小规模、指纹形状的数据上，随机森林更胜一筹。

随机森林（本集）

在这些情形下选它……

  • 数据量属中小规模——几十到几千个化合物。
  • 特征是表格式 / 指纹，本身已有信息量。
  • 你需要可解释性——且只需 CPU 上几分钟。

图神经网络（深度学习）

在这些情形下选它……

  • 带标签的数据量很大——数千乃至更多。
  • 分子图才是合适的表示，而非固定的位。
  • 端到端学习特征——额外算力可以接受。
