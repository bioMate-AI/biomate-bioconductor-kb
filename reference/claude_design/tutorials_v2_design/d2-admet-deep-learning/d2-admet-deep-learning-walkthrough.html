Idea · 5 · Classical vs deep — when each wins Concept

Not "deep is always better" — two tools with different trade-offs.

The graph net wins on diverse chemistry; the forest wins on speed and tiny data.

Classical · QSAR + forest
Fixed features — fast and interpretable, but blind to unencoded signal; weak on new scaffolds.
Deep · Chemprop graph net
Learned features — 15 endpoints at once, best across diverse chemistry. BioMate's default.
Both are estimators of experimental values — both need wet-lab confirmation before any decision that matters.
