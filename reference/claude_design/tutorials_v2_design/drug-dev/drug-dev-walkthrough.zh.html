概念 · 为什么新药研发是一个循环，而不是一条直线 概念

一次走完永远产不出一款药——方法是一个会累积收益的循环。

每一轮都从上一轮学到东西——设计、合成、测试、学习——于是每转一圈，错误都更便宜。

让这个循环值得信赖的两项功能：质控闸门（阶段五）和可复现记录（阶段七）。
阶段一 · 概念 · 明确目标 概念

在任何分子出现之前，先写下靶点、目标和约束条件。

后面每个阶段都会继承这些选择——目标含糊，候选清单也含糊。

靶点
一个蛋白，例如 JAK1
你要作用的对象——是一个蛋白，而不是一个分子。
目标
结合 · 吸收 · 安全
强效、可口服吸收、对心脏安全（hERG）。
约束条件
新颖 · 可合成
保持新颖；保持可合成。
这些目标会变成阶段四里用来比较的那些列；hERG 上限会变成阶段五的质控闸门。

阶段七 · 概念 · 血缘与溯源是什么——以及为什么重要 概念

一个结果有多好，取决于你能不能证明它是怎么来的。

溯源，就是从一个输出回溯到它那组确切输入、参数和软件的链条。

每一次运行都记下运行 ID、版本、SHA-256 与引用——一键导出 JSON。输出读不出 → 该条结论被保留而不显示，绝不编造。
