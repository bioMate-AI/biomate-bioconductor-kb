The task · param_prefill

A sentence of science. Dozens of parameters — every one exactly right.

A scientist writes one request: "RNA-seq differential expression, human GRCh38, dUTP strand-specific, treated vs control, FDR 0.05." The job is to fill the workflow's parameters correctly — convert units, honor negations, set boolean flags, and normalize the aliases a schema actually accepts. This is exactly where a raw language model is least reliable: arithmetic unit conversions, deterministic boolean mapping, and schema-constrained enums.

"human" → genome = GRCh38→ "dUTP" → strandedness = reverse→ "FDR 0.05" → padj_threshold = 0.05→ one wrong field = a wrong run
BioMate doing it · hybrid rule + LLM, then validated

Rules do the exact work. The model does only the free-text work.

BioMate extracts parameters with deterministic rules first and the language model as a fallback — then validates every value against the workflow's schema.

RULES — EXACT

Conversions, negations, aliases

Unit conversions (ns → n_steps, fs → dt), negations ("remove adapters" → keep=false), boolean flags ("single-end" → single_end=true), canonical aliases ("human" → GRCh38, "dUTP" → reverse).

LLM — FREE TEXT

The genuinely open fields

Free-text values a rule can't enumerate — SMILES strings, PDB IDs, gene names — and ambiguous enum or multi-parameter inference from prose.

GUARDRAIL — VALIDATE

Checked against the schema

Every extracted value is validated against the workflow's allowed_values; anything that violates a constraint is dropped or normalized before the run.

Rules are exact, zero-cost and testable; the model is reserved for the parts that are genuinely open-ended. Concept view — not a product screenshot.

The takeaway

The rules make extraction exact. The model only fills in the free text.

Unit conversions, negations, boolean flags and canonical aliases are handled by rules that are exact, zero-cost and testable — so they don't drift run to run. The language model is reserved for the genuinely free-text fields a rule can't enumerate, and a schema guardrail checks everything before it runs. That is why BioMate reaches 0.848 where a model asked directly stays at 0.62–0.76.
