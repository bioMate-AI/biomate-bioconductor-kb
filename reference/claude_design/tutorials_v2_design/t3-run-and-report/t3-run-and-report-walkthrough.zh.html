教程 3 · 运行工作流并读懂报告 第 0 / 8
日常的中间环节——先跑起来，再读结果

运行一条经过测试的流水线，读一份你拿得出依据的报告。

工作流就是一整套多步骤的分析，已经替你测试并连接好。你用自然语言说清楚目标、附上数据，BioMate 就在云端把这条流水线跑完，再交回一份报告——结果、每一个输出文件，以及一份完整的生成过程记录。

贯穿示例：对三个分子——阿司匹林、咖啡因、布洛芬——运行预测 ADMET 性质（AI），一次真实、已完成的运行。我们会看着它从配置、到实时进度、再到那份报告：一个合并的 结果（Results） 标签页——发现摘要，下方逐个预览每个输出文件——以及 可复现记录（Reproducibility record） 标签页。

确认并运行→ 看实时阶段→ 结果·发现→ 结果·输出→ 可复现记录
开始前要懂的几个概念

五个词，就能让整份报告读得懂。

你不用去拼装工具——你运行一条现成的流水线，再读取返回的结果。这五个概念，就是你需要的全部。

1 · 工作流

流水线

一套现成、经过测试的多步骤分析。你直接运行，而不用自己搭建。

2 · 阶段／步骤

各个阶段

大的阶段，每个由一个个具体的工具步骤组成。每一步接收输入、产出输出。

3 · 参数

各项设置

运行所用的设置——带着合理的默认值，在任何东西开跑之前先展示。

4 · 质控闸门

护栏

运行途中的一次自动检查。它绝不会悄悄放过一个没通过的结果。

5 · 运行后报告

结果

两个标签页：合并的 结果（Results） 视图（发现 + 每个输出）以及可复现记录。

"测试过／经过验证"是指每一步用的都是已发表、成熟的方法——不代表结果在临床上已被证明。工作流是计算层面的早期筛查，不是成品答案。

背景——每一次运行共享的词汇表
第一步 · 配置并确认运行

在任何算力被花掉之前——看清将要发生什么。

你用自然语言提出了 ADMET 的需求；BioMate 挑中了那个经过验证的工作流，并打开了它的面板。现在核对右侧的配置，再点下"确认并运行"。

  • 输入已映射。这次运行只需要参数——没有数据文件要对接。换成别的工作流，你会在这里附上 FASTQ、CSV、FASTA 或 SMILES 文件。
  • 必填参数，已填好。你的分子列表（阿司匹林、咖啡因、布洛芬）和预测模型都已展示出来，并可编辑。
  • 输出与权限。结果存放在哪里（由 BioMate 托管，90 天），以及你就是能运行它的 Owner（所有者）。
  • 这是你事先核对或修改一切的机会。然后确认并运行。
在你确认之前，什么都不会运行
第二步 · 看着它运行——阶段与质控闸门

实时进度，以及一目了然的质控闸门。

在 Phases（阶段）标签页里，每个步骤实时地从 pending → running → completed 推进。这次 ADMET 运行展示了它的两个步骤，以及它将执行的质控闸门。

  • 步骤实时更新。第一个预测步骤正在运行（0 / 2）；下一步还在等待。
  • 质控闸门是心脏安全性阈值——CiPA hERG 安全裕度、qNet 风险、APD90 延长、EAD 概率。这些就是运行要据以检查的上限。
  • 它绝不会悄悄越过一个没通过的检查。一旦某个结果越线，运行就会把它标出来，并把实测值与上限并列。
  • 你随时可以暂停或停止，也可以让它在后台继续跑，同时继续对话。
质控阈值完整展示
第三步 · 完成——发现报告

一段好读的摘要，数字直接取自你的结果。

运行完成了：一个绿色的 Completed（已完成）徽标，报告停在 结果（Results） 标签页上——一段简短、自然语言的发现摘要，讲清这次运行发现了什么，关键数值都直接读自结果文件。

  • 已完成，并给出清晰结论。"已为 3 个化合物完成 ADMET 预测"——关键性质均对照标准阈值做了评估。
  • 真实数值，摆在最显眼处。hERG 抑制 0.003、DILI 概率 0.855、口服生物利用度 0.873——取自结果文件，而非手写。
  • 展开看细节。Key Results（关键结果）展开按化合物逐一列出的完整表格；Download findings（下载发现）一键存下整份摘要。
  • 如实说明。一行 Caveats（注意事项）提醒你，这些都是计算得出的估计值——在推进之前仍需用湿实验加以验证。
结果直接读自你的文件
第四步 · 输出——每个文件，按步骤归类

摘要的背后：运行产生的每一个文件。

Outputs（输出）区——就在同一个 结果（Results） 标签页、发现摘要的下方——列出运行产生的每一个文件，并按产生它的步骤分组，那是摘要背后的原始结果，可供你亲自下载、阅读。

  • 每个文件，各带其类型。predict_admet_properties_results.json、toxicity_report.json、qc_metrics.json、pk_summary.json、一张结果表格，以及 versions.yml（软件记录）。
  • 归在产生它的步骤之下——于是你能从头到尾追溯整条流水线。
  • 查看或下载任意单个文件，把它们全部打包成一个压缩包，打开来做交互式分析，或保存到某个项目。
  • 这是看清每一步输入与输出的最清晰视图——摘要背后的原始真相。
每一个结果文件，都归你所有
第五步 · 可复现记录——你的审计轨迹

让结果站得住脚的一切，一次下载尽收。

可复现记录是完整的审计轨迹——一切整份保存在一起，不隐藏、也不丢弃任何部分。这正是你附到论文、专利或监管递交材料上的东西。

  • 身份与时间。运行编号 46953d98…、状态 Completed（已完成）、创建与完成的时间戳——把这次确切的运行钉得死死的。
  • 参数与输出——全部九个文件及其类型和大小，外加可展开的方法、软件版本、引用文献、质控报告，以及完整的决策轨迹。
  • 可核验的校验和。每个文件都有一个 SHA-256 指纹，任何人都能据此确认自己拿到的是完全相同的那个结果。
  • 一键：下载记录（JSON）——整份审计轨迹收进单个文件。

一眼看懂这个习惯

确认并运行 → 实时查看 → 读「结果」与记录。

每一次运行都是同一个样子。配置好并确认；实时看着各个阶段和质控闸门；然后读合并的 结果（Results） 视图——发现与每个输出——以及 可复现记录。正是这份记录，把"运行完了"变成一个你能够解释、也拿得出依据的结果。

  3. 3读摘要——用自然语言给出的关键发现
