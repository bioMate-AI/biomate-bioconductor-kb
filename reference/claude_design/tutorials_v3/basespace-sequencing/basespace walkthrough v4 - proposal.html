In BioMate · 2 Workflow

One phase, two steps, and the check beside them.

  1. Differential analysisThe analysis tests every gene for a difference between the groups, taking DESeq2 as the example.
  2. Write resultsThe results table and the volcano plot are saved.
  3. The check runs when step 2 finishesThe number of significant genes is compared with the recorded cutoffs.
· the input
Counts per gene for each sample, plus the group labels.
· the test
Each gene gets a fold-change and an adjusted p-value.
· the cutoff
Significant means padj below 0.05 and a fold-change of at least 2.
