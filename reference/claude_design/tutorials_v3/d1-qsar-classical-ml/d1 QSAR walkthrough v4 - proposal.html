Idea · why QSAR works

Similar structures behave similarly.

So a model learned from measured molecules can put a number on new ones.

  1. Learn from what you measuredSMILES paired with pIC50.
  2. Score what you have only drawnThousands in minutes; make the best.

In BioMate · 2 Workflow

Three phases, and every parameter shows its origin.

  1. Featurize, e.g. a Morgan fingerprintRadius 2, 1024 bits. Each bit records one small substructure.
  2. Train, e.g. a random forest200 trees on resampled data. Their average is the prediction.
  3. Validate, then gate5-fold CV. Phase B starts only if CV R² ≥ 0.5.
· a fingerprint

A few dozen of the 1024 bits are on. Each marks a substructure around an atom.

· many trees, one answer

The trees disagree a little. Their average is stable.

· the gate
If CV R² < 0.5, Phase B is held: no analogue gets a score from a weak model. If it passes, scoring starts.

Read it right · before you make anything

Can you trust it? The evidence sits under the answer.

  1. The model passes its criterionCV R² 0.72 against ≥ 0.5.
  2. It tracks held-out dataPredicted vs measured on folds the model never saw.
  3. The shortlist sits inside the domainThe points outside are extrapolations.
  4. One advisory, recordedWith 42 compounds, CV can be optimistic.
