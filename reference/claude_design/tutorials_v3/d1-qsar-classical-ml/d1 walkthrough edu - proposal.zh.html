概念 · QSAR 为什么可行

结构相似的分子，活性往往也相似。

因此，从已测分子中学到的模型可以预测新分子的活性。

  1. 从实测数据学习SMILES 与对应的 pIC50。
  2. 为新设计的分子打分几分钟内评估数千个分子，只合成最有希望的。
  3. 以随机森林为例BioMate 也提供其他模型，可根据数据规模与任务选择。

概念 · 要解决什么

QSAR 是一道筛子，不是一纸判决。

  1. 输入：还没合成的结构一个以 SMILES 写出的分子——没有样品，没有检测，也没花实验时间。
  2. 输出：一个预测数字活性 pIC50 或毒性风险，并带一条可信度提醒。
  3. 价值：合成之前先分流几分钟为成千上万候选打分，排序分流，绝不替代湿实验。
· 结构 → 打分 → 分流
概念 · 把分子变成特征

模型读不懂分子——先把它变成数字。

  1. 描述符：可解释的理化性质分子量、logP、氢键、环数——短而有含义的向量。
  2. 指纹：子结构在不在Morgan / ECFP：1024 位，每位标记一个局部子结构。
  3. 适用域：可信赖的范围离训练集越远，预测越是外推，越要谨慎。
· 两类特征
概念 · 随机森林

许多浅层决策树，平均成一个稳定预测。

  1. 处理稀疏指纹位1024 个二值位无需缩放，也无需特征选择。
  2. 捕捉非线性构效这是线性模型会错过的关系。
  3. bagging 抵抗过拟合几十个化合物也稳健，还自带特征重要性。
· 一片树林
每棵树只看化合物的一个自助重采样和一个随机特征子集；树与树的分歧相互抵消，信号得以保留。
概念 · 验证与解读

没验证过的模型，只是一个充满希望的猜测。

  1. CV R²：贴合程度接近 1 为好；低于 0.5 阻断，不放过弱模型。
  2. CV RMSE 与特征重要性同单位的典型误差；哪些子结构在驱动预测。
  3. 小样本会虚高少于 50 个化合物，记一条 BRONZE 提醒。
· 交叉验证 + 重要性
真实工作流用 5 折 报告 CV R² 与 RMSE——在模型从未训练过的数据上，预测贴合实际的程度。

在 BioMate 中 · 2 工作流

三个阶段，每个参数都标明来源。

  1. 特征化：以 Morgan 指纹为例半径 2、1024 位，每一位记录一个局部子结构。
  2. 训练：以随机森林为例在重采样数据上训练 200 棵决策树，取其平均值作为预测。
  3. 先验证，再放行五折交叉验证；只有 CV R² ≥ 0.5，阶段 B 才会开始。
· 指纹

1024 位中只有几十位被点亮，每一位标记某个原子周围的一个子结构。

· 多棵树，一个答案

各棵树的预测略有差异，但平均值很稳定。

· 门控
如果 CV R² < 0.5，阶段 B 会被暂停：不会用未达标的模型为任何类似物打分；通过后才开始打分。
在 BioMate 中 · 2 工作流 · 运行中

看它运行，并看懂这个分数为什么可信。

  1. 步骤依次完成在托管算力上运行，无需本地安装。
  2. 每一折留出五分之一五分之四用于训练，剩下五分之一用于测试，轮换五次。
  3. 关卡通过，才进入阶段 BCV R² 0.72 达到 ≥ 0.5 的判据，开始打分。

正确解读 · 合成之前

结果可信吗？证据就在结论下方。

  1. 模型通过判据CV R² 0.72，判据为 ≥ 0.5。
  2. 在留出数据上同样成立在模型未见过的折上比较预测值与实测值。
  3. 入选者都在适用域内适用域之外的点都属于外推。
  4. 记录了一条提示只有 42 个化合物，交叉验证可能偏乐观。
  5. 检查特征化方式应为 morgan_fp_r2_1024，而不是模拟的后备特征。
