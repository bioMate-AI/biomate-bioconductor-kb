问题 · 第 6 集 · 新颖性

你的入围清单
真的是新的吗？

在投入资源之前，结构层面的筛查会把每个候选分子与已知化学做比较。

概念 · 这里的“新颖”指什么

新颖不等于可以自由实施。

  1. 与已知分子比较为每个候选分子计算指纹，并与已知分子库匹配。
  2. 以最相近的匹配为准最佳匹配的相似度低于 0.85，就判为新颖。
  3. 新颖不等于可实施结构新颖不是法律意义上的自由实施（FTO）意见。
· 判定规则
最大 Tanimoto结论之后会怎样
低于 0.85新颖保留在入围清单中
0.85 及以上已被占据在委托外包前剔除
接近阈值已被占据交由专利律师判断
· 仅作示例
这里以 FPSim2 和 Morgan / ECFP4 指纹为例。专利筛查是另一个可选项。未命中并不证明新颖：指纹会漏掉骨架跃迁和电子等排体。
概念 · 为什么要筛

一张 CRO 订单很贵，别花在别人已有的分子上。

  1. 只有少数能下单入围名单很长，预算只够几单真实的合成与检测。
  2. 风险：已被占据的化学候选物可能近似某个已发表、很可能已被专利覆盖的结构。
  3. 关卡在下单之前这道核查必须发生在花钱之前，而不是之后。
· CRO 前的关卡
概念 · 四个词汇

四个概念，方法就顺理成章。

  1. 指纹Morgan / ECFP4 把子结构编码成一串定长的位向量。
  2. Tanimoto 相似度两串指纹的重叠程度，从 0 到 1。
  3. 新颖 vs 已占据最近邻相似度低就是新颖；但新颖不等于法律上清白。
· Tanimoto 怎么算
1.0 表示完全相同。本例以 FPSim2 + Morgan / ECFP4 为例。
概念 · 方法

生成指纹，找最近邻，再做可选的专利核查。

  1. 指纹每条 SMILES 编码为 ECFP4，与库用同一种表示。
  2. 最近邻FPSim2 算出对库的最大 Tanimoto，返回最接近的已知分子。
  3. 可选专利筛查打开后查 SureChEMBL / PubChem 这类化学是否已披露。
· 流水线
设计上失败即放行：某个来源不可访问时，如实报出缺口，绝不悄悄拦下一个候选物。
概念 · 诚实的边界

这是结构筛查，不是法律意见。

  1. 结构性，而非法律性自由实施由专利律师判断，不是一个 Tanimoto 分数。
  2. 指纹有盲区骨架跃迁和电子等排体会被漏掉。
  3. 缺席并非证明没命中只说明所查来源里没有相近之物。
· 它是什么 · 它不是什么
这道筛查给你

一个可查证的结构信号

最大相似度、最接近的已知邻居，以及对照阈值的新颖 vs 已占据判定——廉价、快速、可复现。

它不告诉你

不是一份 FTO 意见

不替代专利律师的自由实施判断；会漏掉骨架跃迁；受库覆盖面限制，缺席不等于清白。

  2. BioMate 检查分子库已知化学库已挂载且可访问。
  3. 每个参数都标明来源0.85 的阈值和专利开关都标注为默认值。
在 BioMate 中 · 2 工作流

两个步骤：先指纹，再比较。

  1. 计算指纹每个候选分子转成 Morgan / ECFP4 指纹。
  2. 找出最近邻在分子库中检索最相似的已知分子。
  3. 判定本身就是关口被占据的候选分子在花钱之前就被剔除。
· 指纹
用固定长度的编码表示分子中的子结构。
· Tanimoto
共有位数除以总位数。1.0 表示完全相同。
· 关口
新颖性判定是对外投入前的最后一道检查。
在 BioMate 中 · 2 工作流 · 运行中

看它运行，看哪些被剔除。

  1. 步骤依次完成先计算指纹，再检索分子库。
  2. 每个候选分子都找到最近邻最相近的已知分子与结论一起给出。
  3. 有一个候选分子已被占先A-12 与已知分子的相似度为 0.88。
在 BioMate 中 · 3 结果

哪些候选是新的，对照的是谁。

  1. 结论先在对话中给出哪些新颖，哪些不是。
  2. 打开运行查看证据面板中是各自的最近邻。
  3. 每个结论都指明对照分子A-07（0.62）和 A-03（0.47）新颖。
  4. A-12 已被占先相似度 0.88，从入围清单中剔除。
正确解读 · 投入资源之前

新颖不等于可以自由实施。

  1. 这是结构层面的筛查它比较的是分子的结构，而不是法律主张。
  2. 未命中不是证明指纹会漏掉骨架跃迁和电子等排体。
  3. 可复现记录列出了设置阈值和专利开关，每一项都标明来源。
  4. 由律师做最终判断接近阈值的情况交给专利律师。
