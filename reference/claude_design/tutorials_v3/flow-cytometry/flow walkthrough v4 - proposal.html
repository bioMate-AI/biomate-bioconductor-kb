The question · flow cytometry

Which cells are
in this sample?

A cytometer records every cell as an event. Gating turns that table of dots into named populations and their percentages. BioMate runs it end to end.

Idea · gating

Gating is the analysis.

  1. Clean up firstRemove debris and doublets so only single, intact cells are counted.
  2. Then pick lineagesEach population is a set of marker thresholds: lymphocytes, then CD3+, then CD4 against CD8.
  3. Correct the spilloverDyes bleed into neighbouring channels. A compensation matrix from your single-stain controls corrects it, and you supply it.
· the gating tree

· an example
Every population is reported against the gate directly above it, so 43% CD4+ means 43% of the CD3+ T cells, not of all events. What you stained decides the assay: surface markers give populations, CFSE gives division, Annexin V and PI give apoptosis.

In BioMate · 2 Workflow

One phase, three steps.

  1. Remove debris and doubletsOnly single, intact cells go forward.
  2. Gate lineages by markerThe compensation matrix is applied, then each gate narrows the cells.
  3. Count and checkEach population is counted against its parent. A sensible run keeps most events in the lymphocyte gate.
· the channels
Use channel names exactly as the instrument wrote them.
· the thresholds
Each gate is a marker range, written once and reused.
· the check
Discarding most events at this gate would be a warning.

Read it right · before you rely on it

A small percentage can be noise.

  1. Check the gates firstMost events should stay in the lymphocyte gate.
  2. A tiny fraction can be an artefactA 0.1% population is easily a gating artefact.
  3. Compensation is on youWithout it, populations can be wrong but look plausible.
  4. Check the first runCompare it with your own manual analysis.
