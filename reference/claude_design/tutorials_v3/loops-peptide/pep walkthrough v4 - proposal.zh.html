问题 · 环肽

能设计出自然界
没有的多肽吗？

环肽会用到二十种天然氨基酸之外的构件。BioMate 用自己训练的生成模型来设计，用物理方法验证，并从每一次实验中学习。

概念 · 多肽有什么不同

化学本身是重点，生成模型是我们自己的。

  1. 环状，带非常规残基D 型氨基酸、N-甲基化，以及带氟或氯的芳香环，都属于设计空间。
  2. 结构预测器是通用工具谁都能用，所以它们用来检验设计，而不是产生设计。
  3. 生成模型才是优势它用环肽数据训练，所以能提出通用工具设计不出来的化学结构。

概念 · 候选是怎样生成的

分阶段构建的生成模型。

  1. 先学会多肽的“语言”先训练自编码器，把一条多肽变成隐空间里的一个点。
  2. 再学会生成隐空间扩散模型学会产生新的点，也就是新的多肽。
  3. 然后对准靶点以靶点为条件的版本，把多肽和结合位点一起设计。
  4. 环状变体进一步扩展环状的微调版本和环肽语言模型，加入了成环和非常规残基。

在 BioMate 中 · 通过关卡的五条肽

五条针对 αvβ6 的环肽，风险项逐条列出。

  1. 靶点和轮次胰腺癌中的 αvβ6，第 1 轮，五条肽通过关卡。
  2. HELM 序列，连同化学细节每条肽都带 RGD 结合基序，非天然残基用粗体标出。
  3. 已经通过的约束通过规则关卡和可开发性检查后没有风险项，净电荷为 +1，平均疏水性约 0.5。
  4. 相对专利是新颖的专利自由实施已经核查，五条都在现有权利要求范围之外。
概念 · 合成之前的三道检查

结构、结合能和性质。

  1. 结构每条肽都与靶点以环状复合物的形式做结构预测，每条肽一个任务，这里以 Boltz-2 为例；第二个预测器只对排名靠前的几条做交叉验证。
  2. 结合能基于物理的打分估算结合强度，自由能引擎负责环肽和金属桥接的肽。
  3. 性质可获得性评分、渗透性和稳定性把住最后一道关。可获得性评分仅供参考。

· 为什么这里用 Boltz-2
它是开放许可，可在本地运行，还能预测亲和力，适合大规模筛选。它负责检验设计，而不是产生设计。
在 BioMate 中 · 从数字到入选

三条肽测过，两条入选。

  1. 每条肽一行结构可信度、结合能、可获得性、渗透性和结合强度并排。
  2. 肽 2 领先结合能最好，为 −42.3 kcal/mol，Kd 为 0.9 µM。
  3. 两条入选肽 2 和肽 5：结合能最好，同时可获得性可以接受。
  4. 没入选的也有用肽 3 和肽 4 成为偏好对中被淘汰的一方。
概念 · 实验室，和循环的闭合

由人来制备，结果用来重新训练生成模型。

  1. 制备由人完成由 CRO 或湿实验室成批制备，每批 48 到 96 条。合成不会自动化。
  2. 三种实验测量结果PAMPA 测渗透性，荧光偏振测结合，另外还有血浆稳定性。
  3. 结果变成偏好对入选的肽与被淘汰的肽配成对。
  4. 生成模型重新训练Diffusion-DPO 让生成模型更偏向有效的设计，第 2 轮提出结合更紧的类似物。

正确解读 · 循环用在哪里

同一套流程，可以用在不同靶点上。

  1. 每一轮都保留设计、验证、实验和偏好对都留有记录。
  2. 生成模型在进步每次重新训练都从上一次出发，提案越来越紧凑。
  3. 同一套流程用于多个靶点胰腺癌中的 αvβ6、GRPR，以及 PD-L1 阻断。
  4. 重新运行由你点击不会有任何东西自己重启。
