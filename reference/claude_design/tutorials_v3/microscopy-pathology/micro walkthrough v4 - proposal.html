The question · microscopy and pathology

How many cells,
and which kinds?

A tissue image is pixels. BioMate finds every cell, measures each marker in it, and counts the cells that are positive.

Idea · segment, measure, count

A cell table is built from the image.

  1. SegmentNuclei and cell boundaries are found, so each cell is one object.
  2. MeasureEach marker’s signal is read inside each cell.
  3. CountA cell is positive for a marker when its signal is high enough.

In BioMate · 2 Workflow

Two phases: segment, then summarise.

  1. Find nuclei and cell boundariesDAPI marks the nuclei, and the boundaries are drawn around them.
  2. Measure markers per cellEvery cell gets a value for each marker.
  3. Count marker-positive cellsThe positive fraction of each marker is worked out.
