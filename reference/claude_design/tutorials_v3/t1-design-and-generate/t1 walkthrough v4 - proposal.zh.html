问题 · 第 T1 集 · 设计与生成

接下来
该设计哪些分子？

筛选只能测试你已有的分子，生成则提出全新的分子，再按你的目标打分。BioMate 从一个种子结构一路做到排好序的候选清单。

概念 · 难在哪里

四项要求同时满足，没有单一分数。

  1. 活性它要能结合疾病靶点。
  2. 安全它不能伤及心脏和肝脏。
  3. 可合成化学家要能把它做出来。
  4. 体内行为它要能被吸收，也不能被清除得太快。
· 四项要求
要求要什么防范的问题
活性结合靶点永远到不了靶点的分子
安全不伤心脏和肝脏hERG 等风险
可合成能被造出来没人能合成的结构
体内行为吸收好、清除不过快体内暴露不足
· BioMate 的做法
每项要求保留各自的数值和单位，从不合并成一个分数，所以弱项不会躲在强项后面。
在 BioMate 中 · 1 设定

在生成之前，先设定约束。

  1. 分子类型小分子、多肽或蛋白。
  2. 种子结构，可选来自 PubChem 或 ChEMBL 的已知结合物可引导搜索。
  3. 骨架策略保持、跃迁或生长：离种子走多远。
  4. 性质范围分子量、logP 和 TPSA 是一个范围，不是截断。
  5. 生成并排序你点击之前，什么都不会生成。
概念 · 骨架策略与性质范围

离种子走多远，药物该是什么样。

  1. 保持核心不变，只换取代基。
  2. 跃迁换成新的核心。
  3. 生长把一个片段逐步长成分子。
  4. 是窗口，不是截断窗口外的好分子排名靠后，但不会被删除。
· 骨架策略
策略变化的部分适用于
保持取代基，不动核心核心值得保留
跃迁核心核心本身有问题
生长片段长成分子从片段命中出发
· 性质范围 · 表单默认值
性质范围含义
分子量≤ 500分子的大小
logP≤ 5亲油还是亲水
TPSA≤ 140极性表面积
在 BioMate 中 · 2 结果

一行一个候选，一列一个目标。

  1. 每个候选占一行生成 8 个，打分 8 个。
  2. 目标保留各自单位类药性（QED）单独一列，不合并。
  3. 得分只用于排序是归一化目标的平均值，不是流程所优化的指标。
  4. 结论与原因入选或淘汰，每行都有“原因？”。
在 BioMate 中 · 3 解读

最佳折中，以及为何有些被搁置。

  1. 权衡视图候选按类药性排在 0 到 1 的线上。
  2. 前沿一目了然最佳折中点更大；被支配的仍然可见。
  3. 淘汰按原因计数四个候选带有结构警示。
  4. 被淘汰的仍然列出每个都保留一行和被搁置的原因。
正确解读 · 合成之前

得分只是排序依据，不是测量值。

  1. 得分只负责排序各目标得分经归一化后取平均，用于排序。
  2. 预测不是实验类药性由结构计算得出，并非在实验台测得。
  3. 安全是一道关卡只要有结构警示，其他数值再好也会被淘汰。
  4. 待验证的假设最终由实验室决定合成什么。

你看到它是

· 下单之前
这里没有任何实测亲和力。先合成，再测量：只有实验结果才能说明设计是否奏效。
下一步 · 闭环

候选清单只是开始，实验结果让下一轮更好。

  1. 合成导出给实验室的订单表。
  2. 测试实测结果以数据集的形式回来。
  3. 学习它们进入“模型”，让下一轮更准。
