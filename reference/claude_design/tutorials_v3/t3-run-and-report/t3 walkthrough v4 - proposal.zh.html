问题 · 第 3 集 · 运行工作流

怎样从一个问题
走到值得信赖的报告？

工作流是一条经过测试的流水线，在云端运行，最后交回一份报告。跟随一次真实的运行：气道细胞经地塞米松处理后，哪些基因发生了变化，从设置一直到三个标签页的报告。

概念 · 先了解几个词

五个词，就能读懂整份报告。

  1. 工作流是现成的流水线你只需运行，不必自己搭建。它分为阶段，每个阶段再分为步骤。
  2. 参数在运行前就已显示设置一目了然，默认值合理，每一项都标明来源。
  3. 检查和报告在最后出现检查把结果与记录的判据比较；报告以三个标签页交回。

· “已测试”是什么意思
每个步骤都采用成熟、已发表的方法，因此流水线可靠。但这并不意味着结果已经过临床证明。
在 BioMate 中 · 1 数据

说明目标，核对设置，然后确认。

  1. 用自然语言说明目标你想做哪种比较：这里是地塞米松与未处理对照。
  2. BioMate 选好工作流并在右侧打开面板，绑定你的输入：基因计数表和分组标签。其他工作流会在这里附上 FASTQ、CSV 或 SMILES 文件。
  3. 每个参数都标明来源比较方式来自你的消息，方法是推荐值，阈值是默认值。
在 BioMate 中 · 2 工作流

一个阶段，两个步骤，旁边是检查。

  1. 差异分析DESeq2 检验每个基因在两组之间是否存在差异。
  2. 写出结果保存结果表和火山图。
  3. 第 2 步完成时运行检查把显著基因的数量与记录的阈值比较。
· 每个基因
同时检验 34,371 个基因，所以 p 值要针对这一点做校正。
· 结果
每个基因一行，带着它的倍数变化和校正 p 值。
· 检查
显著的标准是 padj 低于 0.05，且倍数变化至少为 2。
在 BioMate 中 · 2 工作流 · 运行中

看每个步骤从排队变为完成。

  1. 步骤依次完成面板实时更新，你可以继续对话。
  2. 检查列在步骤旁边显著基因数，对照 padj 低于 0.05 且倍数变化至少为 2。
  3. 检查结果是发现，不是停止运行会完成，并如实报告它发现了什么。
在 BioMate 中 · 3 结果

先给答案，再给证据。

  1. 结论先在对话中给出34,371 个基因中，有 1,242 个在地塞米松处理后发生显著变化。
  2. 打开运行查看证据面板中有计数、变化最强的基因和图。
  3. 每个基因都显示方向和可信度倍数变化给出方向和幅度；校正 p 值告诉你有多大把握。
  4. 火山图是同一结果的图像上调在右，下调在左，越高越确定。
正确解读 · 三个标签页

摘要背后：每个文件，以及完整记录。

  1. 数字背后的文件deseq_results_top200.csv 记录了各基因的倍数变化和校正 p 值。
  2. 每个文件都归在产生它的步骤下六个输出，各有类型，可以从头到尾追溯流水线。
  3. 记录固定了这次运行带来源的参数、软件，以及检查和它的结果。
  4. 一键下载整份记录以 JSON 导出，可用于论文、专利或评审。
