The question · your own data

Which file did
this result come from?

A file you bring in becomes a dataset object with its type, a quality check and its history. Every later result points back to it.

In BioMate · 1 The hub

Two panes, and it belongs to a project.

  1. Data belongs to a projectYou pick the project first, then see its data.
  2. A file tree on the leftUploads sit under inputs, and each run’s results get their own folder.
  3. A quality dot on every rowA glance tells you which files are clean.
  4. The file opens on the rightAs an object, not just a path.
In BioMate · 2 The object

One header, six tabs.

  1. The headerName, type, size, a quality pill and a version count.
  2. Six tabsPreview, Quality, Lineage, Consumers, Versions and Origin.
  3. Preview is the fastest checkThe first rows show a wrong file or a bad separator at once.
  4. Open it elsewhereJupyter, RStudio, a plot viewer, or ask about it in chat.
In BioMate · 3 Quality

The verdict, and the reading behind it.

  1. A one-word verdictBioMate reads the file and says Good, Watch, Blocked, or not checked.
  2. Rows and columnsFor a table, the size comes first.
  3. Effective NHow many independent observations the data really holds.
  4. NotesAnything to read before you run.
Idea · grey does not mean bad

Four verdicts, and grey means not checked.

  1. Good, greenReadable and nothing obviously wrong. Go ahead.
  2. Watch, amberUsable, but read the notes first.
  3. Blocked, redBioMate could not read it. Fix it first.
  4. Not checked, greyGrey is not a bad file. It was not profiled.

In BioMate · 4 Use it

Attach it, ask a question, and every result traces back.

  1. The data control in the message boxAttach a file, or point at data you already have, so you do not upload twice.
  2. Both become the same objectA dataset object with the same checks and the same history.
  3. Then describe the analysisBioMate runs it only after you confirm, and the result points back to this file.
