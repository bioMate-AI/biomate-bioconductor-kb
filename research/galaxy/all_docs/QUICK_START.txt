🚀 快速开始（6个步骤）：

1. 获取API Key
   http://localhost:8080 → User → Preferences → API Key

2. 安装工具（20-40分钟）
   nano install_workflow_tools.py  # 设置API_KEY
   python3 install_workflow_tools.py

3. 重启Galaxy
   pkill -f gunicorn ; pkill -f celery
   bash start_galaxy_cloud.sh &

4. 导入Workflow
   http://localhost:8080 → Workflow → Import
   选择: real_complex_workflow.ga

5. 上传数据
   Upload Data → real_test_data/sample_reads.fastq.gz

6. 运行并验证
   Workflow → Run
   查看作业destination应该是cloud_*
