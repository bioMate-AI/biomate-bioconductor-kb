## 💡 核心理解

### Galaxy云执行的本质

```
Galaxy工具 = XML描述 + Docker容器镜像
云端执行 = AWS Batch运行Docker容器
job_conf_cloud.yml = 控制工具路由到云端
```

### 完全云端的含义

```
99%的工具在AWS Batch执行
只有2个工具必须本地（上传和元数据）
所有workflow步骤默认云端执行
Docker镜像自动从BioContainers拉取
```

### 配置的核心

```yaml
execution:
  default: cloud_small  # 关键！默认云端

tools:
  - id: "__UPLOAD__"
    environment: local  # 唯一例外1
  - id: "__SET_METADATA__"
    environment: local  # 唯一例外2
  - id: ".*"
    environment: cloud_small  # 所有其他工具
```
