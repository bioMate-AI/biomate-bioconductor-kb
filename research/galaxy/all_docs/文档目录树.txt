===========================================
验证云端执行
===========================================

方法1: 查看Galaxy作业
  运行workflow → 历史记录 → 作业详情
  → 检查 "Job Destination"
  → 应该显示: cloud_small/medium/large ✅

方法2: 查看AWS Batch
  aws batch list-jobs \
    --job-queue galaxy-cloud-queue \
    --job-status RUNNING

方法3: 查看S3数据
  aws s3 ls \
    s3://galaxy-cloud-data-1760241377/jobs/ \
    --recursive

方法4: 查看日志
  tail -f galaxy_startup.log | \
    grep -i "submit.*batch\|destination.*cloud"
