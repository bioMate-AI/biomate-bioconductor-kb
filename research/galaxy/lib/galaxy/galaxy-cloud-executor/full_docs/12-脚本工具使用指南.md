# 脚本工具使用指南

## 概述

Galaxy Cloud Executor 提供了两套工具：
1. **诊断和管理脚本** - 验证配置、排查问题、管理 AWS 资源
2. **Workflow 测试工具** - 批量测试复杂 workflows（详见 [05-Workflow云测试工具详解.md](05-Workflow云测试工具详解.md)）

---

## 工具分类

### A. 诊断脚本（本文档）

所有脚本位于: `lib/galaxy/galaxy-cloud-executor/scripts/`

| 脚本名称 | 用途 | 何时使用 |
|---------|------|---------|
| `check_integration_ready.sh` | 集成就绪检查 (15项) | ⭐ 合并配置后,启动 Galaxy 前 |
| `diagnose_batch.sh` | Batch 配置完整诊断 | 作业卡住或失败时 |
| `check_aws_credentials.sh` | AWS 凭证检查 | AWS 连接失败时 |
| `create_aws_batch.sh` | 自动创建 AWS Batch | ✅ 已使用 (基础设施创建) |
| `create_job_role.sh` | 创建 BatchJobRole | ✅ 已使用 (S3 权限配置) |
| `fix_launch_template.sh` | 修复 Launch Template | ✅ 已使用 (IAM Profile 修复) |
| `check_asg_failure.sh` | ASG 启动失败诊断 | EC2 实例无法启动时 |
| `check_ecs_instance.sh` | ECS 实例注册检查 | 实例无法注册到 ECS 时 |
| `check_instance_logs.sh` | EC2 实例日志查看 | 需要查看实例启动日志时 |

### B. Workflow 测试工具 ⭐ NEW

所有工具位于: `lib/galaxy/galaxy-cloud-executor/testing/`

| 工具名称 | 用途 | 何时使用 |
|---------|------|---------|
| `run_any_workflow.py` | 单个 workflow 云测试 | ⭐ 测试任意 workflow |
| `batch_test_workflows.sh` | 批量 workflow 测试 | 批量验证兼容性 |
| `analyze_real_workflow.py` | Workflow 结构分析 | 了解 workflow 复杂度 |
| `check_failed_job.py` | 失败作业诊断 | 作业失败时排查 |

> **详细使用指南**: 参见 [05-Workflow云测试工具详解.md](05-Workflow云测试工具详解.md)

## 1. check_integration_ready.sh ⭐

### 用途

**最重要的脚本!** 在启动 Galaxy 前运行,检查所有配置是否就绪。

### 何时使用

- ✅ 合并配置文件到 Galaxy 后
- ✅ 修改 job_conf.yml 或 aws_cloud_config.yaml 后
- ✅ Galaxy 启动失败时

### 使用方法

```bash
cd /Users/renyuankai/work/biometa/galaxy
bash lib/galaxy/galaxy-cloud-executor/scripts/check_integration_ready.sh
```

### 检查项 (15项)

#### 1. AWS 基础设施 (5项)
- AWS 凭证有效性
- Batch 队列存在且启用
- S3 存储桶可访问
- BatchJobRole 存在
- BatchJobRole 附加 S3 策略

#### 2. Galaxy 配置文件 (6项)
- job_conf.yml 存在
- job_conf.yml 包含 galaxy_cloud runner
- job_conf.yml 包含云环境
- job_conf.yml YAML 语法正确
- aws_cloud_config.yaml 存在
- aws_cloud_config.yaml 包含 job_role_arn

#### 3. Python 模块 (3项)
- galaxy_cloud 模块可导入
- boto3 已安装
- PyYAML 已安装

#### 4. (可选) Galaxy 运行状态
- Galaxy 进程运行
- Galaxy 日志显示 galaxy_cloud 加载
- Galaxy Web 服务监听端口

## 2. diagnose_batch.sh

### 用途

完整诊断 AWS Batch 配置,包括 Job Queue, Compute Environment, IAM 角色等。

### 何时使用

- 作业卡在 RUNNABLE 状态
- 作业提交失败
- EC2 实例无法启动

### 使用方法

```bash
cd /Users/renyuankai/work/biometa/galaxy
bash lib/galaxy/galaxy-cloud-executor/scripts/diagnose_batch.sh
```

### 检查项

1. **Job Queue 配置**
   - 队列状态 (ENABLED/DISABLED)
   - 优先级
   - 关联的 Compute Environment

2. **Compute Environment 配置**
   - 状态 (ENABLED/DISABLED)
   - 状态健康 (VALID/INVALID)
   - 资源配置 (minvCpUs, maxvCpUs)
   - 实例类型

3. **Auto Scaling Group**
   - DesiredCapacity
   - 当前实例数
   - Launch Template 配置

4. **IAM 角色**
   - ecsInstanceRole 存在
   - Instance Profile 包含角色
   - BatchJobRole 存在

5. **Launch Template**
   - IamInstanceProfile 配置
   - 安全组配置
   - 用户数据
