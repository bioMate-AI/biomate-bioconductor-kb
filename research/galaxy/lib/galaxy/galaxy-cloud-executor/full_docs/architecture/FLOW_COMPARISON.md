┌─────────────────────────────────────────────────────────────┐
│ 测试阶段 - 手动验证 AWS Batch 配置                           │
└─────────────────────────────────────────────────────────────┘

你手动执行命令：
┌──────────────────────────────────────────────────────────┐
│ $ python3 testing/run_any_workflow.py workflow.json      │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ 测试脚本解析 workflow JSON                                │
│ - 读取 steps 定义                                         │
│ - 分析依赖关系（dependencies）                            │
│ - 构建 DAG 拓扑图                                         │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ 自动生成 MOCK 数据                                        │
│ - 输入文件：自动创建假的 input.txt                        │
│ - 参数：使用默认值                                        │
│ - 命令：简单的 echo 命令                                  │
│                                                           │

                           ↓

│ 直接调用 AWS Batch API                                    │
│ - boto3.client('batch').submit_job()                      │
│ - 不经过 Galaxy                                           │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ AWS Batch 执行简单命令                                    │
│ - 容器：python:3.9 (不是真实工具)                         │
│ - 命令：echo 命令（不是真实分析）                         │

## 🚀 Galaxy 集成后的真实流程（生产）

```
┌─────────────────────────────────────────────────────────────┐
│ 生产环境 - Galaxy UI 自动调用                                │
└─────────────────────────────────────────────────────────────┘

用户在 Galaxy UI 操作：
┌──────────────────────────────────────────────────────────┐
│ 1. 上传真实数据文件（例如：sample.fastq, ref.fasta）      │
│ 2. 选择 Workflow（例如：变异检测流程）                    │
│ 3. 点击 "Run Workflow" 按钮                               │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ Galaxy 内部调用                                           │
│ GalaxyCloudJobRunner.queue_job()                          │
│                                                           │
│ 📁 位置：galaxy_cloud/galaxy_workflow/                    │
│          galaxy_job_runner.py:171                         │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ GalaxyCloudJobRunner 解析作业                             │
│ - 获取工具 ID (例如：bwa_mem)                             │
│ - 获取用户输入文件路径                                    │
│ - 获取工具参数                                            │
│                                                           │
│ 📁 调用：tool_registry.get_tool_container()               │
│          → 获取真实的 BioContainer 镜像                   │
│          例如：quay.io/biocontainers/bwa:0.7.17           │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ DataManager 上传真实数据到 S3                             │
│                                                           │
│ 📁 位置：galaxy_cloud/galaxy_workflow/                    │
│          data_manager.py                                  │
│                                                           │
│ 上传的真实文件：                                          │
│ - s3://galaxy-cloud-data/inputs/sample.fastq ✅           │
│ - s3://galaxy-cloud-data/inputs/ref.fasta ✅              │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ 创建真实的 JobSpec                                        │
│                                                           │
│ container:                                                │
│   image: quay.io/biocontainers/bwa:0.7.17                 │
│   command: ["bwa", "mem"]                                 │
│   args: ["-t", "8", "ref.fasta", "sample.fastq"]         │
│                                                           │
│ resources:                                                │
│   vcpus: 8                                                │
│   memory_mb: 16384                                        │
│                                                           │
│ input_files:                                              │
│   - s3://galaxy-cloud-data/inputs/sample.fastq            │
│   - s3://galaxy-cloud-data/inputs/ref.fasta               │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ AWSBatchExecutor 提交作业                                 │
│                                                           │
│ 📁 位置：galaxy_cloud/providers/aws/executor.py           │
│                                                           │
│ - 调用 batch_client.register_job_definition()            │
│ - 调用 batch_client.submit_job()                         │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ AWS Batch 启动真实工具容器                                │
│                                                           │
│ Container: quay.io/biocontainers/bwa:0.7.17               │
│                                                           │
│ 容器内执行：                                              │
│ 1. 从 S3 下载输入文件                                     │
│    aws s3 cp s3://.../sample.fastq /tmp/                  │
│    aws s3 cp s3://.../ref.fasta /tmp/                     │
│                                                           │
│ 2. 执行真实的 BWA 比对分析                                │
│    bwa mem -t 8 /tmp/ref.fasta /tmp/sample.fastq         │
│    > /tmp/aligned.sam                                     │
│                                                           │
│ 3. 上传输出结果到 S3                                      │
│    aws s3 cp /tmp/aligned.sam s3://.../outputs/           │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ DataManager 下载结果回 Galaxy                             │
│                                                           │
│ - 从 S3 下载 aligned.sam                                  │
│ - 导入到 Galaxy 数据库                                    │
│ - 关联到用户的 History                                    │
└──────────────────────────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────┐
│ 用户在 Galaxy UI 看到结果 🎉                              │
│                                                           │
│ - 可以查看 aligned.sam 文件                               │
│ - 可以下载结果                                            │
│ - 可以继续后续分析                                        │
└──────────────────────────────────────────────────────────┘

用途：⭐⭐⭐ 生产环境，永久使用
```

| 对比项 | 测试工具 (testing/) | 真实生产 (galaxy_cloud/) |

## 💡 为什么需要两种代码？

### 测试工具的必要性
在集成 Galaxy **之前**，我们需要验证：
- ✅ AWS Batch 配置是否正确
- ✅ 作业能否正常提交
- ✅ 依赖关系是否正确
- ✅ 日志能否正常查看

**如果没有测试工具**，我们必须：
1. 先完成 Galaxy 集成（复杂，需要修改多个配置文件）
2. 然后才能发现 AWS Batch 配置错误
3. 修复后又要重新集成 Galaxy
4. 效率很低，调试困难

**有了测试工具**：
1. 先用测试工具快速验证 AWS Batch ✅
2. 确认基础设施没问题后
3. 再进行 Galaxy 集成（信心满满）
4. 集成后大概率一次成功 🎉

### galaxy_cloud/ 的核心地位
`galaxy_cloud/` 才是**真正的产品代码**：
- 这是 Galaxy 永久使用的执行器
- 处理真实用户数据
- 调用真实生物信息学工具
- 提供生产级别的可靠性

测试工具验证基础设施 → galaxy_cloud/ 提供真实服务
