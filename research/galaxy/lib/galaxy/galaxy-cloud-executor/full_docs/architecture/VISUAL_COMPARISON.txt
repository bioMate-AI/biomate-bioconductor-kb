┌──────────────────────────────────────────────────────────────────────────────────┐
│  Part 2: 真正的云执行器 (galaxy_cloud/) - 生产代码 ⭐⭐⭐                         │

    用户（最终用户）
        │
        │ 在 Galaxy UI 点击 "Run Workflow"
        ↓
    ┌─────────────────────────────────────────┐
    │ Galaxy UI                               │
    │ • 选择工具: BWA-MEM                     │
    │ • 上传数据: sample.fastq (真实)        │
    │ • 点击 "Run"                            │
    └─────────────────────────────────────────┘
        │
        │ Galaxy 内部自动调用
        ↓
    ┌─────────────────────────────────────────┐
    │ galaxy_cloud/galaxy_workflow/           │
    │ galaxy_job_runner.py                    │
    │ • queue_job() 方法                      │
    └─────────────────────────────────────────┘
        │
        │ 查询工具容器
        ↓
    ┌─────────────────────────────────────────┐
    │ galaxy_cloud/galaxy_workflow/           │
    │ tool_registry.py                        │
    │ • 查询 BioContainers API                │
    │ • 返回: quay.io/biocontainers/bwa:0.7.17│
    └─────────────────────────────────────────┘
        │
        │ 上传真实数据
        ↓
    ┌─────────────────────────────────────────┐
    │ galaxy_cloud/galaxy_workflow/           │
    │ data_manager.py                         │
    │ • 上传 sample.fastq 到 S3               │
    │ • s3://galaxy-cloud-data/.../input.fastq│
    └─────────────────────────────────────────┘
        │
        │ 提交作业
        ↓
    ┌─────────────────────────────────────────┐
    │ galaxy_cloud/providers/aws/             │
    │ executor.py                             │
    │ • 调用 AWS Batch API                    │
    │ • 提交真实作业                          │
    └─────────────────────────────────────────┘
        │
        │ AWS Batch 启动容器
        ↓
    ┌─────────────────────────────────────────┐
    │ AWS Batch                               │
    │ • 容器: quay.io/biocontainers/bwa:0.7.17│
    │ • 从 S3 下载 sample.fastq               │
    │ • 执行: bwa mem ref.fa sample.fastq     │
    │ • 上传结果到 S3                         │
    └─────────────────────────────────────────┘
        │
        │ 下载结果
        ↓
    ┌─────────────────────────────────────────┐
    │ galaxy_cloud/galaxy_workflow/           │
    │ data_manager.py                         │
    │ • 从 S3 下载 aligned.sam                │
    │ • 导入到 Galaxy 数据库                  │
    └─────────────────────────────────────────┘
        │
        │ 自动更新
        ↓
    ┌─────────────────────────────────────────┐
    │ Galaxy UI                               │
    │ • 用户看到 "aligned.sam" ✅             │
    │ • 可以查看、下载、继续分析              │
    └─────────────────────────────────────────┘

    用途: 真正的生产执行器
    特点: • 集成到 Galaxy 内部
          • 使用真实数据
          • 真实生物信息学工具
          • 永久使用 ⭐⭐⭐
