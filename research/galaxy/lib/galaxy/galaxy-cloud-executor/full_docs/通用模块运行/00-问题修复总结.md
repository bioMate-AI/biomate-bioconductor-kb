### 1. **存储Provider Scheme映射问题**

**问题**:
```
Storage provider for scheme 'aws' not found. Available schemes: s3
```

**原因**: `GalaxyDataManager.initialize_storage_client()` 使用provider名称('aws')直接调用`CloudStorageFactory.create()`，但Factory期望URI scheme ('s3')。

**修复**: [galaxy_cloud/galaxy_workflow/data_manager.py:74-90](../../galaxy_cloud/galaxy_workflow/data_manager.py#L74-L90)
```python
async def initialize_storage_client(self, provider: str, config: Dict[str, Any]) -> CloudStorage:
    if provider not in self.storage_clients:
        # Map provider name to storage scheme
        scheme_mapping = {
            'aws': 's3',
            'gcp': 'gs',
            'azure': 'az',
            'kubernetes': 'pv'
        }
        storage_scheme = scheme_mapping.get(provider, provider)

        storage_client = CloudStorageFactory.create(storage_scheme, config)
        await storage_client.__aenter__()
        self.storage_clients[provider] = storage_client

    return self.storage_clients[provider]
```

### 2. **Python环境和包依赖问题**

**问题**:
- aioboto3安装到Python 3.8，但脚本使用Python 3.13
- Python 3.13无aioboto3包
- Python 3.8缺少tenacity包

**修复**: [run_qiime2_cloud.sh:14-34](../../run_qiime2_cloud.sh#L14-L34)

添加了自动Python环境检测：
```bash
# 检测并使用正确的Python环境
if command -v python &> /dev/null && python -c "import aioboto3" &> /dev/null; then
    PYTHON_CMD="python"
elif command -v python3 &> /dev/null && python3 -c "import aioboto3" &> /dev/null; then
    PYTHON_CMD="python3"
else
    # 使用Anaconda Python
    if [ -f "$HOME/opt/anaconda3/bin/python" ]; then
        PYTHON_CMD="$HOME/opt/anaconda3/bin/python"
    fi
fi
```

安装了缺失的包：
```bash
pip install tenacity pydantic
```

### 3. **Python 3.8类型标注兼容性问题**

**问题**:
```python
TypeError: 'type' object is not subscriptable
```

**原因**: Python 3.8不支持 `tuple[str, str]` 语法（需要Python 3.9+）

**修复**: [galaxy_cloud/providers/aws/storage.py:1-10](../../galaxy_cloud/providers/aws/storage.py#L1-L10)
```python
from __future__ import annotations  # 启用延迟类型标注

from typing import Dict, Any, Optional, AsyncIterator, Tuple  # 导入Tuple
```

### AWS凭证过期

**问题**:
```
The security token included in the request is invalid.
```

**原因**: 使用AWS SSO临时凭证，通常12小时后过期

**解决方案**（3选1）:

#### **方案1: 使用SSO登录（推荐）**
```bash
# 查看SSO配置
grep -A 10 "\[profile" ~/.aws/config

# SSO登录
aws sso login --profile AdministratorAccess-399683337364

# 设置环境变量
export AWS_PROFILE=AdministratorAccess-399683337364

# 验证
aws sts get-caller-identity
```

#### **方案2: 使用刷新脚本**
```bash
./refresh_aws_credentials.sh
```

#### **方案3: 从AWS Console获取新凭证**
1. 登录AWS Console
2. 点击右上角用户名
3. 选择 "Command line or programmatic access"
4. 复制临时凭证并export:

```bash
export AWS_ACCESS_KEY_ID="..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_SESSION_TOKEN="..."  # 重要！
export AWS_DEFAULT_REGION="us-west-2"
```
