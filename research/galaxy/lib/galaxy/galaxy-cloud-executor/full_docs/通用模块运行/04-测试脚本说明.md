#### 2. `examples/run_any_galaxy_workflow.py` ⭐⭐⭐

**位置:** `/Users/renyuankai/work/biometa/galaxy/lib/galaxy/galaxy-cloud-executor/examples/run_any_galaxy_workflow.py`

**用途:** 通用Galaxy workflow执行器（核心脚本）

**功能:**
- ✅ 执行任何Galaxy workflow
- ✅ 自动识别输入类型（文件/目录）
- ✅ 支持多云平台
- ✅ 环境变量或配置文件
- ✅ 可选实时监控
- ✅ 完整的命令行参数

**使用:**
```bash
PYTHONPATH=/Users/renyuankai/work/biometa/galaxy/lib python3 examples/run_any_galaxy_workflow.py \
    workflow.json \
    --input 0:/path/to/data \
    --provider aws \
    --monitor
```

**参数:**
- `workflow` - Workflow JSON文件路径（必需）
- `--input` - 输入数据（可多次使用）
- `--provider` - 云提供商（默认：aws）
- `--staging` - S3临时区域（默认：workflows/staging）
- `--output` - S3输出区域（默认：workflows/outputs）
- `--config` - 配置文件路径（可选）
- `--max-parallel` - 最大并行作业数（默认：5）
- `--timeout` - 作业超时时间（默认：3600秒）
- `--monitor` - 实时监控执行
- `--log-level` - 日志级别（DEBUG/INFO/WARNING/ERROR）

**输入格式:**
```bash
# 单个文件
--input 0:/path/to/file.fastq.gz

# 目录（自动识别为collection）
--input 0:/path/to/directory

# 多个输入
--input 0:/path/to/data --input 1:/path/to/ref.fa
```

**配置文件** - 更灵活：

```yaml

  enabled: true
  region: us-west-2
  batch_queue: my-batch-queue
  s3_bucket: my-s3-bucket
  resource_limits:
    max_concurrent_jobs: 20

default_provider: aws
```

使用：
```bash
python3 examples/run_any_galaxy_workflow.py \
    workflow.json \
    --config my_config.yaml \
    --input 0:/data \
    --monitor
```

## 🆘 常见问题

### Q: 如何只测试不实际执行？

A: 目前没有dry-run选项，但可以：
1. 选择"快速验证"模式（不监控）
2. 提交后立即取消作业

### Q: 如何查看详细日志？

A: 使用 `--log-level DEBUG`:
```bash
python3 examples/run_any_galaxy_workflow.py \
    workflow.json \
    --input 0:/data \
    --log-level DEBUG
```

### Q: 支持哪些输入格式？

A:
- 单个文件: `--input 0:/path/to/file`
- 目录（collection）: `--input 0:/path/to/directory`
- 多个输入: `--input 0:/data1 --input 1:/data2`

### Q: 如何自定义staging路径？

A: 使用 `--staging` 和 `--output`:
```bash
python3 examples/run_any_galaxy_workflow.py \
    workflow.json \
    --staging my-project/staging \
    --output my-project/results
```
