## 错误 #1: ToolContainerInfo 对象不可订阅

### 错误信息
```
'ToolContainerInfo' object is not subscriptable
```

### 根本原因
代码混淆了两种数据类型：
- `tool_registry.get_tool_container()` 返回 `ToolContainerInfo` 对象
- `tool_registry.get_default_container()` 返回字典

代码统一使用字典访问 `container_info['image']`，导致对象访问失败。

### 修复方案
在 `_create_job_spec()` 方法中分别处理：

```python
if not container_info:
    # 字典类型 - 使用字典访问
    default_container = self.tool_registry.get_default_container()
    image = default_container['image']
    command = default_container.get('command')
    ...
else:
    # 对象类型 - 使用属性访问
    image = container_info.image
    command = container_info.command
    ...
```

**修改文件**: `galaxy_job_runner.py:196-223`

## 错误 #2: 'str' object has no attribute 'id'

### 错误信息
```
AttributeError: 'str' object has no attribute 'id'
File "galaxy_job_runner.py", line 238, in _create_job_spec
    'galaxy_user': str(job_wrapper.user.id) if job_wrapper.user else 'anonymous'
```

### 根本原因
`job_wrapper.user` 可能是字符串，也可能是对象，代码直接访问 `.id` 属性会失败。

### 修复方案
安全地获取 user ID：

```python
# 安全获取 user ID
if job_wrapper.user:
    if isinstance(job_wrapper.user, str):
        user_id = job_wrapper.user
    elif hasattr(job_wrapper.user, 'id'):
        user_id = str(job_wrapper.user.id)
    else:
        user_id = str(job_wrapper.user)
else:
    user_id = 'anonymous'
```

**修改文件**: `galaxy_job_runner.py:227-236`

## 错误 #3: 'list' object has no attribute 'get_id_tag'

### 错误信息
```
File "galaxy_job_runner.py", line 496, in __init__
    super().__init__(job_wrapper, [])
File "/lib/galaxy/jobs/runners/__init__.py", line 787, in __init__
    self.set_defaults(files_dir)
AttributeError: 'list' object has no attribute 'get_id_tag'
```

### 根本原因
`CloudJobState` 初始化时传递给 `AsynchronousJobState` 的参数顺序错误。

`AsynchronousJobState.__init__()` 的第一个参数应该是 `files_dir`，而不是 `job_wrapper`。

### 修复方案
正确传递关键字参数：

```python
class CloudJobState(AsynchronousJobState):
    def __init__(self, job_wrapper, future):
        super().__init__(
            files_dir=None,
            job_wrapper=job_wrapper,
            job_id=None,
            job_file=None,
            output_file=None,
            error_file=None
        )
        self.future = future
```

**修改文件**: `galaxy_job_runner.py:495-503`

## 错误 #4: Executor 'kubernetes' not found

### 错误信息
```
Failed to submit cloud job for 40: Executor 'kubernetes' not found. Available executors: aws-batch
```

### 根本原因
多个配置问题：
1. `_get_cloud_provider()` 默认返回 `'kubernetes'`，但应该返回 `'aws-batch'`
2. 配置文件使用 `provider: aws`，但代码检查 `cloud_provider`
3. `_get_cloud_executor()` 的映射不完整，没有处理 `'aws-batch'` 值
4. `_get_cloud_executor()` 没有接收 job_destination 参数来读取 AWS 配置

### 修复方案

#### 4.1 修复 `_get_cloud_provider()`
```python
def _get_cloud_provider(self, job_destination: JobDestination) -> str:
    # 检查 'provider' 和 'cloud_provider' 两个键
    if 'cloud_provider' in job_destination.params:
        provider = job_destination.params['cloud_provider']
    elif 'provider' in job_destination.params:
        provider = job_destination.params['provider']
    else:
        provider = 'aws-batch'  # 默认使用 aws-batch

    # 标准化 provider 名称
    provider_mapping = {
        'aws': 'aws-batch',
        'gcp': 'gcp-batch',
        'azure': 'azure-batch',
        'kubernetes': 'kubernetes'
    }

    return provider_mapping.get(provider, provider)
```

**修改文件**: `galaxy_job_runner.py:163-195`

#### 4.2 添加 `_build_provider_config()` 方法
```python
def _build_provider_config(self, job_destination: JobDestination) -> Dict[str, Any]:
    """从 job destination 参数构建云提供商配置"""
    params = job_destination.params

    config = {}
    if 'aws_region' in params:
        config['region'] = params['aws_region']
    if 'aws_batch_queue' in params:
        config['queue_name'] = params['aws_batch_queue']
    if 'aws_s3_bucket' in params:
        config['s3_bucket'] = params['aws_s3_bucket']

    return config
```

**修改文件**: `galaxy_job_runner.py:96-110`

#### 4.3 更新 `_get_cloud_executor()`
```python
async def _get_cloud_executor(self, provider: str, job_destination: JobDestination = None) -> CloudExecutor:
    if provider not in self.cloud_executors:
        # 从 job_destination 构建配置
        if job_destination:
            provider_config = self._build_provider_config(job_destination)
        else:
            provider_config = self._load_cloud_config().get('cloud_providers', {}).get(provider, {})

        # 完整的映射表
        executor_type_map = {
            'aws': 'aws-batch',
            'aws-batch': 'aws-batch',
            'azure': 'azure-batch',
            'azure-batch': 'azure-batch',
            'gcp': 'gcp-batch',
            'gcp-batch': 'gcp-batch',
            'kubernetes': 'kubernetes'
        }

        executor_type = executor_type_map.get(provider, 'aws-batch')
        executor = CloudExecutorFactory.create(executor_type, provider_config)

        await executor.__aenter__()
        self.cloud_executors[provider] = executor

    return self.cloud_executors[provider]
```
