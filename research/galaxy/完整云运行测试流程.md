### 步骤2: 获取Galaxy API Key

**方法1: 通过Web界面**

1. 打开浏览器访问: http://localhost:8080
2. 登录或注册账号
3. 点击右上角用户名 → Preferences
4. 左侧菜单 → Manage API Key
5. 点击 "Create a new key"
6. 复制API Key（格式: `xxxxxxxxxxxxxxxx`）

**方法2: 通过命令行（如果有管理员权限）**

```bash
# 创建API key
python3 << 'EOF'
from galaxy.model import User, APIKeys
from galaxy.model.database_utils import get_session

session = get_session()
user = session.query(User).filter_by(email='admin@galaxy.org').first()

if user:
    from galaxy.security import GalaxyRBACAgent
    import uuid

    api_key = str(uuid.uuid4())
    new_key = APIKeys()
    new_key.user = user
    new_key.key = api_key
    session.add(new_key)
    session.commit()
    print(f"API Key: {api_key}")
else:
    print("User not found")
EOF
```

保存API Key到环境变量：
```bash
export GALAXY_API_KEY="your_api_key_here"
```

### 步骤3: 安装Workflow所需工具

```bash
# 编辑工具安装脚本，添加API Key
cat > install_tools_with_key.py << 'SCRIPT'
#!/usr/bin/env python3
import os
import requests
import time

# Galaxy配置
GALAXY_URL = "http://localhost:8080"
API_KEY = os.environ.get("GALAXY_API_KEY")

if not API_KEY:
    print("❌ 请设置环境变量: export GALAXY_API_KEY='your_key'")
    exit(1)

# 需要安装的工具
TOOLS = [
    {
        "name": "fastqc",
        "owner": "devteam",
        "tool_shed_url": "https://toolshed.g2.bx.psu.edu",
        "changeset_revision": "5ec9f6bceaee",
    },
    {
        "name": "trimmomatic",
        "owner": "pjbriggs",
        "tool_shed_url": "https://toolshed.g2.bx.psu.edu",
        "changeset_revision": "d94aff5ee623",
    },
    {
        "name": "bowtie2",
        "owner": "devteam",
        "tool_shed_url": "https://toolshed.g2.bx.psu.edu",
        "changeset_revision": "a9d4f71dbfb0",
    },
]

headers = {"x-api-key": API_KEY}

print("=" * 60)
print("开始安装Workflow所需工具")
print("=" * 60)

for tool in TOOLS:
    print(f"\n📦 安装工具: {tool['name']} (owner: {tool['owner']})")

        "tool_shed_url": tool["tool_shed_url"],

        print(f"   状态码: {response.status_code}")
        print(f"   响应: {response.text[:200]}")

print("\n" + "=" * 60)
print("⏳ 工具安装需要15-30分钟")
print("💡 可以在Galaxy UI查看安装进度:")
```

### 步骤6: 运行Workflow

**通过Web界面运行**：

1. 访问 http://localhost:8080
2. 顶部菜单 → Workflow
3. 找到 "Real Bioinformatics Pipeline"
4. 点击 ▶️ 运行按钮
5. 选择输入数据（上传的FASTQ文件）
6. 点击 "Run Workflow"

**通过API运行**：

```bash
python3 << 'RUN'
import os
import requests

API_KEY = os.environ.get("GALAXY_API_KEY")
GALAXY_URL = "http://localhost:8080"
headers = {"x-api-key": API_KEY}

# 获取workflow列表
resp = requests.get(f"{GALAXY_URL}/api/workflows", headers=headers)
workflows = resp.json()

# 找到我们的workflow
target_workflow = None
for wf in workflows:
    if "Real Bioinformatics Pipeline" in wf.get("name", ""):
        target_workflow = wf
        break

if not target_workflow:
    print("❌ 未找到workflow")
    exit(1)

print(f"✅ 找到workflow: {target_workflow['name']}")
workflow_id = target_workflow["id"]

# 获取历史记录
resp = requests.get(f"{GALAXY_URL}/api/histories", headers=headers)
history_id = resp.json()[0]["id"]

# 获取历史记录中的数据集
resp = requests.get(
    f"{GALAXY_URL}/api/histories/{history_id}/contents",
    headers=headers
)
datasets = [d for d in resp.json() if d["type"] == "file"]

if not datasets:
    print("❌ 历史记录中没有数据集")
    exit(1)

input_dataset_id = datasets[0]["id"]
print(f"✅ 使用数据集: {datasets[0]['name']} ({input_dataset_id})")

# 运行workflow
run_data = {
    "workflow_id": workflow_id,
    "history_id": history_id,
    "inputs": {
        "0": {"id": input_dataset_id, "src": "hda"}
    }
}

resp = requests.post(
    f"{GALAXY_URL}/api/workflows/{workflow_id}/invocations",
    json=run_data,
    headers=headers
)

if resp.status_code in [200, 201]:
    invocation_id = resp.json()["id"]
    print(f"\n✅ Workflow已启动!")
    print(f"   Invocation ID: {invocation_id}")
    print(f"\n🔍 在Galaxy UI查看进度:")
    print(f"   http://localhost:8080/workflows/invocations")
else:
    print(f"❌ 运行失败: {resp.status_code}")
    print(resp.text)
RUN
```

## ❌ 常见问题排查

### 问题1: 作业一直在队列中

**症状**: 作业状态为 `queued`，长时间不变

**检查**:
```bash
# 检查Galaxy日志
tail -f galaxy_startup.log | grep -i error

# 检查云执行模块是否加载
grep -i "GalaxyCloud" galaxy_startup.log | tail -5
```

**解决**:
- 确认 `lib/galaxy_cloud` 软链接正确
- 重启Galaxy服务

---

### 问题2: AWS凭证过期

**症状**: 作业失败，日志显示 `ExpiredToken` 或 `InvalidAccessKeyId`

**检查**:
```bash
# 测试AWS凭证
aws sts get-caller-identity
```

**解决**:
```bash
# 刷新凭证
cd lib/galaxy/galaxy-cloud-executor/
bash refresh_aws_credentials.sh
```

---

### 问题3: Batch作业失败

**症状**: AWS Batch作业状态为 `FAILED`

**检查**:
```bash
# 获取失败作业ID
JOB_ID=$(aws batch list-jobs \
  --job-queue galaxy-cloud-queue \
  --job-status FAILED \
  --query 'jobSummaryList[0].jobId' \
  --output text)

# 查看失败原因
aws batch describe-jobs --jobs $JOB_ID \
  --query 'jobs[0].statusReason'

# 查看日志
aws batch describe-jobs --jobs $JOB_ID \
  --query 'jobs[0].container.logStreamName' \
  --output text | \
  xargs -I {} aws logs get-log-events \
    --log-group-name /aws/batch/job \
    --log-stream-name {}
```

**常见原因**:
- Docker镜像拉取失败
- 内存或CPU不足
- 工具执行错误

---

### 问题4: S3权限错误

**症状**: 作业失败，日志显示 `Access Denied` 或 `NoSuchBucket`

**检查**:
```bash
# 测试S3访问
aws s3 ls s3://galaxy-cloud-data-1760241377/

# 检查IAM角色
aws iam get-role --role-name BatchJobRole
```

**解决**:
- 确认S3 bucket存在且有权限
- 检查IAM角色策略
