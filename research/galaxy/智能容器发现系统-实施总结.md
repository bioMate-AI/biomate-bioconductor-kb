## 系统架构

```
用户运行工具
    ↓
EnhancedToolRegistry.get_tool_container()
    ↓
┌─────────────────────────────────────┐
│ 第一层：Tool XML Container Declaration │
│ - 从tool.xml提取<container>标签       │
│ - 优先级最高，最准确                  │
│ - 约40%的工具有声明                  │
└─────────────────────────────────────┘
    ↓ (如果未找到)
┌─────────────────────────────────────┐
│ 第二层：BioContainers Registry Query  │
│ - 查询BioContainers API             │
│ - 7000+生物信息学工具                │
│ - 约90%覆盖率                       │
└─────────────────────────────────────┘
    ↓ (如果未找到)
┌─────────────────────────────────────┐
│ 第三层：Auto-build from Conda        │
│ - 提取tool.xml中的conda依赖           │
│ - 生成Dockerfile                    │
│ - 调用AWS CodeBuild构建镜像          │
│ - 推送到AWS ECR                     │
└─────────────────────────────────────┘
    ↓ (如果都失败)
┌─────────────────────────────────────┐
│ 回退：Static Mappings File           │
│ - config/tool_containers.json      │
│ - 手动配置的映射                     │
└─────────────────────────────────────┘
    ↓
返回 ToolContainerInfo
```

## 代码示例

### 第一层：从Tool XML提取

```python
async def _get_from_tool_xml(self, tool_id: str) -> Optional[ToolContainerInfo]:
    """Extract container info from tool's XML declaration."""

    # 获取Galaxy工具对象
    tool = self.galaxy_app.toolbox.get_tool(tool_id)

    # 检查工具的容器声明
    if hasattr(tool, 'containers') and tool.containers:
        container = tool.containers[0]
        container_id = container.identifier

        # 解析容器标识
        # 例如: quay.io/biocontainers/fastqc:0.12.1--hdfd78af_0
        return self._parse_container_identifier(tool_id, container_id)

    return None
```

**支持的Tool XML格式**:
```xml
<!-- 方式1: 直接在requirements中声明 -->
<tool id="fastqc">
    <requirements>
        <container type="docker">
            quay.io/biocontainers/fastqc:0.12.1--hdfd78af_0
        </container>
    </requirements>
</tool>

<!-- 方式2: 在requirement中指定 -->
<tool id="fastqc">
    <requirements>
        <requirement type="package" version="0.11.9">fastqc</requirement>
        <requirement type="container">
            quay.io/biocontainers/fastqc:0.12.1--hdfd78af_0
        </requirement>
    </requirements>
</tool>
```

### 第二层：BioContainers查询

```python
async def _get_from_biocontainers(self, tool_id: str, tool_version: Optional[str] = None):
    """Query BioContainers registry."""

    # 清理工具ID
    # toolshed.g2.bx.psu.edu/repos/devteam/fastqc/fastqc/0.74+galaxy0
    # → fastqc
    clean_id = self._clean_tool_id_for_biocontainers(tool_id)

    # 查询BioContainers API
    biocontainer_info = await self._query_biocontainers_api(clean_id, tool_version)

    if biocontainer_info:
        # 返回标准化的容器信息
        return ToolContainerInfo(
            tool_id=tool_id,
            image=f"quay.io/biocontainers/{biocontainer_info.name}",
            tag=biocontainer_info.version,
            registry="quay.io/biocontainers"
        )

    return None
```

### 第三层：自动构建（框架）

```python
async def _auto_build_from_conda(self, tool_id: str, tool_version: Optional[str] = None):
    """Auto-build container from conda requirements."""

    tool = self.galaxy_app.toolbox.get_tool(tool_id)

    # 提取conda包
    conda_packages = []
    for req in tool.requirements:
        if req.type == 'package':
            conda_packages.append(f"{req.name}=={req.version}")

    if not conda_packages:
        return None

    return None
```

## 性能优化

### 1. 缓存机制

```python
# 内存缓存
self.resolved_cache = {
    'fastqc:0.74+galaxy0': ToolContainerInfo(...),
    'trimmomatic:0.38.1': ToolContainerInfo(...),
}

# 缓存命中
cache_key = f"{tool_id}:{tool_version or 'latest'}"
if cache_key in self.resolved_cache:
    return self.resolved_cache[cache_key]
```

**性能对比**:
| 查找方式 | 首次延迟 | 缓存后延迟 |
|---------|---------|-----------|
| Tool XML | <1ms | <1ms |
| BioContainers | ~500ms | <1ms |
| Auto-build | 5-10分钟 | <1ms |

### 2. 并发查询

```python
# 未来优化：并行查询多个来源
async def get_tool_container_parallel(self, tool_id: str):
    tasks = [
        self._get_from_tool_xml(tool_id),
        self._get_from_biocontainers(tool_id),
    ]

    # 返回第一个成功的结果
    for coro in asyncio.as_completed(tasks):
        result = await coro
        if result:
            return result
```

## 与静态映射对比

| 特性 | 静态映射 (tool_containers.json) | 智能发现系统 |
|------|--------------------------------|-------------|
| 配置工作量 | 每个工具手动配置 | 零配置（自动） |
| 新工具支持 | 需要手动添加映射 | 自动发现 |
| 版本管理 | 手动更新 | 自动匹配 |
| 维护成本 | 高 | 低 |
| 覆盖范围 | 有限（已配置的） | 全部工具 |
| 延迟 | <1ms | <1ms（缓存后） |
| 可靠性 | 最高 | 高 |
| 灵活性 | 低 | 高 |

**建议**:
- 静态映射作为**回退机制**继续保留
- 智能发现作为**主要方式**
- 两者结合，确保100%可用性
