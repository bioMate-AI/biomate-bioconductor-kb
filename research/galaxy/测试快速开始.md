## 🎯 4种测试选项

运行 `bash test_cloud_execution.sh` 后可以选择：

### 1️⃣ 快速测试（5分钟）⭐推荐新手
- 使用简单的内置工具（cat/concatenate）
- 创建测试文件，上传，运行工具
- 验证Job Destination显示云端
- **适合**: 快速验证配置是否正确

### 2️⃣ 完整测试（30分钟+）
- 使用真实的生物信息学workflow
- 6个步骤：FastQC → Trimmomatic → FastQC → Bowtie2 → BAM Stats
- 需要先安装工具（首次约20-30分钟）
- **适合**: 验证真实场景下的云执行

### 3️⃣ 只验证配置
- 检查job_conf_cloud.yml配置
- 不运行任何workflow
- 显示当前配置状态
- **适合**: 确认配置是否正确

### 4️⃣ 查看AWS资源状态
- 显示Batch Queue状态
- 显示最近的作业（RUNNING/SUCCEEDED/FAILED）
- 显示S3中的数据
- **适合**: 监控云端资源使用情况

## 📋 完整测试流程（手动）

如果不使用脚本，可以按以下步骤手动测试：

### 步骤1: 前置检查
```bash
# 检查AWS凭证
aws sts get-caller-identity

# 检查Batch Queue
aws batch describe-job-queues --job-queues galaxy-cloud-queue

# 检查S3
aws s3 ls s3://galaxy-cloud-data-1760241377/

# 检查Galaxy配置
grep "default: cloud_small" config/job_conf_cloud.yml

# 检查Galaxy服务
ps aux | grep gunicorn
```

### 步骤2: 访问Galaxy
```bash
# 打开浏览器
open http://localhost:8080

# 或使用curl测试
curl -s http://localhost:8080/api/version
```

### 步骤3: 获取API Key
1. 登录Galaxy（或注册新账号）
2. 右上角用户名 → Preferences
3. 左侧菜单 → Manage API Key
4. 点击 "Create a new key"
5. 复制API Key

### 步骤4: 快速测试
```bash
# 创建测试文件
echo "test data for cloud execution" > test_cloud.txt

# 在Galaxy UI:
# 1. Upload Data → 上传 test_cloud.txt
# 2. 搜索 "cat" 工具
# 3. 运行工具
# 4. 查看Job Destination
```

### 步骤5: 验证云执行
```bash
# 查看AWS Batch作业
aws batch list-jobs --job-queue galaxy-cloud-queue --job-status RUNNING

# 查看S3数据
aws s3 ls s3://galaxy-cloud-data-1760241377/jobs/ --recursive
```

## 🔧 常见问题

### Q1: Galaxy服务未运行
```bash
# 启动Galaxy
nohup bash start_galaxy_cloud.sh > galaxy_startup.log 2>&1 &

# 查看日志
tail -f galaxy_startup.log
```

### Q2: AWS凭证过期
```bash
# 刷新凭证
cd lib/galaxy/galaxy-cloud-executor/
bash refresh_aws_credentials.sh
```

### Q3: Job Destination显示local而不是cloud
```bash
# 检查配置
cat config/job_conf_cloud.yml

# 确认默认环境是cloud_small
grep "default:" config/job_conf_cloud.yml
# 应该输出: default: cloud_small

# 如果不是，修改配置后重启Galaxy
```

### Q4: 工具安装失败
```bash
# 在Galaxy UI查看安装状态
# 访问: Admin → Manage installed tools

# 或通过API查看
curl -s http://localhost:8080/api/tool_shed_repositories \
  -H "x-api-key: YOUR_API_KEY"
```
