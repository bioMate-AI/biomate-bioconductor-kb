# Experimental data and dry–wet replay assessment

## What the current data supports

The 4,157-complex PepBench training split is sufficient for an initial structural baseline and runtime qualification. It does not establish that a new all-atom generator is competitive, nor does it provide matched potency, permeability, stability, selectivity and synthesis outcomes for each structure. The initial PepGLAD model supports canonical peptide chemistry; the modified cyclic peptides in the permeability corpus require a separate chemical representation and endpoint model.

The existing S3 CycPeptMPDB snapshot contains 8,466 rows, 7,991 distinct raw SMILES and 7,298 numeric PAMPA values before identity and censoring cleanup. These are snapshot counts, not the counts in the original database publication. Repeated compounds, related chemical series and dominant source publications reduce the effective independent sample size. Some entries use numerical placeholders for detection limits or poor solubility; these must not silently become precise regression labels.

## Prioritized experimental resources

| Resource | What is experimental | Use | Main limitation |
|---|---|---|---|
| [CycPeptMPDB](https://doi.org/10.1021/acs.jcim.2c01573) | Curated membrane-permeability assays | First retrospective batch-selection replay; already in S3 | Keep PAMPA, Caco-2, MDCK and RRCK separate; source conditions, repeats and censoring matter |
| [MacroConf](https://pubs.rsc.org/en/content/articlehtml/2023/dd/d3dd00053b) | Solution NMR evidence for 68 cyclic peptides/macrocycles | Compare predicted conformational ensembles with experimental distance constraints | Small conformational benchmark; not potency or synthesis-success labels |
| [CycPeptMPDB-4D](https://github.com/Gobliu/CycPeptMPDB-4D) | Original CycPeptMPDB PAMPA measurements; MD conformations are computational | Evaluate whether water/hexane ensembles improve permeability predictions | 5,160 simulated peptides do not represent 5,160 additional independent wet-lab measurements |
| [PeptideCLM-2 datasets](https://pmc.ncbi.nlm.nih.gov/articles/PMC12803269/) | Downstream datasets include blood stability and other experimental peptide endpoints | Follow-up stability and developability predictors | Audit each original dataset and its label provenance; pretraining molecules are not experimental outcome labels |
| [BindingDB](https://www.bindingdb.org/) | Measured ligand–target affinity, with source documents and dates | Target-specific peptide binding dataset | Entire database is mostly other ligand types; do not count all records as peptide data or pool Kd, Ki and IC50 indiscriminately |

The [published iterative peptide-design benchmark](https://pmc.ncbi.nlm.nih.gov/articles/PMC7842147/) supports retrospective active-learning evaluation, but some negative labels were generated by scrambling sequences or by assumed nonoverlap. Those are not verified inactive wet-lab measurements. Its tested active-learning methods did not consistently beat random selection, so random selection is a required control, not an assumed inferior method.

## Implemented first replay

`replay_permeability.py` reuses the existing local/S3 snapshot. Three source groups are prespecified: 2020_Townsend, 2021_Kelly and 2024_Faris. It retains finite PAMPA values, excludes rows carrying either detection-limit annotation and numerical values at/below the apparent -10 floor, canonicalizes chemical identity with stereochemistry, and collapses repeated identities within each source using median labels. This conservative filtering itself introduces selection bias and is reported.

Each source is a separate finite candidate library. A molecule-disjoint 20% test set remains outside acquisition and training; the remaining library starts with 20 revealed measurements. Five rounds select ten additional candidates per round. Each selected candidate's existing experimental label is revealed to the learner, which refits from scratch. Random selection and forest mean-plus-one-standard-deviation selection use the same initial pool for three fixed seeds. The tree disagreement is an acquisition heuristic, not calibrated uncertainty. Fingerprints include chirality. No pretrained permeability model is used because its prior exposure to these labels could contaminate the replay.

Report best measured permeability, recovered top-decile candidates, and untouched-test MAE versus number of revealed measurements. The oracle's top-decile threshold is used only by evaluation; acquisition never receives hidden outcome values. All selected IDs are retained in the result history. The small run is an implementation/pilot comparison, not an optimized scientific benchmark. Within-publication grouping does not guarantee uniform assay protocols or new-scaffold performance.

## What this can and cannot simulate

This replays the decision loop: select candidates → reveal real historical measurements → retrain → select the next batch. It can compare experiment-selection policies at equal label budgets. It cannot reveal the true outcome of a newly generated peptide absent from the measured library. Scoring such a peptide with a learned predictor creates a surrogate simulation, not new experimental evidence.

A physics layer can be checked independently against MacroConf NMR constraints and, subsequently, matched permeability measurements. MD and docking are predictions; neither substitutes for measured potency, stability, cytotoxicity or synthesis success.

A prospective dry–wet program additionally needs a chosen therapeutic target and peptide topology, laboratory assay definitions and conditions, permitted partner data, feasible synthesis budgets, controls, replicates and failed experiments. These are not currently established for this project. Public-data work can proceed without inventing them.

Guided selection recovered more top-decile library members in this pilot. It did not consistently improve test MAE or the best individual measurement. There is no prospective benefit claim; more seeds, source-protocol checks and genuinely new-family evaluations are needed. ## Additional data collected

The pinned MacroConf data bundle (331 files including README/license; 3,560,410 uncompressed bytes) and PeptideCLM-2 PepMSND stability bundle (25 files; 12,598,365 uncompressed bytes) are now archived in S3. All downloaded files matched their Git blob hashes, and each S3 archive passed a full SHA256 readback check. The acquisition manifests contain exact paths and revisions.

The actual MacroConf CSV has 69 solvent-specific rows and 68 distinct nonempty raw SMILES. The collected PepMSND derivative has 640 rows, 605 distinct raw SMILES, and binary labels (367 class 0, 273 class 1); these are not 640 raw half-life measurements. The [original PepMSND paper](https://pubs.rsc.org/en/content/articlehtml/2025/dd/d5dd00118h) describes 635 samples, so the derivative/source count difference requires reconciliation before modeling. Species and experimental-environment encodings must also be resolved.

The PepMSND count difference is explained at the ID level: 635 unique IDs occur in 640 rows. Four IDs repeat across supplied folds, and 29 raw SMILES occur in multiple folds. These supplied folds must not be treated as molecule-disjoint. The audit is in `results/pepmsnd_fold_audit.json`.

## Stability folds rebuilt (leak-free)

`rebuild_stability_folds.py` canonicalizes every SMILES (RDKit, isomeric; all 640 parse), collapses the rows to **605 unique structures**, and rebuilds cross-validation folds so no identical molecule — and no source ID — crosses folds. Tests are in `tests/test_rebuild_stability_folds.py` (4 passing; full suite 16 passing).

Two findings matter for any generalization claim:

1. **The supplied clusters are unusable as leak-free CV folds.** Merging clusters that share an identical structure (union-find over the 29 cross-cluster structures) collapses **all 10 original clusters into a single component** — no held-out fold remains. The supplied clustering is too interlinked by shared molecules to salvage by merging.
2. **Three structures carry conflicting binary labels** (the same canonical molecule appears with both label 0 and label 1). These are flagged in the audit, not silently resolved; they need source reconciliation before modeling.

Because of (1), the rebuild assigns fresh **label-stratified 10-fold** splits directly over the 605 unique structures: fold sizes 60–61, each ~34:26/27 (matching the 340:265 overall balance), with **0 structures and 0 IDs crossing folds**. This removes the duplication/leakage artifact; it does **not** establish scaffold-level separation between folds — a scaffold split remains future work. Rebuilt table: `data/processed/pepmsnd_stability_folds.csv`; audit: `results/pepmsnd_fold_rebuild.json`.
