# Integrin subtype selectivity of RGD-type ligands: a large, document-controlled ChEMBL benchmark with an independent external test

STATUS: Section A (data, licence, pre-registration) was written and committed BEFORE any model was fitted (see git log for the commit that adds this file with only sections A-B). Sections C onward (deviations, results, verdict) are appended after the fits.

## A. Data and licence

* Source: ChEMBL REST API (https://www.ebi.ac.uk/chembl/api/data/), queried 2026-10-25 (cache of raw JSON kept outside the repo; not committed). ChEMBL is licensed CC BY-SA 3.0 (EMBL-EBI); the derived tables committed here (`data/long_all.csv.gz`, `data/pairs_all.csv.gz`, activity-count json) are derivative works and are therefore shared under the SAME licence (CC BY-SA 3.0). No raw dumps are committed.
* Targets used (human, ChEMBL target type PROTEIN COMPLEX; chosen because they are the RGD-binding heterodimers, found via `/target/search`): avb3 CHEMBL1907598, avb5 CHEMBL2096675, avb6 CHEMBL2111416, avb8 CHEMBL3430892, avb1 CHEMBL2111407, a5b1 CHEMBL2095226, aIIbb3 CHEMBL2093869, a8b1 CHEMBL6066586. Other RGD-type integrins (avb? with no data, a3b1, a4b1, ...) were searched and are not RGD-selectivity relevant or have no/very few records. Mixed/ambiguous ChEMBL targets (avb3/avb5 mixed CHEMBL4106150, a5b1+avb3 group CHEMBL2111425, avb3+aIIbb3 selectivity group CHEMBL2111443, aV/a5 CHEMBL3430893, a5/b6 CHEMBL6066570, a5/b6/b8, a5/b8, and single-chain alpha-V, beta-1/3/5/6, alpha-IIb, alpha-5) were counted but NOT used as such. RESCUE RULE (documented deviation from "use ChEMBL target ids"): records on those targets whose assay description names exactly ONE of the eight heterodimers in its first 300 characters are re-assigned to that heterodimer and flagged `remapped` (this is mostly CHEMBL6066570, "alpha-5/beta-6", whose assays are actually alpha-V/beta-6 solid-phase assays - an obvious target annotation error). Sensitivity without remapped rows is reported.
* Activities: standard_type in {IC50, Ki, Kd}; standard_units == nM (other units dropped; counted); standard_value > 0; relation in {=, <, >, <=, >=} (records with NO relation are dropped; counted). pAct = 9 - log10(nM). IC50, Ki, Kd are pooled as "pAct" (stated judgment call; Ki/Kd are only 7 percent of records). Assay type B (binding) only for the primary dataset; type F (functional/cell adhesion, aggregation) is counted but excluded because functional readouts mix integrin binding with cell-level effects; type A excluded. data_validity_comment must be empty and potential_duplicate = 0. Structures: largest fragment, neutralised, InChIKey (RDKit); the FLAT key (first 14 characters, connectivity only) identifies a compound for every leakage rule (conservative: stereoisomers count as the same compound).
* Aggregation: one value per (document, compound, target) = median over records within the preferred assay class (solid_phase > homogeneous > spr > other_binding > cell, by regex on the assay description; heuristic). Equal-relation values are used if any exist; otherwise the record is flagged censored (`gt`: IC50 > x, i.e. pAct is an upper bound; `lt`: pAct lower bound). Main analysis uses uncensored ('=') values only.
* Document-controlled PAIRS: for every document and compound with uncensored values on >= 2 targets, each target pair (A,B) gives delta = pAct(A) - pAct(B). Primary pairs require both values to come from the same assay class (heuristic); pairs from different assay classes are kept in `data/pairs_all.csv.gz` (`same_class` flag) as a sensitivity set.
* Data funnel (counts per target at every filter): `data/funnel.json`, copied into section D after the run.

## B. PRE-REGISTRATION (fixed before fitting)

B1. Units. Long table `U` = uncensored (document d, compound c, target t, pAct) rows. Pair table `Pp` = primary same-class pairs. Evaluation set `E` = rows of `U` that take part in at least one pair of `Pp` (document-controlled; 77 documents). Training data for any fold = ALL of `U` outside the held-out unit (including single-integrin documents), after the split-specific exclusions below.

B2. Tasks and primary metrics.
* T1 potency per integrin: predict pAct(c,t) for rows of `E`. Primary: pooled RMSE. Secondary: Spearman, per-target RMSE, document-macro RMSE (mean over documents of per-document RMSE).
* T2 selectivity: predict delta(c,A,B) for pairs of `Pp`. Primary: pooled RMSE over all pairs; secondary: Spearman; sign accuracy on pairs with |delta| >= 0.3; and the avb6 subset (A=avb6 vs B in avb3, avb5, avb8, a5b1) reported separately; per-pair results where >= 10 test documents.
* T3 selectivity classification: for each pair BOTH orientations (A,B),(B,A) are used; label 1 if delta_AB >= 1 (>= 10-fold selective for A), else 0. Score = predicted delta. Primary: pooled AUROC. Secondary: mean within-pair AUROC over pairs with both classes present in >= 10 documents.

B3. Splits (all with no shared compound FLAT InChIKey between train and test):
* S0 random: 5-fold over (document,compound) units. INFLATED, reference only (the same compound/series appears on both sides).
* S1 leave-cluster-out: Butina clustering (Tanimoto >= 0.6 on ECFP4 bit vectors, 2048 bits) of all compounds in `U`; test = 10 folds of whole clusters (clusters assigned to folds at random, seed fixed); in addition every TRAINING compound with Tanimoto >= 0.6 to ANY test compound of the fold is removed (so no cluster or near-neighbour leakage).
* S2 leave-one-document-out (LODO) over the documents of `E`: test = all `E` rows of the held-out document; training = all other documents minus every compound that has the same flat InChIKey as any compound of the held-out document. S2b (sensitivity) additionally removes training compounds with Tanimoto >= 0.6 to any test compound.
* S3 EXTERNAL: training = all of `U` EXCEPT (i) ChEMBL documents corresponding to the Kapp 2017, Quigley 2023 and Tomassi 2021 panels (Kapp 2017 is not in ChEMBL; Tomassi 2021 = CHEMBL5214901; Quigley 2023 searched by DOI/title: if absent from ChEMBL, stated), and (ii) every compound with the same flat InChIKey as ANY of the 34 Kapp ligands that have a structure. Test = the previous agent's `matrix.csv` Kapp 2017 cells (uncensored cells for the primary metrics) for the ligands for which a structure could be obtained unambiguously (`data/external_ligands.csv`: 20 of 34; 7 tier A registry-retrieved, 13 tier B built by rule; 14 unresolved and listed in `data/external_set_summary.json`). The 5 model integrins plus aIIbb3 are scored when both ends exist. S3b (sensitivity) additionally removes training compounds with Tanimoto >= 0.6 to any resolved Kapp ligand.

B4. Nulls (must be beaten; identical protocol):
* T1: N1 per-target training mean; N2 per-target training mean after document-offset removal (the same quantity the models see); N3 per-document-per-target mean (only defined in S0/S1, where the document is seen; NOT available in S2/S3); N4 compound promiscuity = mean pAct of the test compound's OTHER targets in the same document (an ORACLE-information null: it uses test-side data that models do not get; falls back to N1 if the compound has no other uncensored target) and N4b = promiscuity + (target mean - mean of the other targets' means); N5 1-nearest-neighbour Tanimoto (nearest training compound with that target measured, copy its pAct).
* T2/T3: Z delta = 0 (T3 constant); N1 training mean delta for that target pair (T3: pair prior); N5 1-NN Tanimoto (nearest training compound with that pair measured, copy its delta); the promiscuity null reduces to delta = 0 and is not listed separately. T3 score for Z is constant (AUROC 0.5).
* STRONGEST null = the null with the best primary metric on that task/split (chosen ON the test set: deliberately conservative against the model).

B5. Models (CPU only). Hyper-parameters tuned ONLY inside training folds by inner grouped CV over training documents (5 folds) where a grid is stated; all others fixed a priori:
* M1 ridge on ECFP4 count fingerprint (radius 2, 2048, log1p), one ridge per target (alpha in {0.3, 1, 3, 10, 30}, nested), response = pAct minus the estimated document offset (see below).
* M2 Tanimoto (min-max) kernel ridge per target (lambda in {0.03, 0.1, 0.3, 1}, nested), same response.
* M3 gradient boosting (sklearn HistGradientBoostingRegressor, max_iter 200, lr 0.05, max_leaf_nodes 15, l2 1.0, FIXED, not tuned) on RDKit 2D descriptors + ECFP4 counts (1024) + target one-hot, trained jointly across targets, same response.
* M4 multitask MLP (torch, CPU): shared 2048 -> 512 -> 128 encoder, 8 per-target heads, loss on observed (compound,target) rows only, 60 epochs Adam lr 1e-3, weight decay 1e-4, dropout 0.2, FIXED (not tuned), same response.
* M5 pairwise ridge predicting delta directly from the fingerprint: one ridge per unordered target pair with >= 25 training pairs (alpha nested as M1), otherwise the pair's training mean delta.
* M6 pairwise gradient boosting: HistGB (settings as M3) on descriptors + ECFP counts + one-hot(A) + one-hot(B), trained on both orientations of every training pair, predicts delta.
* Difference models for T2/T3: delta_hat = f_A - f_B from M1-M4.
* Document offset ("document random effect"): u_d = n_d/(n_d+5) * mean over d's training rows of (pAct - target mean); models are trained on pAct - u_d; test predictions use u = 0 (the held-out document's offset is unknowable; for T1 this is a real cost, for T2/T3 it cancels).
* No message-passing network (decision: no evidence on this CPU budget that it would change the verdict; stated, not hidden).

B6. Uncertainty. 95 percent percentile bootstrap, 2000 resamples, CLUSTER bootstrap: whole documents are resampled for S2/S2b (S0: compound-cluster groups; S1: Butina clusters; S3/S3b: Kapp LIGANDS). Differences (model minus null) are paired on the same resample.

B7. CLAIM RULE. For each task (T1, T2, T3) the "best model" is the model with the best primary metric under S2 (selected on S2 - this selection is mildly optimistic for S2 and is disclosed; it is NOT re-selected for S3). A task is POSITIVE only if that model beats the STRONGEST null with the 95 percent CI of the difference excluding zero in the favourable direction under BOTH S2 and S3. NEGATIVE if the CI of the difference excludes zero in the UNfavourable direction under S2 or S3. Otherwise NULL (underpowered or no effect). If a task is positive under S0/S1 only: "within-series interpolation". S2b/S3b/S0/per-pair/avb6 subset results are descriptive and cannot make a task positive. With 3 tasks and 2 splits no multiplicity correction is applied to the claim rule; this is acknowledged and the rule is stringent (both splits).
B8. avb6. Whether any avb6-specific claim is possible is decided by document counts (stated plainly in the results), not by the model: an avb6 claim requires the avb6-pair subset to satisfy B7 on its own.
