## Core Claim

BioMate is the first platform to implement machine-readable, evidence-graded QC governance for multi-omics workflows, enabling reproducible analysis at the protocol and citation level rather than the parameter level.

The governance stack:
```
Layer 0: Red Lines          — 4 metrics, hardcoded, never overridable
Layer 1: GOLD thresholds    — community gold standard, no user override
Layer 2: SILVER/BRONZE      — literature-supported, user override with audit trail
Layer 3: Named profiles     — 20 curated protocol-aware sets (FFPE RNA, cardiac scRNA, soil meta, etc.)
Layer 4: Metadata-inferred  — system suggests profile from sample metadata (Phase 3 / Paper 2)
```

**One-sentence pitch:** "MultiQC tells you the run failed after it finished; BioMate stops the run when it can still be saved, shows you exactly what parameter to change, and knows that 38% mitochondrial reads in cardiac tissue is biology, not a problem."

## Benchmark Experiment (Figure 1)

**Design:** Run BioMate + MultiQC on the same 5 public datasets. Compute 2×2 confusion matrix per domain.

| Dataset | Accession | Expected outcome |
|---|---|---|
| GM12878 RNA-seq (ENCODE) | ENCSR000AED | Both tools: pass (true negative baseline) |
| FFPE nasopharyngeal RNA-seq | GSE68086 | MultiQC: false positive; BioMate rnaseq_ffpe profile: pass |
| Cardiac scRNA-seq (Nomura 2018) | GSE121893 | MultiQC: false positive; BioMate scrna_cardiac profile: pass |
| Topsoil metagenomics (Bahram 2018) | SRP047083 | MultiQC: false positive; BioMate metagenomics_soil profile: pass |
| K562 ATAC-seq, ENCODE-flagged | ENCSR356LIU | Both tools: fail (true positive — BioMate independently finds ENCODE-flagged failure) |

**Headline:** BioMate independently identified the same QC failures that ENCODE's internal QC team flagged, while eliminating false positives on FFPE, cardiac, and environmental samples.

**Compute cost:** ~$500 on AWS Batch.
