# Abstract — BioMate (flagship systems paper)

**Working title:** An Orchestrated Biological Agent System with Evidence-Graded Quality-Control Governance, Evaluated Against Frontier Baselines on Public Bioinformatics Benchmarks

Autonomous agents are increasingly used to drive end-to-end biomedical computation, but two requirements have been under-served: governing the hundreds of threshold-dependent quality-control (QC) decisions an agent makes per run with an auditable, evidence-graded rationale, and evaluating agent competence honestly against the published frontier rather than on a single inflated score. We present BioMate, a biological agent system that interprets a natural-language request, routes it across 2,455 Nextflow workflows spanning 34 domains, extracts parameters, recovers missing prerequisites, executes the workflow on AWS Batch, and governs every QC decision through a single architecture in which each of 57 gates across 25 domains is annotated GOLD (citation-anchored consensus), SILVER (method-specific convention), or BRONZE (operational heuristic), with a portable JSONL audit trail aligned to 21 CFR Part 11. On the open-answer BixBench agentic benchmark — where the agent must *execute* the analysis rather than select a multiple-choice option — BioMate's execution path scores ≈48% (n = 50), exceeding the published open-answer state of the art (K-Dense Analyst 29.2%) and the latest frontier models (GPT-5 22.9%, Gemini 2.5 Pro 18.3%); we report this as SOTA-competitive pending a full-benchmark confirmation run, because our measurement is on the 50-question Verified subset rather than the full 296-question set. On BiomniEval1, BioMate scores 71.3% (n = 223), above the fine-tuned Biomni-R0-32B-Preview baseline (≈65%). Governance is deployed at scale: a 659-workflow Bioconductor QC harness (658/658 dynamic checks passing) and 20/20 protocol-threshold gates verified end-to-end on live audit-logged runs. Protocol-aware profiles eliminated 100% of false-rejections of biology-valid marginal samples under default thresholds (HTS, LNP, cryo-EM), and the orchestrated pipeline reconstructs *E. coli* β-galactosidase (EMPIAR-10028) to FSC 0.143 = 1.78 Å as a methods validation. Autonomous closed-loop parameter remediation is implemented but advisory by default, pending validation of an efficient parameter search. BioMate shows that evidence-graded governance and honest, frontier-referenced evaluation can be unified in one regulatory-traceable agent.
