## Scoring Rubric

- **Accuracy (0–10 per task):** Weighted checklist against published gold standards.
  Points awarded for: correct #1 pick, correct #2, correct disqualification/failure flags, correct mechanism reasoning, correct publication citation.
- **Stability (% runs with modal score):** 5 runs per model per task. 100% = fully deterministic; <80% = stochastic.
- **Structure compliance (0–5):** Fully parseable CSV + all required fields present = 5; partial = 1–4; prose-only = 0.
  BioMate structure = always 5 (workflow-enforced schema); LLM structure depends on instruction-following.

## Note on Memorization

All five gold standards are from published literature (Musunuru 2021 Nature, HARMONi-2 trial, Capstan CPTX2309 IND filing, FDA approval records).
LLMs with web-search access or post-2021 training data may have seen these answers.
Accuracy scores therefore reflect **knowledge retrieval under structured-output constraint**, not novel reasoning.
The experiment's primary differentiator is **output structure compliance** and **cross-run stability** — where BioMate's workflow execution provides a structural advantage that is not replicable by prompt engineering alone.
