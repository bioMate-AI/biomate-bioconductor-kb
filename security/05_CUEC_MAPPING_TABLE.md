# Complementary User Entity Controls (CUEC) — Mapping Table

> **Required submission artifact** (per Sentry's guide): submit CUECs as a **mapping table, not a list**. Four columns: the CUEC · the commitment/system requirement it supports · BioMate's complementary control · the applicable TSC. **If a row can't be filled in, it is not a CUEC — delete it.**
