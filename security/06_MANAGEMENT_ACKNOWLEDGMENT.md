## Management's self-review checklist (all must be true before signing)
- [ ] All nine description criteria (DC1–DC9) are addressed, or non-applicability is explained.
- [ ] No bracketed placeholders, "TBD," or template instructions remain anywhere in the document.
- [ ] Every technology named is one BioMate actually runs — and everything relied on is named.
- [ ] The system boundary states what is out of scope, and why.
- [ ] Principal service commitments trace to a real contract, SLA, DPA, or published policy.
- [ ] Every control described matches practice: owner, frequency, system, and evidence produced.
- [ ] Subservice organizations are identified, with the method elected and CSOCs stated for carve-outs.
- [ ] CUECs are submitted as a mapping table to commitments, complementary controls, and criteria.
- [ ] Reportable incidents in the period are disclosed — or it is affirmatively stated there were none.
- [ ] Significant changes are disclosed with dates and before/after detail — or it is stated there were none.
- [ ] A named member of management has read the description end to end.
- [ ] No sentence in the document would be equally true of a competitor.
