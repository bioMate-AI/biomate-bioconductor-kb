# BioMate AI — Information Security Policy Set (Index)

Adoptable policy drafts for the SOC 2 Type 2 (Security) examination and the HIPAA track. Each is written to reflect **how BioMate actually operates** (grounded in repo/config recon), with `[CONFIRM]` where an operational fact or an owner must be verified before adoption.

**Adoption steps (per policy):** (1) resolve `[CONFIRM]` fields; (2) assign an owner and approver; (3) approve + publish in Vanta; (4) collect employee acknowledgment; (5) set annual review + version history.
