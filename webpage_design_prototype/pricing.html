FAQ

Common questions

Do I need a credit card to start the free trial?
No. The Pilot plan is free forever and requires no credit card. The 14-day Professional trial also requires no card — we'll ask only when you choose to upgrade.
What happens to my data when a run completes?
Pilot outputs are stored for 7 days, Professional for 90 days. Enterprise has configurable retention. All data is encrypted at rest and in transit, and you can download outputs at any time.
Can I use my own AWS account for compute?
Enterprise deployments run in your own VPC and AWS account — you control the infrastructure and costs. Professional uses BioMate's managed AWS Batch environment.
How does pricing work for GPU-intensive workflows like cryo-EM or MD?
GPU workflows (cryo-EM SPA, Molecular Dynamics) consume more compute. Professional includes GPU access; heavy usage is metered. Enterprise customers negotiate flat-rate GPU pools.
Is BioMate suitable for clinical / regulated environments?
Enterprise includes a compliance package with HIPAA-ready architecture, audit logs, and documentation for regulatory submissions. We can also support GxP validation projects.
Can we add custom workflows not in the standard library?
Yes. Enterprise includes custom workflow development. Professional users can also bring Nextflow scripts — BioMate wraps them in the same AI-assisted UI and execution environment.

Need a private deployment?

BioMate Enterprise runs entirely inside your institution's AWS account — no data ever leaves your environment. HIPAA-ready, SOC2-aligned, and compliant with data sovereignty requirements.
